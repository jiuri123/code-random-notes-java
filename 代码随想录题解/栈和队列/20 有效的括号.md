# 20.有效的括号

[https://leetcode.cn/problems/valid-parentheses/description/](https://leetcode.cn/problems/valid-parentheses/description/)

本题给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。思路在于设置一个栈，遇到左括号就入栈，遇到右括号就开始判断或出栈。代码如下：

```java
class Solution {
    public boolean isValid(String s) {
        Stack<Character> myStack = new Stack<>();
        Scanner sc = new Scanner(System.in);
        for(int i = 0; i < s.length(); i++){
            char c = s.charAt(i);
            if(c == '(' || c == '{' || c == '['){
                myStack.push(c);
            }else{
                if(myStack.isEmpty()){
                    return false;
                }else if(c == ')' && myStack.peek() != '(' ||
                c == '}' && myStack.peek() != '{' ||
                c == ']' && myStack.peek() != '['){
                    return false;
                }else{
                    myStack.pop();
                }
            }
        }
        if(!myStack.isEmpty()){
            return false;
        }else{
            return true;
        }
    }
}
```

注意：最后返回true的时候记得看看栈里面是否还有括号，因为有可能出现字符串中只含左括号的情况。

## 方法二

```java
class Solution {
    public boolean isValid(String s) {
        // 如果字符串长度是奇数，一定不合法
        if (s.length() % 2 != 0) return false;

        Deque<Character> stack = new ArrayDeque<>();
        
        for (char c : s.toCharArray()) {
            // 技巧：遇到左括号，把期待的右括号入栈
            if (c == '(') {
                stack.push(')');
            } else if (c == '[') {
                stack.push(']');
            } else if (c == '{') {
                stack.push('}');
            } 
            // 如果是右括号，检查栈是否为空（代表没有左括号匹配）
            // 或者栈顶元素是否与当前右括号一致（同时弹出栈顶元素）
            else if (stack.isEmpty() || stack.pop() != c) {
                return false;
            }
        }
        
        // 最后如果栈为空，说明所有括号都正确匹配并抵消了
        return stack.isEmpty();
    }
}
```
