# 225. 用队列实现栈

![image.png](225%20%E7%94%A8%E9%98%9F%E5%88%97%E5%AE%9E%E7%8E%B0%E6%A0%88/image.png)

https://leetcode.cn/problems/implement-stack-using-queues/description/

本题用两个队列实现一个栈的操作。

## 方法一

我的思路是先将一个非空队列中除最后一个元素外的元素加入到另一个队列中，然后继续出队列的最后一个元素就是栈顶的元素。其他几个操作也是如出一辙。代码如下：

```java
class MyStack {
    Queue<Integer> myQueue1;
    Queue<Integer> myQueue2;

    public MyStack() {
        myQueue1 = new LinkedList<>();
        myQueue2 = new LinkedList<>();
    }
    
    public void push(int x) {
        if(!myQueue1.isEmpty()){
            myQueue1.offer(x);
        }
        else{
            myQueue2.offer(x);
        }
    }
    
    public int pop() {
        if(!myQueue1.isEmpty()){
            while(myQueue1.size() != 1){
                myQueue2.offer(myQueue1.poll());
            }
            return myQueue1.poll();
        }else{
            while(myQueue2.size() != 1){
                myQueue1.offer(myQueue2.poll());
            }
            return myQueue2.poll();
        }
    }
    
    public int top() {
        if(!myQueue1.isEmpty()){
            while(myQueue1.size() != 1){
                myQueue2.offer(myQueue1.poll());
            }
            int topNum1 = myQueue1.peek();
            myQueue1.poll();
            myQueue2.offer(topNum1);
            return topNum1;
        }else{
            while(myQueue2.size() != 1){
                myQueue1.offer(myQueue2.poll());
            }
            int topNum2 = myQueue2.peek();
            myQueue2.poll();
            myQueue1.offer(topNum2);
            return topNum2;
        }
    }
    
    public boolean empty() {
        if(myQueue1.isEmpty() && myQueue2.isEmpty()){
            return true;
        }else{
            return false;
        }
    }
}
```

## 方法二（推荐）

当然也可以像代码随想录中提供的那几种思路，主要的思想就是将其中一个队列作为主队列，另一个队列作为辅助存储空间的队列，这样就可以省去很多的重复代码。举例代码如下：

```java
class MyStack {

    Queue<Integer> queue1; // 和栈中保持一样元素的队列
    Queue<Integer> queue2; // 辅助队列

    /** Initialize your data structure here. */
    public MyStack() {
        queue1 = new LinkedList<>();
        queue2 = new LinkedList<>();
    }

    /** Push element x onto stack. */
    public void push(int x) {
        queue2.offer(x); // 先放在辅助队列中
        while (!queue1.isEmpty()){
            queue2.offer(queue1.poll());
        }
        Queue<Integer> queueTemp;
        queueTemp = queue1;
        queue1 = queue2;
        queue2 = queueTemp; // 最后交换queue1和queue2，将元素都放到queue1中
    }

    /** Removes the element on top of the stack and returns that element. */
    public int pop() {
        return queue1.poll(); // 因为queue1中的元素和栈中的保持一致，所以这个和下面两个的操作只看queue1即可
    }

    /** Get the top element. */
    public int top() {
        return queue1.peek();
    }

    /** Returns whether the stack is empty. */
    public boolean empty() {
        return queue1.isEmpty();
    }
}

```

也可以在加入元素时先将q1中的元素依次出栈压入q2，然后将新加入的元素压入q1，再将q2中的元素依次出栈压入q1。本质上都是将新加入的元素移动到主队列的最前面，使得出队的顺序就是出栈的顺序。

## 方法三

也可以优化到只需要一个队列就可以实现：

```java
class MyStack {

    Queue<Integer> queue;

    public MyStack() {
        queue = new LinkedList<>();
    }

    //每 offer 一个数（A）进来，都重新排列，把这个数（A）放到队列的队首
    public void push(int x) {
        queue.offer(x);
        int size = queue.size();
        //移动除了 A 的其它数
        while (size-- > 1)
            queue.offer(queue.poll());
    }

    public int pop() {
        return queue.poll();
    }

    public int top() {
        return queue.peek();
    }

    public boolean empty() {
        return queue.isEmpty();
    }
}
```
