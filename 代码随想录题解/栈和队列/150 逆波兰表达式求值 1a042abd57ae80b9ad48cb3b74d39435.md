# 150. 逆波兰表达式求值

[https://leetcode.cn/problems/evaluate-reverse-polish-notation/description/](https://leetcode.cn/problems/evaluate-reverse-polish-notation/description/)

本题较为简单，思路是遇到数字就入栈，遇到运算符就弹出两个数进行计算。代码如下：

```
class Solution {
    public int evalRPN(String[] tokens) {
        Stack<Integer> numStack = new Stack<>();
        for(int i = 0; i < tokens.length; i++){
            String str = tokens[i];
            if(str.equals("+")){
                int leftNum = numStack.pop();
                int rightNum = numStack.pop();
                numStack.push(rightNum + leftNum);
            }else if(str.equals("-")){
                int leftNum = numStack.pop();
                int rightNum = numStack.pop();
                numStack.push(rightNum - leftNum);
            }else if(str.equals("*")){
                int leftNum = numStack.pop();
                int rightNum = numStack.pop();
                numStack.push(rightNum * leftNum);
            }else if(str.equals("/")){
                int leftNum = numStack.pop();
                int rightNum = numStack.pop();
                numStack.push(rightNum / leftNum);
            }else{
                numStack.push(Integer.valueOf(str));
            }
        }
        return numStack.peek();
    }
}
```

易错点：

1. 因为会有负数的出现，所以使用`str.charAt(0) == '-'`这种方法来判断是否是数字，很有可能会忽略掉负数，从而将负数判断为负号，导致错误；
2. `str.equals("+")`是字符串之间的比较，所以不可以写成`str.equals('+')` 。里面应该用双引号；
3. 注意`Integer.parseInt`和`Integer.valueOf`两个的区别。虽然二者都可以将字符串进行相应的转换，但是`Integer.parseInt`直接返回`Int`类型，不涉及对象的包装，但是`Integer.valueOf`返回的是 `Integer` 对象，也就是对基本数据类型 `int` 进行了包装后的对象。在本题中哪个都可以，因为Java有自动装箱机制（当把一个 `int` 类型的值赋值给 `Integer` 类型的变量，或者将 `int` 类型的值作为参数传递给需要 `Integer` 类型参数的方法时，Java 编译器会自动将 `int` 类型的值转换为 `Integer` 对象）。
