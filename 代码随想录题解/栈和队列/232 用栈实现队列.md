# 232.用栈实现队列

![image.png](232%20%E7%94%A8%E6%A0%88%E5%AE%9E%E7%8E%B0%E9%98%9F%E5%88%97/image.png)

https://leetcode.cn/problems/implement-queue-using-stacks/description/

这题需要用两个栈来实现队列，思路是将其中一个栈作为入队的栈，另一个作为出队的栈，然后在出队的时候再对元素进行迁移操作。代码如下：

```java
class MyQueue {
    Stack<Integer> myStack1;
    Stack<Integer> myStack2;

    public MyQueue() {
        myStack1 = new Stack<>();
        myStack2 = new Stack<>();
    }
    
    public void push(int x) {
        myStack1.push(x);
    }
    
    public int pop() {
        if(!myStack2.isEmpty()){
            return myStack2.pop();
        }else{
            while(!myStack1.isEmpty()){
                myStack2.push(myStack1.pop());
            }
            return myStack2.pop();
        }
    }
    
    public int peek() {
        if(!myStack2.isEmpty()){
            return myStack2.peek();
        }else{
            while(!myStack1.isEmpty()){
                myStack2.push(myStack1.pop());
            }
            return myStack2.peek();
        }
    }
    
    public boolean empty() {
        if(myStack2.isEmpty() && myStack1.isEmpty()){
            return true;
        }else{
            return false;
        }
    }
}
```

需要注意本题不可能在队列为空的时候进行出队操作，因此出队时不需要对队列为空的情况进行判断。
