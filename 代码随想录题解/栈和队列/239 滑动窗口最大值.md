# 239. 滑动窗口最大值

[https://leetcode.cn/problems/sliding-window-maximum/description/](https://leetcode.cn/problems/sliding-window-maximum/description/)

## 方法一

本题需要依次给出一个向右滑动的窗口中的最大值，需要用到一个新的数据结构——**单调队列**，顾名思义，就是队列中的元素是按照降序或者升序的顺序进行排列的。本题中该队列包含三个操作：**加入元素，删除元素和取最大值元素**。

首先看加入元素，每次遇到一个需要加入到队列中的元素时，不断删除队尾比这个元素要小的元素（因为这些元素都不可能是最大值，也就没有必要继续维护），直到队尾的元素比要加入的元素要大，这时才把这个元素加入到队列，意思是这个元素在接下来有可能成为最大值。

再看删除元素，这一步只需要将要删除的元素与队头元素进行比较，如果相等就说明这个要删除的元素恰好是队列中的最大值，那么直接删除这个队头元素就好了。如果不相等呢？不相等的话，说明这个要删除的元素不是队列中的最大值（即还没轮到最大值被删除，说明最大值还在滑动窗口内），这时什么都不用做（因为不是最大值的删除操作在加入元素的操作中已经实现）。所以从这里也可以看出，删除元素操作的目的其实就只是为了删掉队列中的最大值，因为这个最大值在加入元素的操作中是不可能被删除的，因此这里增加一个删除元素的操作来应对遇到需要删除最大值元素的特殊情况。最后取最大值的操作直接返回队头元素即可。代码如下：

```java
class Solution {
    // 自定义一个MyQueue类
    class MyQueue{
        Deque<Integer> myDeque = new LinkedList<>();

        // 出队，可以看成是为了删除队列中的最大值
        void poll(int val){
		        // 判断要出队的元素是否是队列中的最大值
            if(!myDeque.isEmpty() && val == myDeque.peek()){
                myDeque.poll(); // 是就删除
            }
            // 不是的话直接忽略（因为这个数已经在入队的时候就被删除了）
        }

        // 入队，始终保持队列元素递减
        void add(int val){
		        // 把比当前要入队的元素小的那些元素全部出队
            while(!myDeque.isEmpty() && val > myDeque.getLast()){
                myDeque.removeLast();
            }
            // 然后再把新元素入队
            myDeque.add(val);
        }

        // 取队头元素（最大值）
        int peek(){
            return myDeque.peek();
        }
    }

    public int[] maxSlidingWindow(int[] nums, int k) {
        if(nums.length == 1){
            return nums;
        }
        int[] resArr = new int[nums.length - k + 1];
        int index = 0;
        MyQueue myQueue = new MyQueue(); // 新建一个自定义的类
        //先加入前k个元素（0~k-1），即窗口的初始位置
        for(int i = 0; i < k; i++){
            myQueue.add(nums[i]);
        }
        // 记录前k个元素的最大值
        resArr[index++] = myQueue.peek();

        //从第k+1个元素开始进行窗口的移动
        for(int i = k; i < nums.length; i++){
            myQueue.poll(nums[i - k]); // 1.先将窗口第一个元素出队
            myQueue.add(nums[i]); // 2.再将新元素入队（1和2这两步可以反过来，不影响最终结果）
            resArr[index++] = myQueue.peek(); // 最后记录新窗口的最大值
        }
        return resArr;
    }
}
```

也可以这么理解：处于队列中peek位置的值的左边位置的这些值，在原数组中一定是出现在peek这个值所在的原数组位置的右边。因为这个peek是窗口内的最大值，假如这个最大值出现在当前窗口的中间位置，那么当这个最大值在之前加入到窗口中的时候，就已经将当前窗口的最大值所在位置的左边那些值全部从队列中清除出去了，后续能加入到队列中的值都是比这个最大值大，而且是在这个最大值的左边的那些值。因此出队的时候，只需要判断当前要出队的值是否是队列中的最大值就好了。而那些要出队的值如果不是队列中的最大值，那就说明这些值在数组中是处于当前队列中最大值在数组中的位置的右边那些值，而这些值目前还在窗口中，因此出队的时候不需要进行任何操作。

有点绕，但是整体的理解思路就是将最大值所在的数组中的位置看成一个分割线，将当前窗口分成了【左边元素，最大值，右边元素】，而将队列分成了【右边元素，最大值】。左边元素在最大值入队的时候，就已经被全部从队列中清除出去了，因此队列中是没有左边元素的。而最大值是窗口的左边即将离开这个最大值的时候，才会出队。那最大值出去之后，剩下的右边元素是怎么回事？其实又回到开头了。最大值出去之后，窗口加入新的值，这个新的窗口中还是被分成新的【左边元素，最大值，右边元素】，而队列也是分成了【右边元素，最大值】。发现没有，又回到最初的起点了，因此进行相同的处理操作。总之就是将窗口看成三个部分：左边元素，最大值和右边元素。这样就可以很好的理解这题的出入队思路。

```java
// 方法二（面试推荐）
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0 || k <= 0) return new int[0];
        
        int n = nums.length;
        int[] result = new int[n - k + 1];
        int resultIndex = 0;
        
        // 双端队列，存储的是元素的下标
        Deque<Integer> deque = new ArrayDeque<>();
        
        for (int i = 0; i < n; i++) {
            // 1. 维护单调性：如果新进入的元素比队列尾部的元素大，
            // 那么尾部元素永远不可能成为最大值了，直接弹出。
            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
                deque.removeLast();
            }
            
            // 2. 将当前下标加入队尾
            deque.addLast(i);
            
            // 3. 移除过期下标：如果队头的下标已经不在当前窗口范围内了，移除它
            if (deque.peekFirst() <= i - k) {
                deque.removeFirst();
            }
            
            // 4. 记录答案：当窗口形成（i >= k-1）时，队头就是当前窗口的最大值
            if (i >= k - 1) {
                result[resultIndex++] = nums[deque.peekFirst()];
            }
        }
        
        return result;
    }
}
```
