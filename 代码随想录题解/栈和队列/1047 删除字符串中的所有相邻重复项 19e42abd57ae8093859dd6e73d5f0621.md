# 1047. 删除字符串中的所有相邻重复项

[https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/description/](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/description/)

本题旨在删除字符串中两个相邻且相同的字母。解法用一个栈就搞定，具体就是从左到右遍历字符串，如果遇到的字符和栈顶的字符相同，则出栈；否则就入栈。代码如下：

```java
class Solution {
    public String removeDuplicates(String s) {
        Stack<Character> myStack = new Stack<>();
        myStack.push(s.charAt(0));
        for(int i = 1; i < s.length(); i++){
            if(myStack.isEmpty() || s.charAt(i) != myStack.peek()){
                myStack.push(s.charAt(i));
            }else{
                myStack.pop();
            }
        }

        StringBuilder sb = new StringBuilder();
        while(!myStack.isEmpty()){
            sb.append(myStack.pop());
        }
        return sb.reverse().toString();
    }
}
```
