# 202. 快乐数

[https://leetcode.cn/problems/happy-number/description/](https://leetcode.cn/problems/happy-number/description/)

本题对数字n进行循环计算之后只有两种情况，一种是到达1，也就是快乐数；一种是进入一个循环的圈。所以这题其实就是判断一个链表是否存在环，与[142.环形链表II](../%E9%93%BE%E8%A1%A8/142%20%E7%8E%AF%E5%BD%A2%E9%93%BE%E8%A1%A8II.md) 这道题的解法十分类似。有两种解法，一种是通过哈希表判断新得到的数之前是否加入过哈希表中，来得到是否存在环；另一种是设置两个快慢指针，看看两个指针最后是否会相遇，要么相遇，要么快指针遇到1结束循环。代码如下：

```java
class Solution {
    // 方法一：哈希表
    public boolean isHappy1(int n) {
        int tempNum = 0;
        Map<Integer, Integer> myMap = new HashMap<>();
        while(true){
            tempNum = squareSum(n);
            if(myMap.containsKey(tempNum)){
                return false;
            }else if(tempNum == 1){
                return true;
            }else{
                myMap.put(tempNum, 1);
                n = tempNum;
            }
        }
    }

    // 方法二：快慢指针
    public boolean isHappy2(int n) {
        int slowRunner = n;
        int fastRunner = squareSum(n);
        while(fastRunner != 1 && slowRunner != fastRunner){
            slowRunner = squareSum(slowRunner);
            fastRunner = squareSum(squareSum(fastRunner));
        }

        if(fastRunner == 1){
            return true;
        }else{
            return false;
        }
    }

    public int squareSum(int n) {
        int num = 0;
        while(n != 0){
            num += Math.pow(n % 10, 2);
            n /= 10;
        }
        return num;
    }
}
```

我之前的错误的思路是以为得到的新数字要么是1，要么就是又得到前一个新得到的数字，也就是`n == squareSum(n)` ，但是这只是链表存在环路的最极端的例子（最小的环，即只有两个节点的环）而已，并没有判断完其他可能存在环路的情况。
