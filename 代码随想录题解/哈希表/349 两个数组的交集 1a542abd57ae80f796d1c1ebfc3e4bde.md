# 349. 两个数组的交集

[https://leetcode.cn/problems/intersection-of-two-arrays/description/](https://leetcode.cn/problems/intersection-of-two-arrays/description/)

比较简单，直接用两个数组作为输入数组的哈希表，然后一次遍历并判断就好了。代码如下：

```java
class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        int[] nums1Map = new int[1002];
        int[] nums2Map = new int[1002];
        for(int i = 0; i < nums1.length; i++){
            nums1Map[nums1[i]]++;
        }
        for(int i = 0; i < nums2.length; i++){
            nums2Map[nums2[i]]++;
        }

        List<Integer> resList = new ArrayList<>();
        for(int i = 0; i < 1002; i++){
            if(nums1Map[i] > 0 && nums2Map[i] > 0){
                resList.add(i);
            }
        }

				// 将ArrayList转成int[]
        int[] resArray = new int[resList.size()];
        int index = 0;
        for(int i : resList){
            resArray[index++] = i;
        }

        return resArray;
    }
}
```
