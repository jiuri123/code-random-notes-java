# 1. 两数之和

[https://leetcode.cn/problems/two-sum/description/](https://leetcode.cn/problems/two-sum/description/)

## 方法一（面试推荐）

本题的思路在于利用一个哈希表来存储已经遇到过的值，然后遍历数组的过程中看看哈希表中是否有符合条件的元素，哈希表可以使得搜索另一个元素的代价从O(N)降到O(1)。代码如下：

```
class Solution {
    public int[] twoSum(int[] nums, int target) {
		    // key:数组元素；value:数组下标
        Map<Integer, Integer> myMap = new HashMap<>();
        for(int i = 0; i < nums.length; i++){
		        // 检查之前遍历过的元素中是否包含target - nums[i]
            if(myMap.containsKey(target - nums[i])){
		            // 如果包含，直接返回下标
                return new int[]{myMap.get(target - nums[i]), i};
            }
            myMap.put(nums[i], i);
        }
        // 返回空数组
        return new int[0];
    }
}
```

自己对算法的理解：遍历到一个元素的时候，如果哈希表里面存储的元素没有符合条件的，说明数组中该元素的前面没有符合条件的元素，那么符合条件的元素（如果有的话）一定在数组中该元素位置的后面，那么就先把这个元素加入到哈希表中，等到后面遇到符合条件的元素的时候再取出来返回。

有个小细节需要注意：因为不能使用两次相同的元素，所以可以边遍历数组，边往哈希表里加入元素，这样可以避免找到的元素是自身。我之前的错误想法就是想着先把所有元素加入到哈希表中在进行数组的遍历，但是这样的话就会使得代码非常的复杂。
