# 242.有效的字母异位词

[https://leetcode.cn/problems/valid-anagram/description/](https://leetcode.cn/problems/valid-anagram/description/)

这题比较简单，因为只有小写字母，因此用一个数组当做哈希表就可以，然后就统计第一个字符串各个字符的个数，但是不需要统计第二个字符串各个字符的个数，直接在哈希表上减掉对应的值就可以了，最后检查哈希表里面是否有非零元素就OK。代码如下：

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        int[] sCount = new int[26];
        for(int i = 0; i < s.length(); i++){
            sCount[s.charAt(i) - 'a']++;
        }

        for(int i = 0; i < t.length(); i++){
            sCount[t.charAt(i) - 'a']--;
        }

        for(int i = 0; i < sCount.length; i++){
            if(sCount[i] != 0){
                return false;
            }
        }

        return true;
    }
}
```

还有个要注意的点是比较`Integer`不要用`==`，应该用`equals` 。因为`==` 比的是地址，而`equals` 比的才是值。那为什么我的代码有一部分示例是对的呢？因为Java 会对 `-128` 到 `127` 之间的整数进行缓存。当使用自动装箱创建这个范围内的 `Integer` 对象时，实际上会复用缓存中的对象，此时使用 `==` 比较也可能得到正确的结果。如：

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b); // 输出 true，因为 a 和 b 指向缓存中的同一个对象（地址一样）

Integer a = 128;
Integer b = 128;
System.out.println(a == b); // 输出 false，因为 a 和 b 指向不同的对象（地址不一样）
```
