# 454. 四数相加 II

[https://leetcode.cn/problems/4sum-ii/description/](https://leetcode.cn/problems/4sum-ii/description/)

本题的思路是将四个四组分成两组，每组两个数组。然后遍历第一组数组，算出两个数组相加之后各种和的个数，加入到一个`map`中。最后遍历第二组数组，求出和之后去`map`中看看是否有符合条件的值并计数。代码如下：

```java
class Solution {
    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        // Key：nums1与nums2的和
        // value：这个和有多少种组合方式
        Map<Integer, Integer> sumMap = new HashMap<>();
        for(int i = 0; i < nums1.length; i++){
            for(int j = 0; j < nums2.length; j++){
                int sum = nums1[i] + nums2[j];
                sumMap.put(sum, sumMap.getOrDefault(sum, 0) + 1);
            }
        }

        int count = 0;
        for(int i = 0; i < nums3.length; i++){
            for(int j = 0; j < nums4.length; j++){
                int sum = nums3[i] + nums4[j];
                count += sumMap.getOrDefault(-sum, 0);
            }
        }
        return count;
    }
}
```

时间复杂度：O($N^2$)，但如果是暴力解法，时间复杂度就是O($N^4$)
