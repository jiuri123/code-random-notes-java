# 383. 赎金信

[https://leetcode.cn/problems/ransom-note/description/](https://leetcode.cn/problems/ransom-note/description/)

本题和[**242.有效的字母异位词**](242%20%E6%9C%89%E6%95%88%E7%9A%84%E5%AD%97%E6%AF%8D%E5%BC%82%E4%BD%8D%E8%AF%8D.md) 感觉是一样的思路，都是设置一个哈希表，然后遍历加减，最后判断哈希表里面的值是否有小于0的就行。代码如下：

```java
class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        int[] hashmap = new int[26];
        for(int i = 0; i < magazine.length(); i++){
            hashmap[magazine.charAt(i) - 'a']++;
        }

        for(int i = 0; i < ransomNote.length(); i++){
            hashmap[ransomNote.charAt(i) - 'a']--;
        }

        for(int i = 0; i < hashmap.length; i++){
            if(hashmap[i] < 0){
                return false;
            }
        }
        return true;
    }
}
```
