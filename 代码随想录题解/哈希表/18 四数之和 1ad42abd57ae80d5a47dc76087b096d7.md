# 18. 四数之和

[https://leetcode.cn/problems/4sum/description/](https://leetcode.cn/problems/4sum/description/)

与三数之和有异曲同工之妙，还是用n指针法。主要思路就是先定前两个数，然后利用双指针法去剩下的区间中找剩下的两个数，因此也是需要先对数组进行排序。与三数之和唯一的区别就是外面需要多加一层循环并去重（因为多加了一个数），因此时间复杂度也从三数之和的O($n^2$)变成四数之和的O($n^3$)。代码如下：

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        List<List<Integer>> ansList = new ArrayList<>();
        if(nums.length < 4){
            return ansList;
        }
        Arrays.sort(nums);

        for(int i = 0; i < nums.length - 3; i++){
            //对第一个数去重，注意是用if不是while
            if(i > 0 && nums[i] == nums[i - 1]){
                continue;
            }

            for(int j = i + 1; j < nums.length - 2; j++){
                //对第二个数去重，注意是用if不是while
                if(j > i + 1 && nums[j] == nums[j - 1]){
                    continue;
                }

                //开始用双指针法找剩下的两个数
                int left = j + 1; 
                int right = nums.length - 1;
                while(left < right){
                    long sum = (long)nums[i] + nums[j] + nums[left] + nums[right];
                    if(sum < target){
                        left++;
                    }else if(sum > target){
                        right--;
                    }else{
                        ansList.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
                        left++;
                        right--;
                        while(left < right && nums[left] == nums[left - 1]) left++;
                        while(left < right && nums[right] == nums[right + 1]) right--;
                        // 问题：可不可以省略left < right？
                        // 不可以，因为有可能会数组越界
                        // 那意思就是可以写成下面的形式咯？
                        // while(left < nums.length - 1 && nums[left] == nums[left - 1]) left++;
                        // while(right >= 0 && nums[right] == nums[right + 1]) right--;
                        // 是的没错，这样写也是对的，因为有大循环while(left < right)保证逻辑
                        // 由此也可以看出left < right只是为了防止数组越界
                        // 只是写成left < right的形式明显使得逻辑更加容易理解
                    }
                }
            }
        }
        
        return ansList;
    }
}
```
