# 15. 三数之和

[https://leetcode.cn/problems/3sum/description/](https://leetcode.cn/problems/3sum/description/)

本题寻找一个数组中三个元素的和是否满足某个条件，可以使用n指针法（自己起的名字）。主要思路是先对数组排序（双指针法的主要步骤），然后定一个主指针i，这个主指针一直指向三个数中的最左边那个数，从0开始遍历到数组的末尾。定好主指针之后就开始在主指针的右边范围寻找另外两个符合条件的数。由于是已经排好序的，所以可以讲右边的两个指针设置为i+1和length-1，然后看看三个数相对于0的大小来分别决定对右边的哪个指针来进行移动。

上面就是主要的思路，现在说说如何去重。去重就是不允许出现相同的三元组。但是请注意，一个三元组中的每个元素的值是可以重复的，比如说(0, 0, 0)，其中的0来自于数组中不同的位置，但是不允许出现多个(0, 0, 0)这样的三元组。去重的思路是对左中右三个数分别进行去重，首先对最左边的那个数去重，可以在该数移动的过程中对其进行去重，一旦找到一个和之前不一样的数，说明就进入新一轮的对右边两个数的寻找。在寻找右边两个数过程中再对这两个数进行去重。

代码如下：

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);
				// 找出a + b + c = 0
        // a = nums[i], b = nums[left], c = nums[right]
        for (int i = 0; i < nums.length; i++) {
		        // 排序之后如果第一个元素已经大于零，那么无论如何组合都不可能凑成三元组
            if (nums[i] > 0) {
                return result;
            }
            
            // 错误的去重方法：从第一个元素就开始去重，并将当前元素与后一个元素进行比较
            // 会漏掉nums = {-1,-1,2}（只含三个元素）这种情况
            // 因为会将第一个 -1 给跳过
            /*
            if (nums[i] == nums[i + 1]) {
                continue;
            }
            */
            
            // 正确的去重方法：从第二个元素才开始去重，并将当前元素与前一个元素进行比较
            // 这样就不会将第一个 -1 给跳过
            if (i > 0 && nums[i] == nums[i - 1]) {  
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;
            while (right > left) {
		            // 去重复逻辑如果放在这，对于{0，0，0}的情况，
		            // 可能直接导致 right <= left 并退出循环了
                /*
                while (right > left && nums[right] == nums[right - 1]) right--;
                while (right > left && nums[left] == nums[left + 1]) left++;
                */
                int sum = nums[i] + nums[left] + nums[right];
                if (sum > 0) {
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
								    // 对b和c的去重逻辑应该放在找到一个三元组之后
								    // 先去重再增减或者先增减再去重都是一样的，但是先增减再去重比较好理解
								    // 而且这样的去重思路也与前面对a进行去重的时候思路统一起来了
								    // 因为前面去重的时候也是与已经遍历过的数进行去重
                    // while (right > left && nums[right] == nums[right - 1]) right--;
                    // while (right > left && nums[left] == nums[left + 1]) left++;
                    left++;
                    right--;
                    while(left < right && nums[left] == nums[left - 1]) left++;
                    while(left < right && nums[right] == nums[right + 1]) right--;
                }
            }
        }
        return result;
    }
}
```

总结：**先使用再去重，即与用过的数进行比较去重，而不是与还没遇到的数进行去重。**

简化版：

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(nums); // 不要忘记排序，这是双指针的基础
        int n = nums.length;

        for(int i = 0; i <= n - 3; i++){
            // 排序之后如果第一个元素已经大于零，那么无论如何组合都不可能凑成三元组
            if(nums[i] > 0){
                return res;
            }

            // 手动去重
            if(i != 0 && nums[i] == nums[i - 1]){
                continue;
            }

            int left = i + 1;
            int right = n - 1;
            while(left < right){
                int sum = nums[i] + nums[left] + nums[right];
                
                if(sum < 0){
                    left++;
                }else if(sum > 0){
                    right--;
                }else{
                    res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    left++;
                    right--;

                    // 手动去重（且只需要在sum == 0的逻辑中去重）
                    while(left < right && nums[left] == nums[left - 1]) left++;
                    while(left < right && nums[right] == nums[right + 1]) right--;
                }
            }
        }

        return res;
    }
}
```

易错点：

1. 总是忘记排序。
2. 只有在sum == 0的if循环中才需要加上去重逻辑，另外两个sum < 0和sum > 0不需要加上去重逻辑，他们会自动去重。因为如果下一个元素还是一样的话，此时依然是sum < 0或sum > 0的情况，又是直接移动指针，相当于自动去重了。
