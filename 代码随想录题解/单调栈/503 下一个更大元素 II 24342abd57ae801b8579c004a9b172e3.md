# 503. 下一个更大元素 II

![image.png](503%20%E4%B8%8B%E4%B8%80%E4%B8%AA%E6%9B%B4%E5%A4%A7%E5%85%83%E7%B4%A0%20II/image.png)

整体思路和上题[**496. 下一个更大元素 I**](496%20%E4%B8%8B%E4%B8%80%E4%B8%AA%E6%9B%B4%E5%A4%A7%E5%85%83%E7%B4%A0%20I%2024242abd57ae80a9bf50f011f5ec2722.md) 差不多，唯一的区别是本题的数组是循环数组，这意味着需要对数组进行循环遍历。那遍历多少次才能得出最终的结果呢？如果数组中的最大值是位于数组的最后那个位置，那么只需要遍历一次就可以得到最终的答案；但是如果数组中最大值并不在数组最后的位置，那么就需要遍历两次才能得到最后的结果，其中第一次遍历得出的是最大值左边那些元素的结果，而第二次遍历得出的就是最大值右边那些元素的结果。总的来说，我们最多需要对数组进行循环遍历两次就可以得到最终可以作为答案返回的结果。那由此得出的解法就有以下两种。

## 方法一

第一种解法是直接新建一个大小为原数组两倍的新数组，这个新数组其实就是将原数组复制一份，接在原数组后面得到的新数组。然后我们只需要对这个新数组遍历一遍就可以得出最后的答案。整体代码如下：

```java
// 方法一：复制原数组，遍历新数组
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        Deque<Integer> stack = new ArrayDeque<>();

        int len = nums.length;
        int[] newNums = new int[len * 2];
        for(int i = 0; i < len * 2; i++){ // 将两个原数组接在一起，相当于复制两遍
            newNums[i] = nums[i % len];
        }
        
        int[] ans = new int[len];
        Arrays.fill(ans, -1);

        for(int i = 0; i < len * 2; i++){
            if(stack.isEmpty() || newNums[i] <= newNums[stack.peek()]){
                stack.push(i);
            }else{
                while(!stack.isEmpty() && newNums[i] > newNums[stack.peek()]){
                    ans[stack.peek() % len] = newNums[i];
                    stack.pop();
                }
                stack.push(i);
            }
        }

        return ans;
    }
}
```

## 方法二

方法一的缺点就是比较麻烦，还需要新建一个数组来存储复制的旧数组。那么可不可以直接在遍历旧数组的过程中直接进行两次循环遍历呢？当然是可以的，也就是利用取余（%）这个符号，这就是下面的方法二。方法二也可以分为两种，一种是直接将i的遍历终点从len升级到2*len，然后for循环中直接使用i % len来进行计算，这样当i变化到len的时候，在取余符号的作用下，i又从0开始遍历，因此又重新从数组的起始位置开始遍历，相当于是又对数组做了一次遍历。代码如下：

```java
// 方法二：代码随想录
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        Deque<Integer> stack = new ArrayDeque<>();
        int len = nums.length;
        int[] ans = new int[len];
        Arrays.fill(ans, -1);
        for(int i = 0; i < len * 2; i++){ // len * 2等价于是将数组循环遍历两次
            if(stack.isEmpty() || nums[i % len] <= nums[stack.peek()]){
                stack.push(i % len);
            }else{
                while(!stack.isEmpty() && nums[i % len] > nums[stack.peek()]){
                    ans[stack.peek()] = nums[i % len];
                    stack.pop();
                }
                stack.push(i % len);
            }
        }

        return ans;
    }
}
```

## 方法三

另一种是每当i变化到len时，就直接将i置为0，也就是重新从头开始遍历数组。当然需要设置一个变量记录目前是第几轮遍历，一旦遍历了两轮后，就退出循环。代码如下：

```java
// 方法二：自己的
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        Deque<Integer> stack = new ArrayDeque<>();
        int len = nums.length;
        int[] ans = new int[len];
        Arrays.fill(ans, -1);
        int i = 0; // 数组下标
        int loopCount = 1; // 记录目前是第几轮循环
        while(loopCount != 3){ // 一旦遍历了两轮就退出循环
            if(stack.isEmpty() || nums[i] <= nums[stack.peek()]){
                stack.push(i);
            }else{
                while(!stack.isEmpty() && nums[i] > nums[stack.peek()]){
                    ans[stack.peek()] = nums[i];
                    stack.pop();
                }
                stack.push(i);
            }
            i++;
            if(i == len){ // 说明当前循环结束，进入下一轮循环
                i = 0;
                loopCount++; // 进入下一轮循环
            }
        }

        return ans;
    }
}
```

那么此时问题来了，对数组的第二次遍历，难道不会覆盖掉原来已经得到的正确答案（ans中的值）吗？其实不会，这里自己模拟几个例子就知道了，要么将一个相同的值覆盖ans中的值，并不会改变ans中的值，要么是一直存储在栈中不出来，也就无法改变ans中的值。

题目其实不难关键是要想到最多只需要对数组循环遍历两次，就可以得出最终的答案。我之前的思路是知道需要对数组循环遍历两次就可以得出结果，但是第二次遍历不需要对数组遍历完，而是只需要遍历到某一个关键位置就好了，比如遍历到了数组中的最大值，比如遍历到栈中只剩下一个元素，但是这些终止条件都很难用代码实现，过程非常复杂，还不如直接在第二次循环中将数组中的所有元素都重新遍历一遍，这个终止条件就非常容易实现。不过我之前可能也想到这个了，但是担心会将原来得到的正确结果覆盖掉，事实上只要自己模拟一遍就发现不会。
