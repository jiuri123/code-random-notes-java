# 496. 下一个更大元素 I

![image.png](496%20%E4%B8%8B%E4%B8%80%E4%B8%AA%E6%9B%B4%E5%A4%A7%E5%85%83%E7%B4%A0%20I/image.png)

思路跟上题[**739. 每日温度**](739%20%E6%AF%8F%E6%97%A5%E6%B8%A9%E5%BA%A6.md) 差不多，都是用一个单调递增的单调栈来存储已经遍历过的元素，然后在遍历的过程中不断计算结果就好了。不同之处就在于上题计算的是从当前元素开始，“几天后”出现第一个比当前元素大的元素，需要计算两者之间的下标之差，因此单调栈存储的是下标。而本题计算的是第一个比当前元素大的元素是多少，不需要知道下标之差，因此直接存储元素就可以了。

综上，总的思路就是运用上题所述的算法对数组`nums2`进行遍历，计算得到一个数组`hashMap`，这个`hashMap`中存储的是数组`nums2`中每个元素对应的下一个更大元素，同时直接以`nums2`中元素本身的值作为下标，这样就可以通过元素本身的值，直接去`hashMap`中找到该元素的下一个更大元素。（为什么要这样做呢？因为题目也说了，本题给出的数组中的元素都是不重复的，因此我们就可以以元素本身的值作为下标来存储该元素的下一个更大元素，从而使得待会遍历数组`nums1` 的时候，可以更方便的通过元素的值来找到元素的下一个更大的元素。）最后一个步骤就是对数组`nums1`进行遍历，对每个元素，直接去`hashMap`中找相应的下一个更大的元素，将其存储在数组 **`ans` 中，并进行返回。整体代码如下：

```java
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        Deque<Integer> stack = new ArrayDeque<>();
        int[] hashMap = new int[10001];
        int nums2Len = nums2.length;
        for(int i = 0; i < nums2Len; i++){
            if(stack.isEmpty() || nums2[i] <= stack.peek()){
                stack.push(nums2[i]);
            }else{
                while(!stack.isEmpty() && nums2[i] > stack.peek()){
                    hashMap[stack.peek()] = nums2[i]; // 以元素本身的值作为键
                    stack.pop();
                }
                stack.push(nums2[i]);
            }
        }

        int nums1Len = nums1.length;
        int[] ans = new int[nums1Len];
        for(int i = 0; i < nums1Len; i++){
            if(hashMap[nums1[i]] != 0){ // 有下一个更大的元素
                ans[i] = hashMap[nums1[i]];
            }else{ // 没有下一个更大的元素
                ans[i] = -1;
            }
        }

        return ans;
    }
}
```
