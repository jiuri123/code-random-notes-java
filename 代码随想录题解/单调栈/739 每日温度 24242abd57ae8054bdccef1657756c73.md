# 739. 每日温度

![image.png](739%20%E6%AF%8F%E6%97%A5%E6%B8%A9%E5%BA%A6/image.png)

对于这种寻找某个元素左边或者右边**第一个**比自己大或者小的元素的题目（并不是左边或右边最大，找左边或右边最大可以使用动规，见题目[**42. 接雨水**](42%20%E6%8E%A5%E9%9B%A8%E6%B0%B4%2024442abd57ae80f792b8ded98b343a61.md) 的方法三），可以使用一种叫做单调栈的数据结构来解决。单调栈跟栈一样只允许在一边进出，但是跟一般的栈区别在于单调栈里面的元素是单调递增或递减的，也就是说栈顶的元素是栈中最小或者最大的，因此遍历元素的过程中要时刻保持单调栈的单调性质。

对于本题来说，要找当前元素的右边那些元素中，第一个比当前元素大的元素。那么可以定义一个单调递增的单调栈（即栈顶存放栈中的最小值，对于为什么不是单调递减，后面解释），这个单调栈用来存放那些已经遍历过的元素的下标，且这些元素都还没有遇到其右边位置中第一个比自己大的元素。那那些已经遍历过且也已经遇到了其右边位置中第一个比自己大的元素的元素去哪了呢？这些元素其实都已经没有存放在栈中的意义，早就被弹出栈了，这个后面也会解释。至于为什么单调栈中记录下标，而不是直接记录元素，是因为记录下标不仅可以通过下标寻找到元素，还可以通过下标计算两个元素的相关位置信息。而如果只记录元素，就会丢失位置这个关键的信息（这也是题目所要求的东西）。

定义好了这个栈，就开始从头遍历数组。每遍历到一个元素，就将这个元素和栈顶的元素进行比较。前面说到，这个栈顶的元素就是之前已经遍历过的元素中的最小那个，而且目前为止还没有遇到过比自己大的元素。此时会出现下面三种情况：

1. 当前遍历的元素比栈顶的元素大。那么就说明栈顶的那个元素终于遇到了其右边位置第一个比自己大的元素，那么此时直接计算二者的差值，就可以得到栈顶元素的下一个更高温度出现在几天后。此时这个栈顶元素就没什么用了，可以直接弹出，然后继续将当前元素与下一个栈顶元素进行比较，重复上述过程，直到出现下面两种情况。从这种情况也可以解释前面提出的问题：为什么单调栈中非得设置成单调递增而不是单调递减？因为我要求的是当前元素的右边位置中，第一个比自己大的元素，那么只要后续遇到第一个大的元素，我就直接弹出，什么时候停止弹出呢？上面也说了，就是遇到当前遍历的元素比栈顶的元素小或相等的情况，此时就停止弹出。因此就保证了栈中的元素总是保持着单调递增的性质，这条性质并不是提前就约定好的，而是又我的算法来决定的（也可以这么理解，设置成单调递增是为了及时将已经遍历过的元素中，那些小的元素及时弹出来。最好反向思考一下如果单调栈设置成单调递减，会发生什么）。反之，如果求的是当前元素的右边位置中，第一个比自己小的元素，那么单调栈就设置成单调递减的性质。
2. 当前遍历的元素比栈顶的元素小。此时为了保持单调递增的性质，直接将当前遍历的元素压入栈中就好了。
3. 当前遍历的元素和栈顶的元素相等。与2同理，也是直接将当前遍历的元素压入栈中。除非题目问的是下一个相等或更高温度出现在几天后，那么就应该像1一样进行比较和弹出。

将上述三种情况对所有元素进行遍历后，可以发现有时候栈中还会存在一些没有弹出的元素，那是因为这些元素的右边并没有比自己更大的元素，根据题意，这些元素的相应位置直接设置为0。最后总的代码如下：

```java
// 版本一：易懂版
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        Deque<Integer> stack = new ArrayDeque<>(); // java定义栈的方式
        int len = temperatures.length;
        int[] answer = new int[len];
        for(int i = 0; i < len; i++){
            // 当前遍历元素小于等于栈顶元素的情况
            if(stack.isEmpty() || 
              temperatures[i] <= temperatures[stack.peek()]){
                stack.push(i);
            }else{ // 当前遍历元素大于栈顶元素的情况
                while(!stack.isEmpty() && 
                  temperatures[i] > temperatures[stack.peek()]){
                    answer[stack.peek()] = i - stack.peek();
                    stack.pop();
                }
                stack.push(i);
            }
        }
        return answer;
    }
}

// 版本二：简化版
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        // 栈中存储的是温度数组的下标 (Index)
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            int currentTemp = temperatures[i];
            
            // 当栈不为空，且当前温度大于栈顶下标对应的温度时
            // 说明找到了栈顶元素“之后第一个更高温度”的日子
            while (!stack.isEmpty() && currentTemp > temperatures[stack.peek()]) {
                int prevIndex = stack.pop();
                // 计算天数差
                answer[prevIndex] = i - prevIndex;
            }
            
            // 将当前下标入栈，等待寻找它的更高温日子
            stack.push(i);
        }
        
        return answer;
    }
}
```
