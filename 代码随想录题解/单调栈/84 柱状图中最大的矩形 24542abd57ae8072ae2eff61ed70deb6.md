# 84. 柱状图中最大的矩形

![image.png](84%20%E6%9F%B1%E7%8A%B6%E5%9B%BE%E4%B8%AD%E6%9C%80%E5%A4%A7%E7%9A%84%E7%9F%A9%E5%BD%A2/image.png)

刚开始怎么想都想不出来，但是一看随想录的思路，其实还蛮容易理解的。首先明确很重要的一点，就是对于柱状图中的每一个矩形，都一定是至少以其中一个柱子为顶的。比如说上述示例中标出的那个面积为10的那个最大矩形，就是以高度为5的柱子为基准的。也可以这么说，对于柱状图中的每一个柱子，都可以找出多个以这个柱子为高的矩形。将每个柱子所对应的那些矩形中面积最大的那个取出来，分别进行比较，面积最大的那个就是该柱状图中，能够勾勒出来的矩形的最大面积。因此我们的思路就是遍历每根柱子，然后计算这根柱子所对应的那些矩形中，面积最大的那个矩形面积是多少，最后取每根柱子所对应的最大面积的矩形中面积最大的那个矩形的面积，就是题目需要的答案。

此时问题就来了，怎么计算每根柱子所对应的那个最大面积的矩形是多少呢？其实仔细想想也很简单，因为这个矩形的高是已经确定的了（也就是当前基准柱子的高），那么我要使得面积尽可能的大大，唯一的办法就是增加宽度了，因此我接下来的目标就是找到这个最大的宽是多少。可以这么想，因为我现在已经确定了基准的柱子，那么我可以将这个柱子在保持高度不变的情况下，尽可能的往左往右延伸。那延伸到什么时候会停止呢？当然是遇到第一个比基准柱子矮的柱子的时候就停止，比如上图中的第二个高度为2的柱子，往左延伸到高度为1的柱子之前就得停止。但还有一种情况就是该基准柱子延伸的过程中没有遇到比自己矮的柱子，那就说明这个柱子延伸的过程中遇到的都是比自己大或者和自己相等的柱子，因此该基准柱子可以一直延伸到边界，此时的宽就以边界来计算。此时问题又从找刚刚的最长宽的问题，变成了找当前基准柱子左右两边的那些柱子中第一个比自己矮的柱子。找到了这两个柱子，我就知道最长可以延伸的边界在哪，也就知道了宽是多少。然后用宽和高就可以得到以当前柱子为基准所对应的那些矩形当中，面积最大的那个矩形的面积是多少。而找左右两边的第一个比自己矮的柱子这个问题，这不就是用单调栈可以轻松解决的问题吗？只不过之前都是求左右两边第一个比自己高的，现在刚好反过来，求的是左右两边第一个比自己矮的。代码也基本原封不动，只需要将大小于号互换位置就好了，而且栈中第二个元素也是有规律的，就是左边第一个比自己小的元素（同时注意此时的栈中存放的元素由原来的递增变成了递减）。

弄清了思路，代码也就很简单了：

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        Deque<Integer> stack = new ArrayDeque<>();
        int len = heights.length;
        int maxArea = 0;
        int rightIndex = 0; // 记录右边第一个比当前元素小的元素的下标
        int midIndex = 0; // 记录自己的下标
        int leftIndex = 0; // 记录左边第一个比当前元素小的元素的下标
        int wide = 0; // 记录以当前元素为基准（高）的最大矩形的宽度
        for(int i = 0; i < len; i++){
            if(stack.isEmpty() || heights[i] >= heights[stack.peek()]){ // 与之前题目相反的处理
                stack.push(i);
            }else{
                while(!stack.isEmpty() && heights[i] < heights[stack.peek()]){
                    rightIndex = i;
                    midIndex = stack.pop();
                    if(!stack.isEmpty()){ // 说明当前元素存在左边第一个比自己小的元素
                        leftIndex = stack.peek();
                        wide = rightIndex - leftIndex - 1;
                        maxArea = Math.max(maxArea, wide * heights[midIndex]);
                    }else{ // 说明当前元素不存在左边第一个比自己小的元素
		                    // maxArea = Math.max(maxArea, (rightIndex - 0) * heights[midIndex]);
                        maxArea = Math.max(maxArea, rightIndex * heights[midIndex]);
                    }
                }
                stack.push(i);
            }
        }

        while(!stack.isEmpty()){ // 栈中剩下没弹出的元素都是不存在右边第一个比自己小的元素
            rightIndex = len; // 说明右边可以一直延伸数组边界
            midIndex = stack.pop();
            if(!stack.isEmpty()){ // 说明当前元素存在左边界
                leftIndex = stack.peek();
                wide = rightIndex - leftIndex - 1;
                maxArea = Math.max(maxArea, wide * heights[midIndex]);
            }else{ // 说明当前元素不存在左边界
                maxArea = Math.max(maxArea, rightIndex * heights[midIndex]);
            }
        }
        return maxArea;
    }
}
```

当然也可以用暴力解法和双指针解法，暴力解法大概思路就是每遍历到一个柱子，就遍历去找该元素左右两边第一个小于该柱子的下标，计算矩形面积的思路也跟上面的单调栈思路一样，但是时间复杂度为O($n^2$)，超时了。而双指针解法是对暴力解法的优化，就是用空间换时间的思路，即将每个柱子左右两边第一个小于该柱子的下标都提前计算好，然后在对每个柱子进行遍历，而不是像暴力解法那样边遍历柱子，边去找左右两边第一个小于该柱子的下标。这两种解法的思路跟上题[**42. 接雨水**](42%20%E6%8E%A5%E9%9B%A8%E6%B0%B4%2024442abd57ae80f792b8ded98b343a61.md) 中的方法二和方法三是异曲同工的，这么就不过多介绍了。

## 方法二：单调栈+哨兵技巧（面试推荐）

哨兵技巧：在原数组的前后各加一个高度为 `0` 的柱子：

- **前面的 0**：统一所有元素的面积计算公式，不需要通过判断这个元素是否存在左边界来选择不同的计算公式（见方法一，判断逻辑较复杂）。
- **后面的 0**：保证遍历结束时，栈内所有剩余的柱子都会被弹出并计算面积，最后不需要单独增加一个将栈中剩下的元素一一弹出的操作（见方法一）。

```java
// 单调栈 + 哨兵
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        if (n == 0) return 0;
        
        // 1. 准备工作：添加哨兵
        // 在原数组前后各加一个高度为 0 的元素
        // **前面的 0**：统一所有元素的面积计算公式
        // **后面的 0**：保证遍历结束时，栈内所有剩余的柱子都会被弹出并计算面积
        int[] newHeights = new int[n + 2];
        // System.arraycopy(Object src, int srcPos, Object dest, int destPos, int length)
        System.arraycopy(heights, 0, newHeights, 1, n);
        newHeights[0] = 0;
        newHeights[n + 1] = 0;
        
        // 2. 初始化单调栈（存储索引）
        // 使用 ArrayDeque 作为栈，效率比 Stack 高
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0); // 先放入左侧哨兵的索引
        
        int maxArea = 0;
        
        // 3. 遍历数组（从第2个元素开始，因为第1个是哨兵）
        for (int i = 1; i < newHeights.length; i++) {
            // 当发现当前高度小于栈顶高度时，开始“收割”栈顶元素
            while (newHeights[i] < newHeights[stack.peek()]) {
                int midHeight = newHeights[stack.pop()]; // 确定高度
                int rightBorder = i;                     // 右边界（第一个比它矮的）
                int leftBorder = stack.peek();           // 左边界（新的栈顶，即左侧第一个比它矮的）
                
                int width = rightBorder - leftBorder - 1;
                maxArea = Math.max(maxArea, midHeight * width);
            }
            // 将当前索引入栈，保持单调递增
            stack.push(i);
        }
        
        return maxArea;
    }
}
```

`System.arraycopy(Object src, int srcPos, Object dest, int destPos, int length)`

- **`src` (Source)**: 源数组，即你要从哪复制？（`heights`）
- **`srcPos`**: 源数组的起始位置，从哪开始拷？（`0`，从头开始）
- **`dest` (Destination)**: 目标数组，你要拷到哪去？（`newHeights`）
- **`destPos`**: 目标数组的起始位置，从第几个格子开始放？（**`1`**，这是关键，为了留出索引 `0` 给左哨兵）
- **`length`**: 拷贝多少个元素？（`n`，即原数组的总长度）
