# 42. 接雨水

![image.png](42%20%E6%8E%A5%E9%9B%A8%E6%B0%B4/image.png)

看起来很难，但只要理清了思路，就感觉还行。总共有五种方法，下面先介绍两种暴力解法，比较容易理解，但是很不幸的是都超时了。之所以介绍暴力解法是因为第三种双指针法的思路就来自于暴力解法的改进版，而且并没有超时。

## 方法一（超时）

**首先是第一种我自己想出来的暴力解法。**首先明确一点，要存储水，就需要一个近似于碗状的结构，也就是两边高中间低的结构。那么既然如此，当我遇到一个碗的左边缘的时候，我是否可以根据这个左边缘找到这个碗的右边缘，然后根据取左右两个边缘的高度最小值，乘上碗的长度，在减去这个碗里面的“石块”（也就是其中的方块，这些方块把原本可以放水的地方给占用掉），不就是这个碗可以存的水的容量吗？当然可以，“根据左边缘去找这个碗的右边缘”恰好可以用单调栈来解决，因为单调栈就是去找当前元素的右边当中第一个比自己更高的元素，这不就是找右边缘吗？那好，我现在就可以先按照常规单调栈的思路，计算每个元素对应的右边缘在哪。然后根据这个右边缘数组，计算出每个碗的容量，最后将所有的碗的容量相加就是答案。整体代码如下：

```java
// 方法一：我自己的暴力单调栈解法，超时
class Solution {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>();
        int len = height.length;
        int[] nextHigherIndex = new int[len];
        for(int i = 0; i < len; i++){ // 计算每个柱子右边第一个比自己高的柱子在哪
            if(stack.isEmpty() || height[i] < height[stack.peek()]){
                stack.push(i);
            }else{
                while(!stack.isEmpty() && height[i] >= height[stack.peek()]){
                    nextHigherIndex[stack.peek()] = i;
                    stack.pop();
                }
                stack.push(i);
            }
        }

        int res = 0;
        int index = 0;
        while(index != len){
            int left = height[index]; // 左边缘的高度
            // 右边第一个比自己高的柱子的高度，即右边缘的高度
            int right = height[nextHigherIndex[index]]; 
            int boxNum = 0; 
            // 计算左右边缘中间有多少个方块，这会影响总的蓄水量
            for(int i = left + 1; i < right; i++){
                boxNum += height[i];
            }
            // 计算我俩之间可以存的蓄水量，记得要减去中间的方块数
            res += (right - left - 1) * Math.min(left, right) - boxNum; 
            index = right; // 将索引移动到右边第一个比自己高的柱子，开始下下一个碗的计算
        }
        return res;
    }
}
```

可惜的是，这种暴力解法超时了，因为在第二阶段计算每个碗的容量的时候，虽然是从左到右进行遍历的（还是跳着遍历的），但是对于每个碗，还要遍历计算每个碗的中间有多少个方块，因此时间复杂度为O($n^2$)。

## 方法二（超时）

**第二种是代码随想录上面介绍的暴力解法。**思路也很简单，就是每遍历到一个柱子，就分别去找这个柱子左边和右边的所有柱子中最高的那两个（左边一个最高的，右边一个最高的，就是两个，如果没有最高的，那么就把自己作为最高的）。然后根据左边最高的柱子的高度和右边最高的柱子的高度，以及当前柱子的高度，我们就可以计算出当前这个柱子上面最多可以放多少的水（宽度为1）。对每个柱子重复上述的计算，计算水量总和，就可以得出答案。代码如下：

```java
// 方法二：代码随想录的暴力解法，超时
class Solution {
    public int trap(int[] height) {
        int res = 0;
        int len = height.length;
        for(int i = 0; i < len; i++){
            if(i == 0 || i == len - 1){
                continue;
            }

            int leftMaxHeight = height[i]; // 记录当前柱子左边最大值
            int rightMaxHeight = height[i]; // 记录当前柱子右边最大值
            for(int j = i - 1; j >= 0; j--){ // 开始找左最大值
                if(height[j] > leftMaxHeight){
                    leftMaxHeight = height[j];
                }
            
            for(int j = i + 1; j < len; j++){ // 开始找右最大值
                if(height[j] > rightMaxHeight){
                    rightMaxHeight = height[j];
                }
            }

            // 宽度为1，因此高度就是当前柱子上方可以存储的雨量
            res += Math.min(leftMaxHeight, rightMaxHeight) - height[i]; 
        }
        return res;
    }
}
```

很明显，这种暴力解法也超时了，因为每遇到一个柱子，都要重新将当前柱子的左右两边去遍历一遍，相当于是重新对数组遍历一遍了，时间复杂度也是O($n^2$)。可以看到时间复杂度的提高主要是因为循环中又嵌套一个循环，那么此时可以思考一下：这内循环是真的有必要嵌套在外循环里面呢？我是否可以将内循环放在外循环外面呢？这样时间复杂度不就降低成O(n)了吗？当然是可以的，这也就是下面要介绍的双指针解法。

## 方法三

**方法三：双指针解法，其实就是对方法二的改进。**思路就是用空间换时间，即提前计算好每个柱子左边和右边的柱子最大值，并通过两个数组记录下来，而不是将这个计算过程放在遍历柱子的过程中。然后对柱子遍历并计算蓄水量的时候，直接去这两个数组中取对应的数计算就好了。整体代码如下：

```java
// 方法三：双指针/动规，对于方法二暴力解法的优化，以空间换时间
class Solution {
    public int trap(int[] height) {
        if (height == null || height.length == 0) return 0;
        int n = height.length;
        
        // 1. 记录每个柱子“左侧（含自身）”出现过的最大高度
        int[] leftMax = new int[n];
        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) {
            leftMax[i] = Math.max(height[i], leftMax[i - 1]);
        }
        
        // 2. 记录每个柱子“右侧（含自身）”出现过的最大高度
        int[] rightMax = new int[n];
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMax[i] = Math.max(height[i], rightMax[i + 1]);
        }
        
        // 3. 再次遍历，计算每一列的接水量
        int totalWater = 0;
        for (int i = 0; i < n; i++) {
            // 木桶效应：水位取决于左右两边最高柱子中较短的那个
            int minHeight = Math.min(leftMax[i], rightMax[i]);
            // 减去柱子本身的高度，即为该列的水量
            totalWater += minHeight - height[i];
        }
        
        return totalWater;
    }
}
```

注意：这里是找左右两边柱子的最大值，而不是找左右两边柱子中第一个比当前柱子要高的柱子，因此使用的方法是动规方法，而不是单调栈的方法。单调栈的方法是为了求当前柱子左右两边的最值。

## 方法四

**下面介绍比较复杂的方法四：单调栈解法。**对于一个柱子，如果我知道了它左边第一个比它高的柱子，以及它的右边第一个比它高的柱子，那么我是可以计算出这个柱子上面是可以存储多少水的。怎么计算呢？首先计算碗的宽，也就是将右边柱子的下标减去左边柱子的下标再减去1就是碗的宽。然后在计算碗的高，也就是将左右两根柱子中较矮的那根柱子的高度减去当前柱子的高度就是碗的高。最后宽乘以高就是这个碗可以转的水的量。举个例子，比如[20, 10, 30]，10左边第一个比它高的柱子是20，而右边第一个比它高的柱子是30，那么宽为2-0-1=1（因为30下标为1，20下标为0），高为20-10=10（20为较矮的那一根柱子），因此总的蓄水量为1*20=20。

此时问题就来了，对于每个柱子，通过之前的单调栈解法找到你右边第一个比你高的柱子是很简单，但问题是左边第一个比你高的柱子在哪呢？这里当然可以对数组反着来进行一遍单调栈解法，但是没必要，因为左边第一个比当前柱子高的柱子就藏在单调栈中。具体来说就是当当前遍历到的元素比栈顶的元素要高的时候，此时当前遍历到的元素就是栈顶元素的右边第一个比栈顶元素要大的元素，**而此时栈中从栈顶开始数的第二个元素就是栈顶元素的左边第一个比栈顶元素要大的元素！**很神奇对吧，其实仔细想想也没啥神奇的，因为我每次将一个元素压入栈里面的时候，都要将从栈顶开始的比当前元素小的元素全部从栈中弹出，这一步相当于是将当前元素的左边那些比自己小的元素都弹出栈了，直到遇到比当前元素要大的元素，才将这个元素压入栈中，而此时这个遇到的比当前元素要大的元素就是当前元素的左边元素中第一个比自己大的元素。因此此时栈顶存放的就是当前元素，而从栈顶开始数的第二个位置的元素存放的就是栈顶元素的左边元素中第一个比自己大的元素。这不是什么神奇的事，这就是由于单调栈的存取性质决定的，没啥好稀奇的。

解决了找左边第一个比自己大的元素的问题，这道题就迎刃而解了。直接看整体的代码：

```java
// 方法四：单调栈，横向求解
class Solution {
    public int trap(int[] height) {
        int len = height.length;
        if(len <= 2){
            return 0;
        }
        Deque<Integer> stack = new ArrayDeque<>();
        int res = 0;
        for(int i = 0; i < len; i++){
            if(stack.isEmpty() || height[i] < height[stack.peek()]){
                stack.push(i);
            }else if(height[i] == height[stack.peek()]){ // 相等的情况下，只存最后一个相等的元素下标
                // 只存第一个相等元素的下标是有问题的，比如[5, 5, 1, 7]
                // continue;
                // 只存最后一个相等元素的下标就没问题
                stack.pop();
                stack.push(i);
            }else{
                while(!stack.isEmpty() && height[i] > height[stack.peek()]){
                    int rightIndex = i; // 右柱子，相当于碗的右边缘
                    int midIndex = stack.pop(); // 中柱子，相当于碗底
                    if (!stack.isEmpty()){ // 需要判空，因为上一段语句pop后，栈可能为空
                        int leftIndex = stack.peek(); // 左柱子，相当于碗的左边缘
                        // 开始计算蓄水量
                        int h = Math.min(height[rightIndex], height[leftIndex]) - height[midIndex];
                        int w = rightIndex - leftIndex - 1;
                        res += h * w;
                    }
                }
                stack.push(i);
            }
        }
        return res;
    }
}
```

这里还有一个小问题，就是当当前遍历到的元素和栈顶元素相同的时候怎么处呢？有两种处理方法，一种是像上面那段代码一样，直接将相等的元素从栈中弹出，只保存一系列相等元素中，最右边的那个。为什么不存一系列相等元素中最左边那个呢？举个例子就明白了：[5, 5, 1, 7]，如果此时只存最左边那个5，那么当计算第三个元素1的蓄水量的时候，宽度就变成了2而不是1，计算的蓄水量就比正确答案多了一倍，很明显是不对的。因此只能存最右边那个。

## 方法五

另一种是遇到相等的元素，直接压入栈中，此时栈中就有一系列相等的元素，但是这些相等的元素在后续计算蓄水量的时候，并不会对结果造成任何影响，因为除了一系列相等的元素中的第一个元素，其他元素计算蓄水量的时候，h总是为0（因为栈顶和栈顶第二个元素都是一样的值），那么就不会对res的计算产生任何的影响，并且还会被弹出栈。整体代码如下：

```java
// 方法五：方法四的简化版，区别在于在元素相等的情况下，直接将相等元素放入栈中，而不是弹出
class Solution {
    public int trap(int[] height) {
        int len = height.length;
        if(len <= 2){
            return 0;
        }
        Deque<Integer> stack = new ArrayDeque<>();
        int res = 0;
        for(int i = 0; i < len; i++){
            if(stack.isEmpty() || height[i] <= height[stack.peek()]){ // 与方法四的区别
                stack.push(i);
            }else{
                while(!stack.isEmpty() && height[i] > height[stack.peek()]){
                    int rightIndex = i;
                    int midIndex = stack.pop();
                    if (!stack.isEmpty()){ // 因为前面对于相等的元素也放入其中，此处会出现无效计算（即出现h为0的情况）
                        int leftIndex = stack.peek();
                        int h = Math.min(height[rightIndex], height[leftIndex]) - height[midIndex];
                        int w = rightIndex - leftIndex - 1;
                        res += h * w;
                    }
                }
                stack.push(i);
            }
        }
        return res;
    }
}
```

## 方法六（面试推荐）

计算当前高度的时候，只看左边最高的柱子，而不看右边最高的柱子，那有没有可能出现左边最高柱子的高度是大于右边最高柱子的高度的？这样计算当前柱子的蓄水量就出现了高估的情况？

- 不可能出现这种情况，这种情况在之前的遍历中就已经过滤掉了，可以自己模拟一下

```java
// 双指针法（面试推荐）
// 时间复杂度：O(N)
// 空间复杂度：O(1)
class Solution {
    public int trap(int[] height) {
        // 边界条件处理
        if (height == null || height.length == 0) {
            return 0;
        }

        int left = 0;
        int right = height.length - 1;
        int leftMax = 0;
        int rightMax = 0;
        int res = 0;

        while (left < right) {
            // 核心逻辑：哪边矮，就先算哪边
            if (height[left] < height[right]) {
                // 如果当前高度大于等于左边最大高度，更新左边最大高度
                if (height[left] >= leftMax) {
                    leftMax = height[left];
                } else {
                    // 否则，当前位置可以接水：水量 = 左边最高 - 当前高度
                    res += leftMax - height[left];
                }
                left++;
            } else {
                // 同理处理右侧
                if (height[right] >= rightMax) {
                    rightMax = height[right];
                } else {
                    res += rightMax - height[right];
                }
                right--;
            }
        }

        return res;
    }
}
```
