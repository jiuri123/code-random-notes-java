# 151.翻转字符串里的单词

[https://leetcode.cn/problems/reverse-words-in-a-string/description/](https://leetcode.cn/problems/reverse-words-in-a-string/description/)

本题主要是翻转一句英文里的单词，也就是将单词倒序输出，但不是将单词中的每个字符倒序。

## 方法一

先介绍第一种方法，也就是我自己的方法。就是直接从后往前遍历数组，遇到一个单词就添加到新开辟的空间里，最后就自然倒序了，时间复杂度为O(n)，空间复杂度也为O(n)。代码如下：

```java
// 方法一：我自己
class Solution {
    public String reverseWords(String s) {
        String str = s.trim();
        str = " " + str + " "; // 句子前后加上空格，统一操作
        StringBuilder sb = new StringBuilder(); // 存放反转后的结果
        int end = str.length() - 2; // 是-2不是-1，因为句子前后加了空格
        int begin = -1;
        while(end >= 0){
            begin = end - 1;
            while(begin >= 0 && str.charAt(begin) != ' '){
                begin--;
            }
            sb.append(str.substring(begin + 1, end + 1) + " ");
            end = begin - 1;
            while(end >= 0 && str.charAt(end) == ' '){
                end--;
            }
        }
        return sb.deleteCharAt(sb.length() - 1).toString();
    }
}

// 方法一：优化改进版，并不需要将s搬移到str中，而是直接对s进行遍历
class Solution {
    public String reverseWords(String s) {
        StringBuilder sb = new StringBuilder();
        // 从字符串末尾开始向前遍历
        int i = s.length() - 1;
        while (i >= 0) {
            // 1. 跳过单词后的空格
            while (i >= 0 && s.charAt(i) == ' ') {
                i--;
            }
            if (i < 0) break; // 已经遍历完

            // 2. 记录单词的结尾位置
            int end = i;

            // 3. 寻找单词的开始位置
            while (i >= 0 && s.charAt(i) != ' ') {
                i--;
            }
            // 单词的范围是 [i + 1, end]
            
            // 4. 将单词和空格追加到结果中
            // 如果 sb 不是空的，说明前面已经有单词了，需要加个空格分隔
            if (sb.length() > 0) {
                sb.append(' ');
            }
            // substring 是左闭右开区间，所以是 (i, end + 1]
            sb.append(s.substring(i + 1, end + 1));
        }
        return sb.toString();
    }
}
```

第二种方法是直接用Java内置API：`split` 和 `join`来处理。可读性强，适合日常开发，但是要非常熟悉各种API的使用。代码如下：

```java
// 方法二：使用Java内置API
class Solution {
    public String reverseWords(String s) {
        // 1. 去除首尾空格
        String trimmedStr = s.trim();
        if (trimmedStr.isEmpty()) {
            return "";
        }
        
        // 2. 按一个或多个空格分割成单词列表
        // "\\s+" 是一个正则表达式，表示匹配一个或多个空白字符
        String[] words = trimmedStr.split("\\s+");
        
        // 3. 将单词列表反转
        Collections.reverse(Arrays.asList(words));
        
        // 4. 用单个空格将单词连接起来
        return String.join(" ", words);
    }
}
```

`Arrays.asList()` 返回的 `List` 并不是我们常用的 `java.util.ArrayList`。它是一个特殊的、固定大小的 `List`。**这个 `List`** **和原始的 `words` 数组是“视图”关系，它们共享内部的数据**。所以对我们对这个`List` 进行反转操作的时候，其实也就是对**`words`** 进行反串操作。

最后第三种方法是先将整个句子倒序一次，最后再对每个单词进行一次倒序即可。此方法比较复杂，时间时间复杂度为O(n)。代码如下：

```java
// 方法三（用StringBuilder实现，来自我自己）
class Solution {
    public String reverseWords(String s) {
        // 去除多余字符串中多余的空格（包括前中后）
        s = removeExtraSpaces(s);
        // 翻转整个字符串
        s = reverse(s);
        // 翻转每个单词后返回
        return reverseEachWord(s);
    }

    // 去除字符串中额外的空格
    public String removeExtraSpaces(String s) {
        StringBuilder sb = new StringBuilder();
        for(int i = 0; i < s.length(); i++){
            if(s.charAt(i) != ' '){
                // 除了第一个单词外，其他每个单词后面都要加空格
                if(!sb.isEmpty()){ 
                    sb.append(" ");
                }
                while(i < s.length() && s.charAt(i) != ' '){
                    sb.append(s.charAt(i));
                    i++;
                }
            }
        }
        return sb.toString();
    }

    // 翻转字符串
    public String reverse(String s) {
        StringBuilder sb = new StringBuilder();
        for(int i = s.length() - 1; i >= 0; i--){
            sb.append(s.charAt(i));
        }
        return sb.toString();
    }

    // 翻转字符串中的单词
    public String reverseEachWord(String s) {
        StringBuilder sb = new StringBuilder();
        int begin = 0;
        int end = -1;
        while(begin < s.length()){
            end = begin;
            while(end < s.length() && s.charAt(end) != ' '){
                end++;
            }
            if(!sb.isEmpty()){
                sb.append(" ");
            }
            sb.append(reverse(s.substring(begin, end)));
            begin = end + 1;
        }
        return sb.toString();
    }
}

// 方法三（用char[]实现，来自代码随想录）
class Solution {
    //用 char[] 来实现 String 的 removeExtraSpaces，reverse 操作
    public String reverseWords(String s) {
        char[] chars = s.toCharArray();
        //1.去除首尾以及中间多余空格
        chars = removeExtraSpaces(chars);
        //2.整个字符串反转
        reverse(chars, 0, chars.length - 1);
        //3.单词反转
        reverseEachWord(chars);
        return new String(chars);
    }

    //1.用 快慢指针 去除首尾以及中间多余空格，可参考 27.移除元素
    public char[] removeExtraSpaces(char[] chars) {
        int slow = 0;
        for (int fast = 0; fast < chars.length; fast++) {
            //先用 fast 移除所有空格
            if (chars[fast] != ' ') {
                //在用 slow 加空格。 除第一个单词外，单词末尾要加空格
                if (slow != 0)
                    chars[slow++] = ' ';
                //fast 遇到空格或遍历到字符串末尾，就证明遍历完一个单词了
                while (fast < chars.length && chars[fast] != ' ')
                    chars[slow++] = chars[fast++];
            }
        }
        //相当于 c++ 里的 resize()
        char[] newChars = new char[slow];
        System.arraycopy(chars, 0, newChars, 0, slow); 
        return newChars;
    }

    //双指针实现指定范围内字符串反转，可参考字符串反转题解
    public void reverse(char[] chars, int left, int right) {
        if (right >= chars.length) {
            System.out.println("set a wrong right");
            return;
        }
        while (left < right) {
            chars[left] ^= chars[right];
            chars[right] ^= chars[left];
            chars[left] ^= chars[right];
            left++;
            right--;
        }
    }

    //3.单词反转
    public void reverseEachWord(char[] chars) {
        int start = 0;
        //end <= s.length() 这里的 = ，是为了让 end 永远指向单词末尾后一个位置，这样 reverse 的实参更好设置
        for (int end = 0; end <= chars.length; end++) {
            // end 每次到单词末尾后的空格或串尾,开始反转单词
            if (end == chars.length || chars[end] == ' ') {
                reverse(chars, start, end - 1);
                start = end + 1;
            }
        }
    }
}
```
