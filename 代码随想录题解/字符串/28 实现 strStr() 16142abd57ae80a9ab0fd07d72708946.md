# 28. 实现 strStr()

[https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/)

我这辈子就跟KMP干上了，学个KMP花了我两个晚上，真的绝了！

本题主要是给出两个字符串，然后返回在大字符串中第一次匹配到小字符串的起始位置，典型KMP算法题。暴力解法就不介绍了，主要就来讲讲KMP算法。KMP算法有点利用到了动态规划的思想，主要就是边遍历边存储有用的信息，而当主串与模式串的某个字符不匹配时，可以利用之前遍历存储的信息来避免从头开始去匹配。接下来直接介绍算法。

首先要建立模式串的前缀表，如下图为模式串`aabaaf`的前缀表。比如下标4位置的前缀表元素为2，指的就是`aabaa`这个子字符串的最长相等前后缀的长度，也就是`aa`。

![image.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/image.png)

建立好前缀表后，就开始主串和模式串的匹配。第一次开始匹配如下图所示：

![image.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/image%201.png)

可以看到匹配到最后一位时发生失配（b ≠ f），此时关键的地方来了。按理说根据暴力匹配算法，当不匹配的时候，需要将文本串的`i`指针从刚开始进行匹配的地方往后移一位，也就是`i = 1`的位置；而模式串则应该回退到最开始的位置，也就是`j = 0`的位置，然后开始下一轮的匹配。可是KMP算法不需要动`i`指针，也不需要将`j`指针回到开始位置，只需要让`j`回退到模式串中从`0`到`j - 1`的子串的最长相等前后缀的长度作为下标的位置。上图中即让`j`回退到`b`的位置，因为`aabaa`的最长相等前后缀长度为`2`，因此`j`直接回退到索引为`2`的模式串位置开始匹配就好，然后继续`i`跟`j`的匹配。注意`i`并没有动，动的只是`j`。下一轮比较如下图：

![7F8D959A0A7A9F93368FE22F9D6A40A1.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/7F8D959A0A7A9F93368FE22F9D6A40A1.png)

此时问题来了，为什么i可以不用回退，`j`也不用回到模式串的起始位置，而是可以这样开始匹配，你怎么就知道中间跳过的那些例子就一定匹配不上了呢？也就是说为什么可以不用像暴力解法那样一格一格的移动模式串来进行匹配了呢？

因为当我匹配到b≠f的时候，我已经知道在`f`之前的模式串子串是`aabaa`了，而且主串中`b`前面的元素也一定是`aabaa`（否则我不可能匹配到模式串f的位置才发现失配），也就是说失配位置的前面的子串是一样的。由此如果我们只向右移动一格模式串来与主串进行匹配的话，其实也就是再用`aabaa`的前四个字符和后四个字符进行匹配（也就是将长度为`4`的前后缀进行匹配），而这是不可能匹配成功的。为什么？很简单，因为如果匹配成功，说明`aabaa`的最长相等前后缀长度应该是`4`而不是前面算出来的`2`，这里就出现了矛盾。见下图：

![30B08947DBD34C047A464FD0ED0EB756.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/30B08947DBD34C047A464FD0ED0EB756.png)

同理，即使再把模式串往后移动一位的这个例子也不需要匹配了，因为这就相当于将`aabaa`的前三个字符和`aabaa`的后三个字符进行比较，而比较结果一定为`false`，理由同上，`aabaa`的最长相等前后缀长度是`2`而不是`3`。综上，只需要直接跳到最长相等前后缀的位置开始比较就可以了，中间那些是不可能匹配的。**这里关键就在于一旦主串和模式串失配，那么从失配位置（不包含失配位置）之前的子串，主串和模式串是相同的！**请看代码随想录中的解释：

**下标5之前这部分的字符串（也就是字符串`aabaa`）的最长相等的前缀 和 后缀字符串是 子字符串aa ，因为找到了最长相等的前缀和后缀，匹配失败的位置是后缀子串的后面，那么我们找到与其相同的前缀的后面重新匹配就可以了。**

接下来来看如何建立模式串的`next`数组，这个数组中`next[i]` 指的是模式串前`i`个字符组成的子串（包括`i`位置）的最长相等前后缀的长度，如下：

![image.png](28%20%E5%AE%9E%E7%8E%B0%20strStr()/image%202.png)

可以看到模式串第4个`a`的前缀表的值`next[4] = 2`，也就是说`aabaa`的最长相等前后缀的长度为`2`（也就是`aa`）。下面直接看求`next`数组的代码：

```
public void getNext(int[] next, String needle){
    int j = 0; 
    next[0] = 0;
    for(int i = 1; i < needle.length(); i++){
        while(j > 0 && needle.charAt(i) != needle.charAt(j)){
            j = next[j - 1];
        }
        if(needle.charAt(i) == needle.charAt(j)){
            j++;
        }
        next[i] = j;
    }
}
```

首先变量`j`有两重含义：1.指向前缀末尾的位置；2.`i`之前的模式串子串（包括`i`）的最长相等前后缀的长度。`next[0]`初始化为`0`，表明模式串第一个元素的最长相等前后缀的长度是`0`（前后缀不包括自身）。然后进入`for`循环，`i`指向后缀末尾的位置，因为要拿`i`和`j`位置的字符作比较，因此`i`初始化为`1`而不是`0`。接下来分别处理两种情况：1.`i`和`j`位置的字符不相等；2.`i`和`j`位置的字符不相等。

首先处理第一种情况。进入`while`循环，发现为什么`j`要大于`0`？因为循环体中出现了`j-1`，如果`j=0`的话会导致`next`数组越界。当`i`和`j`位置的字符不相等的时候，`j`是需要不断地回溯的（因此是`while`循环而不是`if`），直到找到相等的字符。为什么要不断回溯呢？首先要知道`next[j - 1]`是什么意思。`next[j - 1]`指的是`j`之前的字符组成的子串（不包含j位置那个字符）的最长前缀的末尾位置下标的后一个位置，也就是说既然`i`位置的字符和`j`位置的字符不相等，说明你这个后缀和`0-j`这个前缀不相等，说明你`i`位置不可能填`j`，但是你`i`位置是要放`0-i`这个串最大相等前后缀的长度的，那我的`j`就帮你去看看你是否和`0-(j-1)`这个子串的最长前缀的末尾位置相等。而这个位置信息我之前是已经算出来了的，也就是`next[j-1]`（有点动规那味）。

接着处理第二种相等的情况。找到相等的字符之后，需要将`j++`，此时`++`后的`j`表示的是`0-i`（含`i`）的子串的最长相等前后缀的长度，也就是`0-i`（含`i`）的子串的最长相等前后缀的末尾位置索引的下一个位置（此时循环还未结束，因此`i`还未`++`，所以说是`0-i`）。最后`i++`，指向`0-(i-1)`的最长后缀的下一个位置，此时可以发现`i`和`j`都指向了将要比较的位置（也就是前后缀的后一个位置，这个位置还没有开始比较，留给下一轮比）。至此`next`数组求解结束！

下面看完整的代码 ：

```java
class Solution {
    public int strStr(String haystack, String needle) {
        if(needle.length() == 0){
            return 0;
        }
        int[] next = new int[needle.length()];
        getNext(next, needle);

        int j = 0;
        // KMP关键位置开始
        for(int i = 0; i < haystack.length(); i++){ //i是不需要回溯的
		        // 下面的while循环和if似乎和getNext函数中是一样的
		        // 只不过这里的i从0开始，而且这里是用haystack和needle比较
            while(j > 0 && haystack.charAt(i) != needle.charAt(j)){
                j = next[j - 1]; //不等，则j回溯，从j位置开始比较
            }
            if(haystack.charAt(i) == needle.charAt(j)){
                j++;
            }
            if(j == needle.length()){ // 比较到模式串的末尾，说明有匹配的串
                return i - needle.length() + 1;
            }
        }
        return -1;
    }

		//获取next数组
    public void getNext(int[] next, String needle){
        int j = 0;
        next[0] = 0;
        for(int i = 1; i < needle.length(); i++){
            while(j > 0 && needle.charAt(i) != needle.charAt(j)){
                j = next[j - 1];
            }
            if(needle.charAt(i) == needle.charAt(j)){
                j++;
            }
            next[i] = j;
        }
    }
}
```
