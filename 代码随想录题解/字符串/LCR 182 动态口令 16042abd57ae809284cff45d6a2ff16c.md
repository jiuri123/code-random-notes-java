# LCR 182. 动态口令

[https://leetcode.cn/problems/zuo-xuan-zhuan-zi-fu-chuan-lcof/description/](https://leetcode.cn/problems/zuo-xuan-zhuan-zi-fu-chuan-lcof/description/)

本题比较简单，主要是将一个字符串的前n个字符不更改顺序整体交换到字符串的末尾。Java和Python直接用切片法就好，而C++可以来点骚的，就是三次翻转法，就是先反转前半部分，再反转后半部分，最后再来一个整体反转，但是用Java的string实现不了，只能先转成char[]数组，本题就不再介绍，主要介绍一下几种方法。Java语言代码如下：

方法一：字符串切片

```java
class Solution {
    public String dynamicPassword(String password, int target) {
        String newPassword = password.substring(target) + password.substring(0, target);
        return newPassword;
    }
}
```

方法二：列表遍历切片。若面试规定不允许使用方法一的**切片函数** ，则使用此方法。

```
class Solution {
    public String dynamicPassword(String password, int target) {
        StringBuilder res = new StringBuilder();
        for(int i = target; i < password.length(); i++)
            res.append(password.charAt(i));
        for(int i = 0; i < target; i++)
            res.append(password.charAt(i));
        return res.toString();
    }
}
```

方法三：字符串遍历切片。若规定 Java 只能用 String ，则使用此方法。

```java
class Solution {
    public String dynamicPassword(String password, int target) {
        String res = "";
        for(int i = target; i < password.length(); i++)
            res += password.charAt(i);
        for(int i = 0; i < target; i++)
            res += password.charAt(i);
        return res;
    }
}
```
