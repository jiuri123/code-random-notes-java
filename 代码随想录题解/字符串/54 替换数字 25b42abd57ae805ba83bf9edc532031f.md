# 54. 替换数字

直接用StringBuilder，然后遍历原字符串，遇到数字就在末尾接number，否则就在末尾接上自己。代码如下：

```
// 方法一
import java.util.Scanner;

public class Main{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        String inputStr = sc.nextLine();
        StringBuilder sb = new StringBuilder();

        char[] charArray = inputStr.toCharArray();
        for(int i = 0; i < inputStr.length(); i++){
            if(charArray[i] >= '0' && charArray[i] <= '9'){
                sb.append("number");
            }else{
                sb.append(inputStr.charAt(i));
            }
        }
        System.out.println(sb);
    }
}

// 方法一的优化版
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String inputStr = sc.nextLine();
        StringBuilder sb = new StringBuilder();

        // 使用 for-each 循环遍历字符，代码更简洁
        for (char c : inputStr.toCharArray()) {
            // 使用 Character.isDigit() 判断，意图更明确
            if (Character.isDigit(c)) {
                sb.append("number");
            } else {
                sb.append(c);
            }
        }
        System.out.println(sb);
    }
}
```

也可以直接使用正则表达式：

![image.png](54%20%E6%9B%BF%E6%8D%A2%E6%95%B0%E5%AD%97/image%201.png)

```
// 方法三：使用正则表达式
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String inputStr = sc.nextLine();
        
        // 使用正则表达式 "\\d" 匹配所有数字，并替换为 "number"
        String result = inputStr.replaceAll("\\d", "number");
        
        System.out.println(result);
    }
}
```
