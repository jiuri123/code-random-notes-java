# LCR 122. 路径加密

[https://leetcode.cn/problems/ti-huan-kong-ge-lcof/description/](https://leetcode.cn/problems/ti-huan-kong-ge-lcof/description/)

没啥搞头，转换成字符数组然后遍历即可，代码如下：

```java
// 方法一
class Solution {
    public String pathEncryption(String path) {
        char[] charArray = path.toCharArray();
        for(int i = 0; i < path.length(); i++){
            if(charArray[i] == '.'){
                charArray[i] = ' ';
            }
        }
        return new String(charArray);
    }
}
```

当然也可以直接用String的replace方法，但是不建议，因为这道题的目的就是让你实现replace方法：

```java
// 方法二：不建议，因为这道题的目的就是让你实现replace方法
class Solution {
    public String pathEncryption(String path) {
        return path.replace('.', ' ');
    }
}
```

               myCharArray[i] = ' ';

原因就是搞混了`StringBuilder`的`toString`方法，哈哈哈^_^
