# 1143. 最长公共子序列（含子序列/子数组类总结）

![image.png](1143%20%E6%9C%80%E9%95%BF%E5%85%AC%E5%85%B1%E5%AD%90%E5%BA%8F%E5%88%97%EF%BC%88%E5%90%AB%E5%AD%90%E5%BA%8F%E5%88%97%20%E5%AD%90%E6%95%B0%E7%BB%84%E7%B1%BB%E6%80%BB%E7%BB%93%EF%BC%89/image.png)

有了上题的基础，这题就迎刃而解了，因为上题的子数组要求必须连续，但是本题求的最长公共子序列，可以**不连续**，但要保持相对顺序。下面进行动规五部曲分析。

首先是`dp`数组的定义，`dp[i][j]`定义为`text1` 的前 `i` 个字符 (`text1[0...i-1]`) 与 `text2` 的前 `j` 个字符 (`text2[0...j-1]`) 的最长公共子序列的长度。注意与之前的三道题的dp定义的区别，这里并没有严格规定将`dp[i][j]`的定义成以 `text1[i-1]` 结尾且以 `text2[j-1]` 结尾的最长公共子序列的长度。也就是说最长公共子序列结尾的那个元素并不要求一定得是两个字符串的结尾的那个元素了，即我们不需要记录结尾的信息。原因有两个，第一个原因就是本题并不要求**连续性**，因此我们不需要保留了“局部连续性”的信息。第二个原因就是本题不要求**比较性**，即本题并不需要将当前位置的元素和之前的序列中的最后一个位置的元素进行比较，因此我们也不需要记录已有的序列中的最后一个元素的位置信息，即不需要将“结尾位置”作为状态定义的一部分。下面举例分析：

1. 当 `text1.charAt(i - 1) == text2.charAt(j - 1)` 时，那么这个字符**必然可以**被包含在最长公共子序列中。我们只需要找到 `text1` 的前 `i-1` 个字符和 `text2` 的前 `j-1` 个字符的最长公共子序列，然后把这个新发现的公共字符加上去即可。根据我们的定义，`text1[0...i-2]` 和 `text2[0...j-2]` 的最长公共子序列长度就是 `dp[i-1][j-1]`。所以，状态转移方程是：`dp[i][j] = dp[i-1][j-1] + 1`。
2. 当 `text1.charAt(i - 1) != text2.charAt(j - 1)` 时，由于子序列**可以不连续**，最后一个字符不相等并**不意味着失败**。我们只是不能同时使用 `text1[i-1]` 和 `text2[j-1]` 而已。此时的最长公共子序列，要么是 `text1` 的前 `i` 个字符和 `text2` 的前 `j-1` 个字符的公共子序列（相当于扔掉 `text2[j-1]`），要么是 `text1` 的前 `i-1` 个字符和 `text2` 的前 `j` 个字符的公共子序列（相当于扔掉 `text1[i-1]`）。我们取这两种情况中较好的那一个：
    1. `text1[0...i-1]` 和 `text2[0...j-2]` 的最长公共子序列长度是 `dp[i][j-1]`。
    2. `text1[0...i-2]` 和 `text2[0...j-1]` 的最长公共子序列长度是 `dp[i-1][j]`。
    
    所以，状态转移方程是：`dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1])`。
    

总的来说，就是“最长公共子序列”不要求连续，也不要求进行比较，所以不必采用“以...结尾”的定义方式，也不需要一个全局变量 `res` 来记录历史中出现过的峰值。整体代码如下：

```
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();
        
        // 创建 dp 数组，多出一行一列作为初始边界（值为0）
        int[][] dp = new int[m + 1][n + 1];
        
        // 将字符串转为字符数组，可以略微提高在某些 OJ 上的访问速度
        char[] char1 = text1.toCharArray();
        char[] char2 = text2.toCharArray();
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 如果当前字符匹配
                if (char1[i - 1] == char2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 如果不匹配，取左边或上边的最大值
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        
        // 最终结果存储在右下角
        return dp[m][n];
    }
}
```

| --- | --- | --- | --- | --- |
| 最长连续递增子序列 (LCIS) | 连续，需比较（递增） | 一维 (1D) | 以 i **结尾**的最长长度 | max(所有 dp[i]) |
| 最长递增子序列 (LIS) | 不连续，需比较（递增） | 一维 (1D) | 以 i **结尾**的最长长度 | max(所有 dp[i]) |
| 最长公共子数组(Longest Common Subarray) | 连续，不需比较 | 二维 (2D) | 以 (i, j) **结尾**的最长长度 | max(所有 dp[i][j]) |
| 最长公共子序列 (LCS) | 不连续，且不需比较 | 二维 (2D) | 在 (i, j) **范围内**的最长长度，并不要求以……结尾 | dp[m][n] (右下角) |

可以看到只要是涉及到**连续性**和**比较性**两个问题中的其中一个，就必须将dp定义成以……结尾，只有两个问题都不符合，才不需要这么定义。这就是这四道题带给我的最大的收获！明天加油！
