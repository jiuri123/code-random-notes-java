# 416. 分割等和子集

[https://leetcode.cn/problems/partition-equal-subset-sum/description/](https://leetcode.cn/problems/partition-equal-subset-sum/description/)

既然是求两个子集的和相等，那么我可以只关注一个子集，此时只需要选取数组中的某些数，使得这个子集的和为原数组中所有元素的总和的一半就好了，剩下的元素自然就放去另外一个子集，且和也刚好为原数组中所有元素的总和的一半。假设数组所有元素总和为`sum`，那么问题可以转换为背包问题：是否能从数组中选取一些元素（元素就是表示物品，他们的值表示的就是重量），其重量和刚好为所有物品总重量的一半。

由此思路可以衍生出两种方法。第一种方法，是力扣官方给的题解，感觉比较好理解。首先定义`dp[i][j]`数组表示任意搭配选取前`i`个物品（包括`i`），其重量是否能恰好等于`j`。也就是说这些物品的重量是否能刚好装满背包。注意此时`dp[i][j]`要么是`false`，表示不能刚好装满背包；要么是`true`，表示存在这么一个物品组合，使得刚好能装满背包。然后对`dp`数组进行初始化，第一列的值肯定都是`true`，因为此时`j`的值为`0`，表示背包重量为`0`，那么我可以不选物品，此时重量就刚好是`0`，所以是始终存在这么一个物品组合的。同时第一行的`dp[0][nums[0]]`也可以初始化为`true`，因为`i`为`0`，表示此时只能放物品0，那么背包重量为`nums[0]`时可以刚好将物品`0`放进去，因此为`true`。

初始化完成之后，开始正式的二维数组的动态规划。当当前物品的重量大于背包的重量时，此时肯定是不能选这个物品的，那么直接`dp[i][j] = dp[i - 1][j];`就好了。但如果当前物品的重量小于等于背包的重量时，我们此时有两个选择：要么是选当前的物品，此时为`dp[i - 1][j - num]`；要么是不选当前的物品，需要此时为`dp[i - 1][j]`。这两个情况只要有一个为`true`，那么`dp[i][j]`就一定为`true`，所以最后的dp数组为`dp[i][j] = dp[i - 1][j] | dp[i - 1][j - num];`，注意这里是用`|`来连接两个公式。总的代码如下：

```java
// 方法一：二维boolean解法
class Solution {
    public boolean canPartition(int[] nums) {
        int len = nums.length;
        if(len == 1){ // 如果集合只有一个元素
            return false;
        }

        int sum = 0;
        int maxNum = 0;
        for(int i = 0; i < len; i++){
            sum += nums[i];
            maxNum = Math.max(nums[i], maxNum);
        }
        if(sum % 2 == 1){ // 如果所有元素的和是奇数
            return false;
        }
        int target = sum / 2; // 将总和除以二，就是我的背包容量
        if(maxNum > target){ 
		        // 如果最大元素比总和一半还要大，直接返回false
		        // 因为不管这个最大元素放去哪个子集，都不可能符合答案所要求的条件
            return false;
        }

        boolean[][] dp = new boolean[len][target + 1];
        // dp数组初始化
        for(int i = 0; i < len; i++){
            dp[i][0] = true; // 初始化第一列
        }
        dp[0][nums[0]] = true; // 初始化第一行

        // 开始二维动态规划
        for(int i = 1; i < len; i++){
            int num = nums[i];
            for(int j = 1; j <= target; j++){
                if(num <= j){ // 当前物品的重量小于等于背包的重量时
                    dp[i][j] = dp[i - 1][j] | dp[i - 1][j - num];
                }else{ // 当前物品的重量大于背包的重量时
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }
        return dp[len - 1][target];
    }
}

```

为了节省空间，可以将二维数组压缩为一维数组，此时行的概念消失了（可以想象原二维数组往列方向进行收缩，变成了一行），此时的`dp[j]`表示是否可以从数组中选出一些数字（可以是空集），它们的和正好为 `j`。代码如下：

```java
// 方法一的空间改进版（二维改一维）
class Solution {
    public boolean canPartition(int[] nums) {
        // 1. 基础判断
        if (nums == null || nums.length < 2) return false;
        
        int sum = 0;
        int maxNum = 0;
        for (int num : nums) {
            sum += num;
            maxNum = Math.max(maxNum, num);
        }
        
        // 如果总和是奇数，无法平分
        if (sum % 2 != 0) return false;
        
        int target = sum / 2;
        
        // 如果最大值已经超过了目标值，也无法平分
        if (maxNum > target) return false;
        
        // 2. 动态规划：dp[j] 表示是否能凑出和为 j
        boolean[] dp = new boolean[target + 1];
        
        // 基础情况：和为 0 总是可以实现的（什么都不选）
        dp[0] = true;
        
        // 3. 遍历每个数字
        for (int num : nums) {
            // 注意：必须从后往前遍历，防止同一个数字被重复使用（0/1背包的核心）
            for (int j = target; j >= num; j--) {
                if (dp[target]) return true; // 提前剪枝：如果已经找到了目标值，直接返回
                dp[j] = dp[j] || dp[j - num];
            }
        }
        
        return dp[target];
    }
}
```

注意两点：

1. 内循环还是从大到小，否则使用的是更新后的值来更新当前位置，具体原因已在[‣](https://app.notion.com/p/20142abd57ae80438602e78ee8d159e0?pvs=21) 解释过（只要心中始终有一个一维数组画在二维数组上的这么一个图就不难理解）；
2. `dp`数组初始化可以是`dp[0] = true;`，也可以是`dp[nums[0]] = true;`。但是第一种初始化更加符合逻辑，因为dp[0]表示的是是否可以从数组中选出一些数字（可以是空集），它们的和正好为0，此时一定是成立的。但是`dp[nums[0]] = true;`就有点莫名其妙了，我的想法可能是相当于对二维数组中的第一行的值进行了初始化，其实提交后也是可以过的。

下面是第二种方法，也是代码随想录使用的方法。思路大概是**将物品的重量就视为价值，1重量就对应1价值**，也就是说物品越重，价值越大，**所以此时放进背包中的物品总价值永远不可能超过背包的容量（关键点！！！）。**所以既然要我求是否存在任意的物品组合，使得物品的总重量恰好等于背包的重量（其实就是求这些物品的总价值是否恰好等于背包的重量），那我就求**在某种背包容量的情况下的物品的最大的价值**，也就是说尽可能使得背包中物品的价值尽可能的大，这样我才有可能知道是否有这样一种物品组合，这种组合的物品的总价值等于背包的重量。所以就将本题变成了01背包的问题，只不过这里每种物品的单位价值都是1。所以可以定义`dp`数组的定义：`dp[j]`就表示背包容量为`j`的情况下，任选一些物品使得背包的最大价值为`dp[j]`。如果最后求得`dp[sum / 2] == sum / 2`，那么就说明是存在这么一种物品的组合，其放入背包之后的总价值（重量）刚好是等于背包的容量的，也就是等于原数组中所有元素的总和的一半。代码如下：

```java
// 方法二：随想录-01背包法
class Solution {
    public boolean canPartition(int[] nums) {
        int len = nums.length;
        if(len == 1){ // 如果集合只有一个元素
            return false;
        }

        int sum = 0;
        int maxNum = 0;
        for(int i = 0; i < len; i++){
            sum += nums[i];
            maxNum = Math.max(nums[i], maxNum);
        }
        if(sum % 2 == 1){ // 如果所有元素的和是奇数
            return false;
        }
        int target = sum / 2; // 总和除以二就是我的背包容量
        if(maxNum > target){ // 如果最大元素比总和一半还要大
            return false;
        }
        // 以上的初始判断与方法一中是一样的

        int[] dp = new int[target + 1];
        for(int i = 0; i < len; i++){
            for(int j = target; j >= nums[i]; j--){
                dp[j] = Math.max(dp[j], dp[j - nums[i]] + nums[i]);
            }
        }

        if(dp[target] == target) return true;
        return false;
    }
}
```

其实关键就在于我要使得背包中价值尽可能的大，使得背包中物品的总价值尽可能的接近背包的重量，这样我才有可能找到是否有符合条件的物品组合。而本解法妙就妙在将所有物品的单位价值置为了1，因为利用了我要找物品总价值恰好等于背包重量这个需求。
