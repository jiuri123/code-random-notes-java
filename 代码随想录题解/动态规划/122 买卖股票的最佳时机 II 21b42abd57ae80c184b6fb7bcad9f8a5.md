# 122. 买卖股票的最佳时机 II

[https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/description/](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/description/)

与上一题[**121. 买卖股票的最佳时机**](121%20%E4%B9%B0%E5%8D%96%E8%82%A1%E7%A5%A8%E7%9A%84%E6%9C%80%E4%BD%B3%E6%97%B6%E6%9C%BA%2021842abd57ae80c1a96fc5dde827f2a7.md) 的区别在于我不仅限于只买卖一次了，而是可以**多买多卖**，所以dp数组的推导上面会有些微变化。因为可以多买多卖多次，所以对于今天结束的时候，假如我手上是持有股票的，此时我手上拥有的现金可以从两个前提条件来推得：一个是昨天结束的时候就持有股票，今天继续持有，没有变化，这与上一题是一样的；另一个是昨天结束的时候没有持有股票，今天结束的时候持有的股票是今天才买的，但是因为可以多买多卖，所以昨天结束的时候我是可以有现金在手上的（这些现金是昨天及昨天赚来的），所以今天结束的时候我手上的现金是需要加上昨天结束的时候手上的现金的。所以总的dp推导公式如下：

```java
dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
// 下面这句代码是与 121. 买卖股票的最佳时机 唯一不同的地方
dp[i][1] = Math.max(dp[i - 1][1], dp[i - 1][0] - prices[i]);
```

再来对比一下上一题的dp推导公式：

```java
dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
// 下面这句代码是与 121. 买卖股票的最佳时机 唯一不同的地方
dp[i][1] = Math.max(dp[i - 1][1], -prices[i]);
```

可以发现区别就在于第二句代码，也就是说假如我今天结束的时候持有股票，那么我手上的现金需要加上之前赚取到的利润，也就是`dp[i - 1][0]`。那为什么上题不用加呢？因为上题只允许买一次和卖一次（卖了之后游戏直接结束，后面不可以参与），也就是说我之前不持有的话，那我之前的利润一定是0，无法累加利润，这就是这题和上题的区别所在。总的代码如下：

```java
// 方法一：二维dp
class Solution {
    public int maxProfit(int[] prices) {
        int len = prices.length;
        int[][] dp = new int[len][2];
        dp[0][0] = 0;
        dp[0][1] = -prices[0];

        for(int i = 1; i < len; i++){
            dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
            // 下面这句代码是与 121. 买卖股票的最佳时机 唯一不同的地方
            dp[i][1] = Math.max(dp[i - 1][1], dp[i - 1][0] - prices[i]);
        }

        return dp[len - 1][0];
    }
}

// 方法二：一维dp
class Solution {
    public int maxProfit(int[] prices) {
        int len = prices.length;
        int[] dp = new int[2];
        dp[0] = 0;
        dp[1] = -prices[0];

        for(int i = 1; i < len; i++){
            dp[0] = Math.max(dp[0], dp[1] + prices[i]);
            // 下面这段代码是与 121. 买卖股票的最佳时机 唯一不同的地方
            dp[1] = Math.max(dp[1], dp[0] - prices[i]);
        }

        return dp[0];
    }
}
```
