# 72. 编辑距离

![image.png](72%20%E7%BC%96%E8%BE%91%E8%B7%9D%E7%A6%BB/image.png)

与上一题的区别仅仅在于本题不单单可以对单词进行删除操作，还可以对单词进行添加和替换操作。这里先说明一下，其实添加操作等价于删除操作，因为一个当一个单词需要增加一个字母才能与另外一个单词相等的时候，那么也就说明这另外一个单词可以通过删除一个字母来使得这两个单词相等（简单点说，就是一个单词的添加操作，相当于另外一个单词的删除操作）。例如 `word1 = "ad" ，word2 = "a"`，`word1`删除元素`'d'` 和 `word2`添加一个元素`'d'`，变成`word1="a", word2="ad"`， 最终的操作数是一样！本题说通过对`word1`进行增删改操作，将`word1` 转换成 `word2`，似乎规定只能对`word1`进行操作。但是通过上面的分析，对一个单词的添加操作，相当于另外一个单词的删除操作，那么我对`word1`的增加、删除或者替换操作，不就相当于对`word2`的删除、增加或者替换操作吗？因此看似题目只允许你对`word1`进行操作，但是事实上等价于对两个单词都可以进行操作，因此题目也等价于：给出两个单词，返回使得两个单词相等的最少操作数（不严格要求只对其中一个单词进行操作）。知道这点后，本来只允许对`word1`进行增删换的操作，现在我统一为对`word1`进行删除操作，对`word2`进行删除操作，以及对二者进行替换操作（注意这里操作的对象都是针对单词的最后那一位，也就是正在比较的那一位）。其实就是将对`word1`的增加操作改为对`word2`进行删除操作，方便后续dp数组的推导。

接下来按照动规五部曲进行分析。首先定义dp数组的含义：**dp[i][j] 表示将字符串word1[0~i-1]转换成字符串word2[0~j-1]，最近编辑距离为`dp[i][j]`**。定义成**以i-1和j-1结尾**主要还是为了初始化的方便，之前的题目中也提到过这种增加虚拟行的手法。

接下来就是`dp`公式的推导。对于`word1[i - 1] == word2[j - 1]`的情况，说明这个位置不用做什么操作，因为已经相同。我们只需要对除这个位置之外的其他地方进行操作增删改的操作就好了，因此`dp[i][j] = dp[i - 1][j - 1];`。也就是说两个单词除最后那个位置的字符不用动，对剩下的位置进行编辑后，剩下的位置相等了，最后在补上最后那个位置的字符，这个编辑的次数就是dp[i][j]的值。

而对于`word1[i - 1] != word2[j - 1]`的情况，此时就需要进行编辑操作了。上面已经分析过，此时我只有三种操作：1.对`word1`删；2.对`word2`删（从对`word1`增转换而来）；3.替换。还是要提一下这个的三种操作都是针对新进来的那一位（前面也说到过）。下面分析这三种操作的dp递推公式：

1. 对`word1`的最后一位进行删除操作。那么就是以下标`i - 2`为结尾的`word1` 与`j-1`为结尾的`word2`的最近编辑距离，再加上一个**删除**最后一位的操作，此时修改后的两个单词就相同了。即`dp[i][j] = dp[i - 1][j] + 1;`。
2. 对`word2`的最后一位进行删除操作。那么就是以下标`i - 1`为结尾的`word1`与`j-2`为结尾的`word2`的最近编辑距离，再加上一个**删除**最后一位的操作，此时修改后的两个单词就相同了。即 `dp[i][j] = dp[i][j - 1] + 1;`。
3. 对两者的最后一位进行替换（至于将哪个单词的最后一位替换成另外一个单词的最后一位，不重要，随便选一个就行，反正替换后最后一位都相等）。那么就是以下标`i - 2`为结尾的`word1`与`j-2`为结尾的`word2`的最近编辑距离，再加上一个**替换**最后一位的操作，此时修改后的两个单词就相同了。

然后去取述三个操作的最小值，就是`dp[i][j]`的值。整体dp递推公式如下：

```java
if(word1.charAt(i - 1) == word2.charAt(j - 1)){
    dp[i][j] = dp[i - 1][j - 1];
}else{
    dp[i][j] = Math.min(dp[i - 1][j - 1], dp[i][j - 1]);
    dp[i][j] = Math.min(dp[i][j], dp[i - 1][j]) + 1;
}
```

接下来是初始化工作，参考[**115. 不同的子序列**](115%20%E4%B8%8D%E5%90%8C%E7%9A%84%E5%AD%90%E5%BA%8F%E5%88%97%2022642abd57ae80069645fb67d0e0f29d.md) 对初始化的解释。后面遍历顺序和举例省略。整体的代码如下：

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int len1 = word1.length();
        int len2 = word2.length();

        // 将字符串转为字符数组，方便后续按位比较
        char[] charArr1 = word1.toCharArray();
        char[] charArr2 = word2.toCharArray();
        
        // 1. 创建 DP 表
        // dp[i][j] 表示：word1 前 i 个字符 转换成 word2 前 j 个字符 的最小操作数
        int[][] dp = new int[len1 + 1][len2 + 1];

        // 2. 初始化边界：
        // 当 word2 为空时，word1 前 i 个字符全部删除，需要 i 步
        for(int i = 1 ; i <= len1; i++) dp[i][0] = i;
        // 当 word1 为空时，插入 word2 前 i 个字符，需要 i 步
        for(int i = 1 ; i <= len2; i++) dp[0][i] = i;

        // 3. 填充 DP 表
        for(int i = 1; i <= len1; i++){ // i 遍历 word1 的每个字符
            for(int j = 1; j <= len2; j++){ // j 遍历 word2 的每个字符
                if(charArr1[i - 1] != charArr2[j - 1]){
                    // 字符不同：取 替换、删除、插入 三种操作的最小值 + 1
                    // dp[i-1][j-1]：替换 word1（或 Word2） 当前字符
                    // dp[i-1][j]：删除 word1 当前字符
                    // dp[i][j-1]：删除 word2 当前字符（由对 word1 增转换而来）
                    dp[i][j] = Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));
                    dp[i][j] += 1;
                }else{
                    // 如果当前字符相等，不增加操作步数
                    dp[i][j] = dp[i - 1][j - 1];
                }
            }
        }

        // dp[len1][len2] 就是两个完整字符串的最小编辑距离
        return dp[len1][len2];
    }
}
```
