# 1035. 不相交的线

![image.png](1035%20%E4%B8%8D%E7%9B%B8%E4%BA%A4%E7%9A%84%E7%BA%BF/image.png)

要求连线不能相交，而且每个数字只能属于一条连线，仔细想想，这不就是上一题[**1143. 最长公共子序列（含子序列/子数组类总结）**](1143%20%E6%9C%80%E9%95%BF%E5%85%AC%E5%85%B1%E5%AD%90%E5%BA%8F%E5%88%97%EF%BC%88%E5%90%AB%E5%AD%90%E5%BA%8F%E5%88%97%20%E5%AD%90%E6%95%B0%E7%BB%84%E7%B1%BB%E6%80%BB%E7%BB%93%EF%BC%89%2022442abd57ae80849e9eccebeb737253.md) 套了个壳吗？所以代码什么的都不用变，只需要换个变量名就好了。代码如下：

```java
class Solution {
    public int maxUncrossedLines(int[] nums1, int[] nums2) {
        int nums1Len = nums1.length;
        int nums2Len = nums2.length;
        int[][] dp = new int[nums1Len + 1][nums2Len + 1];

        for(int i = 1; i <= nums1Len; i++){
            for(int j = 1; j <= nums2Len; j++){
                if(nums1[i - 1] == nums2[j - 1]){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }else{
                    dp[i][j] = Math.max(dp[i][j - 1], dp[i - 1][j]);
                }
            }
        }
        return dp[nums1Len][nums2Len];
    }
}
```
