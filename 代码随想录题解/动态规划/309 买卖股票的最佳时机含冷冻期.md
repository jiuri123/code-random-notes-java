# 309. 买卖股票的最佳时机含冷冻期

[https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/description/](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/description/)

有两种方法，第一种方法是将一天结束的时候分成不持有股票和持有股票两个状态。对于当天结束不持有股票的状态，要么是继续继承自前一天不持有股票的状态，要么是昨天持有股票，但是今天卖掉了。因此dp递推公式为：

`dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);`

而对于当天结束持有股票的状态，来源于下面两种之前的状态：

1. 继续继承自前一天持有股票的状态；
2. 前天不持有股票，股票是今天买的。

对于第二点，为什么不可以是从昨天不持有股票，今天买股票这个状态来推导出今天持有股票这个状态？因为题目限制有冷却期，也就是说昨天结束的时候不持有股票这个状态里面，其实是包含了昨天把股票卖掉的这个状态。但是如果是昨天把股票卖掉的，那么今天就处于冷却期，也就是处于不能买入股票的状态。所以当天结束持有股票的状态只能来自于前天结束的时候不持有股票的状态，因为前天结束的时候不持有股票，说明股票是前天或者前天之前卖掉的，到了今天早就过了冷却期了，那么就可以买了。所以dp递推公式如下：`dp[i][1] = Math.max(dp[i - 1][1], dp[i - 2][0] - prices[i]);`

整体的代码如下：

```java
// 方法一，将一天结束划分成两个状态
class Solution {
    public int maxProfit(int[] prices) {
        int len = prices.length;
        if(len == 1){ // 只有一天的情况
            return 0;
        }
        int[][] dp = new int[len][2];
        
        dp[0][0] = 0; // 当天结束不持有股票
        dp[0][1] = -prices[0]; // 当天结束持有股票
        // 因为后面会用到i - 2，所以至少初始化前2天
        dp[1][0] = Math.max(dp[0][0], dp[0][1] + prices[1]);
        dp[1][1] = Math.max(dp[0][1], - prices[1]);

        for(int i = 2; i < len; i++){
            dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
            dp[i][1] = Math.max(dp[i - 1][1], dp[i - 2][0] - prices[i]);
        }

        return dp[len - 1][0];
    }
}
```

但是这种方法的缺点是初始化比较麻烦，因为要用到前天的状态，所以初始化的时候要把初始前两天的状态都给初始化（这种方法最好画一个状态转移图）。有没有一种方法可以将前天的记忆放到昨天来记忆，这样我每次推导今天的状态的时候，就只用到昨天的状态，因此初始化的时候我就只用初始化第一天的状态就好了，第二天及其之后的状态都可以通过第一天来进行推导。其实是可以的，这也就是下面介绍的方法二。

方法一每天结束的时候只记忆两种状态，导致没法记忆昨天的状态。问题就在于我每天结束的时候记的东西太少了，那我可以增加每天的记忆量，来将前天的知识也记住。从这一点出发，我可以将每天结束的时候划分成如下四个状态（记忆量由原来的2增加到4）：

1. 当天结束的时候不持有股票，股票是今天之前卖掉的（`dp[0][0]`）
2. 当天结束的时候不持有股票，股票是今天卖掉的（`dp[0][1]`）
3. 当天结束的时候持有股票，股票是今天之前买的（`dp[0][2]`）
4. 当天结束的时候持有股票，股票是今天买的（`dp[0][3]`）

这样记忆的好处就在于我记住了我的股票是昨天卖掉的，还是昨天之前卖掉的，这样我就知道今天我是否可以买股票（即是否处于冷静期）。也就是说今天的状态可以只通过昨天的状态推导得来，而不用依靠前天的状态，初始化就简单了很多。下面计算上述四种状态的dp推导公式。

对于第1种不持有股票且股票是今天之前卖掉的状态，这个状态只能是继承自昨天也是不持有的状态，但是昨天不持有这个状态也是有两种的：要么是昨天卖掉股票的（`dp[i - 1][1]`），要么是昨天之前卖掉股票的（`dp[i - 1][0]`），取这两种状态的最大值，对应的就是今天第1种状态，代码如下：

`dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1]);`

对于第2种不持有股票，股票是今天卖掉的的状态，那么说明昨天结束的时候一定是持有的，然后到今天才卖掉的。但是昨天结束的时候持有也是有两种持有状态的，这里也是需要取这两种持有状态的最大值，代码如下：

`dp[i][1] = Math.max(dp[i - 1][2] + prices[i], dp[i - 1][3] + prices[i]);`

对于第3种持有股票，股票是今天之前买的状态，那么这个股票也是继承自昨天持有的状态，也是分为两种：要么是昨天之前买的股票（`dp[i - 1][2]`），要么就是昨天买的（`dp[i - 1][3]`），也是需要取这两种状态的最大值，代码如下：

`dp[i][2] = Math.max(dp[i - 1][2], dp[i - 1][3]);`

对于第4种持有股票，股票是今天买的状态，由于冷却期的限定，来源就只能有一种了：昨天结束的时候不持有，且股票是昨天之前卖掉的（不可以是昨天卖的），也就是`dp[i - 1][0]`，所以代码为：

`dp[i][3] = dp[i - 1][0] - prices[i];`

因此整体的代码如下：

```java
// 方法二，将一天结束划分成四个状态
class Solution {
    public int maxProfit(int[] prices) {
        int len = prices.length;
        int[][] dp = new int[len][4];

        dp[0][0] = 0; // 当天结束不持有，股票今天之前卖的
        dp[0][1] = 0; // 当天结束不持有，股票今天卖的
        // 以下两种对dp[0][2]的初始化方式都对，
        // 但是初始化成Integer.MIN_VALUE比较符合逻辑
        dp[0][2] = Integer.MIN_VALUE; // 当天结束持有，股票今天之前买的
        // dp[0][2] = -prices[0];
        dp[0][3] = -prices[0]; // 当天结束持有，股票今天买的

        for(int i = 1; i < len; i++){
            dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1]);
            dp[i][1] = Math.max(dp[i - 1][2] + prices[i], dp[i - 1][3] + prices[i]);
            dp[i][2] = Math.max(dp[i - 1][2], dp[i - 1][3]);
            dp[i][3] = dp[i - 1][0] - prices[i];
        }

        return Math.max(dp[len - 1][0], dp[len - 1][1]);
    }
}
```

但是这种方法也有其缺陷，就是推导公式有点麻烦，也就是说随着每天记忆量的增加，计算量也随之增加，因此上述两种方法那个顺手就用那个，没必要纠结。
