# 647. 回文子串

![image.png](647%20%E5%9B%9E%E6%96%87%E5%AD%90%E4%B8%B2/image.png)

刚开始做这道题的时候，想着只定义一个一维的dp数组，题目问什么，我就定义什么，因此定义dp[i]为s[0~i]这个字符串中回文子串的数目。但是这样无法推导出dp数组的递推公式，因为dp[i]和dp[i-1] ，dp[i + 1] 看上去都没啥关系。所以本题不能像之前做动规问题那样，题目问什么，我dp就怎么定义。本题之所以一维dp无法解决，因为一维dp的每个值最多都只能记录结尾的信息（比如说将dp[i]定义成以i结尾的回文子串的个数），但是对于回文子串，我不仅要知道结尾的信息，还要知道开头的信息（因为我要将开头的元素和结尾新加进来的元素进行比较，才知道是不是回文子串）。这样一维dp就无法解决这个问题，只能是上二维dp。

在定义二维dp之前，我们先来看看如何判断一个回文子串。对于新加进来的元素，假如这个元素和原始序列中开头的那个元素相等，而且原始序列除去开头那个元素的剩下那个序列也是回文子串的话，那么新加进来的元素和原始序列组成的新序列就也是一个回文子串。因此可以**将dp[i][j]定义成在s中，以下标`i`开头，到下标`j`结尾的这段字符串`s[i~j]`是否是回文子串，如果是，则`dp[i][j] = true;`；如果不是，则`dp[i][j] = false;`** 。

定义好了dp[i][j]，接下来计算dp的递推公式。假设目前s[i]与s[j]不相等，那么`s[i~j]` 就一定不是回文子串了，因为开头和结尾都不一样，此时直接将dp[i][j]置为false（dp[i][j]默认就是false，因此直接跳过这一位）。

但是假设目前s[i]与s[j]相等的话，此时会出现下面三种情况：

1. i和j是相等的，也就是说`s[i~j]`是一个字符的情况，此时`s[i~j]`肯定是回文子串；
2. i和j+1是相等的，也就是说`s[i~j]`是两个字符的情况，此时`s[i~j]`也肯定是回文子串；
3. i 与 j相差大于1的时候，也就是说`s[i~j]`至少是三个或三个字符以上的情况，这种情况下，我就要看看`s[i+1~j-1]` 是不是回文子串。如果是的话，那么就直接将`s[i]`和`s[j]`分别接在`s[i+1~j-1]`的左右两边，可以组成一个新的回文子串。但如果`s[i+1~j-1]` 不是回文子串，那么`s[i~j]`自然也就不是回文子串。也就是说此时`s[i~j]`的状态是依赖于`s[i+1~j-1]`的状态的。

以上三种情况对应于dp的递推公式如下：

```java
if(s.charAt(i) == s.charAt(j)){
    if(j - i <= 1){
        dp[i][j] = true;
        res++;
    }else if(dp[i + 1][j - 1]){
        dp[i][j] = true;
        res++;
    }
}
```

按照动规五部曲，下面就是初始化的工作。因为遍历的过程中是将`dp[i][j]`设为`true`，而且也不可能刚开始就全部匹配上了，因此`dp[i][j]`初始化为`false`。

然后是遍历顺序的问题，前面说到`s[i~j]`的状态是依赖于`s[i+1~j-1]`的状态的，而`s[i+1~j-1]`位于`s[i~j]`的左下角那个位置，因此当我计算`s[i~j]`的值的时候，左下角必须是已经经过计算的。所以遍历顺序应该是从左到右，从下到上进行遍历，因此`i`从`s.size() - 1`开始遍历，到`0`结束；而`j`由定义可知一定是比`i`大的，因此`j`从`i`开始遍历，到`s.size() - 1`结束。整体代码如下：

```java
// 方法一：动态规划法
class Solution {
    public int countSubstrings(String s) {
        int sLen = s.length();
        boolean[][] dp = new boolean[sLen][sLen];

        int res = 0; // 记录回文子串的个数
        for(int i = sLen - 1; i >= 0; i--){
            for(int j = i; j < sLen; j++){
                if(s.charAt(i) == s.charAt(j)){
                    if(j - i <= 1){ // 相距的距离小于等于1
                        dp[i][j] = true;
                        res++;
                    }else if(dp[i + 1][j - 1] == true){ // 除了开头和结尾也是一个回文子串
                        dp[i][j] = true;
                        res++;
                    }
                }else{ 
                    dp[i][j] = false; // 可以省略
                }
            }
        }

        return res;
    }
}
```

本题除了用到上面的动态规划的方法，还可以用下面的双指针法。具体思路就是从左到右遍历s的每一个元素，假设目前遍历到`i`这个位置，那么此时`i`这个位置的元素可以做某些回文子串的对称中心，`i`和`i+1`的中间这个位置也可以做某些回文子串的对称中心，那么现在的问题就是这两个位置具体可以做哪些回文子串的中心。可以设置两个指针，这两个指针分别从这个对称中心的位置向左向右出发，如果两个指针对应的元素相同（且之前比较过的元素也相同），那么就说明可以组成一个回文子串；否则直接退出，去对下一个位置进行判断。整体代码如下：

```java
// 方法二：双指针法
class Solution {
    public int countSubstrings(String s) {
        int sLen = s.length();
        int res = 0;
        for(int i = 0; i < sLen; i++){
            res += Substrings(s, i, i, sLen); // 以i为回文子串的对称轴
            res += Substrings(s, i, i + 1, sLen); // 以i和i+1的中心为回文子串的对称轴
        }
        return res;
    }

    public int Substrings(String s, int i, int j, int sLen) {
        int res = 0;
        // 下面是双指针思想的主要体现：两指针分别向左向右进行比较
        while(i >= 0 && j < sLen && s.charAt(i) == s.charAt(j)){
            i--;
            j++;
            res++;
        }
        return res;
    }
}
```

双指针法相比于动规法虽然时间复杂度没变，但是空间复杂度优化了很多。
