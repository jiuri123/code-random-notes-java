# 518. 零钱兑换 II（含组合/排列总结）

[https://leetcode.cn/problems/coin-change-ii/description/](https://leetcode.cn/problems/coin-change-ii/description/)

还是比较简单的，因为每一种面额的硬币有无限个，所以就是妥妥的完全背包问题，但还是与原始的完全背包问题有些区别。因为本题求的是组合数，也就是求有多少种取硬币的方法可以凑出给出的金额，因此dp数组中的值应该表示的是组合的个数，而不是总金额（总价值）。二维dp代码如下：

```java
// 二维dp
class Solution {
    public int change(int amount, int[] coins) {
        int coinsLength = coins.length;
        int[][] dp = new int[coinsLength][amount + 1];
        for(int i = coins[0]; i <= amount; i += coins[0]){
            dp[0][i] = 1;
        }
        for(int i = 0; i < coinsLength; i++){
            dp[i][0] = 1;
        }

        for(int i = 1; i < coinsLength; i++){
            for(int j = 1; j <= amount; j++){
                if(coins[i] > j){
                    dp[i][j] = dp[i - 1][j];
                }else{
                    dp[i][j] = dp[i - 1][j] + dp[i][j - coins[i]];
                }
            }
        }

        return dp[coinsLength - 1][amount];
    }
}
```

二维dp内外循环是可以更换的，因为当前位置的值只与左边和上边有关，只要左边和上边保证有值就行。

下面是一维dp的解法：

```java
// 一维dp
class Solution {
    public int change(int amount, int[] coins) {
        int coinsLength = coins.length;
        int[] dp = new int[amount + 1];
        dp[0] = 1;

        for(int i = 0; i < coinsLength; i++){
            for(int j = 0; j <= amount; j++){
                if(coins[i] > j){
                    dp[j] = dp[j];
                }else{
                    dp[j] = dp[j] + dp[j - coins[i]];
                }
            }
        }

        return dp[amount];
    }
}
```

在原始的完全背包问题当中，一维dp内外循环是可以更换的，但是本题的一维dp是不可以的更换内外循环的位置的！为什么呢？本题不也是完全背包的问题吗？因为本题求的是**组合数。**组合与排列最大的区别就是**组合是不区分顺序的，而排列是区分顺序的**。比如：5 = 2 + 2 + 1和5 = 2 + 1 + 2，这两个是一种组合，但是对于排列来说，这两个就是两个排列（即使数相同，但位置不一样就是不同的排列）。而原始的完全背包问题中dp数组记录的是背包里的最大价值，才不管你是怎么组合怎么排列的，只要价值最大就好了，所以内外循环是可以更换的。

所以对于本题来说，**如果是外物品，内背包，求的就是组合数；而如果是外背包，内物品，求的就是排列数。**因为对于外物品，内背包的情况下，我是先定物品，然后去遍历所有的背包容量，然后再去遍历下一个物品。也就是说物品1永远比物品2先放进背包，物品2不可能先于物品1放入背包，所以背包中只会出现{1,2}的组合，而不会出现{2,1}的组合。但是对于外背包，内物品的情况下，我是先定住背包的容量，然后再去遍历所有的物品，假如在此次内循环结束后最终选择将物品2放入背包可以使得当前背包的容量价值最大，那么在下一次外循环（此时背包容量加1了）对所有物品进行遍历的内循环中，就有可能会选择物品1放入背包，使得此时背包中的物品价值最大，那么此时就会出现{2,1}的组合，也就说明这样的算法会重复计算{1,2}和{2,1}，将这两个东西区别看待，计算的是排列数。

再解释一下对于外背包，内物品的情况下为什么计算的是排列数。假如我现在更新的是dp[j]的位置，那么就会用到dp[j - weight[i]]的值，而dp[j - weight[i]]在之前的更新中是遍历过了所有的物品的，此时j - weight[i]这个容量下的背包里面有可能已经存了物品i。而此轮更新dp[j]的值也是要遍历所有的物品的，而且此轮遍历物品就是为了寻找在背包容量为新的j的情况下，选哪个物品放入背包可以使得背包里面的物品价值刚好为给出的总价值（总金额），那么此轮循环就有可能选择下标为0~i-1的物品，也就是说有可能出现{i, i-1}这样的倒序组合，说明求的就是排列数。

当然以后面试的时候不可能去想这么多，目前只要理解后记住这个结论就好了。其实也很简单，外循环遍历物品，每个物品遍历完之后就不会再去看这个物品了（外循环索引不断变大），所以背包中不会出现倒序的物品下标。而内循环遍历物品的话，每次外循环进入下一轮后，内循环都会将所有的物品重新再遍历一边，那么就有可能出现背包中的物品下标倒序的问题。

总结：

**外物品，内背包——求组合数（不同顺序是一种组合，一般比排列数少）；**

**外背包，内物品——求排列数（不同顺序是不同组合，一般比组合数多）。**
