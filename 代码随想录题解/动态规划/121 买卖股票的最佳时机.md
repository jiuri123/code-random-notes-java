# 121. 买卖股票的最佳时机

[https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/description/](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/description/)

有两种方法，一种是贪心法，比较简单，这里就不详细介绍了，直接给代码：

```java
// 贪心法
public class Solution {
    public int maxProfit(int[] prices) {
        // 边界条件处理
        if (prices == null || prices.length == 0) {
            return 0;
        }

        int minPrice = Integer.MAX_VALUE; // 初始化为最大整数，确保第一个值能更新它
        int maxProfit = 0; // 默认利润为 0               

        for (int i = 0; i < prices.length; i++) {
            if (prices[i] < minPrice) {
                // 1. 如果发现更低的价格，更新最低点
                minPrice = prices[i];
            } else if (prices[i] - minPrice > maxProfit) {
                // 2. 如果当前价格减去最低点比之前的最大利润高，更新最大利润
                maxProfit = prices[i] - minPrice;
            }
        }

        return maxProfit;
    }
}
```

第二种方法是动态规划的方法。对于一天结束的时候，我有两种状态，一种是我持有股票的状态，这只股票是今天或者今天之前的某一天买的，一直没卖；另一种是我没持有股票的状态，要么是我一直没买，要么是我之前买的，今天或者今天之前的某一天卖掉了。**由此我们可以定义二维dp数组`dp[prices.length][2]` ，`dp[i][0]`表示第`i`天结束的时候假如我没持有股票，此时手上拥有的现金为`dp[i][0]`。**这种状态可以来源于之前的两种状态：

1. 第i-1天就没持有股票，今天继续保持现状，因此昨天结束的时候现金有多少，今天结束的时候现金就有多少，即`dp[i][0] = dp[i - 1][0]`；
2. 第i-1天的时候持有股票，但是今天卖掉了，因此今天结束的时候手头上拥有的现金等于昨天结束的时候手上拥有的现金加上按照今天的股票价格卖掉股票得到的现金，即`dp[i][0] = dp[i - 1][1] + prices[i]);`。

由于题目要求可以获得的最大利润，因此第i天结束的时候手头上的现金应该等于上述两种状态的最大值，也就是`dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);`。

**对于`dp[i][1]`，则表示第i天结束的时候，假如我持有股票，此时手头上拥有的现金为`dp[i][1]`。**这种状态也可以来源于之前的两种状态：

1. 第i-1天没持有股票，这张股票是今天才买的，因此今天手头上的现金是`dp[i][1] = -prices[i]`（没错，就是负数）
2. 第i-1天就持有股票了（但不一定是第i-1天买的），今天继续持有，没有卖出，因此手头上还有的现金等于昨天结束后手头上还有的现金，即`dp[i][1] = dp[i - 1][1]`。

同样也是要取最大值，即`dp[i][1] = Math.max(dp[i - 1][1], -prices[i]);`。这样就得到了dp数组的递推公式，接下来只需要对dp数组进行初始化，就可以根据上述的递推公式推出这笔交易中可以获取的最大利润。

对于初始化，`dp[0][0]` 表示第0天不持有股票的情况下，手上的现金很明显是0，因此`dp[0][0] = 0;`。而`dp[0][1]` 则表示第0天持有股票，那唯一的可能就是当天买了股票，即`dp[0][1] = -prices[0];`。初始化之后，就可以进行dp滚动了，整体代码如下：

```java
// 动规法：二维dp
class Solution {
    public int maxProfit(int[] prices) {
        int len = prices.length;
        int[][] dp = new int[len][2];
        dp[0][0] = 0;
        dp[0][1] = -prices[0];
        for(int i = 1; i < len; i++){
            dp[i][0] = Math.max(dp[i - 1][0], dp[i - 1][1] + prices[i]);
            dp[i][1] = Math.max(dp[i - 1][1], -prices[i]);
        }
        return dp[len - 1][0];
    }
}
```

可以看到dp[i][0]和dp[i][1]的状态只跟前一天的状态有关，因此可以直接只使用一个一维dp来进行滚动遍历就可以得到结果，节省空间。代码如下：

```java
// 动规法：一维dp（来自二维dp，空间复杂度更低）
class Solution {
    public int maxProfit(int[] prices) {
        int len = prices.length;
        int[] dp = new int[2];
        dp[0] = 0;
        dp[1] = -prices[0];
        for(int i = 1; i < len; i++){
            dp[0] = Math.max(dp[0], dp[1] + prices[i]);
            dp[1] = Math.max(dp[1], -prices[i]);
        }
        return dp[0];
    }
}
```

可以看到这里的一维dp数组其实就来自于二维dp数组沿着列方向压缩后的结果。至于最后为什么返回`dp[0]`（情况下是`dp[len - 1][0]`），因为在本题的条件下，不持有股票手上剩下的现金，一定是比持有股票手上剩下的现金要多的。因为持有一定是负数，但是不持有最小也就是0而已。所以直接返回`dp[0]`即可，不需要返回`Math.max(dp[0], dp[1]);` 的比较结果（多此一举）。
