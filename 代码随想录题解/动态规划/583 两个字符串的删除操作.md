# 583. 两个字符串的删除操作

https://leetcode.cn/problems/delete-operation-for-two-strings/description/

![image.png](583%20%E4%B8%A4%E4%B8%AA%E5%AD%97%E7%AC%A6%E4%B8%B2%E7%9A%84%E5%88%A0%E9%99%A4%E6%93%8D%E4%BD%9C/image.png)

直接按照动规五部曲来进行分析。首先是`dp`递推公式，**定义`dp[i][j]`为使得word1[0~i-1]和word2[0~j-1]这两个子单词相同所需的最小步数。**那么在求dp[i][j]的时候，只可能出现下面两种情况：word1[i-1]和word2[j-1]要么相同，要么不相同，只需要求出这两种情况下的dp推导公式就好了。假设我现在要求的是`word1 = "leetcode", word2 = "etco"`，目前我已经比较到了`word1' = "leetc", word2' = "etc"`，也就是说当前的word1[i-1]和word2[j-1]都是c，即结尾相同。对于相同的这个新来的字母，我们可以不用做删除操作，直接拼接在之前经过删除之后的相同序列后面就可以了，这样就可以删除步数最小。也就是说`"leet"`和`"et"`这两个单词经过删除后得到的那个相同的序列，在这个序列后面接上c，就是`word1' = "leetc", word2' = "etc"`经过删除之后的那个相同序列。因此我只需要计算`"leet"`和`"et"`这两个单词相同所需的步数，就等于`word1' = "leetc", word2' = "etc"`这两个单词相同所需的步数。即`dp[i][j] = dp[i - 1][j - 1];`，此时也表示删除两个序列的最后相同的那位。

上面说的是相同的情况，那对于不相同的呢？假设目前我已经比较到了`word1' = "leetco", word2' = "etc"`，可以发现此时比较的最后一位已经不一样了（`o != c`）。此时我可以将使得`"leetco"`和`"et"`相同所需的最小步数和使得`"leetc"`和`"etc"`相同所需的最小步数进行比较，取最小的那个步数，然后加1，就是不相同的时候我的dp[i][j]的值。为什么可以这样呢？因为我要求的是最小的步数，因此需要将上面两种情况进行比较。上面两种情况经过删除都可以得到一个相同的序列，比如`"leetco"`和`"et"`经过删除后可以得到一个相同的序列，这个相同的序列最后还要接上一个`"etc"`最后的那个c，此时我还需要再加一步将这个c删掉，最终得到的总步数就是使得`word1' = "leetco", word2' = "etc"`相同所需的最小步数。因此dp递推公式如下：

`dp[i][j] = Math.min(dp[i][j - 1], dp[i - 1][j]) + 1;`。

接下来是初始化，增加一个虚拟行，表示的是空字符串。对于空字符串，另外的一个字符串需要删掉自己所有的字符才可以与空字符串相等，因此初始化如下（即你有多长，就删多少次）：

```java
for(int i = 1 ; i <= word1Len; i++){
    dp[i][0] = i;
}
for(int i = 1 ; i <= word2Len; i++){
    dp[0][i] = i;
}
```

最终的代码如下：

```java
// 方法一
class Solution {
    public int minDistance(String word1, String word2) {
        int word1Len = word1.length();
        int word2Len = word2.length();
        int[][] dp = new int[word1Len + 1][word2Len + 1];

        for(int i = 1 ; i <= word1Len; i++){
            dp[i][0] = i;
        }
        for(int i = 1 ; i <= word2Len; i++){
            dp[0][i] = i;
        }

        for(int i = 1; i <= word1Len; i++){
            for(int j = 1; j <= word2Len; j++){
                if(word1.charAt(i - 1) == word2.charAt(j - 1)){
                    dp[i][j] = dp[i - 1][j - 1];
                }else{
                    dp[i][j] = Math.min(dp[i][j - 1], dp[i - 1][j]) + 1;
                }
            }
        }

        return dp[word1Len][word2Len];
    }
}
```

当然本题也可以通过[**1143. 最长公共子序列（含子序列/子数组类总结）**](1143%20%E6%9C%80%E9%95%BF%E5%85%AC%E5%85%B1%E5%AD%90%E5%BA%8F%E5%88%97%EF%BC%88%E5%90%AB%E5%AD%90%E5%BA%8F%E5%88%97%20%E5%AD%90%E6%95%B0%E7%BB%84%E7%B1%BB%E6%80%BB%E7%BB%93%EF%BC%89.md) 计算出两个单词的最长公共子序列的长度，然后分别将两个单词的长度减去两个单词的最长公共子序列的长度，将两个结果相加就是需要删除的字母的长度。代码如下：

```java
// 方法二
class Solution {
    public int minDistance(String text1, String text2) {
        int text1Len = text1.length();
        int text2Len = text2.length();
        int[][] dp = new int[text1Len + 1][text2Len + 1];

        for(int i = 1; i <= text1Len; i++){
            for(int j = 1; j <= text2Len; j++){
                if(text1.charAt(i - 1) == text2.charAt(j - 1)){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }else{
                    dp[i][j] = Math.max(dp[i][j - 1], dp[i - 1][j]);
                }
            }
        }
        
        return text1Len + text2Len - dp[text1Len][text2Len] * 2; // 改动的地方
    }
}
```
