# 509. 斐波那契数（含动规五部曲总结）

[https://leetcode.cn/problems/fibonacci-number/description/](https://leetcode.cn/problems/fibonacci-number/description/)

按照代码随想录上的**动规五部曲**来分析：

1. 确定dp数组以及下标的含义
    
    dp[i] 定义为斐波那契数列中第 i 个数的数值
    
2. 确定递归公式
    
    题目已经给出，即：**dp[i] = dp[i - 1] + dp[i - 2]**
    
3. 确定dp数组初始化方式
    
    题目也已经给出，即：dp[0] = 0; dp[1] = 1;
    
4. 确定遍历顺序
    
    从递归公式可以看出，当前的dp[i]的值是依赖于前两个状态的，所以是从前往后进行遍历的
    
5. 举例推导dp数组
    
    也就是动手推导结果，然后使用IDEA将dp数组打印出来，看看两者结果是否一致
    

通过以上**动规五部曲**可以解决大部分动规的题目，本题的代码入下：

```java
// 方法一：非压缩状态的版本
class Solution {
    public int fib(int n) {
        int[] dp = new int[31];
        dp[0] = 0;
        dp[1] = 1;
        for(int i = 2; i <= n; i++){
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}

// 方法二：压缩状态的版本
class Solution {
    public int fib(int n) {
        if (n < 2) return n;
        int a = 0, b = 1, c = 0;
        for(int i = 2; i <= n; i++){
            c = a + b;
            a = b;
            b = c;
        }
        return c;
    }
}
```

可以看到我们只需要三个变量来记住当前状态和前两个状态就够了，不需要记录所有的状态，所以可以使用方法二来最大化的压缩状态，以减小空间的复杂度。
