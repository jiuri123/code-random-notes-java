# 718. 最长重复子数组

![image.png](718%20%E6%9C%80%E9%95%BF%E9%87%8D%E5%A4%8D%E5%AD%90%E6%95%B0%E7%BB%84/image.png)

链接：https://leetcode.cn/problems/maximum-length-of-repeated-subarray/description/

看到本题说的求子数组的最长长度，虽然并没有说子数组里的值在原数组中是连续的还是离散的，但是**以后见到子数组，默认就是连续的，而子序列默认就是不连续的**。既然是求连续的，那么由前面两题的分析可以大概知道我不需要对前面所有的位置进行比较，因为这样求的是离散的，我只需要与前一位的值进行比较就好了，这就是连续这个条件的限制。可以看到本题的模版题目就是[**674. 最长连续递增序列**](674%20%E6%9C%80%E9%95%BF%E8%BF%9E%E7%BB%AD%E9%80%92%E5%A2%9E%E5%BA%8F%E5%88%97%2022442abd57ae80018d07ea868fe9639a.md) ，因为这两道题都是求关于连续的问题。

由于本题是需要找两个数组中的最长子数组，那么我们可以定义一个二维数组通过动态规划来一步步的推导出最后的结果，因此可以将`dp[i][j]`定义为**在`nums1`中以下标i结尾的子数组`A`，以及在`nums2`中以下标j结尾的子数组`B`，他们的公共的最长重复子数组长度的值为`dp[i][j]`**。即`dp[i][j]` 用来记录**以 `nums1[i]` 结尾**且**以 `nums2[j]` 结尾**的公共子数组的长度。说得再简单一点，就是从`nums1[0~i]`这个子数组中取一个以`nums1[i]` ****结尾的孙子数组，再从`nums2[0~j]`这个子数组中取一个以`nums2[j]` ****结尾的孙子数组，使得取出来的这两个孙子数组**相等且长度最长**。可以看到如果`nums1[i]`和`nums2[j]`即结尾元素相等，那么取出来的这两个子数组长度至少为1；但是如果不相等，那么就没法找出相等的孙子数组（因为结尾不同），这样的孙子数组就取不出来，长度就是0。

即会出现下面两种情况：

1. 如果`nums1[i]`与`nums2[j]` ****相等，说明当前的公共子数组可以向前延伸，即以`nums1[i]`和`nums2[j]`结尾的公共子数组的长度，就等于以`nums1[i-1]`和`nums2[j-1]`结尾的公共子数组的长度加1。也就是：`dp[i][j] = dp[i - 1][j - 1] + 1;`
2. 如果`nums1[i]`与`nums2[j]` 不相等，那么以它们为结尾的公共子数组长度就是 0，所以`dp[i][j]`就直接为0。因为 Java 中 `int` 数组默认初始化为 0，所以代码里省略了 `else { dp[i][j] = 0; }`，逻辑上是存在的。

那么此时问题来了，其实这个问题在前两题提出过，就是`dp[i][j]` 为什么一定要表示成以 `nums1[i]` 和 `nums2[j]` 结尾的公共子数组的长度呢？不表示成结尾可不可以？比如将`dp[i][j]`定义成`nums1`中`0~i`的子数组和`nums2`中`0~j`的子数组，这两个子数组的中公共的 、长度最长的子数组的长度为`dp[i][j]`？答案当然是不可以，如果将 `dp[i][j]` 定义成 `nums1` 前 `i` 个元素和 `nums2` 前 `j` 个元素中的最长公共子数组的长度，我们将**无法推导出正确的状态转移方程**。原因还是前面两题提到的“**连续**”，即这种定义方式破坏了“子数组必须连续”这一特性所需的状态信息。上面提到，子数组默认是连续的，既然是连续的，那么我就要知道之前已知的子数组结尾的信息，不然在`nums1[i]`和 `nums2[j]`相等的情况下，我都不知道要将这个`nums1[i]`（或`nums2[j]`）接去哪个子数组后面，连续就更不能保证了。而且此时根据这个错误的定义，`dp[i-1][j-1]` 存储的是 `nums1[0...i-1]` 和 `nums2[0...j-1]` 这个**范围内的最长**公共子数组长度。这个最长子数组可能出现在任何地方，**并不一定是以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的**！因此，我们从 `dp[i-1][j-1]` 中**丢失了关键信息**：无法得知在 `i-1` 和 `j-1` 这个位置，是否有一个可以被“接续”的公共子数组。我们只知道一个全局的最大值，却不知道这个最大值发生的位置。而正确的定义**之所以有效，是因为它保留了“局部连续性”的信息。** 我们总能知道，在当前位置 `(i, j)` 是否可以延续上一个位置 `(i-1, j-1)` 的连续序列。

接下来是初始化的问题，对于第一行和第一列，只要是相应位置相等的，就设置为`1`，其余位置设置为`0`就好了。这里说一下我的错误解法，我之前因为误解了`dp`数组的含义，以为`dp`数组表示的这个最长重复子数组可以不以`nums1[i]`和`nums2[j]`结尾，只要在前面同时出现过就可以算做是最长重复子数组，比如`[1,2,3]`和`[1,2]`，对于`dp`数组中最右下角的值（即`dp[2][1]`），应该是2（因为同时出现了`[1,2]`），但是很明显对于本题的定义，最右下角的值应该是`0`，因为此时`[1,2,3]`是以`3`结尾的，而`[1,2]`是以`2`结尾的，因此这两个数组根本无法组成最长重复子数组，因此长度是`0`。所以我之前的错误初始化方法如下：

```java
// 错误的dp初始化
boolean flag = false;
for(int i = 0; i < len1; i++){
    if(nums1[i] == nums2[0] || flag == true){
        dp[i][0] = 1;
        flag = true;
    }
    res = Math.max(res, dp[i][0]);
}
flag = false;
for(int i = 0; i < len2; i++){
    if(nums1[0] == nums2[i] || flag == true){
        dp[0][i] = 1;
        flag = true;
    }
    res = Math.max(res, dp[0][i]);
}
```

即只要是之前出现过相同的值，那么后面的位置都直接初始化为`1`，因为我至少包含之前出现过的那个相同的值。但是很明显这种解法没有理解**以下标`i`结尾**这几个字的含义。

正确的解法如下：

```java
// 方法一，复杂解法，需要初始化dp
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int len1 = nums1.length;
        int len2 = nums2.length;
        int[][] dp = new int[len1][len2];
        int res = 0;
        
        // 正确的dp初始化
        for(int i = 0; i < len1; i++){
            if(nums1[i] == nums2[0]){
                dp[i][0] = 1;
            }
            res = Math.max(res, dp[i][0]);
        }
        for(int i = 0; i < len2; i++){
            if(nums1[0] == nums2[i]){
                dp[0][i] = 1;
            }
            res = Math.max(res, dp[0][i]);
        }

        for(int i = 1; i < len1; i++){
            for(int j = 1; j < len2; j++){
                if(nums1[i] == nums2[j]){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }else{ // 这个else可省，因为Java数组默认就是0
                    dp[0][i] = 0;
                }
                res = Math.max(res, dp[i][j]);
            }
        }
        return res;
    }
}
```

可以看到跟上一题[**674. 最长连续递增序列**](674%20%E6%9C%80%E9%95%BF%E8%BF%9E%E7%BB%AD%E9%80%92%E5%A2%9E%E5%BA%8F%E5%88%97%2022442abd57ae80018d07ea868fe9639a.md) 类似，也是需要一个`res`变量来记录最大的结果，因为最长的重复子数组不一定是以`nums[len1-1]`和`nums[len2-1]`结尾的（这个值还有可能是0）。

对与上面这种解法，可以看到初始化非常的麻烦，原因就是我`dp`定义为以i结尾且包括`i`的子数组，这种定义就导致我需要初始化第一行和第一列，不然无法推导出第一行和第一列的问题。既然这样，我可不可以在原先的第一行和第一列上面在多加一行一列，由这个一行一列来推出我原先的第一行和第一列，这样就不用进行初始化了。当然是可以的，这就是之前处理背包问题的时候提到的“虚拟行”（参考之前做过的题：[**494. 目标和（含总结）**](494%20%E7%9B%AE%E6%A0%87%E5%92%8C%EF%BC%88%E5%90%AB%E6%80%BB%E7%BB%93%EF%BC%89%2020642abd57ae80669c2de5df2d9f83d6.md) ）。虚拟行的好处就在于简化了`dp`的初始化工作，**但是`dp`数组的定义也随之改变，应该定义为在`nums1`中以下标`i-1`结尾的子数组`A`，以及在`nums2`中以下标`j-1`结尾的子数组`B`，他们的公共的最长重复子数组长度的值为`dp[i][j]`。**这样定义就导致我第一行和第一列是没有意义的，直接初始化为`0`就好，然后遍历的时候直接从`i=1`和`j=1`开始遍历，因为`dp[1][1]`表示在`nums1`中以下标`0`结尾的子数组`A`，以及在`nums2`中以下标`0`结尾的子数组`B`，他们公共的最长重复子数组的长度。整体代码如下：

```java
// 方法二，更简洁的解法，不需要初始化dp
class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int len1 = nums1.length;
        int len2 = nums2.length;
        // 增加一个虚拟行，就不需要初始化了
        int[][] dp = new int[len1 + 1][len2 + 1];
        int res = 0;

        for (int i = 1; i <= len1; i++) {
            for (int j = 1; j <= len2; j++) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                    res = Math.max(res, dp[i][j]);
                }else{ // 这个else可省，因为Java数组默认就是0
                    dp[0][i] = 0;
                }
            }
        }

        return res;
    }
}
```
