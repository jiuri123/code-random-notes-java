# 516. 最长回文子序列

![image.png](516%20%E6%9C%80%E9%95%BF%E5%9B%9E%E6%96%87%E5%AD%90%E5%BA%8F%E5%88%97/image.png)

本题看似与上题[**647. 回文子串**](647%20%E5%9B%9E%E6%96%87%E5%AD%90%E4%B8%B2%2022842abd57ae8070bbcbd341fb25acc9.md) 好像一样，但是上题求的是回文子串，而本题求的是回文子序列，这两者的区别在于回文子串必须在原字符串中是连续的，但是回文子序列的每个元素在原字符串中可以是离散的。比如`"bbbab"`的一个可能的最长回文子序列为`"bbbb"`，但是最长回文子串只能是`"bbb"`，因为回文子串要保证连续。

直接按照动规五部曲来进行分析。首先定义dp数组：**dp[i][j]表示在s中，以下标`i`开头，到下标`j`结尾的这段字符串`s[i~j]`中的的最长回文子序列的长度**。至于为什么要定义成二维数组，而不定义一个一维数组，原因上题解释过。

接下来就是计算dp的递推公式，**当s[i]和s[j]不相等的时候**，此时`s[i~j]`不能组成一个回文子序列，但是不代表`s[i+1~j-1]`不存在回文子序列。而现在我要求的是最长回文子序列的长度，那么在`s[i+1~j-1]`左右分别加上s[i]和s[j]，此时是有可能使得`s[i+1~j-1]`这个字符串中的最长回文子序列的长度变长的，也就是将s[i]或者s[j]加入到这个最长回文子序列中。因此此时dp的递推公式为：

`dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);`。为什么不用与`dp[i + 1][j-1]`进行比较呢？因为`dp[i + 1][j]`或者`dp[i][j - 1]`中就已经包含了这种情况，没必要在重复计算（其实加上也可以得到正确答案）。这时不相等的情况，那**当s[i]和s[j]相等的时候**呢？此时又分为三种情况：

1. 第一种是i和j相等，那么此时的最长回文子序列的长度就是1，即`dp[i][j] = 1;`
2. 第二种是i和j+1相等，也就是i和j相差1，那么此时的最长回文子序列的长度就是2，即`dp[i][j] = 2;`
3. 第二种是i和j相差至少2个或者2个位置以上，此时我可以先去找`s[i+1~j-1]`这个字符串中的最长回文子序列，然后将s[i]和s[j]分别接在这个最长回文子序列的左右两边，使得这个最长回文子序列的长度增加2。即此时的dp递推公式为：`dp[i][j] = dp[i + 1][j - 1] + 2;`

综上，整体的dp递推公式如下：

```java
if(s.charAt(i) == s.charAt(j)){
    if(i == j){
        dp[i][j] = 1;
    }else if(j - i == 1){
        dp[i][j] = 2;
    }else{
        dp[i][j] = dp[i + 1][j - 1] + 2;
    }
}else{
    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
}
```

对于初始化工作，本题其实是需要初始化的，也就是将dp数组的每个位置都初始化为1，表示每个字符都可以与自己形成一个回文子序列，此时的长度为1。但是由于在上述的dp递推公式中有这么一句：dp[i][j] = 1;，这句就相当于是进行了初始化工作，因此通过这种dp递推公式进行计算的方法，就不需要在遍历之前进行dp数组的初始化工作了。相当于是把初始化工作融入到dp[i][j] = 1;这一句当中。

还有就是遍历方向的问题。由于计算dp[i][j]，可能需要用到dp[i + 1][j - 1]、dp[i + 1][j]和dp[i][j - 1]这三个值，也就是dp[i][j]这个位置的左下角、下边和左边这三个位置的值，因此遍历的方向也一定是从下到上，从左到右进行遍历的，否则无法计算当前位置的值。整体代码如下：

```java
class Solution {
    public int longestPalindromeSubseq(String s) {
        int sLen = s.length();
        int[][] dp = new int[sLen][sLen];

        int res = 0; // 记录最长的距离
        for(int i = sLen - 1; i >= 0; i--){
            for(int j = i; j < sLen; j++){
                if(s.charAt(i) == s.charAt(j)){ // 相等的情况
                    if(i == j){
                        dp[i][j] = 1; // 也相当于是初始化的工作
                    }else if(j - i == 1){
                        dp[i][j] = 2;
                    }else{
                        dp[i][j] = dp[i + 1][j - 1] + 2;
                    }
                }else{ // 不相等的情况
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
                res = Math.max(res, dp[i][j]);
            }
        }

        return res;
    }
}
```
