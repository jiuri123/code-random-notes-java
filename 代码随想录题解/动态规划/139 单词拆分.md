# 139. 单词拆分

[https://leetcode.cn/problems/word-break/description/](https://leetcode.cn/problems/word-break/description/)

思路是将字典作为物品，字符串作为背包，本题就是看能否用物品将背包填满，因此本质上还是背包的问题，但是与常规的背包解法还是有很大的不同。常规的背包解法就是填二维数组，填满二维数组后左下角的值就是答案（也可以填一维数组，但一维数组本质上就是二维数组转化而来的）。但是本题不能简单的用这个方法，否则怎么想都想不出来，需要换个思路来解决。

可以从最简单的解决动态规划的思路来解决此问题，也就是直接定义一个一维数组dp[i]，但是注意这个一维数组并不是背包问题中从二维数组压缩而来的一维数组，就是一个简单的一维dp数组，表示的意思是：**取给定字符串的前i个字符组成的子串，这个子串如果可以利用字典中出现的一个或多个单词拼接出来，那么dp[i]就是true；否则就是false。**

接下来就是递推公式的问题。对于dp[i]，表示的是子串0~i-1，我们可以看看子子串1：0~j-1（0<j<i）以及子子串2：j~i-1（0<j<i）是否是可以被字典里的单词拼接出来的。如果这两个子串都是可以被字典里的单词拼接出来的，那么就说明子串0~i-1也是可以被字典里的单词拼接出来的，这时候就置dp[i]为true；反之只要有一个不成立就是false。由于j可以有很多种切割方法，只要有一种切割方法合法就行，因此我们需要枚举所有可能的j。因此dp数组的递推公式如下：

```java
if(dp[j] && wordDictSet.contains(s.substring(j, i))){
    dp[i] = true;
    break;
}
```

可以看到if判断条件中用到了动态规划中存储的中间状态dp[j]，这也是动态规划的特点之一，不会重复的计算已经计算过的子问题。完整代码如下：

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        // 将 list 转为 HashSet，提高查询效率至 O(1)
        Set<String> wordSet = new HashSet<>(wordDict);

        // dp[i] 表示 s 的前 i 个字符是否可以拼接而成
        int n = s.length();
        boolean[] dp = new boolean[n + 1];

        // 初始状态：空字符串可以被拼接
        dp[0] = true;

        // 遍历s的所有前缀子串
        for(int i = 1; i <= n; i++){
            // 遍历当前前缀子串的所有前缀子串
            for(int j = 0; j < i; j++){
                // 如果前 j 个字符可被拼接，且剩余部分 [j, i) 也在字典中
                if(dp[j] && wordSet.contains(s.substring(j, i))){
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}
```

需要注意的是本题内外循环不可以改变，也就是必须要先遍历背包，再遍历物品，因为本题求的是排列。比如`s = "applepenapple", wordDict = ["apple", "pen"]`的情况，如果先遍历物品，再遍历背包，那么`apple`就不可能出现在`pen`的后面，因为遍历完物品`apple` 之后就不会再回来遍历`apple` 了（所以这里求的是组合问题）。因此只有先遍历背包，在遍历物品，才有可能出现`s`中的`penapple` 这种情况，也就是`apple`出现在了`pen`的后面。

总结：从本题也可以看出，并不是所有的背包问题都是用常规的二维数组的思路（也就是行是物品，列是背包）来解决，还可以用最简单的一维数组的思路来解决背包问题，所以不要被最常规的解法禁锢住了思路。
