# 188. 买卖股票的最佳时机 IV

[https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/description/](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/description/)

简单，就是上一题[**123. 买卖股票的最佳时机 III**](123%20%E4%B9%B0%E5%8D%96%E8%82%A1%E7%A5%A8%E7%9A%84%E6%9C%80%E4%BD%B3%E6%97%B6%E6%9C%BA%20III%2021c42abd57ae80438868e04e0daf1cd0.md) 的升级版，上一题的交易次数是2，而这一题的交易次数是k（1 <= k <= 100），但是很明显从上一题可以看出不论是初始化的时候，还是后续的dp推导的时候，都是有规律的。比如初始化的时候，只要是奇数的天，都直接初始化成`-prices[0]`，其他的都为0。那么直接用一个循环遍历来进行初始化就好了。后面的dp递推也是如此，对于奇数天要减去当天的股票价格，因为此时处于持有的状态，而对于偶数天要加上股票的价格，因为此时处于卖出的状态。整体代码如下：

```java
class Solution {
    public int maxProfit(int k, int[] prices) {
        int len = prices.length;
        int[][] dp = new int[len][2 * k + 1];
        // 循环初始化
        for(int i = 1; i < 2 * k + 1; i += 2){
            dp[0][i] = -prices[0];
        }

        for(int i = 1; i < len; i++){
            dp[i][0] = dp[i - 1][0];
            
            for(int j = 1; j < 2 * k + 1; j++){
                if(j % 2 == 1){
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - 1] - prices[i]);
                }else{
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - 1] + prices[i]);
                }
            }
        }

        return dp[len - 1][2 * k];
    }
}
```
