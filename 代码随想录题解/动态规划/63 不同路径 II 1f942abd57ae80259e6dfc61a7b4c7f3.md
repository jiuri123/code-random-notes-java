# 63. 不同路径 II

[https://leetcode.cn/problems/unique-paths-ii/description/](https://leetcode.cn/problems/unique-paths-ii/description/)

相比于上一题，这题增加了障碍，但是也不难，就是需要注意初始化的时候，障碍点及其后面的点都是无法到达的，所以需要初始化为0（直接break就好）。然后在遍历的过程中如果遇到障碍，也需要将这个点置为0，因为这个点是无法到达的，而且也无法从这个点出发到达其他的点。代码如下：

```java
class Solution {
    public int uniquePathsWithObstacles(int[][] obstacleGrid) {
        int row = obstacleGrid.length;
        int column = obstacleGrid[0].length;
        
        if(obstacleGrid[0][0] == 1){ // 如果初始点就是障碍，那么直接返回0
            return 0;
        }
        int[][] dp = new int[row][column];
        dp[0][0] = 1; // 有一种方法到达原点，那就是保持不动
        for(int i = 1; i < column; i++){ // 初始化第一行
            if(obstacleGrid[0][i] == 1){ // 遇到障碍，直接break，障碍及其后面都是0
                break;
            }else{
                dp[0][i] = 1;
            }
        }

        for(int i = 1; i < row; i++){ // 初始化第一列
            if(obstacleGrid[i][0] == 1){ // 遇到障碍，直接break，障碍及其后面都是0
                break;
            }else{
                dp[i][0] = 1;
            }
        }

        for(int i = 1; i < row; i++){
            for(int j =1; j < column; j++){
                if(obstacleGrid[i][j] == 1){ // 遇到障碍，直接置为0，因为无法到达
                    dp[i][j] = 0;
                }else{
                    dp[i][j] = dp[i][j - 1] + dp[i - 1][j];
                }
            }
        }
        return dp[row - 1][column - 1];
    }
}
```
