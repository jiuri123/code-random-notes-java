# 746. 使用最小花费爬楼梯

[https://leetcode.cn/problems/min-cost-climbing-stairs/description/](https://leetcode.cn/problems/min-cost-climbing-stairs/description/)

本题要求的是最低花费，所以大致思路是当还有一步就到达目标楼层（也就是达到目标楼层的下面两层的某一层）的时候，选择花费费用最小的那个楼层向上爬。可以使得整体的花费最小。本题中dp[i]表示的是到达第i层需要的支付的最小费用，所以推导公式为：Math.min(dp[i - 2] + cost[i - 2], dp[i - 1] + cost[i - 1])。而由于我们可以从第0层开始爬，也可以从第1层开始爬，所以dp[0]和dp[1]都初始化为0。遍历顺序自然也是从低楼层向高楼层的方向遍历。代码如下：

```java
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int len = cost.length;
        int[] dp = new int[len + 1];

        // 从下标为 0 或下标为 1 的台阶开始，因此支付费用为0
        dp[0] = 0;
        dp[1] = 0;

        for(int i = 2; i <= len; i++){
            dp[i] = Math.min(dp[i - 2] + cost[i - 2], dp[i - 1] + cost[i - 1]);
        }
        return dp[len];
    }
}
```

感觉本题其实有贪心算法的影子，因为每次都选代价最小的那个楼层向上爬，局部最优可以推出全局最优。
