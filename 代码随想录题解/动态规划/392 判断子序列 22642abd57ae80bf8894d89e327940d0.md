# 392. 判断子序列

![image.png](392%20%E5%88%A4%E6%96%AD%E5%AD%90%E5%BA%8F%E5%88%97/image.png)

这题其实就是[**1143. 最长公共子序列（含子序列/子数组类总结）**](1143%20%E6%9C%80%E9%95%BF%E5%85%AC%E5%85%B1%E5%AD%90%E5%BA%8F%E5%88%97%EF%BC%88%E5%90%AB%E5%AD%90%E5%BA%8F%E5%88%97%20%E5%AD%90%E6%95%B0%E7%BB%84%E7%B1%BB%E6%80%BB%E7%BB%93%EF%BC%89%2022442abd57ae80849e9eccebeb737253.md) 换了一种问法，因为我只需要知道这两个字符串的最长公共子序列的长度，如果这个长度等于s的长度，那么s就是一定是t的子序列，否则就不是。就这么简单，只需要在[**1143. 最长公共子序列（含子序列/子数组类总结）**](1143%20%E6%9C%80%E9%95%BF%E5%85%AC%E5%85%B1%E5%AD%90%E5%BA%8F%E5%88%97%EF%BC%88%E5%90%AB%E5%AD%90%E5%BA%8F%E5%88%97%20%E5%AD%90%E6%95%B0%E7%BB%84%E7%B1%BB%E6%80%BB%E7%BB%93%EF%BC%89%2022442abd57ae80849e9eccebeb737253.md) 这题的基础上最后在加点判断就好了。代码如下：

```java
// 方法一
class Solution {
    public boolean isSubsequence(String s, String t) {
        int sLen = s.length();
        int tLen = t.length();
        int[][] dp = new int[sLen + 1][tLen + 1];
        for(int i = 1; i <= sLen; i++){
            for(int j = 1; j <= tLen; j++){
                if(s.charAt(i - 1) == t.charAt(j - 1)){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }else{
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

				// 上面代码一样，下面的是本题的关键
        if(dp[sLen][tLen] == sLen){
            return true;
        }else{
            return false;
        }
    }
}
```

下面介绍方法二。可以看到当`s.charAt(i - 1)`不等于`t.charAt(j - 1)`时，递推公式为`dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);`。但其实这个递推公式还可以有另外一种写法，假设现在`s = "ab", t = "ababc**d**"`，`t`最后的**`d`**是新来的，此时`d`不等于`s`末尾的`b`，那么新来的`d`必不可能参与`s`这个子序列的组成，那要找到此时的`t`里面有多少个子序列`s`，只能是去除t末尾新来的`d`之外的那些位置去找子序列s，也就是去`ababc` 这里面去找`s`和`t`的公共子序列。所以当`s.charAt(i - 1)`不等于`t.charAt(j - 1)`时，递推公式还可以写成`dp[i][j] = dp[i][j - 1];`（相当于是最后一位不相等的时候，直接将t中的最后一位删除）。这就是方法二，整体代码如下：

```java
// 方法二
class Solution {
    public boolean isSubsequence(String s, String t) {
        int sLen = s.length();
        int tLen = t.length();
        int[][] dp = new int[sLen + 1][tLen + 1];
        for(int i = 1; i <= sLen; i++){
            for(int j = 1; j <= tLen; j++){
                if(s.charAt(i - 1) == t.charAt(j - 1)){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }else{
                    dp[i][j] = dp[i][j - 1]; // 与方法一的区别
                }
            }
        }

        if(dp[sLen][tLen] == sLen){
            return true;
        }else{
            return false;
        }
    }
}
```

方法二巧妙的利用了**`s` 是`t`的子序列**这一点去简化了递推公式，最终可以保证`dp[sLen][tLen]`位置得到的答案与方法一是一样的，但是`dp`数组中其他位置的值有很多是与真实的位置不符的，也就是说不符合逻辑的，这点可以去模拟一遍就知道了。
