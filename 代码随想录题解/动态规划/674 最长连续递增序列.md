# 674. 最长连续递增序列

![image.png](674%20%E6%9C%80%E9%95%BF%E8%BF%9E%E7%BB%AD%E9%80%92%E5%A2%9E%E5%BA%8F%E5%88%97/image.png)

还是比较简单的，与上一题[**300. 最长递增子序列**](300%20%E6%9C%80%E9%95%BF%E9%80%92%E5%A2%9E%E5%AD%90%E5%BA%8F%E5%88%97.md) 的区别就在于这题的子序列必须是由**连续而非跳跃**的数字组合而成，所以对于i处的`dp`值，我不需要遍历`i`之前所有的位置，只需要看`i-1`位置的值就好了。因此本题`dp[i]`定义为**以下标i结尾的连续递增子序列的长度为`dp[i]`**，与上题的`dp[i]`定义做个比较：上题的`dp[i]`定义为以下标`i`结尾的最长严格递增子序列的长度。这两个定义就在于有没有连续二字：即结尾虽然都必须是`nums[i]`，但是本题的定义要求非结尾的元素在原数组中必须是连续的，而上一题的定义并没有这些要求，即非结尾的元素在原数组中可以是非连续的，也就是可以是离散的。所以上一题才要求遍历并比较i之前所有的元素，但是本题只需要与i-1的位置进行比较就可以，关键的一点就在于**连续**二字。最后整体代码如下：

```java
class Solution {
    public int findLengthOfLCIS(int[] nums) {
        int len = nums.length;
        int[] dp = new int[len];
        Arrays.fill(dp, 1);

        int res = 1;
        for(int i = 1; i < len; i++){
            if(nums[i] > nums[i - 1]){
                dp[i] = dp[i - 1] + 1;
            }
            res = Math.max(res, dp[i]);
        }
        return res;
    }
}
```

同时还是注意要返回的是最终的`dp`数组中的最大值，而不是`dp[len-1]`。

还是与上一题同样的问题：为什么`dp[i]`还是非得定义成以 `nums[i]` 结尾的**连续**递增子序列的长度？直接将`dp[i]`定义成`dp[0~i]`的子序列中，最长的**连续**递增子序列的长度不可以吗？这样最后不就可以直接返回`dp[len-1]`的值了吗？显然，还是不可以。第一个原因就是上题说的“**比较**”，本题依然求的是递增序列，既然有递增，就肯定有元素之间的比较，因此我需要知道`i`之前的所有已知递增序列中的最后一位元素的值，这样我才知道我该把这个元素接在已有的哪个递增序列上，而上述的定义方法很明显将结尾的信息给丢失了，上一题已经解释得很清楚，这里就不解释了。对于第二个原因，关键就在于题目中说到的“**连续**”二字，如果将`dp[i]`定义成`dp[0~i]`的子序列中，最长的连续递增子序列的长度，那么假设我正在计算`dp[i]` ，那么`dp[i-1]`存储的信息是`dp[0~i-1]`的子序列中，最长的连续递增子序列的长度，那么此时我是不知道这个最长的连续递增子序列的结尾元素是哪一位的，因此在我不知道这个最长的连续递增子序列的结尾元素是哪一位的情况下，我又怎么知道该将`dp[i]`接到哪个子序列的结尾呢？总的来说，因为要保证连续，因此我需要知道已有的序列的结尾信息，这样我才知道该将当前元素放在哪个序列的后面，不然我怎么能保证连续？

总结一下上一题[**300. 最长递增子序列**](300%20%E6%9C%80%E9%95%BF%E9%80%92%E5%A2%9E%E5%AD%90%E5%BA%8F%E5%88%97.md) 和本题这两道题，其实就是对子序列的定义不同，一个是允许子序列中连续的元素在原来的序列中可以不连续（**离散**抽取），而一个是要求子序列中连续的元素在原来的主序列中也必须是连续的（**连续**抽取）。所以对于离散的题目类型，需要遍历之前的所有位，然后取那个最大的值作为当前子序列的最长长度；但是对于连续的题目类型，只需要与前一位进行比较就可以得出当前子序列的最长长度，不用在跑去前面把所有位都遍历一遍了。还有就是dp定义的问题，上一题由于“**比较**”的原因，需要将dp定义成以`i`结尾；而本题由于“**比较**”+”**连续**“的原因，需要将dp定义成以i结尾。在接下来的两题中也会看到”**离散“**与**”连续”**以及**“比较”**与**”连续“**这两个问题的探讨。
