# 213. 打家劫舍 II

[https://leetcode.cn/problems/house-robber-ii/description/](https://leetcode.cn/problems/house-robber-ii/description/)

对于第一间和最后一间，有如下三种选择：1.两间都被**考虑**在被偷的范围内；2.只**考虑**偷其中一间；3.两间都不**考虑**偷。既然第一间和最后一间是紧挨着的，那么这两间房子就不能同时考虑被偷，pass掉第1种情况。而第3种情况可以被认为是被包含在了第2种情况当中了，为什么？因为情况2是**考虑（注意是考虑）**只偷其中一间，但是实际去偷的时候，为了获得价值最大值，有可能两间都不偷，所以说第3种情况是被包含在第2种情况当中了。

因此最终将问题分成了两个：一个是**直接不考虑第一间房间但考虑最后一间房**的情况下可以偷窃到的最高金额；另一个是**直接不考虑最后一间房间但考虑第一房**的情况下可以偷窃到的最高金额（要注意“考虑”和“偷”是有区别的：考虑到的房间不一定偷，但是没考虑到的房间是一定不会去偷的），然后比较两种情况的最大值。

分析到这问题就很简单了，只需要将上一题[**198. 打家劫舍**](198%20%E6%89%93%E5%AE%B6%E5%8A%AB%E8%88%8D%2021642abd57ae800ba690cc6a702a3248.md) 提取成一个函数，然后对上面两个问题分别调用这个函数，最后看看谁的结果大就取谁为最终的结果。代码如下：

```java
class Solution {
    public int rob(int[] nums) {
        if(nums.length == 1){
            return nums[0];
        }else if(nums.length == 2){
            return Math.max(nums[0], nums[1]);
        }else{
            // 取两种情况的最大值
            return Math.max(robAction(nums, 0, nums.length - 1), robAction(nums, 1, nums.length));
        }
    }

		// 将 198. 打家劫舍 的题解抽取成函数
    public int robAction(int[] nums, int start, int end) {
        int[] dp = new int[end];
        dp[start] = nums[start];
        dp[start + 1] = Math.max(nums[start], nums[start + 1]);
        for(int i = start + 2; i < end; i++){
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        return dp[end - 1];
    }
}
```

可以看到，`robAction(nums, 0, nums.length - 1)`是考虑第一间的情况，最后一间看都不看。

而`robAction(nums, 1, nums.length)`是考虑最后一间的情况，第一间也是看都不看。
