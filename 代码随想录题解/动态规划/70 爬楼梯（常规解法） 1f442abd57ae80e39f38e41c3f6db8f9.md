# 70. 爬楼梯（常规解法）

[https://leetcode.cn/problems/climbing-stairs/description/](https://leetcode.cn/problems/climbing-stairs/description/)

可以看到每次我们最多可以爬2个台阶，所以当我们达到距离楼顶还有两层楼内的时候，可以直接一步到达楼顶。假如楼顶在5楼，那么我们达到3楼或者4楼后，接下来就可以一步达到楼顶了。那么我们需要计算的就是到达3楼有多少种方法以及达到4楼有多少种方法，两者相加即为到达5楼的方法数。所以我们将dp数组定义为到达 i 楼的方法数量，递推公式为 dp[i] = dp[i - 1] + dp[i - 2]。代码如下：

```
// 常规动规解法（斐波那契数列）
class Solution {
    public int climbStairs(int n) {
        if(n <= 2){
            return n;
        }
        int[] dp = new int[n + 1];
        dp[1] = 1; // 到达1楼有1种方法
        dp[2] = 2; // 到达2楼有2种方法
        for(int i = 3; i <= n; i++){
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}

// 空间优化
class Solution {
    public int climbStairs(int n) {
        // 边界条件处理
        if (n <= 2) {
            return n;
        }

        // 我们只需要记录前两个状态，不需要开辟整个数组
        int first = 1;  // 代表 f(n-2)
        int second = 2; // 代表 f(n-1)
        int res = 0;

        for (int i = 3; i <= n; i++) {
            // 当前阶数的方法数 = 前两阶方法数之和
            res = first + second;
            // 滚动更新变量
            first = second;
            second = res;
        }

        return res;
    }
}
```

**注意本题求的是有多少种方法到达楼顶，而不是需要爬多少次可以到达楼顶**。这个误区没搞清楚可能会导致以为达到 i - 2 层后还需要一步才能上去，所以需要加 1。但是完全不需要，因为我们知道了到达目标楼层的前两层需要的方法数，剩下就只剩下一步就可以上去了，这一步其实是包含在方法内的，所以应该是乘1，而不是加1。可能会觉得到达 i - 2 层之后也可以先去 i - 1 层，所以有两种方法可以到达楼顶。但是这种方法已经包含在到达 i - 1 层的方法数中了。
