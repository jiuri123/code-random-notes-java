# 62. 不同路径

[https://leetcode.cn/problems/unique-paths/description/](https://leetcode.cn/problems/unique-paths/description/)

## 方法一：二维dp

相比与之前的题目，本题的dp数组从一维升级到了二维，但是思路还是很简单的。dp数组的值表示到达[i ,j]这个点有多少种走法。首先可以肯定的是到达dp数组的第一行和第一列的走法只有一种，所以刚开始可以初始化为1。而后从 i = 1, j = 1 这个点开始遍历计算各点的路径数，因为只能往**向下或者向右移动一步，**所以只能从这个点的左边和上边过来，所以到达这个点的路径数就是到达这个点上面和左边这两个点的路径数之和。代码如下：

```java
// 时间复杂度：O(mn)
// 空间复杂度：O(mn)
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for(int i = 0; i < m; i++){
            dp[i][0] = 1;
        }
        for(int i = 0; i < n; i++){
            dp[0][i] = 1;
        }

        for(int i = 1; i < m; i++){
            for(int j = 1; j < n; j++){
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        return dp[m - 1][n - 1];
    }
}
```

## 方法二：一维dp（面试推荐）

```java
// 时间复杂度：O(mn)
// 空间复杂度：O(n)
class Solution {
    public int uniquePaths(int m, int n) {
        // 使用一维数组优化空间，长度为列数 n
        int[] dp = new int[n];
        
        // 初始化第一行：从起点出发，只能一路向右，所以第一行所有路径数都是 1
        for (int i = 0; i < n; i++) {
            dp[i] = 1;
        }

        // 从第二行开始遍历
        for (int i = 1; i < m; i++) {
            // 第一列始终为 1（因为只能一路向下）
            for (int j = 1; j < n; j++) {
                // 当前格子的路径 = 上方格子的路径 (dp[j]) + 左方格子的路径 (dp[j-1])
                dp[j] = dp[j] + dp[j-1];
            }
        }

        return dp[n - 1];
    }
}
```

## 方法三：组合数

![image.png](62%20%E4%B8%8D%E5%90%8C%E8%B7%AF%E5%BE%84/image.png)

```java

// 时间复杂度：O(min(m, n))
// 空间复杂度：O(n)
class Solution {
    public int uniquePaths(int m, int n) {
        // 计算 C(m+n-2, k)，k 取 m-1 和 n-1 中较小的那个以减少计算量
        int k = Math.min(m - 1, n - 1);
        int N = m + n - 2;
        long res = 1; // 使用 long 防止计算中间过程溢出
        
        for (int i = 1; i <= k; i++) {
            // 组合数计算公式
            res = res * (N - i + 1) / i;
        }
        
        return (int) res;
    }
}
```

- 为什么是求组合数，而不是排列数？

问自己一个问题：**“如果我交换了选出来的两个元素，结果会产生一种新的情况吗？**

排列数看重**位置关系**，如果选出来的元素位置不同，结果也不同，就是排列；

组合数看重**分配（填充）关系**，如果选出来的元素交换位置后，结果不变，说明是组合。
