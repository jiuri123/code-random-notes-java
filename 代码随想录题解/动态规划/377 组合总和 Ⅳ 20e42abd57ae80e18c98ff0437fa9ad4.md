# 377. 组合总和 Ⅳ

[https://leetcode.cn/problems/combination-sum-iv/description/](https://leetcode.cn/problems/combination-sum-iv/description/)

因为每个数可以无限次选取，而且诸如`(1, 1, 2)`和`(2, 1, 1)`是不同的组合，因此是典型的完全背包+排列问题。因为是完全背包问题，所以一维dp中遍历物品的循环需要顺序遍历。而又因为是排列问题，所以双层循环中必须先遍历背包，再遍历物品，也就是从上到下、从左到右进行遍历（因为这样才有可能出现2号物品出现在1号背包前面的情况，具体解析看[**518. 零钱兑换 II（含组合/排列总结）**](518%20%E9%9B%B6%E9%92%B1%E5%85%91%E6%8D%A2%20II%EF%BC%88%E5%90%AB%E7%BB%84%E5%90%88%20%E6%8E%92%E5%88%97%E6%80%BB%E7%BB%93%EF%BC%89%2020a42abd57ae8074ba2aebbcde849da3.md) ）。代码如下：

```java
// 一维dp
class Solution {
    public int combinationSum4(int[] nums, int target) {
        int[] dp = new int[target + 1];
        dp[0] = 1;

        int len = nums.length;
        for(int i = 0; i <= target; i++){ // 遍历背包
            for(int j = 0; j < len; j++){ // 遍历物品
                if(i >= nums[j]){
                    dp[i] = dp[i] + dp[i - nums[j]];
                }
            }
        }

        return dp[target];
    }
}
```

下面再给出二维dp（增加虚拟行的解法）：

```java
// 二维dp(增加虚拟行)
class Solution {
    public int combinationSum4(int[] nums, int target) {
        int len = nums.length;
        int[][] dp = new int[len + 1][target + 1];
        dp[0][0] = 1;
        
        for(int j = 0; j <= target; j++){ // 遍历背包
            for(int i = 1; i <= len; i++){ // 遍历物品
                if(j >= nums[i - 1]){ // 如果放得下
                    dp[i][j] = dp[i - 1][j] + dp[len][j - nums[i - 1]];
                }else{ // 如果放不下
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }

        return dp[len][target];
    }
}
```

这里的虚拟行指的就是上面一维dp解法当中的一维dp数组的初始化，关于为什么要增加虚拟行，可以看之前的笔记：[**494. 目标和（含总结）**](494%20%E7%9B%AE%E6%A0%87%E5%92%8C%EF%BC%88%E5%90%AB%E6%80%BB%E7%BB%93%EF%BC%89%2020642abd57ae80669c2de5df2d9f83d6.md) 。其实本题不增加虚拟行也可以解决，但是对二维dp的初始化上面就比较复杂了（所以增加虚拟行就是为了简化dp数组的初始化）。

同时还要注意这里的dp推导公式是`dp[i][j] = dp[i - 1][j] + dp[len][j - nums[i - 1]];`。这里用到了`dp[len][j - nums[i - 1]]` 也就是说更新当前位置的值需要用到的值不再是左边的值和上边的值，而是左下角的值和上边的值，这似乎有违完全背包问题的常规解法，但是由于本题求的是排列数，因此之前的背包容量需要将所有的背包都遍历一遍，这样才有可能出现下标大的背包出现在下标小的背包前面（排列解法还是看之前的笔记，有详细的解释），所以要使用`dp[len][j - nums[i - 1]]`而不是`dp[i][j - nums[i - 1]]`来更新当前位置的值。
