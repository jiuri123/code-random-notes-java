终于开启背包问题的大门！这道题是经典的0-1背包问题，经典解法的思路如下：

1. 定义一个二维的`dp`数组，`dp[i][j]`表示对于背包容量大小为`j`的背包，可以选取前`i`个物品（这里的`i`表示的是物品的下标，即`0~i-1`），且每个物品只能选取一次，使得背包中的最大物品价值为`dp[i][j]`；
2. 接下来初始化这个`dp`数组的第一行（表示只能选取下标为`0`的物品）和第一列（表示背包容量为`0`）。第一行当然是从`dp[0][cost[0]]`开始的后面那些位置都初始化为`value[0]`，因为前面那些背包容量都放不下物品`0`，只有后面才开始放得下，而且现在我也只有物品`0`可以选择；
3. 然后开始一个两层循环来遍历这个二维`dp`数组。外层循环遍历物品，内层循环遍历背包容量，都是顺序遍历。循环体中就是`dp`数组的递推公式，下面开始推导递推`dp`的递推公式；
    1. 对于一个物品，只有两种选择，要么是选，要么就是不选。
        1. 如果不选的话，那么递推公式就是`dp[i][j] = dp[i - 1][j]`，表示不包括当前物品`i`且背包容量为`j`的情况下，背包中可以达到的最大价值；
        2. 如果选的话，那么递推公式就是`dp[i][j] = dp[i - 1][j - cost[i]] + value[i]`，表示我先将背包的容量腾出一个`cost[i]`的空间，也就是物品`i`的重量，然后得出不包括当前物品`i`且背包容量为`j - cost[i]`的情况下，背包中可以达到的最大价值，最后再加上物品`i`的价值`value[i]`（之所以可以加上，是因为前面腾出了`cost[i]`的空间）。
    2. 因为要求的是背包中的最大价值，那我就比较上述两种选择，看看那种选择得到的价值最大，因此整体的dp递推公式就是`dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - cost[i]] + value[i])`。
4. 完成上述的两层循环填充完dp数组之后，最后`dp[n - 1][capacity]`存储的值就是我们要的结果。

整体代码如下：

```java
// 方法一：二维dp解法，先物品后背包
import java.util.*;
public class Main{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        // 读取第一行
        int n = sc.nextInt();
        int capacity = sc.nextInt();
        int[] cost = new int[n];
        int[] value = new int[n];

        // 读取剩下两行
        for(int i = 0; i < n; i++){
            cost[i] = sc.nextInt();
        }
        for(int i = 0; i < n; i++){
            value[i] = sc.nextInt();
        }

        // 初始化dp数组
        int[][] dp = new int[n][capacity + 1];
        for(int i = cost[0]; i <= capacity; i++){
            dp[0][i] = value[0];
        }

        // 开始填充dp数组，先遍历物品，后遍历背包
        for(int i = 1; i < n; i++){
            for(int j = 1; j <= capacity; j++){
                if(cost[i] > j){ // 背包放不下
                    dp[i][j] = dp[i - 1][j];
                }else{ // 背包放得下
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - cost[i]] + value[i]);
                }
            }
        }
        System.out.println(dp[n - 1][capacity]);
    }
}
```

对于此解法，有几个问题需要解决：

1. 常规解法中，是先遍历物品，后遍历背包。那可不可以交换内外循环，即先遍历背包，后遍历物品呢？
    - 看情况。如果此时背包是倒序遍历，那么是不可以轻易交换内外循环，只能是先遍历物品，后遍历背包（关于这点的解释见下面问题3）。否则如果背包是顺序遍历，那么可以交换内外循环。为什么可以交换？先看dp递推公式：dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - cost[i]] + value[i]);，可以发现我更新当前位置dp[i][j]需要用到其上方的值（dp[i - 1][j]）或者其左上方的值（dp[i - 1][j - cost[i]），也就是说只要这两个方向的值是存在的，那么我就可以更新当前位置dp[i][j]的值。在原始方法中，二维dp的遍历顺序是先从左到右，再从上到下，而交换内外循环后，二维dp的遍历顺序就是先从上到下，再从左到右，这两种循环顺序用到的值都是存在的，因此都不影响对当前值的更新。
2. 常规解法中，遍历物品是顺序，那可不可以倒序遍历呢？
    - 不可以！任何情况都不可以！因为如果物品倒序，那么就是二维dp的遍历顺序是先从左到右，再从下到上，而更新当前位置需要用到当前位置上面的值和左上角的值，而再从下到上的过程中，当前位置上面的值和左上角的值大部分是不存在的（还没有更新），因此最后返回的结果会出现错误。即使是交换内外循环（先从下到上，再从左到右）也不可以，原因同上。
3. 常规解法中，遍历背包是顺序，那可不可以倒序遍历呢？
    - 看情况。假如是先遍历物品，后遍历背包，那么背包是可以倒序遍历的。因为此时二维dp的遍历顺序是先从右到左，再从上到下，更新当前位置用到的值都是存在的。但是如果是先遍历背包，后遍历物品，那么背包是不可以倒序遍历的。因为此时二维dp的遍历顺序是先从上到下，再从右到左，更新当前位置用到的值中虽然上方的值存在，但是左上角的值确是不存在的。

**总结：**解决以上三个问题的关键思路就是看二维dp中更新当前位置需要用到的值到底存不存在，因此结论不用记，以后看二维dp数组就可以了。

**最佳实践：**先顺序遍历物品，后顺序遍历背包。这是最经典的解法，也是最符合逻辑的解法。

**CM**：其实直接从“更新当前的值需要用到左上角和上面的值”这个条件出发就能推导出可以选择的遍历顺序。比如“需要用到上面的值”这个条件就硬性规定了遍历物品必须是顺序遍历，这样更新当前位置的时候，上面的值才是存在的（问题2）。再比如“需要用到左上角的值”这个条件，只要左上角这个值是存在的，那么遍历背包的顺序既可以是顺序，也可以是逆序。
