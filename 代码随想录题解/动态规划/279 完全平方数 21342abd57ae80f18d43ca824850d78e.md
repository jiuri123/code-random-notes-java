# 279. 完全平方数

[https://leetcode.cn/problems/perfect-squares/description/](https://leetcode.cn/problems/perfect-squares/description/)

和上一题[**322. 零钱兑换**](322%20%E9%9B%B6%E9%92%B1%E5%85%91%E6%8D%A2%2021242abd57ae807bb1c3eae412c22815.md) 一样的思路，下面讲解以一维dp为例。将可以选择的平方数视为每个物品，平方数的大小表示每个物品的重量，由题意可得每种物品都可以选择多次，因此是完全背包问题。首先定义`dp[i]`为：选取多个和为`i`的完全平方数，这些完全平方数的最少数量为`dp[i]`。然后推导dp递推公式，对于每一个背包，要么是选，要么是不选。选的话就是`dp[j - capacity[i]] + 1`，不选的话就是`dp[j]`，因此dp递推公式为`dp[j] = Math.min(dp[j], dp[j - capacity[i]] + 1);`。由于dp数组的值都是涉及最少的问题，因此初始化dp数组的时候记得要初始化成`Integer.MAX_VALUE` ，同时`dp[0]`要初始化成`0`而不是`1`，因为`dp[0]`表示的是在没有任何数可以选择的情况下凑成整数0的最少完全平方数的数量，很明显就是0（表示不选任何数，尽管没有任何数可以选择）。要注意的是，对于任意给定的整数，都可以找到一个以上的完全平方数来组成这个整数，因为完全平方数中有1。整体代码如下：

```
// 方法一：动态规划前先计算可能用到的所有物品的重量
class Solution {
    public int numSquares(int n) {
        int[] capacity = new int[101];
        for(int i = 0; i <= 100; i++){
            capacity[i] = i * i; // 记录可能用到的所有物品的重量
        }

        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

        // for(int i = 0; i <= 100; i++){ // 区别：i从0开始
        //     for(int j = capacity[i]; j <= n; j++){
        //         if(dp[j - capacity[i]] != Integer.MAX_VALUE){
        //             dp[j] = Math.min(dp[j], dp[j - capacity[i]] + 1);
        //         }
        //     }
        // }

				// 开始动态规划
        for(int i = 1; i <= 100; i++){ // 外循环顺序遍历物品
            for(int j = capacity[i]; j <= n; j++){ // 内循环顺序遍历容量
                dp[j] = Math.min(dp[j], dp[j - capacity[i]] + 1);
            }
        }

        return dp[n];
    }
}

// 方法二：动态规划的过程中计算当前物品的重量
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;

				// 外循环遍历物品，内循环遍历背包
        for(int i = 1; i * i <= n; i++){ // 物品的重量 i^2 不可能大于背包的总容量 n
            for(int j = i * i; j <= n; j++){ // j 从物品的重量开始遍历，这样才放得下物品
                dp[j] = Math.min(dp[j], dp[j - i * i] + 1);
            }
        }

        return dp[n];
    }
}
```

可以看到有两种解法，先看方法一是先将所有可能用到的物品全部记下来，最多可能用到100种物品，因为题目给出`1 <= n <= 10000` ，也就是说背包容量最大为10000，所以物品的重量也不会超过10000，那么最大使用到的需要自乘的整数就是100，因此用个数组记下来能用到的所有可能的最大的物品重量，方便后续遍历。

同时注意到方法一中有两种遍历方式，被注释的代码也可以过，但是要加上`if(dp[j - capacity[i]] != Integer.MAX_VALUE)`这句代码，否则可能会使得dp数组中的值超过`Integer.MAX_VALUE`的范围。如果不想加上这句话，可以直接将i从1开始，也就是方法一中没有被注释的代码，这样就不会出现问题（建议debug一遍）。

方法二与方法一中不同的地方在于没有使用一个数组将所有可能用到的物品的重量存起来，而是直接在遍历的过程中通过物品的下标（i）计算物品的重量（i*i），降低空间复杂度的同时，也降低了时间的复杂度（方法一的i需要遍历到100，有很多不必要的遍历）。

1. 方法二的外循环为什么要限制`i * i <= n`？
    - 因为`i * i`就表示当前物品的重量，而n表示的是背包的容量，如果物品的重量都超过了背包的容量，那么这个物品也就没有遍历的必要了。比如n=12的时候，i只需要遍历到3就可以了，i=4的情况不需要遍历（i*i=16>12）。
