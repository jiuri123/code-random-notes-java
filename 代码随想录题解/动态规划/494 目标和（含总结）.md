# 494. 目标和（含总结）

[https://leetcode.cn/problems/target-sum/description/](https://leetcode.cn/problems/target-sum/description/)

在做这道题的时候真的精彩绝伦、妙不可言，事实证明多问几个为什么，往下不断地深挖真的可以学到很多东西，再加上AI的加持，就没有我学不会的技术，感觉这道题都被我玩出花来了，下面详细介绍我的思路。

从题目可知数组中的整数要么是变成正数，要么是变成负数，那么可以将原整数数组分成两个子集和，一个子集合用来存数组中变成正数的那些非负整数，子集的和记为`positiveSum`；另一个子集和用来存数组中变成负数的那些非负整数（注意存的是原数，而不是将数变成负数后再存进去），子集的和记为`negtiveSum`。由此可得两个式子：

positiveSum + negtiveSum= sum（sum为原整数数组总和）；

positiveSum - negtiveSum= target；

联立两个式子可得：positiveSum= （sum + target）/ 2。根据题目条件，target已经给出，sum也可以求得，因此positiveSum是可以求出来的。此时题目就变成了0-1背包的问题：**从一个非负整数的数组中选取任意个数（每个数可选可不选），使得这些数字的和为positiveSum，有多少种取数的方法？**因为我取出来的数是作为正数的，那么剩下的数就作为负数，此时两个子集和相减就一定能得到target，但是前提是取出来的数字的和一定要刚好为positiveSum，否则就说明没法通过构造来得出target。

思路有了，那么就开始用0-1背包的方法去解决。先介绍简单的二维DP。根据动规五部曲，第一步是先确定dp数组以及下标的含义，从上面分析可知dp[i][j]表示：**从下标为0~i的这几件物品中选任意件物品，使得其总和刚好为j的取物品的方法有dp[i][j]种。**

第二步就是确定递归公式，对于一件物品，要么是取，要么就不取。不取的话有dp[i - 1][j]种方法，取的话有dp[i - 1][j - nums[i]]种方法，这里的j需要减去nums[i]表示的意思是背包里面要给i这件物品预留出nums[i]的位置（nums[i]表示的是物品i的重量）。所以递归公式就是两种取物品的方法数相加：`dp[i][j] = dp[i - 1][j] + dp[i - 1][j - nums[i]];`。当然这只是对与当前遍历的物品能放得进背包的情况，还有放不进的情况，那就直接不能取这个物品，递归公式为：`dp[i][j] = dp[i - 1][j];`。

动规五部曲的第三步就是要初始化，我感觉这其实是本题最难的一个点。首先考虑的是第一行，由于第一行仅考虑物品0，所要将dp[0][nums[0]]初始化为1，表示当背包重量为nums[0]且只有物品0的时候，有1种取物品的方法可以使得此时背包重量恰好为nums[0]，也就是直接取nums[0]。其他位置都暂时初始化为0。最后考虑第一列的初始化，第一列表示背包的重量为0，这时候貌似直接都初始化为1就好了，就是不管考虑多少个物品，我的取法只有一个：一个物品都不取，此时背包的重量就恰好是0。但是问题是nums是一个非负整数数组，也就是说数字（物品的重量）是可以为0的，那么对于背包重量为0且需要考虑的物品中重量为0的有n个，那么我的取法就不总是1，而是2^n种取法。因为一个重量为0的物品此时有两种取法：取或者不取，而不单单是不取那么简单了。所以初始化第一列应该如下代码所示：

```java
int countZero = 0; // 记录出现重量为0的物品的个数
for(int i = 0; i < len; i++){ // dp数组第一列初始化
    if(nums[i] == 0){
        countZero++;
    }
    dp[i][0] = (int)Math.pow(2, countZero);
}
```

初始化结束，就开始进入动规五部曲第四步：遍历方向，从递归公式可以看到更新dp数组当前的位置只与当前位置的上面位置的值和左上角位置的那些值有关，所以先从上到下、再从左到右或者先从左到右、再从上到小进行遍历都是可以的。

动规最后一步是举例推导dp数组，这里省略。总体代码如下：

```java
// 二维dp数组
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for(int i : nums){
            sum += i;
        }

        if(Math.abs(target) > sum){ // 这种情况下即使全正或者全负也无法凑出target
            return 0;
        }

        if((sum + target) % 2 == 1){ // 必须要保证positiveSum不是小数
            return 0;
        }

        int positiveSum = (sum + target) / 2;
        int len = nums.length;
        int[][] dp = new int[len][positiveSum + 1];

        if(nums[0] <= positiveSum){ // dp数组第一行初始化
            dp[0][nums[0]] = 1;
        }

        int countZero = 0; // 记录出现重量为0的物品的个数
        for(int i = 0; i < len; i++){ // dp数组第一列初始化
            if(nums[i] == 0){
                countZero++;
            }
            dp[i][0] = (int)Math.pow(2, countZero);
        }

        for(int i = 1; i < len; i++){
            for(int j = 1; j <= positiveSum; j++){
                if(nums[i] > j){ // 物品太大放不进
                    dp[i][j] = dp[i - 1][j];
                }else{ // 如果放得进，则将选和不选两种方法的方法数求和
                    dp[i][j] = dp[i - 1][j] + dp[i - 1][j - nums[i]];
                }
            }
        }

        return dp[len - 1][positiveSum];
    }
}
```

如果是二维dp，一般还可以转换成一维dp，这就是本题的高潮部分，也是我收获最多的地方。转换过程其实很简单，就是将原来的二维数组往列方向压缩成1行，然后内循环记得从大到小进行遍历就好了（只要心中将这个一维dp放在二维dp的上面，就不难理解）。代码如下：

```java
// 一维dp数组
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for(int i : nums){
            sum += i;
        }

        if(Math.abs(target) > sum){ // 这种情况下即使全正或者全负也无法凑出target
            return 0;
        }

        if((sum + target) % 2 == 1){ // 必须要保证positiveSum不是小数
            return 0;
        }

        int positiveSum = (sum + target) / 2;
        int len = nums.length;
        int[] dp = new int[positiveSum + 1];
        dp[0] = 1;

        for(int i = 0; i < len; i++){
            for(int j = positiveSum; j >= nums[i]; j--){
                dp[j] = dp[j] + dp[j - nums[i]];
            }
        }

        return dp[positiveSum];
    }
}
```

但是最关键的问题就是：为什么一维dp的初始化只需要`dp[0] = 1;`就ok了？因为之前我的理解是一维dp就想相当于是二维dp的第一行，所以就像二维dp对第一行进行初始化一样（`dp[0][nums[0]] = 1;`），一维dp也应该对进行类似的初始化（`dp[nums[0]] = 1;`），但是事实证明完全是我搞错了。一维dp根本就不是二维dp的第一行，而是相当于二维dp的第一行的上面一行（`dp[-1][nums[0]]`），什么意思呢？意思就是初始的一维dp表示的是此时没有任何物品供我选择，这种情况下各种背包容量有多少种取法。很明显此时`dp[0]`应该初始化为1。因为`dp[0]`表示背包容量为0有多少种取法，虽然此时没有任何物品可供选择，但是我依然有一种取法：就是什么物品都不取。而其他位置就初始化为0，因为没有物品，那么也就没有办法使得背包重量超过0。所以此处的初始化相当于是对二维dp的最上面那一行的上一行（虚拟出来的行）进行初始化，而不是直接对二维dp第一行进行初始化（其实我认为这样也是可以的，但是初始化起来就很麻烦，想想二维数组是怎么对第一行第一列初始化的就懂了）。所以初始化后进行正式的二维遍历的时候，i是要从0开始的，也就相当于是从二维dp的第一行开始遍历。

那么问题又来了，既然上面的一维dp表示的是二维dp的虚拟行（暂且称为虚拟行吧），然后对这个一维dp只需要初始化dp[0]就好了，后面的值就都可以根据这一行来推导得出（即使是第一列有很多物品重量为0的情况），那么我是否可以将这个一维dp转换成二维dp，只不过这个二维dp最上面多了一行dp[0][j]，表示什么物品都没有的情况下各容量的背包有多少种取法。当然是可以的！你问我为什么要这么干，当然是初始化简单啊，只需要初始化dp[0][0] = 1（相当于一维dp的初始化dp[0] = 1）就好了，而不是像上面那个旧的二维dp那样还要对第一列和第一行进行如此复杂的初始化。此时的dp[i][j]表示的就是任取前i个物品中（下标为0~i- 1的物品）的任意个物品，有多少种取法使得这些物品的总重量为j。最终代码：

```java
// 增加虚拟行的二维dp数组
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }

        // 检查是否有可能凑出 target
        if (Math.abs(target) > sum) return 0; // 全正或全负都无法达到
        if ((sum + target) % 2 == 1) return 0; // positiveSum 必须是整数
        int positiveSum = (sum + target) / 2;
        if (positiveSum < 0) return 0; // positiveSum 不能为负

        int len = nums.length;
        // 创建二维 DP 数组，行数为 len+1（包含虚拟上一行）
        int[][] dp = new int[len + 1][positiveSum + 1];

        // 初始化虚拟行（i=0，相当于没有物品），非常滴简单！
        dp[0][0] = 1; // 没有物品时，和为 0 的方案数为 1

				// 从虚拟行的下一行开始二维dp，跟之前的二维dp异曲同工
        for (int i = 1; i <= len; i++) {
            for (int j = 0; j <= positiveSum; j++) {
                if (j >= nums[i - 1]) {
                    dp[i][j] = dp[i - 1][j] + dp[i - 1][j - nums[i - 1]];
                }else{
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }

        // 返回结果：最后一行，目标和为 positiveSum 的方案数
        return dp[len][positiveSum];
    }
}
```

全题完结！至此已成艺术！总结一下下：

1. 遇到动态规划的问题不要着急找dp的推导公式，而是应该将问题转换成常见的背包问题，之后再确定dp的推导公式也不迟；
2. 一维dp虽然来自二维dp，但是并不是直接从二维dp的第一行复制而来，而是相当于二维dp最上面那行的上一行（在大气层了属于是）；
3. 接2，这也是为什么建议用一维dp而不是二维dp，因为一维dp不仅省空间，而且初始化非常的简单，不需要考虑那么多有的没的。
