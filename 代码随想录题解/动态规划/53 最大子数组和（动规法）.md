# 53. 最大子数组和（动规法）

![image.png](53%20%E6%9C%80%E5%A4%A7%E5%AD%90%E6%95%B0%E7%BB%84%E5%92%8C%EF%BC%88%E5%8A%A8%E8%A7%84%E6%B3%95%EF%BC%89/image.png)

之前用贪心法做过这道题，见：[**53. 最大子数组和（贪心法）**](../%E8%B4%AA%E5%BF%83/53%20%E6%9C%80%E5%A4%A7%E5%AD%90%E6%95%B0%E7%BB%84%E5%92%8C%EF%BC%88%E8%B4%AA%E5%BF%83%E6%B3%95%EF%BC%89.md) 。本题要求最大和的连续子数组，既然要求连续，那就得保存已知的子数组的结尾信息（这在之前的题目中已经分析过，见[**1143. 最长公共子序列（含子序列/子数组类总结）**](1143%20%E6%9C%80%E9%95%BF%E5%85%AC%E5%85%B1%E5%AD%90%E5%BA%8F%E5%88%97%EF%BC%88%E5%90%AB%E5%AD%90%E5%BA%8F%E5%88%97%20%E5%AD%90%E6%95%B0%E7%BB%84%E7%B1%BB%E6%80%BB%E7%BB%93%EF%BC%89.md) ），那么`dp[i]`就应该定义为从`nums[0~i]`中取出一些**以`nums[i]`结尾的连续**子数组，这些子数组中的最大和就是`dp[i]`。

定义好了`dp[i]`，接下来就是求递推公式。这里有两种方法，一种是我自己的方法，思路还是比较清晰的，直接看代码就好了：

```java
// 方法一：我自己的动规，dp递推公式有点复杂
class Solution {
    public int maxSubArray(int[] nums) {
        int len = nums.length;
        int[] dp = new int[len];
        dp[0] = nums[0];
        int res = nums[0];
        for(int i = 1; i < len; i++){ 
            if(nums[i] >= 0){
                if(dp[i - 1] >= 0){ // 前面的序列和大于等于0才接上去
                    dp[i] = dp[i - 1] + nums[i];
                }else{ // 否则自立门户
                    dp[i] = nums[i];
                }
            }else{ // 同上
               if(dp[i - 1] >= 0){
                    dp[i] = dp[i - 1] + nums[i];
                }else{
                    dp[i] = nums[i];
                } 
            }
            // 更新全局最大值
            res = Math.max(res, dp[i]);
        }
        return res;
    }
}
```

可以看到递推公式好复杂，出现了冗余代码，这是不能忍受的，原因就是没有搞懂dp[i]到底可以从什么子状态推导出来。其实dp[i]只可能从两种状态推导出来：要么是接上dp[i-1]这个子数组，要么是重新创建一个新的子数组，nums[i]作为子数组头。那么这两种状态的判断依据是什么呢？很简单，其实就是对dp[i-1]进行判断就好了，如果dp[i-1]大于0，那就把当前的nums[i]接上去，因为这样可以使得子数组和更加大；反之，就从头开始自立门户，将nums[i]作为新的子数组的头，因为以nums[i-1]为结尾的最大子数组和并不能对我的新的子数组和有什么贡献，甚至还拖我后腿，那我还不如自己新建一个数组。整体代码如下：

```java
// 方法二：随想录的动规，dp递推公式更简单
class Solution {
    public int maxSubArray(int[] nums) {
        int len = nums.length;
        int[] dp = new int[len];
        dp[0] = nums[0];
        int res = nums[0];
        for(int i = 1; i < len; i++){ // 与我的区别
		        // 以当前元素结尾的最大和，要么是当前元素自身
            // 要么是当前元素加上“以上一个元素结尾的最大和”
            dp[i] = Math.max(nums[i], dp[i - 1] + nums[i]); 
            // 更新全局最大值
            res = Math.max(res, dp[i]);
        }
        return res;
    }
}
```

可以看到上面这种解法和贪心算法还是有点异曲同工之妙的，思路都是差不多，大概就是只要之前的子序列无法对我的和有什么新的贡献的时候（小于或等于0），那我就自立门户，划清界限，重新开始。

最后还可以对上述代码做空间优化，因为每个位置的dp值只与前一个位置的dp值有关，所以我只需要记录一个dp值就好了，不需要一个数组来记录。代码如下：

```java
class Solution {
    public int maxSubArray(int[] nums) {
        // 如果数组为空，虽然题目限制不会出现，但加上更严谨
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int res = nums[0]; // 记录全局最大值
        int max = nums[0]; // 用max代替dp数组，记录以当前元素结尾的子数组的最大和

        for (int i = 1; i < nums.length; i++) {
            // 以当前元素结尾的最大和，要么是当前元素自身，
            // 要么是当前元素加上“以上一个元素结尾的最大和”
            max = Math.max(nums[i], max + nums[i]);
            
            // 更新全局最大值
            res = Math.max(res, max);
        }

        return res;
    }
}
```
