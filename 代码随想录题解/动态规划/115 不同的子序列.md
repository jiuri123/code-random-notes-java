# 115. 不同的子序列

直接按照动规五部曲来分析，首先定义`dp[i][j]`。本题`dp[i][j]`定义为在`s[0~j-1]`这个字符串的**所有子序列**中，字符串`t[0~i-1]`在其中出现的个数。比如`s = abab，t = ab`，那么最后输出的答案应该是`3`，因为有如下三种情况**`ab**ab，**a**ba**b，**ab**ab**`可以组成`t`。注意`s`中出现的`t`可以是离散的，所以这里并不是返回`2`哦。而且这里的定义也不要求一定要以`s[j]`或者`t[i]`结尾，因此`dp`数组中记录的是之前出现的子序列的总的次数，而不是非得以……结尾。

接下来第二步就是分析`dp`的递推公式，当计算`dp[i][j]`时，只有两种情况，即要么`s.charAt(j - 1)`和`t.charAt(i - 1)`相等，要么就是不相等，下面举例分析相等的情况。假设某个中间过程`s = abab，t = ab`，且现在正在比较`s`的最后一位`b`和`t`的最后一位`b`，那么此时`dp[i][j]`表示的值就是在`s`中，有多少个`t`。可以看到此时正在比较的两位是相等的（`b=b`），现在要计算`s`中有多少个`t`，主要有两种情况。一种是先去掉`s`和`t`最后相等的`b`，然后去看看`s`除了最后一位`b`之外的位置（即`aba`）有多少个`a`（这个`a`来自于`t`除掉最后一位的`b`剩下的位置），可以发现有两个`a`，此时这两个`a`都可以直接跟最新加入的`b`组成2个`ab`（也就是`t`）。也就是说`dp[i][j]`的等号右边至少有一个是`dp[i - 1][j - 1]`。但是这还不够，因为`s`除了最后一位`b`之外的位置（即`aba`）中也有可能原本就存在`ab`（也就是`t`），所以`dp[i][j]`还得加上这里面出现的`t`的个数，因此总的`dp`递推公式为：`dp[i][j] = dp[i - 1][j - 1] + dp[i][j - 1];`。

上面说的是`s.charAt(j - 1)`和`t.charAt(i - 1)`相等的情况，那不相等的情况呢？不相等的情况下，由于最新加进来的那一位（此时放在`s`的后面）并不能与没加进来新的那一位之前的`s`中的某些字符组成`t`，即新加进来的这一位并不能对我的子序列的个数做成任何贡献，那此时子序列的个数只能是从旧的`s`中去找，即此时`dp[i][j] = dp[i][j - 1];`。综上，总的`dp`递推公式为：

```java
if(s.charAt(j - 1) == t.charAt(i - 1)){
    dp[i][j] = dp[i - 1][j - 1] + dp[i][j - 1];
}else{
    dp[i][j] = dp[i][j - 1];
}
```

下面是`dp`数组的初始化。从上面的递推公式可以看到并没有任何的加数字的操作，因此本题即使增加了虚拟行，还是要对`dp`数组进行初始化，不然一通计算下来整个`dp`数组还是`0`。而且从`dp`数组的定义上看，也应该对增加的虚拟行进行初始化工作，因为此时`dp[0][i]`表示的意思是在`s[0~i-1]`这个字符串的所以子序列中，空字符串出现的个数。为什么`t[0~-1]`表示的就是空字符串呢？因为`t[0~0]`就是要表示一个字符了。因为在`s[0~i-1]`这个字符串的所以子序列中，只有一个是空字符串，因此`dp[0][i]`应该都初始化为`1`。比如对于`s = ab`，它的所有子序列为：`{a}`，`{b}`，`{a, b}`和`{}`（这是很关键的地方！之前的数学课好像教过，不理解这个的话就容易将虚拟行全部初始化为`0`）。那对于`dp[i][0]`表示的意思就是在空字符串的所以子序列中，`t[0~i]`这个字符串出现的个数。当i等于`0`的时候，就应该将`dp`初始化为`1`，因为此时`t[0~i]`表示的就是空字符串。但是其他位置很明显就是`0`了，所以最终的初始化工作如下：

```java
for(int i = 0; i <= sLen; i++){
    dp[0][i] = 1;
}
```

整体的代码如下：

```java
class Solution {
    public int numDistinct(String s, String t) {
        int sLen = s.length();
        int tLen = t.length();
        int[][] dp = new int[tLen + 1][sLen + 1];
        for(int i = 0; i <= sLen; i++){
            dp[0][i] = 1;
        }

        for(int i = 1; i <= tLen; i++){
            for(int j = 1; j <= sLen; j++){
                if(s.charAt(j - 1) == t.charAt(i - 1)){
                    dp[i][j] = dp[i - 1][j - 1] + dp[i][j - 1];
                }else{
                    dp[i][j] = dp[i][j - 1];
                }
            }
        }
        return dp[tLen][sLen];
    }
}
```

总结下来，本题主要就两点比较难，一个是`dp`的递推公式，另一个就是`dp`的初始化，但只要理解了原理，就发现不是很难。
