# 96. 不同的二叉搜索树

[https://leetcode.cn/problems/unique-binary-search-trees/description/](https://leetcode.cn/problems/unique-binary-search-trees/description/)

刚开始看根本就不会做，但是只要理解了之后就简单多了。首先定义`dp`数组的含义为`i`个节点组成的二叉树的种类。因为要求n个节点组成的二叉搜索树的种类，我们可以先计算每个节点都做头结点分别能组成多少种二叉搜索树的种类，然后再将这些情况求和就是答案。比如`n=3`的情况，先计算以1作为头结点有2种情况，以2作为头结点有1种情况，以3作为头结点有2种情况，相加就是答案5种情况。

接下来的问题就是确定了头结点后，怎么计算这种情况下的二叉搜索树的种类。以上面`n=3`举例，当以`1`为头结点的时候，左边是没有节点的，但是右边有两个节点，也就是说我们现在只需要计算这两个节点能组成多少种类型的二叉搜索树就好了，动态规划的巧妙之处就在于我们之前已经存储了对于两个节点能组成的二叉搜索树的种类（也就是`dp[2]`的值），这里就直接利用就好了。

经过上述分析，我们可以得出`dp`的推导公式：`dp[i] += dp[j - 1] * dp[i - j];` `dp[i]`表示现在计算的是有`i`个节点的情况，此时的头结点是`j`。因为要将所有节点都做头结点的情况都加起来，所以要用到`+=`。`j - 1`表示左边节点的个数，则`dp[j - 1]`表示的是这些左边节点能组成的二叉搜索数的种类。而`i - j`表示的就是右边节点的个数，则`dp[i - j]`表示的就是这些右边节点能组成的二叉搜索数的种类。注意此时应该是用乘法。

整体代码如下：

```java
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for(int i = 2; i <= n; i++){
            for(int j = 1; j <= i; j++){
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
}
```
