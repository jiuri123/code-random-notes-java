[**46. 携带研究材料-二维dp（0-1背包，含总结）**](46%20%E6%90%BA%E5%B8%A6%E7%A0%94%E7%A9%B6%E6%9D%90%E6%96%99-%E4%BA%8C%E7%BB%B4dp%EF%BC%880-1%E8%83%8C%E5%8C%85%EF%BC%8C%E5%90%AB%E6%80%BB%E7%BB%93%EF%BC%89.md) 用的是二维dp的解法，时间复杂度已经来到极限，但是空间复杂度还是可以将二维优化成一维的，这就是滚动数组的一维dp解法。因为在二维dp中是一行一行的更新，且更新当前行用到的是上面的值和左上角那边的值，对与更新过的那些值，很多都不会再用到了，没必要用一个二维dp进行存储，因此可以考虑只用一个一维数组进行不断的滚动更新，将那些不会再用到的值挤压出去，就可以省下很多的空间。

具体做法就是将原来的二维dp向列方向压缩，即纵向压缩，数组由原来的n行变成1行，但是列数保持不变，相当于只保留了背包容量这个指标（下标i就是背包容量），物品这个指标被隐藏掉了。即现在的一维dp映射到原来的二维dp中，就是原来二维dp中的一行。因此**dp[i]表示的意思就是当背包容量为i的时候，可以选择当前的所有物品的情况下（每个物品只能选择一次），背包中可以达到的最大价值。**

接下来推导dp递推公式。跟二维dp的思路是差不多的，就是遇到的每个物品要么是选，要么是不选。如果选的话，那么就要给这个物品留出空位，并加上这个物品的价值，即：dp[j] = dp[j - cost[i]] + value[i]。如果不选的话，那么就不需要给这个物品留出空位，也不需要加上这个物品的价值，原来还是多少就是多少，因此dp[j] = dp[j]，即保持不变就可以。为什么？因为更新dp[j]前，dp[j]存储的值就是遍历完上一个物品后留下的值，在二维dp中相当于是dp[i - 1][j]的值，因此保持不变就可以，这里也可以看到一维dp的巧妙之处。最后记得比较两者的大小，具体的代码如下：

```java
// 方法二：一维dp解法，先物品后背包
public class Main{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        // 读取第一行
        int n = sc.nextInt();
        int capacity = sc.nextInt();
        int[] cost = new int[n];
        int[] value = new int[n];

        // 读取剩下两行
        for(int i = 0; i < n; i++){
            cost[i] = sc.nextInt();
        }
        for(int i = 0; i < n; i++){ 
            value[i] = sc.nextInt();
        }

        // 定义一维dp数组，不需要初始化
        int[] dp = new int[capacity + 1];

        // 开始填充dp数组
        for(int i = 0; i < n; i++){ // 顺序遍历物品
            for(int j = capacity; j >= cost[i]; j--){ // 倒序遍历背包
                // 由于for条件为j >= cost[i]，因此循环内部不需要判断cost[i]是否大于j了
                // cost[i]小于j的位置因为没有更新，相当于就是直接等于dp[i - 1][j]
                dp[j] = Math.max(dp[j], dp[j - cost[i]] + value[i]);
            }
        }
        // 注意是输出答案，不是return答案
        System.out.println(dp[capacity]);
    }
}
```

关于一维dp的解法，几个关键的问题：

1. 内循环遍历背包可不可以正序遍历？
    - 不可以，任何情况都必须倒序（即使交换内外循环也必须倒序，下面问题4解答）。这个需要一点想象力，就是将当前的一维dp拓展到原来的二维dp中去考虑，即现在的一维dp就是相当于是原来二维dp中的一行。如果内循环是正序遍历的话，那更新当前位置会用到dp[j - cost[i]]的值，而这个值由于是正序遍历而被更新过了（在二维dp中相当于是当前位置的左边那些值），那现在更新当前位置的值用到的就是左边位置的值了，这很明显是错误的。因为我更新当前位置的值应该用到的是左上角的值而不是左边的值。
    - 而当我倒序遍历之后，虽然也会用到dp[j - cost[i]]的值来更新当前位置，但是dp[j - cost[i]]是还没有被更新过的，其还存储着上一轮循环结束后的值，因此此时的dp[j - cost[i]]在二维dp中就是当前位置左上角的那些值，此时更新当前位置才是正确的。
    - 之前的回答：在二维数组的方法中，要更新当前的值，正确的方法是使用的是**当前位置的上面那个位置的值和上面那个位置的左边位置的那些值**（也就是当前位置的左上角）来更新当前位置的值。到了一维数组中，一维数组目前这一行存储的值实际上就是**当前位置的上面那个位置的值和上面那个位置的左边位置的那些值（可以想象二维数组往列方向进行了收缩，行数变为了1）。**如果内层循环从小到大遍历容量，也就是从小到大遍历数组，那么我们用来更新当前位置的值使用的是已经更新过的值，这些更新过的值逻辑上在二维数组中就等于使用当前位置的左边那些值和当前位置的上面那个位置的值来更新当前位置的值，很明显这与上面正确的分析不符合。但是如果背包的容量是从大到小开始遍历，那用来更新当前位置的值使用的是还没有被当前的内层循环更新过的值，也就是当前位置的左上角及上面位置的那些值，此时求出来的答案才是正确的。其实在二维数组的解法中，不管是交换内外循环的位置，还是改变内循环遍历的方向，都可以得出正确的答案，因为我始终使用的是位于当前位置的上面那个值和当前位置的左上角那些值来更新当前位置的值，这些值都是已经存在的，遍历方向并不会改变这些值的选择。
2. 外循环遍历物品可不可以倒序遍历？
    - 不可以，任何情况都不可以。将一维dp放到二维dp中就很好理解了，因为外循环倒序遍历物品相当于是先从右到左，再从下到上。更新当前位置需要用到的值还未更新。
3. 现在是外循环正序遍历物品，内循环逆序遍历背包，那可不可以交换内外循环的位置（即外循环逆序遍历背包，内循环顺序遍历物品）？
    - 一种思路：将其放到二维dp中去考虑，此时的遍历顺序就相当于是先从上到下（物品顺序），再从右到左（背包逆序）进行遍历，很明显更新当前位置的值用到的左上角的值是没有经过更新的，出现错误。
    - 另一种思路：当交换内外层循环后，若此时容量保持从大到小，那我此时实际上是先定住背包的容量（内循环中`dp[j]`一直保持不变），然后去遍历所有的物品并找到价值最大的物品来放进这个容量大小的背包里面，导致每种容量的背包都只放进了一种物品（因为我应该是各种物品的组合，而不是物品之间的比较），所以答案肯定是错误的。因为背包有可能还可以放其他物品进去，使得价值更加大。也就是说即使背包的容量足够大，但对于每个容量我也只考虑了一种物品。
4. 接问题3，如果交换内外循环的位置后，将遍历背包的顺序由逆序改为顺序，此时还可不可以交换内外循环的位置呢（即外循环顺序遍历背包，内循环顺序遍历物品）？
    - 不可以！一种思路：在问题1中已经解答，大概意思就是更新当前位置会用到dp[j - cost[i]]的值，但是dp[j - cost[i]]的值是已经更新过的，在二维dp中相当于是当前位置的左边那些值，但是更新当前位置应该使用当前位置的左上角那些值，因此出现错误。所以综上，不管什么情况下，一维dp遍历背包都应该逆序遍历。
    - 另一种思路：这种情况下会导致每遇到一种背包的容量，都要去将所有的物品都遍历一遍，这有可能导致一个物品被选择多次，问题就从0-1背包问题变成了完全背包问题（后面会讲解完全背包问题），这肯定是错误的，因此这种遍历方式是不可以的！

**总结：**即使是变换成了一维数组的情况，也不要忘记联系二维数组来进行思考（把一维数组放在二维数组的上面），特别是要知道此时一维数组的值在二维数组中位于什么位置，以及一维数组的遍历顺序在二维数组中又是怎样的遍历顺序，此时很多问题就可以迎刃而解了。

**最佳实践：**外循环**顺序**遍历**物品**，内循环**逆序**遍历**背包**。
