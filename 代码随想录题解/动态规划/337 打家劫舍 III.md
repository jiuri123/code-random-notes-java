# 337. 打家劫舍 III

[https://leetcode.cn/problems/house-robber-iii/description/](https://leetcode.cn/problems/house-robber-iii/description/)

有三种解法，第一种是递归解法（后序遍历，由底向上）。假设现在有爷爷、儿子和孙子三种节点，对于爷爷节点来说，只有偷和不偷两种情况，如果偷的话，那么儿子节点就不能偷，只能是去偷孙子节点；如果不偷的话，那么就只能偷儿子节点。其实这里说**偷**字不太合适，更合适的说法是**考虑。**只要是不在考虑范围内的节点，就一定不会偷；但是在考虑范围的节点，我可以偷，也可以不偷，具体偷还是不偷那要看总金额高不高。递归的代码比较简单：

```java
// 1.递归解法，超时
class Solution {
    public int rob(TreeNode root) {
        if(root == null){
            return 0;
        }
        // 爷爷和孙子
        int yyAndsz = root.val;
        if(root.left != null){
            yyAndsz += rob(root.left.left) + rob(root.left.right);
        }
        if(root.right != null){
            yyAndsz += rob(root.right.left) + rob(root.right.right);
        }

        // 儿子
        int ez = rob(root.left) + rob(root.right);
        return Math.max(yyAndsz, ez);
    }
}
```

运行后发现会超时，因为如果当前的儿子节点成为爷爷节点之后，此时又要重新计算其儿子节点的最高金额，但是这个儿子节点的最高金额在之前计算孙子节点的时候已经计算过了，因此出现了重复计算。那么就可以考虑将每个节点计算的总金额用一个map数组存储起来，这样每次需要用到某节点的结果的时候，就可以直接去map数组里面取。这也就是方法二：记忆化存储方法。代码如下：

```java
// 2.记忆化递归解法（递归解法改进版），用时：2ms
class Solution {
    public int rob(TreeNode root) {
        Map<TreeNode, Integer> memo = new HashMap<>();
        return robAction(root, memo);
    }

    public int robAction(TreeNode root, Map<TreeNode, Integer> memo) {
        if(root == null){
            return 0;
        }
        // 如果之前有记住，那么直接返回就好了，不用多余去计算
        if(memo.containsKey(root)){
            return memo.get(root);
        }

        // 爷爷和孙子
        int yyAndsz = root.val;
        if(root.left != null){
            yyAndsz += robAction(root.left.left, memo) + robAction(root.left.right, memo);
        }
        if(root.right != null){
            yyAndsz += robAction(root.right.left, memo) + robAction(root.right.right, memo);
        }

        // 儿子
        int ez = robAction(root.left, memo) + robAction(root.right, memo);

        // 记住结果
        memo.put(root, Math.max(yyAndsz, ez));

        // 返回结果
        return Math.max(yyAndsz, ez);
    }
}
```

**上面两种解法用到了孙子节点，计算爷爷节点能偷的钱还要同时去计算孙子节点投的钱，虽然有了记忆化，但是还是有性能损耗（来自力扣题解）。**

下面介绍方法三。其实对于每个节点，要么是偷，要么是不偷，只有这两种情况。那么我们可以考虑对于每一个节点都新建一个长度为2数组，分别存储的是偷或者不偷该节点的情况下，可以得到的最大金额是多少，就相当于是每个节点都有一个dp数组来记录自己的状态。

如果不偷当前的节点，那么当前节点能偷到的最大钱数 = 左孩子能偷到的钱 + 右孩子能偷到的钱；如果偷本节点，那么当前节点能偷到的最大钱数 = 左孩子选择自己不偷时能得到的钱 + 右孩子选择不偷时能得到的钱 + 当前节点的钱数。那么dp数组的递推公式就是如下：

```java
// 不偷本节点的情况
rootDp[0] = Math.max(leftDp[0], leftDp[1]) + Math.max(rightDp[0], rightDp[1]);
// 偷本节点的情况
rootDp[1] = root.val + leftDp[0] + rightDp[0];
```

总体的代码如下：

```java
// 3.树形Dp，用时：0ms
class Solution {
    public int rob(TreeNode root) {
        int[] rootDp = robAction(root);
        return Math.max(rootDp[0], rootDp[1]); // 取偷与不偷两种情况的最大值
    }

    public int[] robAction(TreeNode root) {
        if(root == null){
            return new int[]{0, 0};
        }
        // 后序遍历
        int[] leftDp = robAction(root.left);
        int[] rightDp = robAction(root.right);
        int[] rootDp = new int[2]; // 每一个节点都会对应（新建）一个dp数组
        // 不偷本节点的情况，子节点可以选择偷或者不偷
        rootDp[0] = Math.max(leftDp[0], leftDp[1]) + Math.max(rightDp[0], rightDp[1]);
        // 偷本节点的情况，子节点只能是不偷
        rootDp[1] = root.val + leftDp[0] + rightDp[0];
        // 将偷与不偷两种情况得到的值作为一个数组（dp数组），进行状态返回
        return rootDp;
    }
}
```
