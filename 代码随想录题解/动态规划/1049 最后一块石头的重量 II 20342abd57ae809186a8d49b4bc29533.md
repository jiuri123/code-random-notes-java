# 1049. 最后一块石头的重量 II

[https://leetcode.cn/problems/last-stone-weight-ii/description/](https://leetcode.cn/problems/last-stone-weight-ii/description/)

想像这么一个回合制游戏场景，我有三只宠物，你也有三只宠物，我们每个回合各派出一只宠物进行对战，直到所有的宠物都战死，只要最后有一只宠物能活下来，那么胜利就属于谁。这些都只有一个技能：自爆，释放此技能则我的一只宠物与你的一只宠物一起爆炸，进行1:1换血（1血量可以造成1伤害），意味着谁的血量多谁就能活下来，活下来的宠物可以继续与对方的下一只宠物进行换血。问最后活下来（最多只会剩下一只宠物活下来） 的那只宠物血量最低是多少？计算方法就是将我的三只宠物的血量求和之后和你三只宠物血量求和之后相减再求绝对值就是答案，不需要每一只单独拿出来进行多轮单挑（因为加法分配率和结合律）。

回到本题，可以发现两个石头进行碰撞，碰撞后剩下的部分可以继续参与碰撞，所以是与上面游戏中的宠物对战是一样的道理。那为了使得最后剩下的那个石头重量最小，可以将这堆石头分成两堆来进行碰撞，但是这两堆石头的总重量要尽可能的接近（因为最后剩下的石头的重量就是这两堆石头相减的结果），这样就可以使得剩下的石头重量最小。这样又回到了01背包的问题，因为此时问题就变成了我要从这堆石头中选出一些石头，这些石头的重量尽可能的接近这堆石头总重量的一半。此时剩下那堆石头的总重量也相应的会尽可能的接近这堆石头总重量的一半，那么这两堆石头相撞之后最后剩下的那个石头的重量是最小的。**其实关键就在于分成两堆之后，此时可以将两堆石头整体来看待（相当于将石头合并起来，两堆石头相撞变成两个大石头相撞），不需要对每对石头单独来看待。**

有了上面的思路，代码就很简单了：

```java
// 二维dp数组解法
class Solution {
    public int lastStoneWeightII(int[] stones) {
        int sum = 0;
        for(int i : stones){
            sum += i;
        }
        int target = sum / 2; // 总重量除以二
        int len = stones.length;
        int[][] dp = new int[len][target + 1];
        for(int i = stones[0]; i <= target; i++){ // dp数组初始化
            dp[0][i] = stones[0];
        }

        for(int i = 1; i < len; i++){
            for(int j = 1; j <= target; j++){
                if(j < stones[i]){ // 石头太大，放不进
                    dp[i][j] = dp[i - 1][j];
                }else{
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i - 1][j - stones[i]] + stones[i]);
                }
            }
        }

        return (sum - dp[len - 1][target]) - dp[len - 1][target];
    }
}

// 一维dp数组解法
class Solution {
    public int lastStoneWeightII(int[] stones) {
        int sum = 0;
        for(int i : stones){
            sum += i;
        }
        int target = sum / 2;
        int[] dp = new int[target + 1];

        for(int i = 0; i < stones.length; i++){
            for(int j = target; j >= stones[i]; j--){
                dp[j] = Math.max(dp[j], dp[j - stones[i]] + stones[i]);
            }
        }

        return (sum - dp[target]) - dp[target];
    }
}
```
