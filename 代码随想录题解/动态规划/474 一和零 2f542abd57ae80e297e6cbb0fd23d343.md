# 474. 一和零

[https://leetcode.cn/problems/ones-and-zeroes/description/](https://leetcode.cn/problems/ones-and-zeroes/description/)

其实本题还是0-1背包的问题，只不过背包从重量这一个限制维度变成了两个限制维度，可以这么想：**背包既不能放太重的物品，也不能放太大的物品。**对应于本题就是选取的子集中既要保证`0`的个数不能超过`m`，又要保证`1`的个数不能超过`n`。对于一维限制的0-1背包问题，不使用空间优化的情况下需要一个二维`dp`数组，其中数组的第二维表示的是背包的重量，那现在多了一个维度的限制，那么二维`dp`数组就不够用了，应该使用三维`dp`数组`dp[i][j][k]`来解决问题。这里`dp[i][j][k]`表示的是重量限制为`j`、体积限制为`k`的背包从下标为`0~i`的物品中选择任意数量的物品，最多可以选择物品的个数为`dp[i][j][k]`。整体代码如下：

```java
// 原始的三维dp解法
class Solution {
    public int findMaxForm(String[] strs, int m, int n) {
        int strsLen = strs.length;
        List<int[]> countMNList = new ArrayList<>();
        for(int i = 0; i < strsLen; i++){
            countMNList.add(str2CountMN(strs[i]));
        }

        int[][][] dp = new int[strsLen][m + 1][n + 1];
        // 注意三维dp的初始化，即只考虑物品0的情况，此时只能放进物品0
        for(int i = countMNList.get(0)[0]; i <= m; i++){
            for(int j = countMNList.get(0)[1]; j <= n; j++){
                dp[0][i][j] = 1;
            }
        }
        
        for(int i = 1; i < strsLen; i++){
            for(int j = 0; j <= m; j++){
                for(int k = 0; k <= n; k++){
                    if(countMNList.get(i)[0] <= j && countMNList.get(i)[1] <= k){ // 如果背包的两个维度都放得下，那么比较放与不放两种情况
                        dp[i][j][k] = Math.max(dp[i - 1][j][k], dp[i - 1][j - countMNList.get(i)[0]][k - countMNList.get(i)[1]] + 1);
                    }else{ // 至少有一个背包的维度放不下，此时直接抛弃该物品
                        dp[i][j][k] = dp[i - 1][j][k];
                    }
                }
            }
        }

        return dp[strsLen - 1][m][n];
    }

    // 统计每个物品0的个数和1的个数
    public int[] str2CountMN(String str){
        int[] ans = new int[2];
        for(int i = 0; i < str.length(); i++){
            if(str.charAt(i) == '0'){
                ans[0]++;
            }else{
                ans[1]++;
            }
        }
        return ans;
    }
}
```

可以看到代码其实跟原来的0-1背包问题没有特别大的区别，也就改进了如下两点：

1. 因为背包多了一个维度的限制，因此相比于原来的二维数组，本题需要用到三维数组；
2. 数组中存的值不再是背包此时可以存的物品的重量的最大值，而是此时背包可以存的物品的最大数量；

跟之前那些0-1背包问题一样，也可以对其进行空间优化，也就是压缩遍历背包的那个维度：

```
// 进阶的二维dp的解法
class Solution {
    public int findMaxForm(String[] strs, int m, int n) {
        int strsLen = strs.length;
        List<int[]> countMNList = new ArrayList<>();
        for(int i = 0; i < strsLen; i++){
            countMNList.add(str2CountMN(strs[i]));
        }

        int[][] dp = new int[m + 1][n + 1];
        
        for(int i = 0; i < strsLen; i++){
            for(int j = m; j >= countMNList.get(i)[0]; j--){
                for(int k = n; k >= countMNList.get(i)[1]; k--){
                    dp[j][k] = Math.max(dp[j][k], dp[j - countMNList.get(i)[0]][k - countMNList.get(i)[1]] + 1);
                }
            }
        }

        return dp[m][n];
    }

    // 统计每个物品0的个数和1的个数
    public int[] str2CountMN(String str){
        int[] ans = new int[2];
        for(int i = 0; i < str.length(); i++){
            if(str.charAt(i) == '0'){
                ans[0]++;
            }else{
                ans[1]++;
            }
        }
        return ans;
    }
}
```

注意上面的进阶的二维dp的解法不需要对原始dp初始化，因为这里的二维dp数组不只是简单的从之前的三维dp复制而来，它初始情况下表示的是在没有任何物品可以选择的情况下，背包能放多少物品，很明显，都是0。这点在[**494. 目标和（含总结）**](494%20%E7%9B%AE%E6%A0%87%E5%92%8C%EF%BC%88%E5%90%AB%E6%80%BB%E7%BB%93%EF%BC%89%2020642abd57ae80669c2de5df2d9f83d6.md) 中已经解释得非常清楚。

最后还是想总结一下，我总是弄不清楚0-1背包问题中的dp数组的值到底是什么意思，也就是说不太清楚dp数组能解决什么样的问题。但是做完这题发现，其实不用纠结，具体问题表示的值也可以不同，只要能解决问题就行，或者说题目要求什么，那么dp数组就可以定义为什么值。目前为止遇到了如下几种可以用dp数组解决的问题：

1. dp数组中存的是背包中**物品的最大重量**，比如[‣](https://app.notion.com/p/20142abd57ae80438602e78ee8d159e0?pvs=21) 中提到的最原始的0-1背包问题、[**416. 分割等和子集**](416%20%E5%88%86%E5%89%B2%E7%AD%89%E5%92%8C%E5%AD%90%E9%9B%86%2020242abd57ae80e6a1b4c5da31255999.md) 中的方法二以及[**1049. 最后一块石头的重量 II**](1049%20%E6%9C%80%E5%90%8E%E4%B8%80%E5%9D%97%E7%9F%B3%E5%A4%B4%E7%9A%84%E9%87%8D%E9%87%8F%20II%2020342abd57ae809186a8d49b4bc29533.md) ；
2. dp数组中存的是**布尔值**，表示的是到目前为止所考虑的物品中是否可以凑出重量刚好等于背包的重量，比如[**416. 分割等和子集**](416%20%E5%88%86%E5%89%B2%E7%AD%89%E5%92%8C%E5%AD%90%E9%9B%86%2020242abd57ae80e6a1b4c5da31255999.md) 中的方法一；
3. dp数组中存的是**方法个数**，这个数表示的意思是到目前为止所考虑的物品中如果可以凑出重量刚好等于背包的重量，那么有多少种物品搭配的方法（取法），比如[**494. 目标和（含总结）**](494%20%E7%9B%AE%E6%A0%87%E5%92%8C%EF%BC%88%E5%90%AB%E6%80%BB%E7%BB%93%EF%BC%89%2020642abd57ae80669c2de5df2d9f83d6.md) 。

从上面的总结中可以看到动态规划可以解决的问题有很多，不要被最原始的0-1背包问题束缚住了手脚。同时也可以看到最开始就定义清楚dp数组里面的值到底表示什么意思对后面的初始化以及遍历顺序是有多么重要的影响。
