# 52. 携带研究材料-二维dp（完全背包，含总结）

[https://kamacoder.com/problempage.php?pid=1052](https://kamacoder.com/problempage.php?pid=1052)

完全背包与0-1背包的差别：0-1背包问题中每个物品只有一个，而完全背包问题中每种物品有无数个，所以也就是说每种物品可以被选择无数次，只要保证放入背包的物品总重量不超过背包容量就可以了。

按照动规五部曲，先定义完全背包问题中`dp[i][j]`的意义，由上可知`dp[i][j]`表示的是**从下标为`[0-i]`的物品，每个物品可以取无限次，放进容量为`j`的背包，价值总和最大是多少**。

接下来就是推导递归公式，先回顾0-1背包的递归公式：`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);`可以看到其中的`dp[i - 1][j - weight[i]]`表示的是不考虑当前物品i，只考虑物品`0~i-1`，但同时背包又给物品i留下足够的位置的情况下，此时的背包价值最大是多少（也就是取物品`i`）。但是完全背包问题中物品`i`是有无数个的，可以被选择多次，所以此时物品`i`也应该被考虑在内，不应该被排除掉，因此`dp[i - 1][j - weight[i]]`应该变成`dp[i][j - weight[i]]`，也就是考虑物品`0~i`，但同时呢背包又给多一个的物品`i`留下足够位置的情况下，此时的背包价值最大是多少。即`dp[i][j - weight[i]]`里面可能已经包含多个物品`i`，但是留下的空间又可以让我多放一个。最终的推导公式为：`dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);`。可以看到**0-1背包**问题中当前位置的值是由其位置的**上面**（`dp[i - 1][j]`）和（`dp[i - 1][j - weight[i]] + value[i]`）两个位置共同得来，但是**完全背包**问题是通过当前位置的**上面**（`dp[i - 1][j]`）和**左边**（`dp[i][j - weight[i]] + value[i]`）两个位置得来，这就是与0-1背包问题不一样的地方。

第三步是初始化，对于第一行，如果各背包容量能放得下第一个物品的话（也就是下标为0的物品），那就使劲放，放不下就初始化为0；对于第一列，因为背包容量为0，所以直接初始化为0就好了。

第四步是遍历顺序，由于当前位置的值是由当前位置的上位置和左位置共同得来，所以遍历顺序是先从左往右，再从上往下。

第五步省略。二维dp最终代码如下：

```java
// 方法一：完全背包的二维dp解法
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int bagWeight = scanner.nextInt();

        int[] weight = new int[n];
        int[] value = new int[n];

        for (int i = 0; i < n; i++) {
            weight[i] = scanner.nextInt();
            value[i] = scanner.nextInt();
        }

        int[][] dp = new int[n][bagWeight + 1];

        // 初始化二维dp数组的第一行
        for (int j = weight[0]; j <= bagWeight; j++) {
            dp[0][j] = dp[0][j - weight[0]] + value[0];
        }

        // 开始填充二维dp数组
        for (int i = 1; i < n; i++) { // 外循环顺序遍历物品
            for (int j = 0; j <= bagWeight; j++) { // 内循环顺序遍历背包
                if (j < weight[i]) { // 背包放不下
                    dp[i][j] = dp[i - 1][j];
                } else { // 背包放得下
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);
                }
            }
        }

        System.out.println(dp[n - 1][bagWeight]);
        scanner.close();
    }
}
```

完全背包问题二维dp解法的几个注意点：

1. **不管是遍历物品，还是遍历容量，都必须是顺序遍历（即使交换内外循环也是如此）。**这时由“更新当前位置需要用到当前位置左边的值和上边的值”这个条件硬性决定的。因为如果遍历容量逆序的话，左边的值还不存在，出现错误；而遍历物品逆序的话，上边的值还不存在，出现错误。因此不管任何情况下，遍历物品和容量都只能是顺序遍历。
2. **保证上述“遍历物品和容量都是顺序遍历”的前提下，内外循环是可以交换的。**因为不管是先从左往右，再从上往下，还是先从上往下，在从左往右，用来更新当前位置的左边的值和上边的值都是存在的，因此更换内外循环不影响最终结果。
