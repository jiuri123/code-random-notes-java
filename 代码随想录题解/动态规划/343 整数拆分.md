# 343. 整数拆分

[https://leetcode.cn/problems/integer-break/description/](https://leetcode.cn/problems/integer-break/description/)

有两种方法，第一种是动态规划法。首先定义`dp`数组的含义：`dp[i]`的值表示的含义是对数字`i`不管以何种方式进行拆分后得到的最大的那个乘积，这里的拆分方式指的是将数字拆分成至少两个正整数及以上的和。

接下来的问题就是如何求`dp`数组的推导公式。对于遍历到的每个数字，我们需要对其所有的拆分方式进行遍历才能知道这些拆分方式中哪个拆分方式可以使得乘积最大。拆分的方式可以分成两种：一种是拆分成两个数字；还有一种就是拆分成3个及3个以上的数字。所以我们只需要记录这两种拆分方式乘积最大的那个就好了。由此可得DP数组的推导公式如下：

`dp[i] = Math.max(dp[i], Math.max(j * (i - j), j * dp[i - j]));`

`j * (i - j)`表示的就是将数字拆分成两个数的和的形式；`j * dp[i - j]`表示的就是将数字拆分成3个及以上的数的和的形式，这里首先是将数字i拆出一个j，然后将剩下的`i - j`继续进行拆分，但是幸运的是`dp[i - j]`中记录的是对所有`i - j`的拆分方式中乘积最大的那个数，也就是说不用我们重新去计算了，直接使用之前存储的结果就好了。整体的代码如下：

```java
// 方法一：动态规划法
class Solution {
    public int integerBreak(int n) {
        int[] dp = new int[n + 1];
        dp[2] = 1;
        for(int i = 3; i <= n; i++){
            for(int j = 1; j < i; j++){
                dp[i] = Math.max(dp[i], Math.max(j * (i - j), j * dp[i - j]));
            }
        }
        return dp[n];
    }
}
```

其实内循环还可以继续优化。根据数学推论：**拆分一个数 n 使之乘积最大，那么一定是拆分成m个近似相同的子数，那么相乘才是最大的。**也就是说拆分出来的数尽可能的相同，这样乘积才是尽可能大的。比如说10，只有拆成5*5、3*3*4、2*2*2*2*2这几种形式才是有可能使得最后的乘积是最大的，如果拆成6*4，那这个拆分方式的乘积一定是没有前面几种子数尽可能相同的拆分方式的乘积要大的。所以其实`j`遍历到`i/2`就好了，因为`i/2`后面的拆分方式只会让数与数之间的距离越来越大，也就不可能是最大值。或者换一个理解方式，将一个数拆成尽可能相同的几个子数，要么是对半分，也就是拆成两个子数，比如10拆成5*5；要么是拆分成3个及以上的子数，比如10拆成3*3*4和2*2*2*2*2。可以发现`j`的最大值都不会超过`i`的一半，超过就不可能是最大值了。优化后的代码：

```java
// 方法一：动态规划法（内循环优化版）
class Solution {
    public int integerBreak(int n) {
        int[] dp = new int[n + 1];
        dp[2] = 1;
        for(int i = 3; i <= n; i++){
            for(int j = 1; j <= i/2; j++){
                dp[i] = Math.max(dp[i], Math.max(j * (i - j), j * dp[i - j]));
            }
        }
        return dp[n];
    }
}
```

第二种方法是数学推导法。主要基于一下两个推论：

1. **推论一：** 若拆分的数量`*a*`确定， 则**各拆分数字相等时**，乘积最大。
2. **推论二：** 将数字 `*n*` 尽可能以因子 3 等分时，乘积最大。

所以要想使拆分出来的子数乘积最大，那么就要尽可能的将数字分出尽可能多的3出来。代码如下：

```java
// 方法二：数学推导法
class Solution {
    public int integerBreak(int n) {
        if(n <= 3) return n - 1;
        int a = n / 3;
        int b = n % 3;
        if(b == 0) return (int)Math.pow(3, a);
        if(b == 1) return (int)Math.pow(3, a - 1) * 4;
        return (int)Math.pow(3, a) * 2;
    }
}
```

可以看到当余数为1时应该将一个3取出来，和这个1合并成4，也就是2*2，此时结果才是最大的。
