# 55. 跳跃游戏

[https://leetcode.cn/problems/jump-game/description/](https://leetcode.cn/problems/jump-game/description/)

比较简单，遍历节点的时候先看看之前的节点能不能跳到当前的节点，如果不能就直接退出循环了。如果能，就计算当前的节点能跳到的最远距离，看看能否到达最后一个下标。同时记得更新之前记录的能跳到的最远的下标。代码如下：

```java
// 方法一：用set记录范围，但是有很多重复的遍历，时间复杂度太高
class Solution {
    public boolean canJump(int[] nums) {
        if(nums.length == 1){
            return true;
        }
        Set<Integer> set = new HashSet<>();
        set.add(0);
        for(int i = 0; i < nums.length; i++){
            if(!set.contains(i)){
                break;
            }
            for(int j = i + 1; j <= i + nums[i]; j++){
                set.add(j);
                if(j == nums.length - 1){
                    return true;
                }
            }
        }
        return false;
    }
}

// 方法二（推荐）：直接用一个变量记录目前能跳到的最远距离
class Solution {
    public boolean canJump(int[] nums) {
        int farthest = 0; // 记录当前能跳到的最远位置
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            // 如果当前位置已经超过了之前能达到的最远距离，说明断层了，跳不过来
            if (i > farthest) {
                return false;
            }

            // 在当前位置，尝试更新能跳到的最远边界
            farthest = Math.max(farthest, i + nums[i]);

            // 如果最远边界已经覆盖了最后一个下标，直接成功
            if (farthest >= n - 1) {
                return true;
            }
        }

        return false;
    }
}
```
