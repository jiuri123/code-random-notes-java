# 763. 划分字母区间

[https://leetcode.cn/problems/partition-labels/description/](https://leetcode.cn/problems/partition-labels/description/)

因为每个字母只能在一个片段中，那我们分割出来的这个子集要足够的大，使得子集里面的元素不可能在其他子集里面出现，但是也得足够的小，使得子集的数量尽可能的多。我们可以直接对字符串进行遍历，每遍历到一个元素，就去找这个元素在其后的字符串中最后出现的那个位置，将其中的元素都囊括进一个子集中，然后继续对这些囊括进来的元素寻找他们的最远边界（也就是最后出现的位置），不断的更新这个子集的最远边界，这个过程其实是在不断地扩大子集的长度的。在遍历的过程中相当于是要找每一个字母的边界，**如果找到之前遍历过的所有字母的最远边界，说明这个边界就是这个子集的分割点了**。此时前面出现过所有字母，最远也就到这个边界了。代码如下：

```java
// 方法一：显式记录子集长度，遍历的过程找最远边界
class Solution {
    public List<Integer> partitionLabels(String s) {
        List<Integer> ans = new ArrayList<>();
        int strLen = s.length();
        int maxIndex = -1;
        int subStrLen = 0;
        for(int i = 0; i < strLen; i++){
            char c = s.charAt(i);
            int tempMaxIndex = s.lastIndexOf(c);
            // 每遇到一个元素就需要更新maxIndex
            maxIndex = Math.max(maxIndex, tempMaxIndex);
            if(i == maxIndex){ // 到达子集终点
                subStrLen++; // 将当前终点元素加入到子集中
                ans.add(subStrLen);
                subStrLen = 0; // 重新开始计数
            }else{ // i > maxIndex和i < maxIndex的处理逻辑是一样
                subStrLen++;
            }
        }
        return ans;
    }
}

// 方法二：提前记录每个元素的最远边界，隐式记录子集的长度，只记录起始点
class Solution {
    public List<Integer> partitionLabels(String s) {
        List<Integer> ans = new ArrayList<>();
        char[] chars = s.toCharArray();
        int[] edge = new int[26];

        // 记录s中每个元素的最远下标
        for(int i = 0; i < chars.length; i++){
            edge[chars[i] - 'a'] = i;
        }

        int maxIndex = 0; // 记录当前子集中可覆盖的最远边界
        int begin = -1; // 记录当前子集的起始点
        for(int i = 0; i < chars.length; i++){
            // 更新最远边界
            maxIndex = Math.max(edge[chars[i] - 'a'], maxIndex);
            if(i == maxIndex){
                // 这一句很巧妙，包含了“一个点就是一个独立子集”的边界情况
                ans.add(i - begin); 
                begin = i;
            }
        }

        return ans;
    }
}

// gemini
class Solution {
    public List<Integer> partitionLabels(String s) {
        // 1. 统计每个字符最后出现的下标位置
        int[] lastOccurIndex = new int[26];
        for (int i = 0; i < s.length(); i++) {
            lastOccurIndex[s.charAt(i) - 'a'] = i;
        }

        List<Integer> res = new ArrayList<>();
        int begin = 0; // 当前片段的起始位置
        int end = 0;   // 当前片段需要的最小结束位置

        // 2. 贪心划分
        for (int i = 0; i < s.length(); i++) {
            // 更新当前片段中所有字符能到达的最远边界
            end = Math.max(end, lastOccurIndex[s.charAt(i) - 'a']);
            
            // 当遍历到该边界时，说明当前片段可以独立，记录长度
            if (i == end) {
                res.add(end - begin + 1);
                begin = end + 1; // 更新下一个片段的起点
            }
        }
        
        return res;
    }
}
```
