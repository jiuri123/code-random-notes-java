# 1005. K 次取反后最大化的数组和

[https://leetcode.cn/problems/maximize-sum-of-array-after-k-negations/description/](https://leetcode.cn/problems/maximize-sum-of-array-after-k-negations/description/)

本题有两种贪心解法。第一种，既然我要在改变`k`次符号之后使得数组和最大，那么我每次可以将数组中最小的数选出来进行符号变换，因为如果数组里面有负数，那么这个选出来的数就是绝对值最大的负数，将这个绝对值最大的负数变换成整数就可以最大化的增加整体的和；如果数组里面没有负数，那就是将最小的正数或者`0`选出来，将这个数符号变换成负的可以使得对整体和的损失最小。这也就是贪心的思想，代码如下：

```java
class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        for(int i = 0; i < k; i++){
            int minNum = 101;
            int minNumIndex = -1;
            for(int j = 0; j < nums.length; j++){
                if(nums[j] < minNum){
                    minNum = nums[j];
                    minNumIndex = j;
                }
            }
            nums[minNumIndex] = -nums[minNumIndex];
        }

        int sum = 0;
        for(int i = 0; i < nums.length; i++){
            sum += nums[i];
        }
        return sum;
    }
}

```

第二种贪心的思想是我先按照绝对值从大到小的顺序将数组中所有的负数转换为正数，如果此时还剩下`k`，那么就将这个`k`全部交给最小的那个非负整数。代码如下：

```java
class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        // 按照绝对值从大到小排序
        nums = Arrays.stream(nums)
                    .boxed()
                    .sorted((a, b) -> Math.abs(b) - Math.abs(a))
                    .mapToInt(Integer::intValue)
                    .toArray();
        int numsLen = nums.length;
        for(int i = 0; i < numsLen; i++){
            // 对绝对值最大的负数进行符号变换
            // 注意是只对负数进行变换，绝对值大的正数不要动
            if(nums[i] < 0 && k > 0){
                nums[i] = -nums[i];
                k--;
            }
        }

        // 剩下的k全部交给非负整数中最小的那个数
        // 为什么用if而不用while呢？
        // 因为我只对一个数使用k次符号变换，
        // k是偶数符号不变，k是奇数符号相反
        if(k % 2 == 1){
            nums[numsLen - 1] = -nums[numsLen - 1];
        }

        // 求和
        int sum = 0;
        for(int num : nums){
            sum += num;
        }
        return sum;
    }
}
```

注意：不可以使用如下改变排序规则的方法对存储基本数据类型的数组进行排序，除非数组的元素是引用的数据类型，或者不改变规则，直接按照默认的规则：

`Arrays.sort(nums, (a, b) -> Math.abs(b) - Math.abs(a));`

`Arrays`的`sort`方法只能对**引用数据类型**进行排序，对于基本数据类型的排序要么是使用本题的流方法，要么是如下所示将基本数据类型进行包装之后进行排序。

```java
// 将 int 数组转换为 Integer 数组
Integer[] numsWrapper = new Integer[nums.length];
for (int i = 0; i < nums.length; i++) {
    numsWrapper[i] = nums[i];
}
// 按绝对值从大到小排序
Arrays.sort(numsWrapper, (a, b) -> Math.abs(b) - Math.abs(a));
```

要么是直接按照默认的方式进行排序，即`sort`直接传入一个基本数据类型的数组，后面不要有规则。
