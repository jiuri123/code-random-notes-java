# 135. 分发糖果

[https://leetcode.cn/problems/candy/description/](https://leetcode.cn/problems/candy/description/)

思路是对分数数组遍历两遍，第一次遍历是从左到右，将当前的孩子和其左边的孩子进行比较，保证每个孩子的糖果数量一定大于其左边的孩子的糖果数；第二次遍历是从右往左，将当前的孩子和其右边的孩子进行比较，保证每个孩子的糖果数一定大于其右边的孩子的糖果数。两次遍历后，每个孩子的糖果数一定大于其左右两边孩子的糖果数（局部最优），因此全局也是最优的。代码如下：

```java
class Solution {
    public int candy(int[] ratings) {
        int len = ratings.length;
        int[] candy = new int[len];
        
        // 每个孩子至少有一颗糖
        // for(int i = 0; i < len; i++){
        //     candy[i] = 1;
        // }

        candy[0] = 1;
        
        // 保证左局部最优
        for(int i = 1; i < len; i++){
            if(ratings[i] > ratings[i - 1]){
                candy[i] = candy[i - 1] + 1;
            }else{
                // 如果分数没有比左边的孩子多，
                // 那么就只给最少的1颗，保证“最少糖果数目”
                // 其实也等价于上面注释掉的第一个for循环
                candy[i] = 1;
            }
        }

        // 保证右局部最优
        for(int i = len - 2; i >= 0; i--){
            if(ratings[i] > ratings[i + 1]){
                // 加max是为了保证右局部最优的同时，左局部最优的条件不被破坏
                candy[i] = Math.max(candy[i + 1] + 1, candy[i]);
        }

        // 左右都是最优的，局部最优，那么推出全局最优
        int sum = 0;
        for(int i : candy){
            sum += i;
        }
        return sum;
    }
}
```

为什么在保证右局部最优的时候，不是直接candy[i] = candy[i + 1] + 1，而是candy[i] = Math.max(candy[i + 1] + 1, candy[i]);？因为经过左局部最优之后，candy[i]的值是有可能比candy[i + 1]要大很多的，因此如果仅仅只是candy[i] = candy[i + 1] + 1，那么就有可能降低candy[i]的值，使得左局部最优条件被破坏。

那万一max选中的是candy[i + 1] + 1，也就是相当于执行candy[i] = candy[i + 1] + 1，那么会破坏左最优条件吗？不会，因为如果当前的数比左边的数大或者相等，那么再加一个1也还是满足左最优条件的；如果当前的数比左边的数小，那么还是符合左最优条件，知识不符合右最优条件，不过待会右最优循环迟早会循环到这两个数，使得这两个数符合条件，所以现在其实也不用担心。
