# 53. 最大子数组和（贪心法）

[https://leetcode.cn/problems/maximum-subarray/description/](https://leetcode.cn/problems/maximum-subarray/description/)

本题暴力解法就是两层循环，内外循环分别控制连续子数组的终点和起点，然后计算和。但是时间复杂度太高，有很多重复的计算，比如当加入当前元素后，连续子数组的和此时为负数，后面就不需要再继续遍历了，因为负数只会拖累后续加进来的数字。因此此时还不如将后续加进来的数字自成一派，不要你这个和为负数的子数组，我反而还有可能会更大。所以应该将数组的起始点改到当前元素的下一个位置，从下一个位置开始计算连续子数组的和。代码如下：

```java
// 方法一：思路清晰版
class Solution {
    public int maxSubArray(int[] nums) {
        int maxSum = Integer.MIN_VALUE;
        int tempSum = 0;
        for(int i = 0; i < nums.length; i++){
            tempSum += nums[i];
            
            maxSum = Math.max(maxSum, tempSum);

            // 累加和是负数，重新累加
            if(tempSum < 0) tempSum = 0;
        }
        return maxSum;
    }
}

// 方法二：面试推荐法
class Solution {
    public int maxSubArray(int[] nums) {
        // 1. 初始化：由于数组至少包含一个元素，
        // 将第一个元素作为当前的局部最大和全局最大
        int currentSum = nums[0];
        int maxSum = nums[0];

        // 2. 从第二个元素开始遍历
        for (int i = 1; i < nums.length; i++) {
            // 核心逻辑：如果前面的和是负数，则舍弃，从当前数重新开始
            // 否则，将当前数累加到前面的和中
            currentSum = Math.max(nums[i], currentSum + nums[i]);

            // 3. 更新全局最大值
            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}
```

注意，不是遇到负数就重新设置起始点，而是当前子数组的和为负数才重新设置子数组的起始点。因为遇到负数有可能我当前的子数组的和还是为正数的，只要是正数，就代表我这个正数有可能对后续加进来的数字有增强的作用，使得我新的子数组总和更加的大。

还有就是`maxSum`要初始化为最小整数，因为有可能输入数组的数字都为负数，如果`maxSum`初始化为`0`，那返回的结果就是`0`，但是此时的结果应该是最大的那个负数，而不是`0`。
