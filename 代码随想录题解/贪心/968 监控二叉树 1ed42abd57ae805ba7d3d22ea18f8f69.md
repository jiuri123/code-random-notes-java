# 968. 监控二叉树

[https://leetcode.cn/problems/binary-tree-cameras/description/](https://leetcode.cn/problems/binary-tree-cameras/description/)

从示例中可以发现，要使得摄像头数量最少，叶节点最好不要装摄像头，因为叶节点的摄像头完全可以交给叶节点的父节点来安装，这样在某些情况下（也就是某个父节点的两个子节点都是叶节点的情况下）可以节省一个摄像头。所以我们大概的思路就是叶节点的父节点装摄像头（局部最优），此后每隔两个节点就装一个摄像头，可以使得最终的摄像头数量最少（全局最优）。因为要先从叶节点的父节点开始装摄像头，也就是从底向上开始装摄像头，所以使用后序遍历。

问题是怎么做到每隔两个节点就安装一个摄像头呢？可以将子节点的状态向上层节点传递，状态分为3种：0表示该节点没有被监控，1表示该节点安装了摄像头，2表示该节点是被监控的状态。如果当前节点的两个子节点有一个是没被监控的状态，那么当前节点就应该安装一个监控。因为是后序遍历，此时不安装，后面就没有机会安装了，那么那个没有被监控的子节点就永远不会被监控到，所以安装监控的优先级是最高的。其次是假如两个子节点中至少有一个是安装了监控的，那么此节点需要装监控，而是应该向上层放回自己是已被监控的状态，将安装监控的工作交给上层处理。最后是如果两个子节点都是被监控的状态，那么当前节点就需要向上层返回没有被监控的状态，将安装监控的工作交给父节点处理。

还有一种特殊情况是当前节点为空节点，此时应该向上层返回该空节点已被监控的状态，因为如果返回没被监控的状态，那么叶节点就需要安装监控，而我们在上面的分析是不应该由叶节点安装监控，这样会导致监控数量增多，而是应该由叶节点的父节点来安装监控，所以不能返回没被监控的状态。也不能返回已安装监控的状态，否则叶节点的父节点就不能安装监控了，因为叶节点都已被监控。综上，正确的返回状态应该是已被监控的状态，这样叶节点才好返回没被监控的状态，让父节点来完成安装监控的操作，使得最终的摄像头数量最少。整体代码如下：

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    int count = 0;
    public int minCameraCover(TreeNode root) {
        if(inOrderTraversal(root) == 0){ 
		        // 最后还需要检查根节点的状态，如果没有被监控，就需要在头结点装摄像头
            count++;
        }
        return count;
    }

    // 0：该节点没有被监控（没被覆盖）
    // 1：该节点是摄像头
    // 2：该节点已被监控（已被覆盖）
    public int inOrderTraversal(TreeNode root) {
        // 空节点默认被监控，否则叶子节点就要放监控了
        // 空节点也不能是摄像头，否则叶子节点的父节点就不能放监控了
        if(root == null){
            return 2;
        }

        int left = inOrderTraversal(root.left);
        int right = inOrderTraversal(root.right);

        // 以下三个if语句顺序不可以变换
        if(left == 0 || right == 0){ 
		        // 如果左右孩子至少有一个没有被监控，那么当前节点就需要放监控
            count++;
            return 1;
        }else if(left == 1 || right == 1){ 
		        // 如果左右孩子至少有一个是摄像头，那么当前节点就是被监控的状态
            return 2;
        }else{ 
		        // 如果左右孩子都是被监控的状态（没有摄像头）
		        // 那么当前节点就是没有被监控的状态，交给父节点来监控
            return 0;
        }
    }
}
```
