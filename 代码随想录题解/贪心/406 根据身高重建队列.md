# 406. 根据身高重建队列

[https://leetcode.cn/problems/queue-reconstruction-by-height/description/](https://leetcode.cn/problems/queue-reconstruction-by-height/description/)

与[**135. 分发糖果**](135%20%E5%88%86%E5%8F%91%E7%B3%96%E6%9E%9C.md) 类似，本题也涉及到两个维度的贪心，对于此种双维贪心算法，不要同时考虑两个维度的贪心，这样只会顾此失彼，最好的办法是先保证一个维度的贪心，再在此基础上对林外一个维度进行贪心。本题的两个维度分别为身高和前面比自己高的人数，那我们先保证哪一维的贪心呢？可以先尝试对k进行排序，可以发现排序结束之后还是非常的乱，既不能保证身高的降序，很多人的k值所在的位置也是错误的，因此此法不通。那么就只能考虑对身高的降序排序，排完序之后可以发现我们把身高这一维给确定下来了，也就是说不管怎么样，**此时每个人的前面那些人的身高一定是比我高的，**那这时候我需要考虑的维度就小了一维。接下来保证k的贪心就顺理成章了，因为k指的是前面有多少人比我大，那我直接将这个人往前插入到前面那些比我高的人中的第k个位置不就好了，那么前面就只有k个人比我高，而且我的插入也不影响我插入位置的后面那些人，因为我是往前插，而前面的人都是比我高的，不管我插去那里，都不会对那些人的k值产生影响（这里也体现了先确定身高这一维的好处）。因此最后两个维度确定下来，局部贪心保证了全局贪心，得解。代码如下：

```java
class Solution {
    public int[][] reconstructQueue(int[][] people) {
        // 1. 排序，因为people存的是引用数据类型（int[]），可以使用自定义比较规则
        Arrays.sort(people, (a, b) -> {
            if(a[0] != b[0]) return b[0] - a[0]; // 身高不同时，按身高降序
            return a[1] - b[1]; // 身高相同时，按 k 升序
        });

        // 2. 从左到右将元素重新插入到链表中k的位置
        LinkedList<int[]> que = new LinkedList<>();
        for(int[] p : people){
            que.add(p[1], p);
        }

        // 3. 将que转换为二维数组返回
        // new int[people.length][]表示定义一个可存储people.length个int[]的数组
        return que.toArray(new int[people.length][]);
    }
}
```

总结：对于多维贪心算法，不要多维同时考虑，容易顾此失彼。最好的方法是先只考虑一维，保证一维的贪心后，再考虑另外一维的贪心……以此类推。
