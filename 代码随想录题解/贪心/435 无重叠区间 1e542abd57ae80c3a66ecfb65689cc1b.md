# 435. 无重叠区间

[https://leetcode.cn/problems/non-overlapping-intervals/](https://leetcode.cn/problems/non-overlapping-intervals/)

思路就是先对左边界进行排序（为了让区间尽可能的重叠，也为了更方便直接从头到尾进行一次遍历就解决问题），然后从头开始遍历区间，如果当前区间和之前记录的区间有重叠，那么此时就需要移除一个区间使得重叠消失，这里移除哪个区间就体现了贪心的思路：**每次检测到有重叠，就将右边界更远的那个区间移除，因为右边界更远的那个区间更有可能与其他的区间重合。**代码如下：

```java
class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        // 按照左边界从小到大排序
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        // 记录有重叠的情况下，右边界更小的那个区间
        int overlapCount = 0;
        int curBeginIndex = intervals[0][0];
        int curEndIndex = intervals[0][1];
        
        // 开始遍历
        for(int i = 1; i < intervals.length; i++){
            // 如果没有重叠，则不需要移除任何区间，同时记录新区间
            if(intervals[i][0] >= curEndIndex){
                curBeginIndex = intervals[i][0];
                curEndIndex = intervals[i][1];
                continue;
            }else{ // 有重叠区间
                overlapCount++;
                // 优先将右边界更长的那个节点逻辑移除（贪心）
                // 因为这个节点在后面更有可能覆盖更多的区间
                if(intervals[i][1] < curEndIndex){
		                // 重叠情况下，只记录右边界更小的那个区间
		                // 这样就相当于是删除了右边界更大的那个区间
		                // 因为之后的区间不会在与这个右边界更大的区间进行比较了
                    curEndIndex = intervals[i][1];
                }
            }
        }
        
        return overlapCount;
    }
}
```
