# 56. 合并区间

[https://leetcode.cn/problems/merge-intervals/description/](https://leetcode.cn/problems/merge-intervals/description/)

思路比较简单，还是先将区间按照起始点从小到大进行排序，然后依次判断各点之间是否有重叠，有重叠则合并，没有重叠则将点插入进结果队列中。代码如下：

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        // 按照起始点从小到大排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        int len = intervals.length;
        List<int[]> res = new ArrayList<>();
        // 将第一个节点加入到的结果队列中
        res.add(new int[]{intervals[0][0], intervals[0][1]});
        
        for(int i = 1; i < len; i++){
            int currBegin = intervals[i][0];
            int currEnd = intervals[i][1];
            int preEnd = res.get(res.size() - 1)[1];

						// 如果当前结点的左端点小于上一节点的右端点，说明有重叠
            if(currBegin <= preEnd){ 
                if(currEnd > preEnd){ // 延长右端点，相当于合并
                    res.get(res.size() - 1)[1] = currEnd;
                }
            }else{ // 没有重叠，先加入到结果队列中，后续会取出来继续合并
                res.add(new int[]{currBegin, currEnd});
            }
        }
        return res.toArray(new int[res.size()][]);
    }
}
```
