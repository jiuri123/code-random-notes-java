# 738. 单调递增的数字

[https://leetcode.cn/problems/monotone-increasing-digits/description/](https://leetcode.cn/problems/monotone-increasing-digits/description/)

思路是从后往前遍历数字的各位，当当前遍历到的数位比上一个数位要大的时候，可以将这个数位减1，然后将上一个数置为9，使得局部最优，从而可以推出全局最优。比如数字332，当遍历到中间的3时，发现3大于上一位的2，所以将3减一变为2，然后将最后一位的2置为9，这样既可以满足单调递增，还使得最终得到的数字尽量是最大的。代码如下：

```java
class Solution {
    public int monotoneIncreasingDigits(int n) {
        String str = String.valueOf(n);
        char[] c = str.toCharArray();
        int strLen = str.length();
        int start = strLen;
        for(int i = strLen - 2; i >= 0; i--){
            if(c[i] > c[i + 1]){
                c[i]--;
                start = i + 1;
            }
        }

        for(int i = start; i < strLen; i++){
            c[i] = '9';
        }
        
        return Integer.parseInt(String.valueOf(c));
    }
}
```
