# 452. 用最少数量的箭引爆气球

[https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/description/](https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/description/)

本题的贪心思路本质上就是找到重叠气球数最多的那些区间，在这些区间内发射箭头，可以使得爆炸的气球数最多（覆盖的气球最多）。那怎么找到这个区间呢？首先对气球区间的左节点进行从小到大的排序，为什么要排序呢？因为排序可以更加方便的找到重叠区间，加入不排序的话，直接从头开始找重叠区间会非常的麻烦，因为每看一个区间都要从头看一遍其他的区间，看看这个区间属于哪个重叠区间，时间复杂度非常的高。而排序后直接从左到右比较当前气球左边界和重叠区间的右边界就可以找完所有的重叠区间，非常的简单。也可以说：**为了让气球尽可能的重叠，需要对数组进行排序**。

然后接下来每遍历一个气球的区间，就看看这个气球是否与之前记录的重叠区间有交集，如果有的话，就根据这个气球的区间来缩小重叠区间（重叠区间只能是不断地缩小）；如果不在的话，那就说明有新的重叠区间出现（需要新的箭），这时候重新开始记录新的重叠区间。最后得到所有的重叠区间，有多少个重叠区间就表示我要射多少只箭。代码如下：

```java
class Solution {
    public int findMinArrowShots(int[][] points) {
        // 如果输入为空，直接返回 0，因为没有气球需要射
        if (points.length == 0) {
            return 0;
        }

        // 按区间的起始点（points[i][0]）升序排序，若起始点相同，则按结束点（points[i][1]）升序排序
        Arrays.sort(points, (a, b) -> {
            if (a[0] != b[0]) {
                // 比较起始点，优先按起始点排序
                return Integer.compare(a[0], b[0]);
            } else {
                // 起始点相同，比较结束点
                return Integer.compare(a[1], b[1]);
            }
        });

        // 不对结束点进行排序也是可以的
        // Arrays.sort(points, (a, b) -> Integer.compare(a[0], b[0]));

        // 初始化箭头数量
        int arrowCount = 0;
        // 初始化当前重叠区间的起始点和结束点，使用 long 类型防止整数溢出
        long arrowBeginIndex = Long.MIN_VALUE;
        long arrowEndIndex = Long.MIN_VALUE;

        // 遍历所有排序后的区间
        for (int[] point : points) {
            // 如果当前区间的起始点大于当前重叠区间的结束点，说明没有重叠，需要新的一支箭
            if (point[0] > arrowEndIndex) {
                // 增加箭头数量
                arrowCount++;
                // 更新当前重叠区间的起始点和结束点为当前区间的起始点和结束点
                arrowBeginIndex = point[0];
                arrowEndIndex = point[1];
            } else {
                // 区间有重叠，更新当前重叠区间的范围
                // 取重叠区间的起始点为最大值（因为要确保箭头能覆盖所有区间）
                if (point[0] > arrowBeginIndex) {
                    arrowBeginIndex = point[0];
                }
                // 取重叠区间的结束点为最小值（因为箭头只需覆盖到最早结束的点）
                if (point[1] < arrowEndIndex) {
                    arrowEndIndex = point[1];
                }
            }
        }

        // 返回最少需要的箭头数量
        return arrowCount;
    }
}
```

为什么不是不断扩大区间，而是不断缩小区间呢？因为我要使得我射出一只箭可以让尽量多的气球爆炸，这就使得我应该是找重叠区间，而重叠区间就是不断的缩小的。如果不断的扩大，那就不是找重叠区间了，而是找并集，并集里面射一只箭并不能保证这个并集里面的所有气球都爆炸，比如我的并集是1-8，但是其中有两个气球是1-4和5-7，那需要至少两只箭。因此需要找交集，而且是最多气球重叠的那个交集。
