# 455. 分发饼干

[https://leetcode.cn/problems/assign-cookies/description/](https://leetcode.cn/problems/assign-cookies/description/)

本题有两种方法，第一种是通过`for`循环每次选出当前没有饼干的人当中胃口最小的那个人，然后去找这个人能吃下而且也是最小的那块饼干给这个人吃；第二种方法是通过`for`循环每次选出当前没有被吃掉的饼干当中最大的那块饼干，然后去找胃口最大且能吃下这块饼干的那个人。第一种方法是先定人，然后去找饼干，此时是从小到大进行遍历；第二种是先定饼干，然后去找人，此时是从大到小进行遍历。代码如下： 

```java
// 方法一：每次选出胃口最小的人（定），然后去找最小的饼干（动）
class Solution {
    public int findContentChildren(int[] g, int[] s) {
        Arrays.sort(g);
        Arrays.sort(s);
        int indexS = 0;
        int count = 0;
        // 每次for循环选出没有饼干的人当中胃口最小的那个人
        for(int i = 0; i < g.length; i++){
            // 开始找未分配的最小饼干给这个人
            while(indexS < s.length && s[indexS] < g[i]){
                indexS++;
            }

            // 如果while循环是在中间退出，说明找到可满足胃口且未分配的最小饼干
            if(indexS < s.length){
                count++;
                indexS++;
            }
        }
        return count;
    }
}

// 方法二：每次拿出最大的饼干（定），然后去找胃口最大的人（动）
class Solution {
    public int findContentChildren(int[] g, int[] s) {
        Arrays.sort(g);
        Arrays.sort(s);
        int indexG = g.length - 1;
        int count = 0;
        // 每次for循环选出没有分配的饼干当中最大的那块
        for(int i = s.length - 1; i >= 0; i--){
            // 开始找未分配饼干的人当中胃口最大的那个人
            while(indexG >= 0 && g[indexG] > s[i]){
                indexG--;
            }

            // 如果while循环是在中间退出，说明找到一个胃口足够大的人可以吃这个饼干
            if(indexG >= 0){
                count++;
                indexG--;
            }
        }
        return count;
    }
}
```

注意，第一种方法不可以先定饼干，后去找人，因为万一这块饼干很小，所有人吃了都满足不了，但是后面的饼干是有可能满足某些人的。而且由于本题使用的是`index`，也就是说每个人只会遇到一次（因为找过一次的人，`index`就会永久增加）。除非每次for循环都去从头开始找人，然后设置一个`selected`数组记录谁有饼干谁没有，这样才可以先定饼干，后去找人，但是这样时间复杂度太高了。第二种方法也是同理，不可以反过来。
