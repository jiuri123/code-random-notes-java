# 134. 加油站

[https://leetcode.cn/problems/gas-station/description/](https://leetcode.cn/problems/gas-station/description/)

思路是我先得到假设我只从当前加油站出发，白嫖完当前加油站的油量，到下一个加油站之后的剩余油量，用remain数组记录，然后从头开始累加这些剩余油量计算累加和。假设我有一个加油站，从这个加油站出发可以走完全程，那么最后的累加和应该是一个大于等于0的值，否则我整体的剩余油量小于0的话怎么可能走完全程，因此最后要对这个累加和做一个if判断。

现在的问题是怎么找到这个起始加油站，使得我从这个加油站出发可以走完全程？先说结论：我们可以将remain数组画在坐标轴上，假设我们能走完全程的话，那么这个坐标轴上的最小值的那个索引对应的加油站的下一站就是我们的起始加油站，从这个加油站出发可以走完全程。为什么呢？因为从最小值点的前面任何一个加油站（包括最小值点）出发都不可能到达这个最小值点的下一站了，因为不管从哪个点开始累加剩余油量，到达这个最小值点之后，剩余油量都会小于0。还可以这样考虑：我们从某个点出发，就等于将x轴放在这个点，y轴的值表示的就是remain数组里面的值，最小值点的意义就是从这个点开始，后面值都不可能小于0。因此总的来说，只有从最小值点的下一个点开始出发，我们才有可能走完全程，至于能不能走完全程，还要看全程走下来之后我的剩余油量是多少。

因此可以写出如下的代码：

```java
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int len = gas.length;

        // remain：记录的是我只从i出发到达i+1后剩余的油量
        int[] remain = new int[len];

        // sum：走完一圈白嫖的总油量 - 走完一圈消耗的总油量
        int sum = 0;

        // minSum：到目前为止油量最低点，可以为负数
        int minSum = Integer.MAX_VALUE;

        // 记录符合条件的起始点
        int beginIndex = -1;

        for(int i = 0; i < len; i++){
            remain[i] = gas[i] - cost[i];
            sum += remain[i]; // 计算全程剩余油量
            if(sum < minSum){ // 找sum最小值点，并记录最小点的下一个点
                minSum = sum;
                // i及其i之前的点都不可能做为起始点
                // 因为前面的点都不可能有足够的油走到i了
                // 所以起始点只能是i+1或之后的点
                beginIndex = (i + 1) % len;
            }
        }

        // 如果走完全程油量还有剩下
        // 说明能走完全程，返回记录的起始点
        if(sum >= 0){
            return beginIndex;
        }else{ // 反之，如果走完全程油量为负数，说明无论从哪里开始走，都走不完全程
            return -1;
        }
    }
}
```
