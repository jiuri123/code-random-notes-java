# 860. 柠檬水找零

[https://leetcode.cn/problems/lemonade-change/description/](https://leetcode.cn/problems/lemonade-change/description/)

很简单，穷举并模拟所有的情况就好了，但是哪里有体现贪心思想呢？就是在对方付给我20元的时候，我有两个选择，要么给一张10元和一张5元，要么给三张5元。因为5元不仅可以给10元找零，还可以给20元找零，而10元只能给20元找零，所以我们找零的时候优先将10元给出去，留下5元，因为5元比10元在找零方面用处更大，所以优先留下。代码如下：

```java
class Solution {
    public boolean lemonadeChange(int[] bills) {
        int five = 0;
        int ten = 0;
        int twenty = 0;
        for(int i = 0; i < bills.length; i++){
            if(bills[i] == 5){
                five++;
            }else if(bills[i] == 10){
                if(five == 0){
                    return false;
                }else{
                    five--;
                    ten++;
                }
            }else{
                // 优先找10元
                if(ten != 0 && five != 0){
                    ten--;
                    five--;
                    twenty++; // 这句可以删去
                }else if(five >= 3){
                    five -= 3;
                    twenty++; // 这句可以删去
                }else{
                    return false;
                }
            }
        }
        return true;
    }
}
```
