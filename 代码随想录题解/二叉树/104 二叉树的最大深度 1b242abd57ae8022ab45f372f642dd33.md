# 104. 二叉树的最大深度

[https://leetcode.cn/problems/maximum-depth-of-binary-tree/description/](https://leetcode.cn/problems/maximum-depth-of-binary-tree/description/)

求二叉树的最大深度其实就是求二叉树的高度，代码如下：

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // return Depth(root);
        if(root == null){
            return 0;
        }else{
            int leftDepth = maxDepth(root.left);
            int rightDepth = maxDepth(root.right);
            // return Math.max(leftDepth, rightDepth) + 1;
            return (leftDepth > rightDepth ? leftDepth : rightDepth) + 1;
        }
    }

    public int Depth(TreeNode root){
        if(root == null){
            return 0;
        }else{
            int leftDepth = Depth(root.left);
            int rightDepth = Depth(root.right);
            // return Math.max(leftDepth, rightDepth) + 1;
            return (leftDepth > rightDepth ? leftDepth : rightDepth) + 1;
        }
    }
}
```

当然也可以用层次遍历，每到一层深度加1，代码如下：

```
class Solution {
    public int maxDepth(TreeNode root) {
        if(root == null){
            return 0;
        }

        int depth = 0;
        Queue<TreeNode> que = new LinkedList<>();
        que.offer(root);
        while(!que.isEmpty()){
            // 每到一层，深度都要记得加一
            depth++;
            // leverSize表示这一层的节点个数
            int leverSize = que.size();
            // while的目的是为了遍历这一层的节点
            // 然后将这层节点的每个孩子都加入到队列当中
            while((leverSize--) != 0){
                TreeNode node = que.poll();
                if(node.left != null) que.offer(node.left);
                if(node.right != null) que.offer(node.right);
            }
        }
        return depth;
    }
}
```
