# 199. 二叉树的右视图

[https://leetcode.cn/problems/binary-tree-right-side-view/description/](https://leetcode.cn/problems/binary-tree-right-side-view/description/)

层次遍历中将每层的最后一个元素加入到结果队列中就好了，代码如下：

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if(root == null) return result;
        Queue<TreeNode> que = new LinkedList<>();
        que.offer(root);
        while(!que.isEmpty()){
            int len = que.size();
            // 该层只剩下最后一个的时候就停止
            while((len--) != 1){
                TreeNode node = que.poll();
                if(node.left != null) que.offer(node.left);
                if(node.right != null) que.offer(node.right);
            }
            // 特殊处理该层最后一个元素
            TreeNode lastNode = que.poll();
            result.add(lastNode.val);
            if(lastNode.left != null) que.offer(lastNode.left);
            if(lastNode.right != null) que.offer(lastNode.right);
        }
        return result;
    }
}
```
