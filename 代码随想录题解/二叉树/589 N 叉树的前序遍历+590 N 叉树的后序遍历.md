# 589. N 叉树的前序遍历+590. N 叉树的后序遍历

[https://leetcode.cn/problems/n-ary-tree-preorder-traversal/description/](https://leetcode.cn/problems/n-ary-tree-preorder-traversal/description/)

https://leetcode.cn/problems/n-ary-tree-postorder-traversal/description/

很简单，直接对存放孩子节点的集合进行遍历就好了，后序遍历的话需要修改一下元素收集的顺序，前序遍历代码如下：

```java
class Solution {
    public List<Integer> preorder(Node root) {
        List<Integer> result = new ArrayList<>();
        preOrderTraversal(root, result);
        return result;
    }

    public void preOrderTraversal(Node root, List<Integer> result) {
        if(root == null) return;

        result.add(root.val);
        for(Node node : root.children){
            preOrderTraversal(node, result);
        }
    }
}
```

后序遍历：

```java
class Solution {
    public List<Integer> postorder(Node root) {
        List<Integer> result = new ArrayList<>();
        postOrderTraversal(root, result);
        return result;
    }

    public void postOrderTraversal(Node root, List<Integer> result) {
        if(root == null) return;

        for(Node node : root.children){
            postOrderTraversal(node, result);
        }
        result.add(root.val);
    }
}
```
