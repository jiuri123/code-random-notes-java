# 113. 路径总和 II

[https://leetcode.cn/problems/path-sum-ii/description/](https://leetcode.cn/problems/path-sum-ii/description/)

本题思路其实很简单，就是深度优先遍历的过程中记录路径，然后判断该节点是否是叶节点，如果是的话就收集，否则继续寻找更深一层的叶子结点，代码如下：

```java
class Solution {
    List<List<Integer>> result = new ArrayList<>();
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        if(root == null) return result;

        List<Integer> path = new ArrayList<>();
        getPath(root, targetSum, path);
        return result;
    }

    public void getPath(TreeNode root, int targetSum, List<Integer> path){
        path.add(root.val);
        targetSum -= root.val;
        if(root.left == null && root.right == null && targetSum == 0){
            result.add(new ArrayList<>(path));
        }

        if(root.left != null){
            getPath(root.left, targetSum, path);
            // 回到上层之前移除当前的节点
            // path.remove(path.size() - 1);
            // targetSum的值会自动恢复到相减之前的值
            // 因此不需要对targetSum进行任何操作
        }

        if(root.right != null){
            getPath(root.right, targetSum, path);
            // 回到上层之前移除当前的节点
            // path.remove(path.size() - 1);
            // 同理，不需要对targetSum进行任何操作
        }

        // 也可以将上面两步的移除操作放在这里，这样比较好理解
        path.remove(path.size() - 1);
    }
}
```

可以看到回溯的过程有两种写法，我觉得我还是比较喜欢将回溯操作放在最后，也就是在即将返回上一层的过程中将节点从路径中排除，这样的统一操作比较好理解。

这题虽然简单，但是还是有一个可能出错的地方，看我的错误代码：

```java
class Solution {
    List<List<Integer>> result = new ArrayList<>();
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        if(root == null) return result;

        List<Integer> path = new ArrayList<>();
        getPath(root, targetSum, path);
        return result;
    }

    public void getPath(TreeNode root, int targetSum, List<Integer> path){
        path.add(root.val);
        targetSum -= root.val;
        if(root.left == null && root.right == null && targetSum == 0){
            result.add(path);// 错误的地方
        }

        if(root.left != null){
            getPath(root.left, targetSum, path);
            path.remove(path.size() - 1);
        }

        if(root.right != null){
            getPath(root.right, targetSum, path);
            path.remove(path.size() - 1);
        }
    }
}
```

`result.add(path);`看似将`path`加入到了结果队列`result`中，但是其实加的只是`path`的引用，也就是说之后的操作`path.remove(path.size() - 1);`会同时影响到path的值和结果队列`result`的值，而我们并不想已经加入到结果队列`result`的值还在发生变化，这样肯定是不对的，因此解决办法就是新建一个集合对象，再将这个对象加入到结果队列中：`result.add(new ArrayList<>(path));`确保 `result` 中的路径不会受到后续 `path.remove` 的影响。

这里学到一个新知识，就是如何根据旧数组创建一个新数组？除了遍历旧数组，将元素一个一个加入到新数组的方法外，还可以用上面这种方法，将列表作为参数传入`ArrayList`的构造函数中，`new ArrayList<>(path)` 会创建一个新的 `ArrayList`，并将 `path`中的所有元素**复制**到这个新的`ArrayList`中。
