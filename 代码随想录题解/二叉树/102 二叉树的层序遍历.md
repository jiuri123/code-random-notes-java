# 102. 二叉树的层序遍历

[https://leetcode.cn/problems/binary-tree-level-order-traversal/description/](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/)

比较简单，就是用队列来进行模拟就好了，但是由于输出格式的限制，即同属于一层的元素需要放进同一个List里面，因此需要对遍历的过程进行一些特殊处理，代码如下：

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new LinkedList<>();
        if(root == null){
            return result;
        }

        Queue<TreeNode> que = new LinkedList<>();
        que.offer(root);
        while(!que.isEmpty()){
            List<Integer> tempList = new LinkedList<>();
            int len = que.size();
            
            //len > 0说明que里面还有元素，而且这些元素都是树中同一层的
            while(len > 0){
                TreeNode node = que.poll();
                tempList.add(node.val);
                if(node.left != null){
                    que.offer(node.left);
                }
                if(node.right != null){
                    que.offer(node.right);
                }
                len--;
            }

            result.add(tempList);
        }

        return result;
    }

}
```
