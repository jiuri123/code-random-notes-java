# 101. 对称二叉树

[https://leetcode.cn/problems/symmetric-tree/description/](https://leetcode.cn/problems/symmetric-tree/description/)

这道题看着简单，但是像我一样没有完全理解题意就直接开始动手的话，那就很容易走上错误的道路一去不复返。

## 错误方法一

下面先看我的第一种错误解法：

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        List<Integer> inOrderList = new ArrayList<>();
        inOrder(root, inOrderList);
        int len = inOrderList.size();
        for(int i = 0; i < len / 2; i++){
            if(!inOrderList.get(i).equals(inOrderList.get(len - i - 1))){
                return false;
            }
        }

        return true;
    }

    public void inOrder(TreeNode root, List<Integer> inOrderList){
        if(root == null){
            return;
        }else{
            inOrder(root.left, inOrderList);
            inOrderList.add(root.val);
            inOrder(root.right, inOrderList);
        }
    }
}
```

思路是想着既然是对称的，那么中序遍历肯定也是回文的啊，所以我就先获得这棵树的中序遍历，看看中序遍历是不是回文的就好了。结果很明显是错误的，因为没有考虑到一个特殊情况：第一层是1，第二层两个2，第三层也是两个2（前提是分别在根节点两个子节点的两边）。可以看到不论第三层的两个2怎么排，最后得到的中序遍历都是22122，说明即使中序遍历的结果是回文的，这棵树也不一定是对称的。因此回文法不行。

## 错误方法二

再看我的第二个错误解法，代码如下：

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if(root == null){
            return true;
        }

        return isMirror(root);
    }

    public boolean isMirror(TreeNode root){
        if(root == null && root == null){
            return true;
        }else if(root.left == null || root.right == null){
            return false;
        }else{
            return root.left.val == root.right.val && isMirror(root.left) && isMirror(root.right);
        }
    }
}
```

很明显我的代码比较的是任意节点的左右两个子节点是否对称，但是题目要求的是整颗树是否是关于根节点对称，这是两个完全不同的问题。因此本题的解法应该分成两颗树去比较，也就是拿根节点的左子树和右子树来进行比较。

## 方法一

先看比较难懂的方法一代码：

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        return ismirror(root, root);
    }

    public boolean ismirror(TreeNode root1, TreeNode root2) {
        if(root1 == null && root2 == null){
            return true;
        }else if(root1 == null || root2 == null){
            return false;
        }else{
            return (root1.val == root2.val) 
            && ismirror(root1.left, root2.right) //比较左子树左边和右子树右边
            && ismirror(root1.right, root2.left);//比较左子树右边和右子树左边
        }
    }
}
```

上面的代码只要想象一个三层的树就可以很容易想通了。其实就是将整颗树从根节点开始分成左右两颗子树来进行比较，左子树的左边部分就是跟右子树的右边部分进行比较，而左子树右边部分自然就是和右子树左边部分来进行比较。

## 方法二（推荐）

下面给出逻辑更加清晰，结构更加完整的代码（来自代码随想录）：

```java
public boolean isSymmetric(TreeNode root) {
		return compare(root.left, root.right);
}

private boolean compare(TreeNode left, TreeNode right) {
    if (left == null && right != null) {
        return false;
    }
    if (left != null && right == null) {
        return false;
    }
    if (left == null && right == null) {
        return true;
    }
    if (left.val != right.val) {
        return false;
    }
    // 排除掉上面的那些特殊情况，只剩下节点非空且值相等的情况
    // 比较外侧
    boolean compareOutside = compare(left.left, right.right);
    // 比较内侧
    boolean compareInside = compare(left.right, right.left);
    return compareOutside && compareInside;
}
```
