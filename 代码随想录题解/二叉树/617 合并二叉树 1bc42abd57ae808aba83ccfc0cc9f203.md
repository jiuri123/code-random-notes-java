# 617. 合并二叉树

[https://leetcode.cn/problems/merge-two-binary-trees/description/](https://leetcode.cn/problems/merge-two-binary-trees/description/)

本题有两种方法，第一种方法的思路是以第一棵树为主树，遇到空节点的时候，直接复用第二颗树的节点，不去创造新的结点，这样合并后的树中的结点就是与两棵树都是息息相关的。代码如下：

```java
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        if(root1 == null && root2 == null){
            return null;
        }else if(root1 == null){ 
            return root2; // 直接复用的root2节点
        }else if(root2 == null){
            return root1; // 直接使用主树的结点
        }
        root1.val += root2.val;
        // root1的左子树是root1的左子树和root2的左子树合并的结果
        root1.left = mergeTrees(root1.left, root2.left);
        // root1的右子树是root1的右子树和root2的右子树合并的结果
        root1.right = mergeTrees(root1.right, root2.right);
        return root1;
    }
}

```

第二种方法是我自己的方法，思路还是以其中一棵树为主树（比如root1），然后在遇到空节点的时候不复用非主树的节点，而是新建一个节点并插入到主树中，合并后的树与第二棵树就没有任何联系。代码如下：

```
// 方法二
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        root1 = Merge(root1, root2);
        return root1;
    }
    
    public TreeNode Merge(TreeNode targetRoot, TreeNode sourceRoot) {
        if(sourceRoot == null){
            return targetRoot;
        }
        
        if(targetRoot == null){
            targetRoot = new TreeNode(sourceRoot.val);
        }else{
            targetRoot.val += sourceRoot.val;
        }

        targetRoot.left = Merge(targetRoot.left, sourceRoot.left);
        targetRoot.right = Merge(targetRoot.right, sourceRoot.right);
        return targetRoot;
    }
}

// 方法二改进版：不写成函数的形式，感觉更好理解
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        if(root2 == null){
            return root1;
        }
        
        if(root1 == null){
            root1 = new TreeNode(root2.val);
        }else{
            root1.val += root2.val;
        }

        root1.left = mergeTrees(root1.left, root2.left);
        root1.right = mergeTrees(root1.right, root2.right);
        return root1;
    }
}
```

两种方法在功能上是等价的，时间复杂度和空间复杂度基本相同，都能正确合并两棵二叉树。但方法二的实现更加模块化，参数命名更清晰，适合在更复杂的场景中使用。因为直接新建了一个节点做为合并后的节点，而不是直接使用`sourceRoot`的节点，这样之后我对`sourceRoot`进行节点修改的时候不会影响到`targetRoot`的节点。

我之前的代码如下：

```java
// 错误代码
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        TreeNode mergeRoot = new TreeNode(); // 错误点1
        // 将root1合并到mergeRoot
        Merge(mergeRoot, root1);
        // 将root2合并到mergeRoot
        Merge(mergeRoot, root2);
        // 返回合并好的树
        return mergeRoot;
    }

    // 将sourceRoot这棵树合并到targetRoot这颗树中
    public void Merge(TreeNode targetRoot, TreeNode sourceRoot) {
        if(sourceRoot == null){
            return;
        }
        
        if(targetRoot == null){
            TreeNode node = new TreeNode(sourceRoot.val); 
            node.left = null;
            node.right = null;
            targetRoot = node; // 错误点2
        }else{
            targetRoot.val += sourceRoot.val;
        }

        Merge(targetRoot.left, sourceRoot.left);
        Merge(targetRoot.right, sourceRoot.right);
    }
}
```

上面有两错误的地方，首先看错误点1，`TreeNode mergeRoot = new TreeNode();`会新建一个节点，而且节点的值`val`默认设置为`0`，可是这是不符合逻辑的，因为`root1`和`root2`都有可能为`null`，这样的话合并后的树不应该有节点，应该返回`null`。所以正确的做法是`TreeNode mergeRoot = null;`。

然后是错误点2，在`Merge`函数中，形参`targetRoot`是一个局部变量，它与函数外的实参`mergeRoot`实际上是两个东西，虽然两个变量刚开始都是指向同一个变量。但是问题就出在`targetRoot = node;`这句代码，这行代码只是改变了`targetRoot`的指向，但是并没有改变函数外实参`mergeRoot`的指向，所以函数`Merge`执行完之后并没有对`mergeRoot`做任何的改变。正确的做法应该是将形参进行返回，也就是前面提到的两种方法那样。
