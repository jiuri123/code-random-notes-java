# 654. 最大二叉树

[https://leetcode.cn/problems/maximum-binary-tree/description/](https://leetcode.cn/problems/maximum-binary-tree/description/)

本题也是构造二叉树，但是每次使用的是区间中值最大的那个节点做为根节点，然后不断地进行递归构造二叉树，代码如下：

```java
class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        int numsLeft = 0;
        int numsRight = nums.length - 1;
        return buildMaxTree(nums, numsLeft, numsRight);
    }

    public TreeNode buildMaxTree(int[] nums, int numsLeft, int numsRight) {
        if(numsLeft > numsRight){
            return null;
        }

        int maxLoc = findMaxLoc(nums, numsLeft, numsRight);
        TreeNode node = new TreeNode(nums[maxLoc]);
        node.left = buildMaxTree(nums, numsLeft, maxLoc - 1);
        node.right = buildMaxTree(nums, maxLoc + 1, numsRight);
        return node;
    }

		// 返回数组在给定区间中的最大值下标
    public int findMaxLoc(int[] nums, int numsLeft, int numsRight){
        int num = -1;
        int loc = -1;
        for(int i = numsLeft; i <= numsRight; i++){
            if(nums[i] > num){
                num = nums[i];
                loc = i;
            }
        }
        return loc;
    }
}
```
