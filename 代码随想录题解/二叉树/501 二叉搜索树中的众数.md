# 501. 二叉搜索树中的众数

[https://leetcode.cn/problems/find-mode-in-binary-search-tree/description/](https://leetcode.cn/problems/find-mode-in-binary-search-tree/description/)

本题寻找二叉搜索树中出现频率最高的元素（即众数）。有两种方法，第一种是使用HashMap来对二叉树的各元素进行次数的统计，什么遍历方法都行，只要对二叉树遍历一遍就好了。代码如下：

```java
// 方法一，HashMap统计法
class Solution {
    Map<Integer, Integer> hm = new HashMap<>();
    public int[] findMode(TreeNode root) {
        preOrder(root);
        if (hm.isEmpty()) {
            return new int[0]; // 空树返回空数组
        }

        // 找到最大频率
        int maxFreq = 0;
        for (int freq : hm.values()) {
            maxFreq = Math.max(maxFreq, freq);
        }

        // 收集所有频率等于最大频率的值
        List<Integer> resultList = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : hm.entrySet()) {
            if (entry.getValue() == maxFreq) {
                resultList.add(entry.getKey());
            }
        }
        
        // 将list转换成数组，也可以遍历list，然后对元素进行收集
        return resultList.stream().mapToInt(Integer::intValue).toArray();
    }

    public void preOrder(TreeNode root) {
        if(root == null){
            return;
        }
        tm.put(root.val, hm.getOrDefault(root.val, 0) + 1);
        preOrder(root.left);
        preOrder(root.right);
    }
}
```

这种方法是通用的方法，也就说不管二叉树是否是二叉搜索树，都可以使用。但是其实可以在遍历的过程中直接得到众数，当然需要利用到二叉搜索树的性质。可以看到二叉搜索树的中序遍历是有序的，而且题目是允许元素出现重复的，那我就在中序遍历的过程中记录下当前遍历节点重复的次数，因此需要记录前一个节点以及之前最大的频率值。代码如下：

```java
// 方法二，中序遍历统计法
class Solution {
    int curFreq = 0;
    int maxFreq = 0;
    TreeNode preNode = null;
    List<Integer> resList = new ArrayList<>();
    public int[] findMode(TreeNode root) {
        preOrder(root);
        return resList.stream().mapToInt(Integer::intValue).toArray();
    }

    public void preOrder(TreeNode curNode) {
        if(curNode == null){
            return;
        }
        preOrder(curNode.left);
        //更新当前节点的频率
        if(preNode == null){ // 说明是第一个被遍历到的节点
            curFreq = 1;
        }else if(preNode.val == curNode.val){ 
            curFreq++;
        }else{ //说明遇到新的值，重复的值结束
            curFreq = 1;
        }
        
				// 每更新一次频率的值，都要进行一次最大频率更新
        if(curFreq > maxFreq){
            resList.clear(); // 记得清空，因为list里面已经不是最大频率的元素了
            maxFreq = curFreq;
            resList.add(curNode.val);
        }else if(curFreq == maxFreq){
            resList.add(curNode.val);
        }
        preNode = curNode;
        preOrder(curNode.right);
    }
}
```

这题终于知道“定量”是有多么重要。对于方法二，一定要确定每个量在每次遍历到一个新节点的时候到底是什么意思，不然就像我之前的方法那样，一会把curFreq当成curNode的频率，一会又当成preNode的频率，很容易出现代码逻辑错误。定了量之后，后面就不要改了，怕忘记的话最好自己加上注释。
