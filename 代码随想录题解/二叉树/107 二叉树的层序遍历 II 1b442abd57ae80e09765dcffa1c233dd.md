# 107. 二叉树的层序遍历 II

[https://leetcode.cn/problems/binary-tree-level-order-traversal-ii/description/](https://leetcode.cn/problems/binary-tree-level-order-traversal-ii/description/)

本题要求从底向上的层次遍历。只要修改一下收集时的顺序就好了，每遍历完一层就将这层加入到最前面。代码如下：

```
class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        List<List<Integer>> result = new LinkedList<>();
        if(root == null){
            return result;
        }

        Queue<TreeNode> que = new LinkedList<>();
        que.offer(root);
        while(!que.isEmpty()){
            int len = que.size();
            List<Integer> list = new LinkedList<>();
            while((len--) != 0){
                TreeNode node = que.poll();
                list.add(node.val);
                if(node.left != null) que.offer(node.left);
                if(node.right != null) que.offer(node.right);
            }
            // 将当前行加入到结果队列中最前面的位置
            result.add(0, list);
        }
        return result;
    }
}
```
