# 108. 将有序数组转换为二叉搜索树

[https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/description/](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/description/)

要构建的是平衡的二叉树，所以可以利用折半查找的方法（折半查找树就是一颗平衡二叉树），每次将有序序列的中点加入到二叉树中，这样构建出来的树一定是平衡的。代码如下：

```
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        // 初始调用：处理整个数组范围 [0, nums.length - 1]
        return buildBST(nums, 0, nums.length - 1);
    }

    private TreeNode buildBST(int[] nums, int left, int right) {
        // 1. 终止条件：如果左边界超过右边界，说明没有元素了
        if (left > right) {
            return null;
        }

        // 2. 找到中点索引
        // 使用 left + (right - left) / 2 防止大数相加溢出
        int mid = left + (right - left) / 2;

        // 3. 以中点值创建当前根节点
        TreeNode root = new TreeNode(nums[mid]);

        // 4. 递归构建左右子树
        // 左子树使用中点左侧的区间：[left, mid - 1]
        root.left = buildBST(nums, left, mid - 1);
        // 右子树使用中点右侧的区间：[mid + 1, right]
        root.right = buildBST(nums, mid + 1, right);

        // 5. 返回当前构建好的树节点
        return root;
    }
}
```
