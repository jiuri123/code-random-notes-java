# 257. 二叉树的所有路径

[https://leetcode.cn/problems/binary-tree-paths/description/](https://leetcode.cn/problems/binary-tree-paths/description/)

这题考研的时候做过，当时用的是C++，但是都是大同小异。

## 方法一

先说说当时考研用的方法，就是用一个数组记录路径，为什么用数组？因为用数组有个好处就是免去了手动回溯这一步，直接看代码：

```java
class Solution {
    int[] path = new int[200];
    List<String> result = new ArrayList<>();

    public List<String> binaryTreePaths(TreeNode root) {
        treePaths(root, 0);
        return result;
    }

    public void treePaths(TreeNode node, int index){
        if(node == null){
            return;
        }
        path[index++] = node.val;
        if(node.left == null && node.right == null){
			      // 在LeetCode中也可以使用StringJoiner
			      // 但是要导包：import java.util.StringJoiner;
			      // 所以也不是所有的力扣题目都不需要导包，需看情况
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < index; i++) {
                sb.append(path[i]);
                if (i < index - 1) {
                    sb.append("->");
                }
            }
            result.add(sb.toString());
        }else{
		        // 完成下面的函数调用，回到当前的函数时
		        // index原来的值会从栈里面弹出来，恢复到进入递归前的值
		        // 也就是由系统完成了回溯这一步，因为index不是引用变量
		        // 不管函数里面怎么修改index，都不会实际修改index的值
		        // 而将index恢复到进入递归前的值相当于从path数组中弹出路径
		        // 虽然路径还在path里面，但是index已经变了呀，也相当于删除
            treePaths(node.left, index);// 隐式回溯
            treePaths(node.right, index);// 隐式回溯
        }
    }
}
```

当函数调用完成返回的时候，数组的下标index会自动回到原来的位置，因为进入函数递归调用的时候会将当前的index值压入栈中，直到函数调用完毕index的值才会重新从栈里面弹出来进行恢复，也就完成了回溯这一步。

## 方法二

如果想要显式回溯这一步怎么办？可以使用引用数据类型来存储路径，代码如下：

```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> res = new ArrayList<>();// 存最终的结果
        if (root == null) {
            return res;
        }
        List<Integer> paths = new ArrayList<>();// 作为结果中的路径
        traversal(root, paths, res);
        return res;
    }

    private void traversal(TreeNode root, List<Integer> paths, List<String> res) {
        paths.add(root.val);// 前序遍历，中左右
        // 遇到叶子结点，收集路径
        if (root.left == null && root.right == null) {
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < paths.size() - 1; i++) {
                sb.append(paths.get(i)).append("->");
            }
            sb.append(paths.get(paths.size() - 1)); // 最后一个节点单独处理
            res.add(sb.toString()); // 收集一个路径
            return;
        }
        // 递归和回溯是同时进行，所以要放在同一个花括号里
        if (root.left != null) { // 左
            traversal(root.left, paths, res);
            paths.remove(paths.size() - 1);// 显式回溯
        }
        if (root.right != null) { // 右
            traversal(root.right, paths, res);
            paths.remove(paths.size() - 1);// 显式回溯
        }
    }
}
```

使用引用数据类型就必须要显式回溯了，因为在递归调用函数里面对引用数据类型的修改会永久修改里面的值的，因为这是相当于直接将地址传进去了。
