# 701. 二叉搜索树中的插入操作

[https://leetcode.cn/problems/insert-into-a-binary-search-tree/description/](https://leetcode.cn/problems/insert-into-a-binary-search-tree/description/)

有迭代法和递归法两种方法。首先是迭代法，直接去找要插入节点的父节点，找到之后直接插入就好了，代码如下：

```
// 迭代法
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if(root == null){
            root = new TreeNode(val);
            return root;
        }
        TreeNode tempNode = root;
        while(true){
            if(val == tempNode.val){
                break;
            }else if(val < tempNode.val && tempNode.left != null){
                tempNode = tempNode.left;
            }else if(val > tempNode.val && tempNode.right != null){
                tempNode = tempNode.right;
            }else if(val < tempNode.val && tempNode.left == null){
                tempNode.left = new TreeNode(val);
                break;
            }else{
                tempNode.right = new TreeNode(val);
                break;
            }
        }
        return root;
    }
}
```

然后是递归法，也有两种递归法。一种是有返回值的，也就是在找到插入位置并将节点插入之后，将插入节点返回，使得插入节点的父节点的左右指针能找到这个插入节点，代码如下：

```java
// 递归法一：有返回值型
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if(root == null){
            // 找到了插入的位置，直接返回新建的节点
            return new TreeNode(val);
        }

        if(val < root.val){
            // 上面将新建的节点送上去之后，父节点用left接住
            root.left = insertIntoBST(root.left, val);
        }
        if(val > root.val){
            // 同上
            root.right = insertIntoBST(root.right, val);
        }
        // 然后将该节点返回，该节点的父节点的左指针或右指针会接住该节点
        // 一层一层向上，直到最后将顶层的root节点作为函数最后返回的节点
        // 这段代码也包含了val == root.val的情况，此时直接将该节点返回
        return root;
    }
}
```

另一种是没有返回值的递归方法，由于没有将插入的节点作为值进行返回，所以此时将节点插入并返回时会导致插入节点的丢失（插入节点的父节点得不到插入节点的地址）。因此考虑使用一个全局变量记录插入节点的父节点，这样在插入节点的过程中直接就将父节点和插入节点连接在一起。代码如下：

```java
// 递归法二：无返回值型，需设置全局变量记录父节点
class Solution {
		// 全局变量，记录父节点的位置
    TreeNode parent = null;
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if(root == null){
            return new TreeNode(val);
        }
        insertNode(root, val);
        return root;
    }

    public void insertNode(TreeNode root, int val){、
        // 找到插入的位置
        if(root == null){
            // 判断插入的是父节点的哪一边
            if(val < parent.val){
                parent.left = new TreeNode(val); 
            }else{
                parent.right = new TreeNode(val);
            }
            return;
        }

        // 记录父节点
        parent = root;
        if(val < root.val){
            insertNode(root.left, val);
        }
        if(val > root.val){
            insertNode(root.right, val);
        }
    }
}

```
