# 450. 删除二叉搜索树中的节点

[https://leetcode.cn/problems/delete-node-in-a-bst/description/](https://leetcode.cn/problems/delete-node-in-a-bst/description/)

首先是递归找要删除的节点，前中后序都行，找到之后进行几种情况的判断，其中最难的是当要删除节点的两个子节点都不为空的时候，这时有两种删除方法。第一种是将当前节点的右子树中最小值的那个节点替换掉当前的节点（其实也就是将值进行覆盖就好了），然后再次调用当前的函数来递归删除当前节点的右子树中最小值的那个节点。第二种删除方法是将当前节点及其左子树集体搬移到当前节点的右子树中最小值的那个节点的左边，然后将当前节点删除（也就是将当前节点的右子节点进行返回）。代码如下：

```java
class Solution {
    TreeNode parent = null;
    public TreeNode deleteNode(TreeNode root, int key) {
        return Delete(root, key);
    }

    public TreeNode Delete(TreeNode root, int key) {
        if(root == null){
            return root;
        }
        if(root.val > key){
            root.left = Delete(root.left, key);
        }else if(root.val < key){
            root.right = Delete(root.right, key);
        }else{
            // 删除节点为叶子节点的情况
            if(root.left == null && root.right == null){
                return null;
            }

            // 删除节点左子节点为空的情况
            if(root.left == null && root.right != null){
                return root.right;
            }

            // 删除节点右子节点为空的情况
            if(root.left != null && root.right == null){
                return root.left;
            }

            // 最后一种是左右子节点都不为空的情况
            // 找到当前节点的继任者，也就是当前节点右子树中最小的值
            TreeNode successor = findMin(root.right);
            // 方法一：找到当前节点右子树的最小值节点后
            // 将最小值节点替代当前的节点，然后递归删除
            root.val = successor.val;
            root.right = Delete(root.right, root.val);

            // 方法二：找到当前节点右子树的最小值节点后
            // 将当前节点及其左子树整体接到那个最小值节点的左边，
            // 最后将当前节点的右子节点进行返回，相当于将当前节点删除
            // successor.left = root.left;
            // root = root.right;
        }
        return root;
    }

    // 找node这颗树的最小值
    public TreeNode findMin(TreeNode node) {
        while(node.left != null){
            node = node.left;
        }
        return node;
    }
}
```
