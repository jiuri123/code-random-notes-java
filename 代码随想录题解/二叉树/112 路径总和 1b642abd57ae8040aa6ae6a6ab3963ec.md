# 112. 路径总和

[https://leetcode.cn/problems/path-sum/description/](https://leetcode.cn/problems/path-sum/description/)

## 方法一（求和法）

第一种方法是遍历节点的过程中记录路径，直到遇到叶子结点的时候，就遍历当前已经形成的路径并求和，符合条件的话就直接返回true，否则就返回，继续去上一层节点的其他子树找符合条件的路径。代码如下：

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        List<Integer> path = new ArrayList<>();
        // if(root == null) return false;
        return pathSum(root, path, targetSum);
    }

    public boolean pathSum(TreeNode root, List<Integer> path, int targetSum) {
        if(root == null) return false;
        path.add(root.val);
        if(root.left == null && root.right == null){
            int sum = 0;
            for(int i : path){
                sum += i;
            }
            if(sum == targetSum){
                return true;
            }
        }

        boolean isLeftHasPathSum = false;
        if(root.left != null){
            isLeftHasPathSum = pathSum(root.left, path, targetSum);
            path.remove(path.size() - 1); 
        }

        boolean isRightHasPathSum = false;
        if(root.right != null){
            isRightHasPathSum = pathSum(root.right, path, targetSum);
            path.remove(path.size() - 1);
        }
        return isLeftHasPathSum || isRightHasPathSum;
    }
}
```

上面的代码很容易写错，比如最后递归的代码我第一次写的时候是下面这样的：

```java
boolean isLeftHasPathSum = false;
isLeftHasPathSum = pathSum(root.left, path, targetSum);
path.remove(path.size() - 1); 

boolean isRightHasPathSum = false;
isRightHasPathSum = pathSum(root.right, path, targetSum);
path.remove(path.size() - 1);

return isLeftHasPathSum || isRightHasPathSum;
```

也就是说当子节点是空节点的时候也会去递归，因为我想着反正空的子节点递归进去之后会遇到函数的第一句：`if(root == null) return false;`，然后就会返回，可是问题就出在返回之后。当函数调用完成递归回来的时候，会执行`path.remove(path.size() - 1);` ，可是空节点之前递归进去的时候可是什么节点都没有往路径集合里面加，因为遇到第一句话就返回了，所以这里会把当前的结点给从`path`里面删掉。这个问题还不算很大，可是万一是叶子结点呢？就还要去递归右子节点，但是这个右子节点也是空的，回溯回来之后还要执行一次`path.remove(path.size() - 1);`，这就出现逻辑上的错误了，甚至可能导致数组越界问题。

## 方法二（相减法）

解决了上面这个问题，其实代码还可以再优化一下。上面的代码每次遇到一个新的叶子结点都会重新遍历路径来计算路径的长度，其实可以省去遍历这一步，而是在递归的过程中就直接算出遇到的叶子结点是否符合条件，也就是将目标值减去遇到的每个节点，最后遇到叶子结点的时候如果目标值减到0了，说明这条路径的和刚好是目标值。因为目标值不是应用数据类型，所以每次回溯的时候都会恢复到原来的值，因为这个值系统会帮忙存储在系统栈中（函数调用的知识），函数返回就弹出。代码如下：

```
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if(root == null) return false;

				// 关键步骤，用相减代替求和
        targetSum -= root.val;
        if(root.left == null && root.right == null){
            return targetSum == 0;
        }

        if(root.left != null){
            boolean isLeftHasPathSum = hasPathSum(root.left, targetSum);
            if(isLeftHasPathSum){
                return true;
            }
        }

        if(root.right != null){
            boolean isRightHasPathSum = hasPathSum(root.right, targetSum);
            if(isRightHasPathSum){
                return true;
            }
        }
        // 当前节点和左右子节点都不符合，返回false
        return false;

        // 这段代码也可以写成如下形式比较好理解
        // boolean isLeftHasPathSum = false;
        // if(root.left != null){
        //     isLeftHasPathSum = hasPathSum(root.left, targetSum);
        // }

        // boolean isRightHasPathSum = false;
        // if(root.right != null){
        //     isRightHasPathSum = hasPathSum(root.right, targetSum);
        // }

        // return isLeftHasPathSum || isRightHasPathSum;
    }
}
```
