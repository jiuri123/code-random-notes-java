# 236. 二叉树的最近公共祖先

[https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/)

## 方法一

方法一是考研时候学习的，先算出两个节点各自的深度，然后开始向上遍历，深度深的每次往上移动一步，直到两个节点相遇，相遇的节点就是最近的公共祖先。代码如下：

```java
 // 方法一
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if(p == root){
            return p;
        }
        if(q == root){
            return q;
        }
        // 获取两个节点的深度
        int pHeight = getHeight(root, p);
        int qHeight = getHeight(root, q);
        while(p != q){
            // 深度深的先往上移动
            if(pHeight > qHeight){
                // 获取父节点，也就是往上移动一层
                p = getParent(root, p);
                pHeight--;
            }else{
                q = getParent(root, q);
                qHeight--;
            }
        }
        // 相遇节点即是最近公共祖先
        return p;
    }

    //求节点的深度
    public int getHeight(TreeNode root, TreeNode node) {
        Queue<TreeNode> que = new LinkedList<>();
        int height = 0;
        if(root == null){
            return 0;
        }
        que.offer(root);
        while(!que.isEmpty()){
            height++;
            int len = que.size();
            while((len--) != 0){
                TreeNode curNode = que.poll();
                if(curNode == node){
                    return height;
                }
                if(curNode.left != null) que.offer(curNode.left);
                if(curNode.right != null) que.offer(curNode.right);
            }
        }
        return height;
    }

    //求节点的父节点，用于指针往上移动
    public TreeNode getParent(TreeNode root, TreeNode node){
        if(root == null || node == null || root == node){
            return null;
        }

        if(root.left != null && root.left == node){
            return root;
        }
        if(root.right != null && root.right == node){
            return root;
        }
        TreeNode nodeLeft = getParent(root.left, node);
        if(nodeLeft != null){
            return nodeLeft;
        }
        return getParent(root.right, node);
    }
}
```

## 方法二

第二种方法用的是递归，比较难想到。首先想的是用什么递归，既然要找公共的祖先，那肯定是用后序遍历，因为你得知道了两个节点的位置后在往上回溯找最近的祖先，也就是从下往上找。但是先序遍历就是相反，是从上往下找。这是两种遍历方式最明显的区别。

先去左子树找，看看有没有出现p节点或者q节点，出现了就将该节点返回，没有就返回null（此题中返回null表示的意思是当前节点及其子树中不包含p或q节点）。然后去右子树找，逻辑也是一样的。最后在后序的处理逻辑中来对返回的节点进行判断，判断逻辑见下方代码。代码如下：

```java
// 方法二
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 基本情况：空节点返回null
        if(root == null){
            return null;
        }
        
        // 如果当前节点是p或q之一，直接将当前节点往上传，不用去递归了
        if(root == p || root == q){
            return root;
        }
        
        // 递归查找左子树，新建一个节点接住底层传上来的目标节点
        TreeNode nodeLeft = lowestCommonAncestor(root.left, p, q);
        // 递归查找右子树，同理也是需要新建一个节点接住下层传上来的节点
        TreeNode nodeRight = lowestCommonAncestor(root.right, p, q);
        
        // 合并结果
        // 情况1：传上来的左右子树都不为空，说明p和q分布在左右子树中
        // 那么当前的 root 就是最近公共祖先
        if(nodeLeft != null && nodeRight != null){
            return root;
        }
        // 情况2：p或q中至少一个在右子树中，返回右子树的结果
        else if(nodeLeft == null && nodeRight != null){
            return nodeRight;
        }
        // 情况3：p或q中至少一个在左子树中，返回左子树的结果
        else if(nodeLeft != null && nodeRight == null){
            return nodeLeft;
        }
        // 情况4：p和q都不在当前节点的子树中，直接传个空树上去
        else{
            return null;
        }
    }
}

// 方法二简洁写法
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 1. 终止条件：如果 root 为空，或者找到了 p 或 q，直接返回当前的 root
        if (root == null || root == p || root == q) {
            return root;
        }

        // 2. 递归：去左子树和右子树里寻找 p 和 q
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        // 3. 逻辑判断（结果回溯）
        
        // 如果左子树没找到（为null），说明 p 或 q 只可能在右子树，返回右子树的结果
        if (left == null) return right;
        
        // 如果右子树没找到（为null），说明 p 或 q 只可能在左子树，返回左子树的结果
        if (right == null) return left;

        // 如果左子树和右子树都找到了非空节点，说明 p 和 q 分布在当前 root 的两侧
        // 那么当前的 root 就是最近公共祖先
        return root;
    }
}
```

可以这么理解：一旦找到了p节点所在的位置，就将这个节点一路的返回，每返回到一个节点，就去该节点的右子树找q节点，如果没找到，那就继续返回p节点（p节点一个人孤独前行）。直到在某个节点的右子树找到q节点，此时pq终于相遇，说明此节点就是两个节点的最近公共祖先，直接返回就好了。
