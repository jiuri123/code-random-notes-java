# 98. 验证二叉搜索树

[https://leetcode.cn/problems/validate-binary-search-tree/description/](https://leetcode.cn/problems/validate-binary-search-tree/description/)

这道题我竟然写出了两种错误的解法，都是易错点，正好趁此总结一番，看来自己还是要多多努力。

## 错误解法一

下面先看错误解法一：

```java
// 错误解法一
class Solution {
    public boolean isValidBST(TreeNode root) {
        if(root == null || root.left == null && root.right == null){
            return true;
        }
        if(root.left == null){
            return root.val < root.right.val && isValidBST(root.right);
        }else if(root.right == null){
            return root.val > root.left.val && isValidBST(root.left);
        }else{
            return root.val < root.right.val && root.val > root.left.val && isValidBST(root.right) && isValidBST(root.left);
        } 
    }
}
```

错误分析：判断一颗二叉树是不是搜索二叉树，需要判断当前节点的值是否大于左子树中所有节点的最大值，以及是否小于右子树中所有节点的最小值，而不是单纯的将当前节点的值与左子结点和右子节点的值进行比较。

## 错误解法二

```java
// 错误解法二
class Solution {
    public boolean isValidBST(TreeNode root) {
        if(root == null || root.left == null && root.right == null){
            return true;
        }
        TreeNode maxNode = null;
        TreeNode minNode = null;
        if(root.left == null){
            maxNode = root.right;
            while(maxNode.left != null){
                maxNode = maxNode.left;
            }
        }else{
            minNode = root.left;
            while(minNode.right != null){
                minNode = minNode.right;
            }
        }

        if(maxNode == null){
            return root.val > minNode.val && isValidBST(root.left);
        }else if(minNode == null){
            return root.val < maxNode.val && isValidBST(root.right);
        }else{
            return root.val < minNode.val && root.val > maxNode.val && isValidBST(root.right) && isValidBST(root.left);
        }
    }
}
```

错误分析：虽然一颗正确的搜索二叉树确实满足当前节点的值大于左子结点最右下角的值（也就是左子树中最大的值的那个节点），且小于右子节点中最最左下角的值（也就是右子树中最小的那个值）但是这道题是给你一颗不确定是不是二叉搜索树的树，来让你判断是否是二叉搜索树，所以通过上面的代码来判断最多只能知道这三个节点的关系，但是万一左子树中还存在一个更大的值并不在左子结点最右下角的那个位置呢？这时候这个方法就没办法遍历到这个节点了。

以上踩的两个坑，希望以后不要再犯这种错误了，感觉自己还是对概念不是很熟悉，还是得加强练习。

## 方法一

下面看正确的两种解法。首先是解法一，就是得到二叉树的中序遍历序列，然后看看中序遍历是否是递增的就OK，代码如下：

```java
// 正确解法一，中序遍历法一，遍历后判断中序序列
class Solution {
    public boolean isValidBST(TreeNode root) {
        List<Integer> midOrderList = new ArrayList<>();
        midOrder(root, midOrderList);
        for(int i = 1; i < midOrderList.size(); i++){
            if(midOrderList.get(i) <= midOrderList.get(i - 1)){
                return false;
            }
        }
        return true;
    }

    public void midOrder(TreeNode root, List<Integer> midOrderList) {
        if(root == null){
            return;
        }
        midOrder(root.left, midOrderList);
        midOrderList.add(root.val);
        midOrder(root.right, midOrderList);
    }
}
```

## 方法二

下面是正确解法二，也就是在方法外面定义一个变量用来记录中序遍历中上一个节点的值，代码如下：

```
// 正确解法二（中序遍历法二）：中序前值法
class Solution {
    long preValue = Long.MIN_VALUE; // 记录前一个节点的值
    public boolean isValidBST(TreeNode root) {
        if(root == null){
            return true;
        }
        if(isValidBST(root.left) == false){
            return false;
        }
        if(preValue >= root.val){
            return false;
        }
        preValue = root.val;
        return isValidBST(root.right);
    }
}
```

这里有个小坑，就是外面的变量不能为`int`类型，一定要为`long`类型。考虑这样一种特殊情况，一颗只有两个节点的树，根节点值为`Integer.MIN_VALUE`，也就是`int`类型的最小值，然后有一个右子节点为2，很明显这颗树是符合二叉搜索树的性质的。但是如果我的`preValue`初始化也是为`Integer.MIN_VALUE`，那么当我判断根节点的时候就会出现`preValue`的值与根节点的值相等的情况，可是二叉搜索树中是不允许出现相等的值的（这与二叉搜索树的插入算法有关），因为此时方法会返回`false`。解决方法就是将变量`preValue`的值设置为比`Integer.MIN_VALUE`还要小的值，比如`Long.MIN_VALUE`。

## 方法三

那万一题目给的值的范围是`long`怎么办？我们总不可能一直这样扩大范围吧，有没有什么一劳永逸的方法解决最小值的问题？当然有，那就是直接记录前一个节点的地址，而不是值。只有需要使用到值的时候，才通过节点的地址来取出这个节点中的值。代码如下：

```java
// 正确解法三，中序遍历法三：避免long值法
class Solution {
    // 用于记录中序遍历过程中，上一个节点的值
    // 初始值设为 null，方便处理树中第一个节点（可能为 Integer.MIN_VALUE）
    private TreeNode prev = null;

    public boolean isValidBST(TreeNode root) {
        return inorder(root);
    }

    private boolean inorder(TreeNode node) {
        if (node == null) {
            return true;
        }

        // 1. 递归遍历左子树
        if (!inorder(node.left)) {
            return false;
        }

        // 2. 检查当前节点：当前值必须 > 前一个节点的值
        if (prev != null && node.val <= prev.val) {
            return false;
        }
        // 更新 prev 为当前节点，供下一个节点比较
        prev = node;

        // 3. 递归遍历右子树
        return inorder(node.right);
    }
}
```

外面的节点直接设为`null`，这样就避免了与第一个节点进行值比较这个过程，因为与第一个节点进行比较的时候`preNode`肯定为`null`。

## 方法四

有没有什么方法可以避免递归呢？当然可以，那就是中序遍历的迭代法，可以避免递归造成的内存消耗。代码如下：

```java
// 正确解法四，中序遍历迭代法
class Solution {
    TreeNode preNode = null;
    public boolean isValidBST(TreeNode root) {
        if(root == null) return true;
        Stack<TreeNode> st = new Stack<>();
        TreeNode preNode = null;
        TreeNode node = root;
        while(node != null || !st.isEmpty()){
            while(node != null){
                st.push(node);
                node = node.left;
            }
            node = st.pop();
            if(preNode != null && preNode.val >= node.val){
                return false;
            }
            preNode = node;
            node = node.right;
        }
        return true;
    }
}
```

## 方法五（面试推荐）

最后一种方法属于递归方法的简洁解法，为每个节点指定一个有效的值范围（最小值和最大值），代码如下：

```java
// 正确解法五，递归简洁解法
class Solution {
    public boolean isValidBST(TreeNode root) {
        // 使用 Long 类型是为了处理节点值为 Integer.MIN_VALUE 或 MAX_VALUE 的边界情况
        return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean validate(TreeNode node, long min, long max) {
        // 空树也是有效的 BST
        if (node == null) return true;

        // 当前节点的值必须严格在 (min, max) 范围内
        if (node.val <= min || node.val >= max) return false;

        // 递归检查左子树：管你左边最小的值是什么，反正最大值不要大于我的值就行
        // 递归检查右子树：管你右边最大的值是什么，反正最小值不要小于我的值就行
        return validate(node.left, min, node.val) && validate(node.right, node.val, max);
    }
}
```
