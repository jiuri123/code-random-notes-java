# 144+94+145. 二叉树的前中后序遍历(非递归版)

[https://leetcode.cn/problems/binary-tree-preorder-traversal/description/](https://leetcode.cn/problems/binary-tree-preorder-traversal/description/)

https://leetcode.cn/problems/binary-tree-inorder-traversal/

https://leetcode.cn/problems/binary-tree-postorder-traversal/description/

二叉树的遍历既然是用递归解决的，那么自然而然也可以用栈来将递归改成非递归算法。

先看前序遍历。方法是将遇到的第一个节点先入栈，然后不断地出栈，并将出栈节点的左右两个节点放入栈中。因为前序遍历是中左右，所以入栈的顺序是先右节点在左节点，这是易错点。

再看后序遍历。后序遍历是左右中，所以可以将前序遍历的子节点入栈顺序掉一下顺序，变成了中右左，最后将结果反转就可以得到左右中的后序遍历。

最后看最难的中序遍历，方法将就是遇到节点就不断将节点加入到栈中，直到指针移动到二叉树的最左边，这时候才开始出栈并访问节点，然后继续去该被访问节点的右子节点找最左边的那个子层节点，依次访问即可。

```java
// 前序遍历顺序：中-左-右，入栈顺序：中-右-左
public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if(root == null){
            return result;
        }
        
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);

        while(!stack.isEmpty()){
            TreeNode temp = stack.pop();
            result.add(temp.val);
            if(temp.right != null){
                stack.push(temp.right);
            }
            if(temp.left != null){
                stack.push(temp.left);
            }
        }

        return result;
    }
    
    // 中序遍历顺序: 左-中-右 入栈顺序： 左-右
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if(root == null){
            return result;
        }

        Stack<TreeNode> stack = new Stack<>();
        TreeNode cur = root;
        while(cur != null || !stack.isEmpty()){
            if(cur != null){
                stack.push(cur);
                cur = cur.left;
            }else{
                cur = stack.pop();
                result.add(cur.val);
                cur = cur.right;
            }
        }
        return result;
    }
    
    // 入栈顺序：中-左-右 出栈顺序：中-右-左 翻转：左-右-中，即后序遍历
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if(root == null){
            return result;
        }
        
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);

        while(!stack.isEmpty()){
            TreeNode temp = stack.pop();
            result.add(temp.val);
            if(temp.left != null){
                stack.push(temp.left);
            }
            if(temp.right != null){
                stack.push(temp.right);
            }
        }

        Collections.reverse(result);
        return result;
    }
```
