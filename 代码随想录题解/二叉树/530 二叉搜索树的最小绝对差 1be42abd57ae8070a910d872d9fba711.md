# 530. 二叉搜索树的最小绝对差

[https://leetcode.cn/problems/minimum-absolute-difference-in-bst/description/](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/description/)

用中序遍历，用一个值记录中序遍历的前一个节点，再用一个值记录目前差值的最小值，最后返回最小值就好了。代码如下：

```java
class Solution {
    TreeNode preNode = null;
    int minDif = Integer.MAX_VALUE;

    public int getMinimumDifference(TreeNode root) {
        midOrder(root);
        return minDif;
    }

    public void midOrder(TreeNode root) {
        if (root == null) {
            return;
        }

        midOrder(root.left);
        if (preNode != null && root.val - preNode.val < minDif) {
            minDif = root.val - preNode.val;
        }
        preNode = root;
        midOrder(root.right);
    }
}
```
