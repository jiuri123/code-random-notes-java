# 572. 另一棵树的子树

[https://leetcode.cn/problems/subtree-of-another-tree/description/](https://leetcode.cn/problems/subtree-of-another-tree/description/)

本题寻找一颗树中是否有与给出的另一颗树相同的树，我的方法是对主树进行层次遍历，然后将每个节点构成的子树与给出的子树进行比较，比较使用的算法是[**100. 相同的树**](100%20%E7%9B%B8%E5%90%8C%E7%9A%84%E6%A0%91%201b242abd57ae803f9a5def31ae21b866.md) ，代码如下：

```java
class Solution {
    public boolean isSubtree(TreeNode root, TreeNode subRoot) {
        if(root == null){
            if(subRoot == null){
                return true;
            }else{
                return false;
            }
        }
        Queue<TreeNode> que = new LinkedList<>();
        que.offer(root);
        while(!que.isEmpty()){
            TreeNode node = que.poll();
            if(isSameTree(node, subRoot)){
                return true;
            }
            if(node.left != null) que.offer(node.left);
            if(node.right != null) que.offer(node.right);
        }
        return false;
    }

    public boolean isSameTree(TreeNode p, TreeNode q) {
        if(p == null && q == null){
            return true;
        }else if(p == null || q == null){
            return false;
        }else if(p.val != q.val){
            return false;
        }else{
            return isSameTree(p.left, q.left)
            && isSameTree(p.right, q.right);
        }
    }
}
```

另一个方法是使用深度遍历，代码如下：

```java
class Solution {
    public boolean isSubtree(TreeNode root, TreeNode subRoot) {
        if(root == null && subRoot == null) return true;
        if(root == null || subRoot == null) return false;
        return isSameTree(root, subRoot) // 这里用的是isSameTree函数
        || isSubtree(root.left, subRoot) // 而这里用的是isSubtree函数
        || isSubtree(root.right, subRoot); // 同理，这里用的是也是isSubtree函数
    }

		// 检查两个数是否相同，见：**100. 相同的树**
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if(p == null && q == null){
            return true;
        }else if(p == null || q == null){
            return false;
        }else if(p.val != q.val){
            return false;
        }else{
            return isSameTree(p.left, q.left)
            && isSameTree(p.right, q.right);
        }
    }
}
```

其中的

```
if(root == null && subRoot == null) return true;
if(root == null || subRoot == null) return false;
```

这两句是不能省略的，因为`root` 的值可能为`null`，这样当取`root.left`时就会报错。
