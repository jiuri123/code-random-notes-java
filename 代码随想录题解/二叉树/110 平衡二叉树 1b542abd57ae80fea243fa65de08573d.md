# 110. 平衡二叉树

[https://leetcode.cn/problems/balanced-binary-tree/description/](https://leetcode.cn/problems/balanced-binary-tree/description/)

## 方法一

第一种解法就是先递归计算两个子节点的高度，如果子节点的高度符合平衡二叉树的条件而且左右两个子节点也符合平衡二叉树的条件，那么就返回true；否则返回false。代码如下：

```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        return Balanced(root);
    }

    public boolean Balanced(TreeNode root) {
        if(root == null) return true;
        int leftHeight = Height(root.left);
        int rightHeight = Height(root.right);
        if(Math.abs(leftHeight - rightHeight) <= 1 
        && Balanced(root.left) 
        && Balanced(root.right)){
            return true;
        }else{
            return false;
        }
    }

		// 计算高度
    public int Height(TreeNode node){
        if(node == null) return 0;
        int leftHeight = Height(node.left);
        int rightHeight = Height(node.right);
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

## 方法二

第二种方法在上面方法的基础上简化了计算。可以发现，每次递归对某个节点进行判断的时候，**`Height`都会重新计算子树的高度**，而子树的高度计算是独立的，没有记忆化或缓存。同时也可以看到在求左右子节点高度的过程中也要获得这两个子节点的子节点高度才能计算，所有刚好就可以直接判断子节点是否符合平衡二叉树的条件，因此可以在计算高度的同时检查平衡性，避免重复调用 `Height`。代码如下：

```java
class Solution {
    public boolean isBalanced(TreeNode root) {
        return getHeight(root) == -1 ? false : true;
    }

    public int getHeight(TreeNode node){
        if(node == null) return 0;
        
        int leftHeight = getHeight(node.left);
        if(leftHeight == -1){ // 左子树或其子树不平衡，立马返回
            return -1;
        }
        
        int rightHeight = getHeight(node.right);
        if(rightHeight == -1){ // 右子树或其子树不平衡，立马返回
            return -1;
        }
        
        // 如果左右子树都是平衡二叉树，才对当前节点进行判断
        if(Math.abs(leftHeight - rightHeight) > 1){
            return -1;
        }
        
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

方法二其实是一种自底向上的判断方法（左右中，后序遍历），将时间复杂度从方法一的O(n^2)降低到O(n)，因为每个节点只遍历一次。但是方法一的话就每次判断当前节点的时候，还需要去遍历一次它的子节点计算高度后才知道是否是平衡二叉树，每个节点都会被 `Height`函数多次访问，特别是最底层的节点。
