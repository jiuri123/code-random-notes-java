# 513. 找树左下角的值

[https://leetcode.cn/problems/find-bottom-left-tree-value/description/](https://leetcode.cn/problems/find-bottom-left-tree-value/description/)

有两种解法，第一种是层次遍历法，每次记录每层的第一个节点，最后返回的就是最后一层的第一个节点，代码如下：

```java
// 层次遍历法
class Solution {
    public int findBottomLeftValue(TreeNode root) {
        Queue<TreeNode> que = new LinkedList<>();
        que.offer(root);
        int result = 0;
        while(!que.isEmpty()){
            int size = que.size();
            for(int i = 0; i < size; i++){
                TreeNode node = que.poll();
                if(i == 0){
                    result = node.val;
                }
                if(node.left != null) que.offer(node.left);
                if(node.right != null) que.offer(node.right);
            }
        }
        return result;
    }
}
```

第二种解法是递归法，要找二叉树的 **最底层 最左边** 节点的值，也就是要找深度最深的节点中最左边的值，因此可以在先序遍历（中后遍历也行）的过程中记录遇到的第一个深度最深的那个节点，就是答案，代码如下：

```
// 递归法
class Solution {
    int maxDeep = -1;
    int result = 0;
    public int findBottomLeftValue(TreeNode root) {
        findLeftValue(root,0);
        return result;
    }

    public void findLeftValue(TreeNode root, int curDeep) {
        if(root == null) return;
        if(root.left == null && root.right == null){
		        // 找到深度更加深的叶节点，记录下来
            if(curDeep > maxDeep){
                maxDeep = curDeep;
                result = root.val;
            }
        }

				// 隐式回溯
        findLeftValue(root.left, curDeep + 1);
        findLeftValue(root.right, curDeep + 1);
    }
}
```
