# 226. 翻转二叉树

[https://leetcode.cn/problems/invert-binary-tree/description/](https://leetcode.cn/problems/invert-binary-tree/description/)

只需要使用前后序或层次遍历在遍历的过程中进行子节点的反转就可以了。

但是要注意不可以使用中序遍历。简单说就是根节点的左子结点被反转了两次，但是根的右子节点却没有遍历到，因为在即将访问根的右子节点的前一步已经将根的左子结点换了过来，就这么水灵灵的错付了。代码如下：

```java
// 前序遍历翻转法
class Solution {
    public TreeNode invertTree(TreeNode root) {
        invert(root);
        return root;
    }

    public void invert(TreeNode root){
        if(root == null){
            return;
        }else{
            TreeNode temp = root.left;
            root.left = root.right;
            root.right = temp;
            invert(root.left);
            invert(root.right);
        }
    }
}
```
