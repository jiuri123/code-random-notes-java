# 235. 二叉搜索树的最近公共祖先

[https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/description/](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/description/)

可以直接用[**236. 二叉树的最近公共祖先**](236%20%E4%BA%8C%E5%8F%89%E6%A0%91%E7%9A%84%E6%9C%80%E8%BF%91%E5%85%AC%E5%85%B1%E7%A5%96%E5%85%88.md) 这道题的方法，但是既然是二叉搜索树，那就好好利用二叉搜索树的特点。可以发现如果当前节点的值比`p`和`q`节点的值都要大的话，那么最近公共祖先肯定是在当前节点的左子树里面，而不可能在当前节点的右子树里面，此时直接去左子树找就好了。同理，如果当前节点的值比`p`和`q`节点的值都要小的话，那么最近公共祖先肯定是在当前节点的右子树里面，而不可能在当前节点的左子树里面，此时直接去右子树找就好了。但是如果当前节点的值是处于`p`节点的值和`q`节点的值的中间位置的话（包括相等），那么说明这个节点就是要找的最近公共祖先，直接将该节点返回就好了。代码如下：

```
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if(root == null){
            return null;
        }
        
        // 最近公共祖先只可能在左子树
        if(p.val < root.val && q.val < root.val){
            TreeNode leftNode = lowestCommonAncestor(root.left, p, q);
            if(leftNode != null){
                return leftNode;
            }
        }

				// 最近公共祖先只可能在右子树
        if(p.val > root.val && q.val > root.val){
            TreeNode rightNode = lowestCommonAncestor(root.right, p, q);
            if(rightNode != null){
                return rightNode;
            }
        }
				
				// 不符合上面两个条件，说明当前节点出在两个节点的值的中间
				// 那这个节点就是最近公共祖先，直接将该值一层层的返回（送上去）
        return root;
    }
}
```

为什么这么确定这个节点就是他们的最近祖先呢？有没有可能是次近的祖先？也就是说有没有可能通过进一步的向下递归找到一个更近的祖先？不可能，因为该节点就是pq两个节点的分界点，如果继续递归的话，要么就会永远的错过`p`节点，要么就会永远的错过`q`节点。也就是说我们利用二叉搜索树的性质使得我们利用先序遍历也可以解决最近公共祖先的问题。

还有更加简单且容易理解的非递归法：

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        while(true){
            if(p.val < root.val && q.val < root.val){
                root = root.left;
            }else if(p.val > root.val && q.val > root.val){
                root = root.right;
            }else{
                break;
            }
        }
        return root;
    }
}
```
