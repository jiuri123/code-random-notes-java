# 429. N 叉树的层序遍历

[https://leetcode.cn/problems/n-ary-tree-level-order-traversal/description/](https://leetcode.cn/problems/n-ary-tree-level-order-traversal/description/)

很简单，直接将每一层的孩子直接加入到队列中就好了，代码如下：

```java
class Solution {
    public List<List<Integer>> levelOrder(Node root) {
        List<List<Integer>> result = new ArrayList<>();
        if(root == null) return result;

        Queue<Node> que = new LinkedList<>();
        que.offer(root);
        while(!que.isEmpty()){
            int len = que.size();
            List<Integer> list = new ArrayList<>();
            while((len--) != 0){
                Node node = que.poll();
                list.add(node.val);
                que.addAll(node.children);
                // 下面的代码没有addAll速度快
                // for(Node n: node.children){
                //     que.offer(n);
                // }
            }
            result.add(list);
        }
        return result;
    }
}
```

注意：使用 `addAll` 方法比逐个使用 `add` 方法添加元素更高效，尤其是在需要添加大量元素的场景下，这种性能差异会更加明显。
