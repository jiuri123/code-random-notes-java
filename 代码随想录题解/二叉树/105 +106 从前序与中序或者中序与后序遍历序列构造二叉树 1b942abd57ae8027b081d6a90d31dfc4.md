# 105. +106. 从前序与中序或者中序与后序遍历序列构造二叉树

[https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/)

[https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/description/](https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal/description/)

两道题基本上是一样的解法，以105题为例，就是先去找到先序遍历的第一个节点在中序遍历中的位置，这个节点其实这颗子树的根节点。然后在以这个根节点为主节点，继续往下递归，直到数组中的元素被全部遍历完。两道题的代码如下：

```java
// 105. 从前序与中序遍历序列构造二叉树
class Solution {
    // 缓存中序遍历的值与索引，方便快速定位根节点下标
    private Map<Integer, Integer> indexMap;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        int n = preorder.length;
        indexMap = new HashMap<>();
        for (int i = 0; i < n; i++) {
            indexMap.put(inorder[i], i);
        }
        return myBuildTree(preorder, inorder, 0, n - 1, 0, n - 1);
    }

    private TreeNode myBuildTree(int[] preorder, int[] inorder, 
                                 int preLeft, int preRight, 
                                 int inLeft, int inRight) {
        // 递归终止条件
        if (preLeft > preRight) return null;

        // 1. 前序遍历中的第一个节点就是根节点
        int rootVal = preorder[preLeft];
        TreeNode root = new TreeNode(rootVal);

        // 2. 在中序遍历中找到根节点的位置
        int rootIndex = indexMap.get(rootVal);

        // 3. 计算左子树的节点数目
        int leftSubtreeSize = rootIndex - inLeft;

        // 4. 递归构造左子树
        root.left = myBuildTree(preorder, inorder, 
                               preLeft + 1, preLeft + leftSubtreeSize, 
                               inLeft, rootIndex - 1);

        // 5. 递归构造右子树
        root.right = myBuildTree(preorder, inorder, 
                                preLeft + leftSubtreeSize + 1, preRight, 
                                rootIndex + 1, inRight);

        return root;
    }
}

 // 106. 从中序与后序遍历序列构造二叉树
 // 使用的区间是左闭右闭
class Solution {
    public TreeNode buildTree(int[] inorder, int[] postorder) {
        return makeTree(inorder, 0, inorder.length - 1, 
        postorder, 0, postorder.length - 1);
    }

    public TreeNode makeTree(int[] inorder, int inorderLeft, int inorderRight, int[] postorder, int postorderLeft, int postorderRight){
        if(postorderLeft > postorderRight){
            return null;
        }
        int midValue = postorder[postorderRight];
        TreeNode node = new TreeNode(midValue);
        int i = 0;
        for(i = inorderLeft; i <= inorderRight; i++){
            if(inorder[i] == midValue){
                break;
            }
        }

        node.left = makeTree(inorder, inorderLeft, i - 1, 
        postorder, postorderLeft, postorderLeft + i - inorderLeft - 1);

        node.right = makeTree(inorder, i + 1, inorderRight, 
        postorder, postorderLeft + i - inorderLeft, postorderRight - 1);
        return node;
    }
}
```
