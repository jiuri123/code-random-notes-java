# 669. 修剪二叉搜索树

[https://leetcode.cn/problems/trim-a-binary-search-tree/description/](https://leetcode.cn/problems/trim-a-binary-search-tree/description/)

本题要将二叉搜索树中不在区间内的节点删掉，同时还要保留原有的父代子代关系。本题使用递归法，关键难点就在于怎么删除节点，可以直接利用递归来删除节点。如果当前遇到的节点的值比区间最小值还要小的时候，说明该节点及其左子树都是需要删掉的，那么此时直接去递归该节点的右子树，然后返回右子树中经过修建之后的树的根节点。如果节点的值比区间最大值还要大的时候也是同理。

然后就是节点在区间内的情况，这时候直接去递归处理该节点的左右子树就好了，但是记得接住底层传上来的正确节点。或者直接用**示例 2**演示一遍就清楚了。最终代码如下：

```java
class Solution {
		// 函数的功能：将root树中不在区间[low, high]中的节点全部删除
    public TreeNode trimBST(TreeNode root, int low, int high) {
        if(root == null){
            return null;
        }

        // 下面两个if语句包含了节点的筛选和删除
        if(root.val > high){ // 当前节点的值比最大值还要大，剪掉根和右子树，直接递归左子树
            return trimBST(root.left, low, high);
        }
        if(root.val < low){ // 同上
            return trimBST(root.right, low, high);
        }

        // 如果根节点在范围内，递归修剪左右子树
        // 这里会接住子树中符合值在[low, high]的节点
        root.left = trimBST(root.left, low, high);
        root.right = trimBST(root.right, low, high);
        return root;
    }
}
```

二叉树做到这里感觉可以总结一下二叉树的模板了。三点总结：

1. 如本题所示，如何在遍历二叉树中删除节点？可以直接对该节点的左子树或者右子树进行递归，然后将递归的值进行返回，可以看到此时直接将本节点的返回语句跳过，返回的是子树中的某个节点，就相当于将当前节点进行删除；
2. 如何将底层更新好的节点进行返回，并被当前节点接住？模板如下：

```
root.left = trimBST(root.left, low, high);
root.right = trimBST(root.right, low, high);
return root;
```

递归当前节点的左右子树，然后用当前节点的左右指针接住返回的值，最后还要记得将当前节点进行返回。
