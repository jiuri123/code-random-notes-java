# 26. 删除有序数组中的重复项

https://leetcode.cn/problems/remove-duplicates-from-sorted-array/description/

跟[27.移除元素](../27%20%E7%A7%BB%E9%99%A4%E5%85%83%E7%B4%A0.md) 差不多一样的思路，只不过这题是移除相同的元素。因此遇到相同的数就直接跳过，而遇到不同的数就将其加入到新数组（其实也在旧数组中）的最后一位。代码：

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int k = 0;
        for(int i = 1; i < nums.length; i++){
            if(nums[i] != nums[k]){ // 相同的直接跳过不管了，后面会被覆盖
                k++;
                nums[k] = nums[i];
            }
        }
        return k + 1; // 最后记得返回的是k + 1
    }
}
```
