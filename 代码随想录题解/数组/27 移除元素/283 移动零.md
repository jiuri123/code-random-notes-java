# 283. 移动零

![image.png](283%20%E7%A7%BB%E5%8A%A8%E9%9B%B6/image.png)

https://leetcode.cn/problems/move-zeroes/description/

## 方法一（面试推荐）

遍历数组，遇到零就直接跳过，而遇到非零元素就将其与之前遇到的零元素进行交换，久而久之这些非零元素就可以在原数组中的前面那些位置组成一个新数组，但是这个新数组又不占用额外的存储空间。代码如下：

```java
// 方法一：双指针交换法（面试推荐）
class Solution {
    public void moveZeroes(int[] nums) {
        int len = nums.length;
        int index = 0; // 始终指向新数组最后一个元素的下一个位置
        for(int i = 0; i < len; i++){
            if(nums[i] != 0){  // 交换元素
                int temp = nums[i];
                nums[i] = nums[index];
                nums[index] = temp;
                index++;
            }
        }
    }
}
```

## 方法二

同样是使用双指针，但是遇到非零元素不是交换，而是直接将非零元素放到新数组的末尾。直到所有的非零元素都被移动到新数组后，再将除新数组外的其他位置全部置零。但是这种方法需要遍历两次（“非零元素前移”和“零元素后移”）数组；而方法一是严格遍历一次，因此还是推荐使用方法一。

```java
// 方法二：双指针替代法
class Solution {
    public void moveZeroes(int[] nums) {
        int len = nums.length;
        int index = 0;
        for(int i = 0; i < len; i++){
            if(nums[i] != 0){
                nums[index++] = nums[i];
            }
        }
        
        // 非0元素已经全部在index前面
        // 因此直接将后续元素全部置零即可
        while(index != len){ 
            nums[index++] = 0;
        }
    }
}
```
