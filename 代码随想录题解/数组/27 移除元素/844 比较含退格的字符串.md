# 844. 比较含退格的字符串

## 方法一

很容易想到一个常规解法，就是遍历原字符串的时候，用一个额外的空间存储遍历到的字符，当原字符串遍历到#的时候，就删除额外空间里面的最后那一位字符，以此类推。代码如下：

```java
// 方法一：常规解法
class Solution {
    public boolean backspaceCompare(String s, String t) {
        return buildBackStrng(s).equals(buildBackStrng(t));
    }

    public String buildBackStrng(String str){
        StringBuilder sb = new StringBuilder();
        for(int i = 0; i < str.length(); i++){
            char ch = str.charAt(i);
            if(ch != '#'){
                sb.append(ch);
            }else{
                if(sb.length() > 0){
                    // StringBuilder专有的方法，删除对应下标的元素
                    sb.deleteCharAt(sb.length() - 1);
                }
            }
        }
        return sb.toString();
    }
}
```

## 方法二

第二种方法是双指针法。因为遇到#删除的是前一个字符，这样的话我可以从后往前遍历，记录遇到的#的个数，这也代表着我将要去前面删除的字符的个数。然后遍历到字符的时候就将其删除（也不用直接删除，直接跳过就行）。直到找到一个不能被退格的字符（即这个字符后面的那些字符和后面的那些#刚好可以抵消），将这个字符和另一个字符串中也进行了上述相应逻辑找到的字符进行比较。

当然也有可能找不到这样一个元素，此时说明整个字符串都已经遍历完毕了，因此与另一个字符串的对应字符进行比较之前，需要判断某一字符串是否已经遍历完毕。如果两个字符串都没有遍历完，那么就直接比较对应的元素。如果其中一个字符串比较完了，但是另一个字符串没有比较完，此时这两个字符串也没有相等的可能了，直接返回false。但如果两个字符都比较完了，此时会直接退出最大的while循环，然后返回最后的true。详细看代码：

```java
// 方法二：双指针
class Solution {
    public boolean backspaceCompare(String s, String t) {
        int indexS = s.length() - 1;
        int indexT = t.length() - 1;
        int backS = 0; // #的个数，即需要跳过的元素个数
        int backT = 0;
        while(indexS >= 0 || indexT >= 0){
            // 找到s中无法被退格的元素，即要与t进行比较的元素
            while(indexS >= 0){
                if(s.charAt(indexS) == '#'){ // 记录#个数
                    backS++;
                    indexS--;
                }else if(backS > 0){ // 跳过元素
                    backS--;
                    indexS--;
                }else{ // 无法跳过，因此跳出循环，与t中对应元素进行比较
                    break;
                }
            }

            // 同理，找到t中无法被退格的元素，即要与s进行比较的元素
            while(indexT >= 0){
                if(t.charAt(indexT) == '#'){
                    backT++;
                    indexT--;
                }else if(backT > 0){
                    backT--;
                    indexT--;
                }else{
                    break;
                }
            }

            // 开始进行对应元素的比较逻辑
            if(indexS >= 0 && indexT >= 0){ // 两个下标都没有越界
                // 下标对应元素不相等，直接返回false
                if(s.charAt(indexS) != t.charAt(indexT)){
                    return false;
                }else{ // 下标对应元素相等，去看看前面的元素相不相等
                    indexS--;
                    indexT--;
                }
            }else{ // 说明indexS和indexT至少有一个越界了
                if (indexS >= 0 || indexT >= 0) { // 只有一个越界
                    return false; // 不可能相等了
                }else{ // 对于两个都越界的情况，可以不进行判断
                    return true; // 这个else可以省略
                }
                // 因为在进入下一轮循环前如果都越界，会直接退出while
                // 然后执行下面那句return true;
            }
        }
        return true;
    }
}
```

方法二比方法一好在不需要额外的空间，空间复杂度直接降到O(1)。
