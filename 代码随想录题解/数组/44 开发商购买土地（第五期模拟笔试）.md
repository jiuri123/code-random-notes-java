```java
import java.util.*;

public class Main{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int[][] regionArray = new int[n][m];
        int[] rowSum = new int[n]; // 前缀和,row[i]表示前i行（包括第i行）的数据之和
        int[] columnSum = new int[m]; // 前缀和,col[i]表示前i列（包括第i列）的数据之和
        for(int i = 0; i < n; i++){
            for(int j =0; j < m; j++){
                regionArray[i][j] = sc.nextInt();
                rowSum[i] += regionArray[i][j]; // 计算第i行的和
                columnSum[j] += regionArray[i][j]; // 计算第j列的和
            }
        }

        // 通过各行的和计算各行的前缀和
        for(int i = 1 ; i < n; i++){
            rowSum[i] += rowSum[i - 1];
        }
        // 通过各列的和计算各列的前缀和
        for(int i = 1 ; i < m; i++){
            columnSum[i] += columnSum[i - 1];
        }

        int minDiff = Integer.MAX_VALUE; // 记录最小差距
        for(int i = 0; i < n - 1; i++){ // 得到按行划分的最小差距
            minDiff = Math.min(minDiff, Math.abs(rowSum[n - 1] - 2 * rowSum[i]));
        }
        for(int i = 0; i < m - 1; i++){ // 得到按列划分的最小差距
            minDiff = Math.min(minDiff, Math.abs(columnSum[m - 1] - 2 * columnSum[i]));
        }
        System.out.println(minDiff); // 注意不是return，而是直接输出，这是ACM与力扣的不同
    }
}
```

为什么差值的计算是`rowSum[n - 1] - 2 * rowSum[i]`？

因为`rowSum[i]`表示的是前i行（包括第`i`行）的和，而`rowSum[n - 1] - rowSum[i]`表示后`n-i`行的和（不包括第`i`行），即表示的是划线部分下边的和。因此`rowSum[n - 1] - rowSum[i] - rowSum[i]`  表示的就是两个子区域的差距。
