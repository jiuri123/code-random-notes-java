# 59.螺旋矩阵II

[https://leetcode.cn/problems/spiral-matrix-ii/description/](https://leetcode.cn/problems/spiral-matrix-ii/description/)

本题需要生成一个顺时针方向的内螺旋二维矩阵。主要思路就是设置一个大循环，当数组未被填满的时候循环继续。然后在设置四个小循环，分别对于右→下→左→上四个方向的处理，小循环的结束条件用边界条件和标记数组来判断。小循环结束之后记得更新下一次小循环的初始位置。

## 一刷代码

```java
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] resultMatrix = new int[n][n]; //结果数组
        boolean[][] flagMatrix = new boolean[n][n]; //检查矩阵该位置的值是否已经生成
        int count = 0; //要填入矩阵中的值，也可以理解为已经加入到数组中的元素个数
        int LocatX = 0, LocatY = 0; //每一圈的初始点
        String[] Direct = {"right", "down", "left", "up"}; //方向数组，按照：右-下-左-上，元素位置不可更改
        int directIndex = 0; //方向数组的索引
        while(count < n * n){ //当值还没有填完时，循环继续
            if(Direct[directIndex].equals("right")){
                for(; isSafeLocat(LocatX, LocatY, n) && !flagMatrix[LocatX][LocatY]; LocatY++){
                    count++;
                    resultMatrix[LocatX][LocatY] = count;
                    flagMatrix[LocatX][LocatY] = true;
                }
                //更新初始位置
                //LocatY--是因为在for循环的最后一轮循环中LocatY多加了1，因此需要减去1
                LocatX++;
                LocatY--;
            }else if(Direct[directIndex].equals("down")){
                for(; isSafeLocat(LocatX, LocatY, n) && !flagMatrix[LocatX][LocatY]; LocatX++){
                    count++;
                    resultMatrix[LocatX][LocatY] = count;
                    flagMatrix[LocatX][LocatY] = true;
                }
                LocatY--;
                LocatX--;
            }else if(Direct[directIndex].equals("left")){
                for(; isSafeLocat(LocatX, LocatY, n) && !flagMatrix[LocatX][LocatY]; LocatY--){
                    count++;
                    resultMatrix[LocatX][LocatY] = count;
                    flagMatrix[LocatX][LocatY] = true;
                }
                LocatX--;
                LocatY++;
            }else{
                for(; isSafeLocat(LocatX, LocatY, n) && !flagMatrix[LocatX][LocatY]; LocatX--){
                    count++;
                    resultMatrix[LocatX][LocatY] = count;
                    flagMatrix[LocatX][LocatY] = true;
                }
                LocatY++;
                LocatX++;
            }
            //更新方向，方向有四个，不断循环，因此需要取余
            directIndex = (directIndex + 1) % 4;
        }

        return resultMatrix;
    }

    //判断位置是否越界
    public boolean isSafeLocat(int x, int y, int n) {
        if (x >= 0 && x < n && y >= 0 && y < n) {
            return true;
        } else {
            return false;
        }
    }
}
```

易错点：

1. 大小循环的循环结束条件
2. 四个小循环结束后更新初始位置
3. 小循环结束后方向索引的更新没有取余

## 二刷代码

```java
class Solution {
    public int[][] generateMatrix(int n) {
        int[][] res = new int[n][n]; // 用于存放结果
        boolean[][] flag = new boolean[n][n]; // 记录该位置是否已被填充
        int remainCellNum = n * n; // 还剩多少个位置没有被填充
        int inputNum = 1; // 当前位置应该填入的数字
        int row = 0, column = 0; // 每一圈的初始点
        int right = 0, down = 1, left = 2, up = 3; // 遍历方向
        int direction = right; // 初始方向
        while(remainCellNum > 0){ // 当还有位置没有被填充时，循环继续
            if(direction == right){ // 往右遍历
                while(isLegalLoc(n, row, column) && !flag[row][column]){
                    res[row][column] = inputNum;
                    inputNum++;
                    remainCellNum--;
                    flag[row][column] = true;
                    column++;
                }
                column--; // while循环中column会多走一步，因此此处需减一
                row++;
                direction = down;
            }else if(direction == down){ // 往下遍历
                while(isLegalLoc(n, row, column) && !flag[row][column]){
                    res[row][column] = inputNum;
                    inputNum++;
                    remainCellNum--;
                    flag[row][column] = true;
                    row++;
                }
                row--;
                column--;
                direction = left;
            }else if(direction == left){ // 往左遍历
                while(isLegalLoc(n, row, column) && !flag[row][column]){
                    res[row][column] = inputNum;
                    inputNum++;
                    remainCellNum--;
                    flag[row][column] = true;
                    column--;
                }
                column++;
                row--;
                direction = up;
            }else{ // 往上遍历
                while(isLegalLoc(n, row, column) && !flag[row][column]){
                    res[row][column] = inputNum;
                    inputNum++;
                    remainCellNum--;
                    flag[row][column] = true;
                    row--;
                }
                row++;
                column++;
                direction = right;
            }
        }
        return res;
    }

    // 判断当前位置是否越界
    public boolean isLegalLoc(int n, int row, int column) {
        if(row < 0 || row >= n){
            return false;
        }else if(column < 0 || column >= n){
            return false;
        }
        return true;
    }
}
```
