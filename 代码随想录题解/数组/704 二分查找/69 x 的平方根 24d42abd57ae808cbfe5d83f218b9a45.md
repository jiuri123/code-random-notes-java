# 69. x 的平方根

![image.png](69%20x%20%E7%9A%84%E5%B9%B3%E6%96%B9%E6%A0%B9/image.png)

https://leetcode.cn/problems/sqrtx/

暴力解法就是从0开始遍历，直到某个数的平方大于x就退出循环，最后返回这个数-1的值就好了。代码如下：

```java
// 方法一：暴力解法，未超时，但是时间复杂度高
class Solution {
    public int mySqrt(int x) {
        if(x == 0 || x == 1){
            return x;
        }

        long i = 0;
        for(i = 0; i < x; i++){
            if(i * i > x){
                break;
            }
        }
        return (int)(i - 1);
    }
}

```

但是因为x的平方根一定是在[0, x]范围之内的，并且这个范围之内的数都是有序的（12345……x），因此可以通过二分法去这个范围里面找x的算术平方根。代码如下：

```java
// 方法二：二分法，我自己的
class Solution {
    public int mySqrt(int x) {
        // 处理特殊情况：如果 x 为 0 或 1，直接返回 x
        // x == 1这个特殊情况也可以去掉，留给后面的循环来处理
        if (x == 0 || x == 1) {
            return x;
        }

        // 初始化二分查找的边界
        // left 从 1 开始，因为 x >= 1 时，平方根的整数部分 >= 1
        // right 设置为 x，因为平方根的整数部分 <= x
        long left = 1, right = x;

        // 使用二分查找寻找平方根的整数部分
        // left < right说明是不断二分到区间只剩下一个数，然后直接退出循环
        while(left < right){
            long mid = left + (right - left) / 2;
            if(mid * mid > x){ // 如果 mid * mid 大于 x，平方根在左半部分（mid 太大）
                right = mid - 1;
            }else if(mid * mid < x){ // 如果 mid * mid 小于 x，平方根在右半部分（mid 太小）
                left = mid + 1;
            }else{ // 如果 mid * mid 等于 x，mid 即为精确平方根
                return (int)mid;
            }
        }

        // （接上）但是不确定退出循环的的时候，
        // 这个数的平方是小于目标值还是大于目标值
        // 比如对于8来说，不知道left指向的是2还是3
        // 因此还需要进行如下判断才能将正确结果返回
        if(left * left > x){
            return (int)left - 1;
        }else{
            return (int)left;
        }
    }
}

// 方法三：二分法，来自Grok，简洁一点
class Solution {
    public int mySqrt(int x) {
        if (x == 0 || x == 1) { 
            return x;
        }
        
        // 也可以这么理解，因为最后返回的是left
        // 因此[left, right]区间中必须包含所有可能的结果
        long left = 1, right = x;

        // left <= right说明是先不断地二分到区间只剩一个数的情况，
        // 然后right往左（或left往右）再走一步，使得left > right
        while (left <= right) {
            long mid = left + (right - left) / 2;
            long square = mid * mid;
            if (square == x) {
                return (int) mid;
            } else if (square < x) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        // （接上）因此循环结束后，right 刚好是满足 right * right <= x 的最大整数
        // 即为平方根的整数部分
        return (int) right;
    }
}
```

通过方法二和方法三，我们可以总结出一个更加抽象的通用思路来理解二分查找法。

首先看方法二的循环条件：while(left < right)，即只有当left == right的时候才退出循环，这说明什么？**说明我原本的查找区间从原来的整个数组，被二分法不断地二分之后，最后只剩下一个元素，即退出循环的时候left和right都只指向同一个元素。**而这个元素，即有可能是刚好符合条件的元素，也有可能是刚好符合条件的元素的后一个元素，因此最后返回正确答案前还需要进行一次判断。

然后看方法三的循环条件：while(left ≤ right)，即只有当left > right的时候才退出循环，这又说明什么？**说明我原本的查找区间从原来的整个数组，被二分法不断地二分之后，最后退出循环的时候left和right指向两个元素，而且left == right + 1。**而这两个被指向的元素的其中一个就是正确答案，可以做些简单的判断在返回正确答案，也可以直接返回想要的正确答案（比如本题直接返回小的那个，因为其刚好就是平方根的整数部分）。

总之就是以后不要过于钻到二分法的细节里面，而是要从一个更抽象，更高层的视角去看这个问题。**最重要的就是直接从循环条件下手**，想一想：如果设置成<，说明最后退出循环的时候是只一起指向同一个元素的，这是我想要的答案吗？而如果设置成≤，说明最后退出循环的时候是分别指向两个元素的，这两个元素分别代表什么？其中一个元素是否是我想要的答案？**从循环条件出发，思考退出循环时的元素个数，然后一步步推导出我想要的结果，这才是解决二分法问题的高级解决思路。**
