# 34. 在排序数组中查找元素的第一个和最后一个位置

![image.png](34%20%E5%9C%A8%E6%8E%92%E5%BA%8F%E6%95%B0%E7%BB%84%E4%B8%AD%E6%9F%A5%E6%89%BE%E5%85%83%E7%B4%A0%E7%9A%84%E7%AC%AC%E4%B8%80%E4%B8%AA%E5%92%8C%E6%9C%80%E5%90%8E%E4%B8%80%E4%B8%AA%E4%BD%8D%E7%BD%AE/image.png)

有两种方法，第一种方法的思路是利用二分查找法，并将查找区间定义为左闭右闭。先找第一个目标元素出现的位置，再找最后一个目标元素出现的位置。下面以找第一个目标元素出现的位置为例，查找的过程中会出现如下三种情况：

1. 区间的中间元素和目标元素相同，此时中间元素有可能是第一个出现的目标元素，因此不妨先将其位置记录下来。但是也有可能第一个出现的目标元素在当前查找区间的左半段，当前的这个中间元素只是多个相同的目标元素所组成的数组中靠后的那个目标元素，因此还要去看看左半段是否还出现目标元素。
2. 目标元素比中间元素小，说明第一个目标元素出现的位置一定是在当前查找区间的前半段（不包括中间位置），因此直接去前半段找。
3. 目标元素比中间元素大，说明第一个目标元素出现的位置一定是在当前查找区间的后半段（不包括中间位置），因此直接去后半段找。

整体代码如下：

```java
// 方法一：左闭右闭
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int firstPos = -1; // 记录第一个位置
        int lastPos = -1; // 记录最后一个位置
        int left = 0; // 记录查找区间（左闭）
        int right = nums.length - 1; // 记录查找区间（右闭）
        // 找第一个目标元素出现的位置
        while(left <= right){
            int mid = left + (right - left) / 2;
            if(target == nums[mid]){ // 目标值在当前位置或左半段
                firstPos = mid; // 记录当前位置为可能的第一个位置
                right = mid - 1; // 左边可能还有target，继续向左搜索
            }else if(target < nums[mid]){ // 目标值在左半段
                right = mid - 1;
            }else{ // 目标值在右半段
                left = mid + 1;
            }
        }

        // 查找区间记得重新初始化
        left = 0;
        right = nums.length - 1;
        // 找最后一个目标元素出现的位置
        while(left <= right){
            int mid = left + (right - left) / 2;
            if(target == nums[mid]){ // 目标值在当前位置或右半段
                lastPos = mid; // 记录当前位置为可能的最后一个位置
                left = mid + 1; // 右边可能还有target，继续向右搜索
            }else if(target < nums[mid]){ // 目标值在左半段
                right = mid - 1; 
            }else{ // 目标值在右半段
                left = mid + 1;
            }
        }

        return new int[]{firstPos, lastPos};
    }
}

// 方法一改进：提取成函数
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int[] result = new int[]{-1, -1};
        
        // 第一次二分查找寻找左边界
        result[0] = findBound(nums, target, true);
        
        // 如果左边界没找到，说明目标值不存在，直接返回
        if (result[0] == -1) {
            return result;
        }
        
        // 第二次二分查找寻找右边界
        result[1] = findBound(nums, target, false);
        
        return result;
    }

    // 辅助函数：查找边界，左闭右闭区间
    // true 表示找第一个位置，false 表示找最后一个位置
    private int findBound(int[] nums, int target, boolean isFirst) {
        int low = 0, high = nums.length - 1;
        int bound = -1;

        // 左闭右闭区间一定是等号
        while (low <= high) {
            int mid = low + (high - low) / 2; // 防止溢出

            if (nums[mid] == target) {
                bound = mid; // 暂时记录当前位置
                if (isFirst) {
                    high = mid - 1; // 寻找左边界，向左收缩
                } else {
                    low = mid + 1;  // 寻找右边界，向右收缩
                }
            } else if (nums[mid] > target) {
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return bound;
    }
}
```

第一种方法使用的是左闭右闭区间的二分查找法来查找元素，第二种方法则是将其改造成左闭右开区间的二分查找法，代码不难，整体如下：

```java
// 方法二：左闭右开
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int firstPos = -1; // 记录第一个位置
        int lastPos = -1; // 记录最后一个位置
        int left = 0; // 记录查找区间（左闭）
        int right = nums.length; // 记录查找区间（右开）

        // 找第一个目标元素出现的位置
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (target == nums[mid]) {
                firstPos = mid; // 先记录可能的答案
                right = mid; // 继续在左半段查找
            } else if (target < nums[mid]) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        // 重置查找区间
        left = 0;
        right = nums.length;

        // 找最后一个目标元素出现的位置
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (target == nums[mid]) {
                lastPos = mid; // 先记录可能的答案
                left = mid + 1; // 继续在右半段查找
            } else if (target < nums[mid]) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        return new int[]{firstPos, lastPos};
    }
}
```

总之，两种方法的思路都是直接找我们想要的元素（第一个或者最后一个），然后在找的过程中记录那些可能是答案的结果，最后找完之后那个记录的中间结果就是我们的答案。

其实上述两种方法的代码还可以进一步简化，因为找第一个目标元素出现的位置和找最后一个目标元素出现的位置两段代码中，只有在target == nums[mid]的判断逻辑中代码才不一样，其他的都是一样的，因此可以将这两段代码提取成一个函数。以方法二为例，将其简化如下：

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int left = binarySearch(nums, target, true); // 找第一个位置
        int right = binarySearch(nums, target, false); // 找最后一个位置 + 1
        if (left == right) return new int[]{-1, -1}; // target不存在
        return new int[]{left, right - 1};
    }

    // 通用二分查找函数，lower=true找第一个位置，lower=false找最后一个位置+1
    private int binarySearch(int[] nums, int target, boolean lower) {
        int left = 0, right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (target < nums[mid]) {
                right = mid;
            } else if (target > nums[mid]) {
                left = mid + 1;
            } else {
                if (lower) {
                    right = mid; // 找第一个位置，继续向左搜索
                } else {
                    left = mid + 1; // 找最后一个位置+1，继续向右搜索
                }
            }
        }
        return left;
    }
}
```
