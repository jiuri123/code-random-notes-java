# 367. 有效的完全平方数

![image.png](367%20%E6%9C%89%E6%95%88%E7%9A%84%E5%AE%8C%E5%85%A8%E5%B9%B3%E6%96%B9%E6%95%B0/image.png)

https://leetcode.cn/problems/valid-perfect-square/description/

其实就是验证这个数的平方根是否是小数，即这个数的平方根的平方是否刚好是这个数本身。直接用[**69. x 的平方根** ](69%20x%20%E7%9A%84%E5%B9%B3%E6%96%B9%E6%A0%B9.md) 这道题的方法求出平方根的整数部分，然后将其相乘进行判断就好。代码：

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        if(num == 0 || num == 1){
            return true;
        }

        long left = 1;
        long right = num;
        while(left <= right){
            long mid = left + (right - left) / 2;
            if(mid * mid == num){
                return true;
            }else if(mid * mid > num){
                right = mid - 1;    
            }else{
                left = mid + 1;
            }
        }

        if(right * right == num){
            return true;
        }else{
            return false;
        }
    }
}
```
