# 35. 搜索插入位置

![image.png](35%20%E6%90%9C%E7%B4%A2%E6%8F%92%E5%85%A5%E4%BD%8D%E7%BD%AE/image.png)

有三种方法。第一种暴力解法就是顺序遍历数组，一旦遇到比目标值大的或者相同的元素，就直接返回这个元素的下标。整体代码如下：

```java
// 方法一：暴力解法
class Solution {
    public int searchInsert(int[] nums, int target) {
        for(int i = 0; i < nums.length; i++){
            if(nums[i] >= target){ // 遇到比target大和相等的值
                return i; // 就直接把target返回
            }
        }
        return nums.length; // target比数组中所有元素都大的情况
    }
}
```

第二种和第三种方法就是用二分法，因为数组是排好序的（以后遇到排好序的数组，都可以考虑二分法）。而二分法的查找区间既可以是左闭右闭区间，也可以是左闭右开区间，因此可以分成方法二和方法三。整体代码如下：

```java
// 方法二：二分法，左闭右闭
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;

        // 核心：使用 [left, right] 的闭区间搜索
        while (left <= right) {
            // 防止 (left + right) / 2 可能导致的整型溢出
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                // 1. 找到目标值，直接返回索引
                return mid;
            } else if (nums[mid] < target) {
                // 2. 目标在右半部分，更新左边界
                left = mid + 1;
            } else {
                // 3. 目标在左半部分，更新右边界
                right = mid - 1;
            }
        }

        /**
         * 为什么最后返回 left？
         * 当循环结束时，left 总是指向第一个大于 target 的元素位置，
         * 这也恰恰是 target 应该插入的位置。
         */
        return left;
    }
}

// 方法三：二分法，左闭右开
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0;
        int right = nums.length; // 区别一
        while(left < right){ // 区别二
            int mid = left + (right - left) / 2;
            if(nums[mid] == target){
                return mid;
            }else if(nums[mid] < target){
                left = mid + 1;
            }else{
                right = mid; // 区别三
            }
        }
        return right; // 区别四
    }
}
```

需要注意的是最后的返回值，方法二和方法三的最终返回元素是不同的，这个推导一下就可以。
