# 904. 水果成篮

![image.png](904%20%E6%B0%B4%E6%9E%9C%E6%88%90%E7%AF%AE/image.png)

https://leetcode.cn/problems/fruit-into-baskets/description/

本题核心其实就是需要保证子数组中的元素种类必须要小于或等于2。可以设定两个指针确定一个滑动窗口来表示子数组的左右边界，我们需要保证滑动窗口中的水果种类数始终小于等于2（可以用一个哈希表来表示）。可以这样，右边界每即将加入一个新元素前，就看这个新元素是否属于当前滑动窗口中的某一种类的水果。如果是的话，就直接将其加入到这种水果的篮子中。如果不属于滑动窗口中任何一种水果，那就看当前的滑动窗口中所包含的水果种类是否已经为2了。如果不是，那么就直接加入到滑动窗口中，并更新所收集水果的最大值。如果已经为2了，就向右移动滑动窗口的左边界，不断地删除元素，直到滑动窗口中的水果种类数小于2为止，然后再将这个新元素加入到的滑动窗口中，这样就能始终保证滑动窗口中的水果种类数始终保持在2及2以下。代码如下：

```java
class Solution {
    public int totalFruit(int[] fruits) {
        int sum = 0, maxSum = Integer.MIN_VALUE; // 记录所收集水果的数量
        HashMap<Integer, Integer> hm = new HashMap<>(); // 模拟两个篮子
        int left = 0;
        for(int right = 0; right < fruits.length; right++){
            if(!hm.containsKey(fruits[right])){ // 两个篮子都不是这种水果
                while(hm.size() == 2){ // 如果两个篮子都放了水果
                    // 不断移动左边界，直到某个篮子为空（直到手上只剩下一种水果）
                    sum--;
                    hm.put(fruits[left], hm.get(fruits[left]) - 1);
                    if(hm.get(fruits[left]) == 0){
                        hm.remove(fruits[left]);
                    }
                    left++;
                }
                // 空出一个篮子之后，再将当前的新品种水果放入其中
                sum++;
                maxSum = Math.max(maxSum, sum);
                hm.put(fruits[right], hm.getOrDefault(fruits[right], 0) + 1);
            }else{ // 某个篮子里有这种水果，那么直接放入该篮子中
                sum++;
                maxSum = Math.max(maxSum, sum);
                hm.put(fruits[right], hm.get(fruits[right]) + 1);
            }
        }
        return maxSum;
    }
}
```
