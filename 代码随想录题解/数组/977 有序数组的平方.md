# 977. 有序数组的平方

[https://leetcode.cn/problems/squares-of-a-sorted-array/description/](https://leetcode.cn/problems/squares-of-a-sorted-array/description/)

本题要将一个非递减数组中的每个元素求平方，然后返回这个平方数组，且也要以非递减的形式返回。本题的思路主要在于对数组中的每个元素取平方之后，此时可以发现数组中最大的元素一定是位于数组边界的两个数的其中一个。将其中一个加入新数组，原数组中删掉该元素后得到的数组依然符合“最大值处于边界”这个条件。因此使用双指针法不断将边界元素加入到新数组中即可排序完成，时间复杂度为O(n)；空间复杂度为O(n)。我一刷的代码：

```java
// 一刷的代码
class Solution {
    public int[] sortedSquares(int[] nums) {
        int[] tempNums = new int[nums.length];
        for(int i = 0; i < nums.length; i++){
            nums[i] = nums[i] * nums[i];
        }
        int i = 0;
        int j = nums.length - 1;
        int index = tempNums.length - 1;
        while(i < j){
            if(nums[i] == nums[j]){
                tempNums[index--] = nums[i++];
                tempNums[index--] = nums[j--];
            }else if(nums[i] < nums[j]){
                tempNums[index--] = nums[j];
                j--;
            }else{
                tempNums[index--] = nums[i];
                i++;
            }
        }
        tempNums[0] = nums[i];
        return tempNums;
    }
}

```

代码随想录标准答案：

```java
class Solution {
    public int[] sortedSquares(int[] nums) {
        int right = nums.length - 1;
        int left = 0;
        int[] result = new int[nums.length];
        int index = result.length - 1;
        while (left <= right) {
            if (nums[left] * nums[left] > nums[right] * nums[right]) {
                // 正数的相对位置是不变的， 需要调整的是负数平方后的相对位置
                result[index--] = nums[left] * nums[left];
                ++left;
            } else {
                result[index--] = nums[right] * nums[right];
                --right;
            }
        }
        return result;
    }
}
```

我二刷的代码（跟代码随想录的差不多，只不过随想录是边遍历边计算平方）：

class Solution {
    public int[] sortedSquares(int[] nums) {
        for(int i = 0; i < nums.length; i++){
            nums[i] = nums[i] * nums[i];
        }

        int[] res = new int[nums.length];
        int resIndex = nums.length - 1;
        int left = 0;
        int right = nums.length - 1;
        while(left <= right){
            if(nums[left] < nums[right]){
                res[resIndex--] = nums[right--];
            }else{
                res[resIndex--] = nums[left++];
            }
        }
        return res;
    }
}
