# 27.移除元素

![image.png](27%20%E7%A7%BB%E9%99%A4%E5%85%83%E7%B4%A0/image.png)

https://leetcode.cn/problems/remove-element/description/

本题需要原地移除数组中值为`val`的元素，并返回移除后数组的新长度，且不可以有额外的空间。我的思路在于定义两个指针`left`和`right`。`left`表示存储`nums`数组中不等于`val`值的元素组成的新数组，初始值为0，表示刚开始还没有找到符合条件的值；`right`表示在旧数组中搜索的下标，如果从右边开始搜索，初始值为`nums.length - 1` 。`left`从数组左边开始循环，当遇到符合条件的元素，`left` +1，说明将该元素加入到新数组中。若不符合条件，直接将其与`right`位置的元素交换位置，`right` -1，`left` 保持不变（因为`left` 是刚刚与`right`互换过来的元素，没有被检测过，因此不能直接加入新数组）。一直循环，直到`left`> `right` ，说明数组每个元素都已检测完毕，循环结束。代码整体如下：

```
// 方法一：双指针
class Solution {
    public int removeElement(int[] nums, int val) {
        int k = 0;
        int i = 0, j = nums.length - 1;
        while(i <= j){ //易错点，不是while(i < j)
            if(nums[i] == val){ // 将不符合条件的元素放到后面
                int temp = nums[j];
                nums[j] = nums[i];
                nums[i] = temp;
                j--;
            }else{
                i++;
                k++;
            }
        }
        return k;
    }
}
```

但是上面的代码有点啰嗦，其实不符合条件的元素直接不用管就好了，后面再用符合条件的元素将其会直接覆盖就OK。这就是代码随想录的代码，整体代码如下：

```java
// 方法二：快慢指针，推荐
class Solution {
    public int removeElement(int[] nums, int val) {
        // 快慢指针
        int slowIndex = 0;
        for (int fastIndex = 0; fastIndex < nums.length; fastIndex++) {
            if (nums[fastIndex] != val) {
                nums[slowIndex] = nums[fastIndex];
                slowIndex++;
            }
        }
        return slowIndex;
    }
}
```

总结下来，我的方法是从数组的右边开始检测（看似检测的是左边，但是左边这个元素也是从右边换过去的），而代码随想录的方法是从左边开始检测，并且不符合条件的元素直接就被覆盖掉了，因此代码比我的简洁。
