# 704.二分查找

![image.png](704%20%E4%BA%8C%E5%88%86%E6%9F%A5%E6%89%BE/image.png)

https://leetcode.cn/problems/binary-search/description/

本题旨在一个升序数组中查找给定的元素。整体的解题思路是每次从目标数组（用两个变量标记该数组上下标的位置）的中间元素开始查找，将数组中间元素与待查找元素进行比较。若中间元素等于待查找元素，直接返回中间元素下标。若中间元素比待查找元素要大，说明待查找元素如果存在的话，一定在中间元素的左边，此时直接去处于中间元素左边位置的元素中去查找目标值（即修改上标的位置为的中间元素坐标减1）；反之说明待查找元素一定在中间元素的右边位置，此时直接去处于中间元素右边位置的元素中去查找目标值（即修改下标的位置为的中间元素坐标加1）。不断重复上述过程，直到找到目标元素或者查找失败。该解法每次可将问题规模减少一半，因此时间复杂度为O($lgn$)。空间复杂度O(1)。

此时可以衍生出两种代码思路。第一种是将查找的区间定义在一个左闭右闭区间的区间当中，整体代码如下：

```java
// 方法一：左闭右闭
class Solution {
    public int search(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;
        int mid = 0;
        while(left <= right){
		        // mid = (left + right) / 2; // left + right可能溢出
            mid = left + (right - left) / 2; // 这样可防止溢出
            if(nums[mid] == target){
                return mid;
            }else if(nums[mid] < target){
                left = mid + 1;
            }else{
                right = mid - 1;
            }
        }
        return -1;
    }
}
```

第二种是将每次寻找的区间定义在**左闭右开**的区间中，即high位置是无效的，只寻找low到high-1位置的元素就行。整体代码如下：

```java
// 方法二：左闭右开
class Solution {
    public int search(int[] nums, int target) {
        int left = 0;
        int right = nums.length; // 与方法一的区别一
        int mid = 0;
        while(left < right){ // 与方法一的区别二
            mid = left + (right - left) / 2;
            if(nums[mid] == target){
                return mid;
            }else if(nums[mid] < target){
                left = mid + 1;
            }else{
                right = mid; // 与方法一的区别三
            }
        }
        return -1;
    }
}
```

总结：

1. 对于方法一，其查找区间为左闭右闭区间，因此`left = right`是有意义的，此时说明查找的区间只剩下一个元素，因此`while`循环的条件要写成`left <= right`；但是对于方法二，其查找区间为左闭右开区间，因此`left = right`是没有意义的，此时代表着该查找区间已经没有一个元素了，那么循环就没有必要继续进行下去，直接退出就好，所以`while`循环的条件要写成`left < right`。
2. 由上面的两段代码也可以看出，如果我要修改所查找区间的定义，那么在后续查找中的每一次边界处理中，都要坚持之前所定义的区间来操作，这就是**循环不变量原则**。比如方法二从左闭右闭变成左闭右开，那么后续的`while`循环条件以及`while`循环中`right`的赋值都要进行相应的修改。不可以前面是`int right = nums.length;`，但后面又是`right = mid - 1;`，这就导致两次使用的区间是不一致的。
3. 使用`(low + high) / 2`计算`mid`的值可能会导致`low + high`溢出，可修改成`mid = left + (right - left) / 2`来求`mid`。

我的错误代码（不推荐）：

```java
class Solution {
    public int search(int[] nums, int target) {
        int low = 0;
        int high = nums.length - 1;
        int mid = 0;
        while(true){
            mid = low + (high - low) / 2;
            if(low == high && nums[mid] != target){
                return -1;
            }else if(nums[mid] == target){
                return mid;
            }else if(nums[mid] > target){
                high = mid - 1;//错误的地方，没有考虑边界情况，应为high = mid
            }else{
                low = mid + 1;
            }
        }
    }
}
```

错误原因：边界更新错误。在更新 `high` 和 `low` 的边界时，虽然大部分情况下是正确的，但对于某些边界值可能存在问题。例如，当 `nums[mid] > target` 时，将 `high` 更新为 `mid - 1`，但在某些情况下（如查找边界值时），可能需要将 `high` 更新为 `mid` 才是正确的。考虑数组 `[1, 2]` 中查找 `1` 的情况，按照如上的代码，第一次 `mid = 0`，发现 `nums[mid] = 1 == target` 会正确返回，但如果查找 `0`，第一次 `mid = 0`，发现 `nums[mid] > target`，将 `high` 更新为 `-1`，这会导致错误的结果，因为实际上 `0` 不存在于数组中，应该继续在 `[0, 0]` 这个区间查找，即 `high` 应该更新为 `mid` 而不是 `mid - 1`。但是上上面正确的代码中就不需要考虑这个情况，因为`while`的终止条件为`low <= high`。
