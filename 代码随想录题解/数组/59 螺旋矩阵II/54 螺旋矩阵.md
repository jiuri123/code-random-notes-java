## 方法一

跟[**59.螺旋矩阵II**](../59%20%E8%9E%BA%E6%97%8B%E7%9F%A9%E9%98%B5II.md) 思路差不多，只不过这题是取数，而上题是填数，但代码都是差不多的。整体代码如下：

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> res = new ArrayList<>(); // 用于存放结果
        int m = matrix.length, n = matrix[0].length; // 获取行和列，易错点
        boolean[][] flag = new boolean[m][n]; // 记录该位置是否已被遍历
        int remainCellNum = m * n; // 还剩多少个位置没有被遍历
        int row = 0, column = 0; // 每一圈的初始点
        int right = 0, down = 1, left = 2, up = 3; // 遍历方向
        int direction = right; // 初始方向
        while(remainCellNum > 0){ // 当还有位置没有被遍历时，循环继续
            if(direction == right){ // 往右遍历
                while(isLegalLoc(m, n, row, column) && !flag[row][column]){
                    res.add(matrix[row][column]);
                    remainCellNum--;
                    flag[row][column] = true;
                    column++;
                }
                column--; // while循环结束后column会多走一步
                row++;
                direction = down;
            }else if(direction == down){ // 往下遍历
                while(isLegalLoc(m, n, row, column) && !flag[row][column]){
                    res.add(matrix[row][column]);
                    remainCellNum--;
                    flag[row][column] = true;
                    row++;
                }
                row--;
                column--;
                direction = left;
            }else if(direction == left){ // 往左遍历
                while(isLegalLoc(m, n, row, column) && !flag[row][column]){
                    res.add(matrix[row][column]);
                    remainCellNum--;
                    flag[row][column] = true;
                    column--;
                }
                column++;
                row--;
                direction = up;
            }else{ // 往上遍历
                while(isLegalLoc(m, n, row, column) && !flag[row][column]){
                    res.add(matrix[row][column]);
                    remainCellNum--;
                    flag[row][column] = true;
                    row--;
                }
                row++;
                column++;
                direction = right;
            }
        }
        return res;
    }

    // 判断当前位置是否越界
    public boolean isLegalLoc(int m, int n, int row, int column) {
        if(row < 0 || row >= m){
            return false;
        }else if(column < 0 || column >= n){
            return false;
        }
        return true;
    }
}
```

**要注意一个点是如何获取二维数组的行和列。**因为在java中的二维数组并不是一个严格的矩形数组，而是数组的数组，如本题中的matrix其实是一个一维数组，只不过它里面的每一个元素是一个int[]，而它的每一个元素就构成了一行。因此matrix.length返回的是外层数组的长度，即这个matrix 中存储的 int[] 数组的个数，这个个数就是矩阵的行数。而matrix[0].length返回的是matrix中第一个元素的长度，也就是返回的是内层数组的长度，这个个数也就是矩阵的列数。

## 方法二（面试推荐）：边界收缩法

我们将矩阵看作一个洋葱，一层一层地向内剥开。通过定义四个边界（上、下、左、右），每次遍历完一个方向就缩小相应的边界。
**核心思路**
1. **定义边界**：设定 `upper`, `lower`, `left`, `right` 四个变量。
2. **循环遍历**：按照 **左→右**、**上→下**、**右→左**、**下→上** 的顺序循环。
3. **边界收缩**：每遍历完一行或一列，就将对应的边界向内推进。
4. **终止条件**：当边界重合或交错（例如 `upper > lower` 或 `left > right`）时，说明所有元素已遍历完成。

```java
// 边界收缩法（面试推荐）
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> result = new ArrayList<>();
        if (matrix == null || matrix.length == 0) return result;

        // 初始化四个边界
        int upper = 0;
        int lower = matrix.length - 1;
        int left = 0;
        int right = matrix[0].length - 1;

        while (true) {
            // 1. 从左到右遍历上边界
            for (int i = left; i <= right; i++) {
                result.add(matrix[upper][i]);
            }
            if (++upper > lower) break; // 上边界下移，若越过下边界则结束

            // 2. 从上到下遍历右边界
            for (int i = upper; i <= lower; i++) {
                result.add(matrix[i][right]);
            }
            if (--right < left) break; // 右边界左移

            // 3. 从右到左遍历下边界
            for (int i = right; i >= left; i--) {
                result.add(matrix[lower][i]);
            }
            if (--lower < upper) break; // 下边界上移

            // 4. 从下到上遍历左边界
            for (int i = lower; i >= upper; i--) {
                result.add(matrix[i][left]);
            }
            if (++left > right) break; // 左边界右移
        }

        return result;
    }
}
```

好处：不需要维护“前进方向”和“是否访问过”，简洁易记。
