最暴力的方法就是每次根据输入的区间，去给定的数组中遍历并求和返回，可是这样每次给一个区间都要再去遍历查询一遍，非常的耗时。一个比较好的方法是用动态规划法，即定义dp[i]为到目前为止输入的前i+1个数的和，最后返回区间和的时候，直接返回dp[b] - dp[a] + array[a]就行，因为dp[b] - dp[a]表示[a+1, b]，再加上a就是[a, b]。这样就将查询区间和的时间降低到了o(1)。代码如下：

```java
// 方法一：我的方法，dp[i]为到目前为止输入的前i+1个数的和
import java.util.*;

public class Main{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
 
        // 先记录下第一个输入的值
        int[] array = new int[n]; // 用来存放输入的值
        array[0] = sc.nextInt();
        long[] dp = new long[n]; // dp一直在累加，可能会越界，因此用long而不是int
        dp[0] = array[0];
        for(int i = 1; i < n; i++){
            array[i] = sc.nextInt();
            dp[i] = dp[i - 1] + array[i];
        }

        int a, b;
        while(sc.hasNextInt()){
            a = sc.nextInt();
            b = sc.nextInt();
            // 会将dp[a]给删掉，因此需要加回来
            System.out.println(dp[b] - dp[a] + array[a]);
        }
    }
}

// 方法二：dp[i]为到目前为止输入的前i个数的和，具体实现有些许不同
import java.util.*;

public class Main{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        long[] dp = new long[n + 1];
        for(int i = 0; i < n; i++){
            int num = sc.nextInt();
            dp[i + 1] = dp[i] + num;
        }

        int a, b;
        while(sc.hasNextInt()){
            a = sc.nextInt();
            b = sc.nextInt();
            System.out.println(dp[b + 1] - dp[a]);
        }
    }
}
```
