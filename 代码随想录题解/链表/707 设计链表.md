# 707.设计链表

本题旨在实现一个链表类。较为简单，只是代码量比较多，需要注意两点：

1. 题目给的是一个链表的类，因此需要自己在创建一个链表节点的类
2. `while`循环中的判断条件并不能判断`null`
3. 增减节点的时候，记得更新`size`的值
4. 注意，由于`addAtIndex`可以增加元素在末尾，因此这里的`index`是可以取`size`的；但是`deleteAtIndex`的`index`就不可以取`size`

代码如下：

```java
// 创建一个自定义节点类
class MyLinkedListNode{
    int val;
    MyLinkedListNode next;

    MyLinkedListNode(){}
    MyLinkedListNode(int val){
        this.val = val;
    }
    MyLinkedListNode(int val, MyLinkedListNode next){
        this.val = val;
        this.next = next;
    }
}

// 题目给的链表类
class MyLinkedList {
    int size; //链表节点数量
    MyLinkedListNode head;

    public MyLinkedList() {
        size = 0;
        head = new MyLinkedListNode(0, null);
    }
    
    public int get(int index) {
        if(index < 0 || index >= size){
            return -1;
        }
        MyLinkedListNode temp = head.next;
        for(int i = 0; i < index; i++){
            temp = temp.next;
        }
        return temp.val;
    }
    
    public void addAtHead(int val) {
        MyLinkedListNode addNode = new MyLinkedListNode(val, null);
        addNode.next = head.next;
        head.next = addNode;
        size++;
    }
    
    public void addAtTail(int val) {
        MyLinkedListNode addNode = new MyLinkedListNode(val, null);
        MyLinkedListNode temp = head;
        while(temp.next != null){
            temp = temp.next;
        }  
        temp.next = addNode;
        size++;
    }
    
    public void addAtIndex(int index, int val) {
        if(index < 0 || index > size){
            return;
        }else if(index == size){
            addAtTail(val);
            return;
        }else{
            MyLinkedListNode temp = head;
            for(int i = 0; i < index; i++){
                temp = temp.next;
            }
            MyLinkedListNode addNode = new MyLinkedListNode(val, null);
            addNode.next = temp.next;
            temp.next = addNode;
        }
        size++;
    }
    
    public void deleteAtIndex(int index) {
        if(index < 0 || index >= size){
            return;
        }else{
            MyLinkedListNode temp = head;
            for(int i = 0; i < index; i++){
                temp = temp.next;
            }
            temp.next = temp.next.next;
        }
        size--;
    }
}
```
