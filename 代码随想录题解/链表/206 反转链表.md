# 206.反转链表

[https://leetcode.cn/problems/reverse-linked-list/](https://leetcode.cn/problems/reverse-linked-list/)

## 方法一

本题比较简单，我的方法主要是使用链表的头插法，也就是新建一个新的链表，不断将旧链表中的节点通过头插法插入到新链表中。该算法唯一的缺点就是空间复杂度较高，为O(n)，时间复杂度是O(n)：

```java
// 方法一：头插法
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode beforeHead = new ListNode(0, head);
        ListNode newListHead = new ListNode(0, null);
        while(beforeHead.next != null){
            ListNode tempNode = beforeHead.next;
            beforeHead.next = tempNode.next;
            tempNode.next = newListHead.next;
            newListHead.next = tempNode;
        }
        return newListHead.next;
    }
}
```

## 方法二

如果想要降低空间复杂度到O(1)，可以使用下面代码随想录的三指针法。主要思路就是设置前中后三个指针，中间那个指针每次都将自己的指向修改成指向前一个节点，然后三个指针同时往后移动，直到到达最后一个节点。代码如下：

```java
// 方法二：我写的三指针方法
class Solution {
    public ListNode reverseList(ListNode head) {
        if(head == null){
            return null;
        }
        ListNode pre = head;
        ListNode cur = head.next;
        while(cur != null){
            ListNode temp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = temp;
        }
        head.next = null;
        return pre;
    }
}

// 方法二（改进）：更标准的三指针方式，好处：
// 1. 自动处理空链表和单节点的情况，不需要额外判断
// 2. 结尾处不需要额外设置 head.next = null
public ListNode reverseList(ListNode head) {
    ListNode pre = null;
    ListNode cur = head;
    
    while(cur != null){
        ListNode temp = cur.next;
        cur.next = pre;
        pre = cur;
        cur = temp;
    }
    
    return pre;
}
```

## 方法三

还有一种方法是递归的方法，递归也分为两种方法。第一种递归方法其实就是上述方法二的简单变形，具体的思路跟方法二还是一致的。第二种递归方法有点类似于二叉树的后序遍历，思路就是先找到链表的最后一个节点，然后将这个最后的节点作为新链表的头结点，然后通过不断的返回将这个节点往上传送，传送的过程中顺带将遇到的节点的指向反转，这样就完成了链表的反转。

```java
// 方法三：递归（从前往后，跟方法二思路一致）
class Solution {
    public ListNode reverseList(ListNode head) {
        return reverse(null, head);
    }

    public ListNode reverse(ListNode pre, ListNode cur) {
        if(cur == null){
            return pre; // 注意是返回pre，而不是cur
        }

        // 记录下一节点
        ListNode temp = cur.next;
        // 让当前节点指向前一节点
        cur.next = pre;

        // 相当于是将pre和cur同时后移
        return reverse(cur, temp);
    }
}

// 方法三：递归（从后往前，类似于二叉树的后序遍历）
class Solution {
    public ListNode reverseList(ListNode head) {
        if(head == null || head.next == null){
            return head;
        }

        // 先递归找到最后一个节点，即新的头结点
        ListNode newHead = reverseList(head.next);

        // 反转当前节点
        head.next.next = head;  // 让下一个节点指向当前节点
        head.next = null;

        // 不断地将新的头结点往上返回
        return newHead;
    }
}
```
