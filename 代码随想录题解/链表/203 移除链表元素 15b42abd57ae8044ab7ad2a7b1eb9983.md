# 203.移除链表元素

[https://leetcode.cn/problems/remove-linked-list-elements/submissions/](https://leetcode.cn/problems/remove-linked-list-elements/submissions/)

本题旨在删除链表中等于给定值 `val`的所有节点。这题主要有两种解法，一种是直接在不含头结点的原数组中进行删除元素的操作，另一种是新建一个头结点，统一每个节点的删除操作。

## 方法一

先解释第一种方法，首先用一个循环来对首节点进行处理，直到找到非`val`值的起始节点作为新的`head`，接着再对head之后的节点进行删除操作。

第一种方法代码如下：

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        ListNode front = null;
        ListNode tempHead = null;
        while(head != null && head.val == val){
            head = head.next;
        }
        tempHead = head;
        while(tempHead != null && tempHead.next != null){
            if(tempHead.next.val == val){
                tempHead.next = tempHead.next.next;
            }else{
                tempHead = tempHead.next;
            }
        }
        return head;
    }
}
```

## 方法二（推荐，不易出错）

```java
/**
 * 时间复杂度 O(n)
 * 空间复杂度 O(1)
 * @param head
 * @param val
 * @return
 */
public ListNode removeElements(ListNode head, int val) {
    // 设置一个虚拟的头结点
    ListNode dummy = new ListNode();
    dummy.next = head;

    ListNode cur = dummy;
    while (cur.next != null) {
        if (cur.next.val == val) {
            cur.next = cur.next.next;
        } else {
            cur = cur.next;
        }
    }
    return dummy.next; //注意不要返回虚拟节点，而应该是虚拟节点的下一个节点
}
```
