# 面试题 02.07. 链表相交

[https://leetcode.cn/problems/intersection-of-two-linked-lists-lcci/description/](https://leetcode.cn/problems/intersection-of-two-linked-lists-lcci/description/)

本题旨在找出两个链表节点是否有相交的节点，相交的节点指的是地址值相同的节点，而不仅仅是里面的值相同。

## 方法一

方法一解题思路是先计算两个链表的长度，然后设置两个指针分别指向两个链表初始位置，并按照如下规则移动这两个指针：如果两个链表长度相等，则将两个指针同时向后移动；否则每次只需要移动长度更长的那个链表的指针。代码如下：

```java
// 方法一
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        //定义虚拟头结点
        ListNode kobeHeadA = new ListNode(-1, headA);
        ListNode kobeHeadB = new ListNode(-1, headB);
        //计算两个链表的长度
        int headACount = 0;
        int headBCount = 0;
        ListNode tempA = headA;
        ListNode tempB = headB;
        while(tempA != null){
            headACount++;
            tempA = tempA.next;
        }
        while(tempB != null){
            headBCount++;
            tempB = tempB.next;
        }
        tempA = kobeHeadA;
        tempB = kobeHeadB;
        while(tempA.next != null && tempB.next != null){
            if(tempA.next == tempB.next){
                break;
            }else{
                //谁长动谁
                if(headACount > headBCount){
                    tempA = tempA.next;
                    headACount--;
                }else if(headACount < headBCount){
                    tempB = tempB.next;
                    headBCount--;
                }else{ //同样长就一起动
                    tempA = tempA.next;
                    tempB = tempB.next;
                    headACount--;
                    headBCount--;
                }
            }
        }
        //易错点，不能直接返回tempA.next
        //因为跳出上面的while循环有两种情况：
        //1.两个链表走到头了都没找到相同的节点
        //2.找到了某个相同的节点
        if(tempA.next == tempB.next){
            return tempA.next;                                               
        }else{
            return null;
        }
    }
}
```

为什么要移动的较长的链表的指针呢？因为对于两个长度不相等的链表，如果它们存在相等的节点，那么它们从相等节点开始，后面的节点及长度都是一模一样，唯一不同的就是相等节点之前的节点和长度，容易发现长链表更长，因此需要花费更多的步数才能到达相等的节点。因此每次比较先移动长链表的指针，使得后续它们在同步移动的过程中可以正好同时抵达相交的那个节点，这样长链表的指针多走几步之后就可以赶上短链表的指针。最后两个链表的指针携手共进，一起去寻找光明的未来（也就是那个相同的节点）。

例如，链表 `A` 长度为 8 个节点，链表 `B` 长度为 5 个节点，且它们相交，相交节点是 `A` 中的第 4 个节点（从头部开始计数），也是 `B` 中的第 1 个节点。我们要找到这个相交节点，那就需要先让链表 `A` 的指针先走 `3` 步（因为 `8 - 5 = 3`，也就是长链表比短链表多出来的节点个数，这些个多出来的节点不可能是相交的节点），然后再让 `A` 和 `B` 的指针同步往后移动，这样它们就能同时到达相交节点了。总结：**长链表比短链表多出来的前面那几个节点不可能是相交的节点（关键！！！）。**

## 方法二

另外一种解法：算出两个链表的长度差`k`后，将长链表的头指针直接向后移动长度`k`个节点，使得两个链表的剩余长度一样，然后两个链表的头结点开始同步移动并比较，直到找到相同节点或到达链表末尾。代码如下：

```java
// 方法二
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        // 计算headA的长度
        int lenA = 0;
        ListNode curA = headA;
        while(curA != null){
            lenA++;
            curA = curA.next;
        }

        // 计算headB的长度
        int lenB = 0;
        ListNode curB = headB;
        while(curB != null){
            lenB++;
            curB = curB.next;
        }

        // 移动长度更长的链表节点到相同位置
        curA = headA;
        curB = headB;
        int gap = 0; // 两个链表的长度差值
        if(lenA > lenB){
            gap = lenA - lenB;
            while((gap--) != 0){
                curA = curA.next;
            }
        }else{
            gap = lenB - lenA;
            while((gap--) != 0){
                curB = curB.next;
            }
        }

        // 开始同步移动并比较
        while(curA != null && curB != null){
            if(curA == curB){
                return curA;
            }else{
                curA = curA.next;
                curB = curB.next;
            }
        }
        return curA;
    }
}
```

## 方法三（面试推荐，简短好记）：浪漫相遇法

方法三来自代码随想录，代码虽然简洁，但是有点难理解。主要思路就是设置两个指针同时指向两个链表的头，然后同时往后走，直到某个节点到达该链表的末尾之后，就将该节点指向另一链表的头结点。同理，另一个节点也做此操作，直到两个节点所指向的结点相等，就退出循环。代码如下：

```
// 方法三
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode curA = headA;
        ListNode curB = headB;
        while(curA != curB){
            // curA每次走一步
            if(curA != null){
                curA = curA.next;
            }else{ // 如果走到末尾，就转到headB链表
                curA = headB;
            }

            // curB也是每次走一步
            if(curB != null){
                curB = curB.next;
            }else{ // 如果走到末尾，就转到headA链表
                curB = headA;
            }
        }
        return curA;
    }
}
```

为什么这样做可行呢？因为节点同步向后移动的时候，一定是短的那个链表的结点先走到末尾，此时该节点指向另一长链表的头结点，这意味着原本长链表的那个节点还剩下需要走的结点数恰好就是两个链表节点数的差。因此只要继续将长链表的那个节点走到头并转移到短链表的头结点，那么短链表的那个节点（此时在长链表）刚好在长链表走的步数就是两个链表的差值（此时变成方法二），也就是说此时两个节点所指向的链表所剩下结点数就是一样的，此时相当于是回到了方法二和方法一。有点绕，自己走一遍就能理解。

Gemini的解释：

**核心思路：浪漫相遇法**
假设链表 A 的非公共部分长度为 a，链表 B 的非公共部分长度为 b，公共部分长度为 c。
• 指针 `pA` 走完链表 A，再从链表 B 的头开始走。它到达相交点时走的步数为：a + c + b。
• 指针 `pB` 走完链表 B，再从链表 A 的头开始走。它到达相交点时走的步数为：b + c + a。
**由于 a + c + b = b + c + a，两个指针一定会同时到达相交节点。** 如果两个链表不相交，它们最终会同时指向 `null`（相当于 c=0），循环也会自然结束。
