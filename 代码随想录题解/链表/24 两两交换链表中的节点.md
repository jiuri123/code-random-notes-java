# 24. 两两交换链表中的节点

[https://leetcode.cn/problems/swap-nodes-in-pairs/](https://leetcode.cn/problems/swap-nodes-in-pairs/)

本题旨在交换链表中的两个节点，注意不是冒泡排序，而是交换那些没有被交换过的链表节点。本题比较简单，直接模拟就OK，需要注意一些边界条件。

## 方法一

这是我的方法一，可以看到由于没有设置初始节点，因此需要对第一个节点做特殊处理。虽然也能解决问题，但是代码会非常的臃肿，而且逻辑也不是很清晰，容易出错。

```java
// 方法一：我的方法，由于没有设置虚拟头结点，导致代码臃肿
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode headPre = new ListNode(-1, head); // 自定义一个虚拟头结点
        ListNode firstNodePre = headPre;
        ListNode firstNode;
        ListNode secondNode;
        ListNode temp;
        // 预处理阶段下面是对链表前两个节点的处理
        if(head != null){
            firstNode = head;
        }else{
            return head;
        }
        if(head.next != null){
            secondNode = head.next;
            temp = secondNode.next;
        }else{
            return head;
        }
        // 正式开始交换算法
        while(true){
            firstNodePre.next = secondNode;
            secondNode.next = firstNode;
            firstNode.next = temp;
            if(temp == null || temp.next == null){
                break;
            }else{
                firstNodePre = firstNode;
                firstNode = temp;
                secondNode = temp.next;
                temp = secondNode.next;
            }
        }
        return headPre.next;
    }
}

// 方法二：我的方法，其实也可以不用设置虚拟节点
```

## 方法二

下面是我的方法二，虽然还是没有设置虚拟头结点，但是还是可以统一对所有节点的操作，只不过逻辑上不是很清晰，还是推荐后面介绍的方法三。思路就是当改变后一个节点的指向后，并需要改变第一个节点的指向前，需要进行判断：如果这两个节点的后面没有节点了，那就将第一个节点直接指向null，循环退出；如果这两个节点的后面还剩下一个节点，那就将第一个节点直接指向这个节点，循环退出；如果这两个节点的后面剩下不只一个节点（两个或两个以上），那就将第一个节点指向当前两个节点的下两个节点的第二个节点，并移动指针，循环继续。

之前的错误就是在改变第一个节点的指向的时候，没有进行判断，而是直接将其指向下两个节点的第一个节点，但是这样做会导致某些节点脱离链表的主线（推导一下就知道），所以这个判断不仅是统一操作的保证，也是防止某些节点脱离主线的必要操作。

```java
// 方法二：不设置虚拟头结点，但是统一操作
class Solution {
    public ListNode swapPairs(ListNode head) {
        if(head == null || head.next == null){
            return head;
        }
        ListNode pre = head;
        ListNode cur = head.next;
        // 新的头结点应该是旧头结点的下一个节点
        ListNode newHead = head.next;   
        while(true){
            ListNode temp = cur.next;
            cur.next = pre; // 改变第二个节点的指向
            // 改变第一个节点的指向（关键代码）
            if(temp == null){ // 如果后面没有剩余节点
                pre.next = null;
                break;
            }else if(temp.next == null){ // 如果后面还剩下一个节点
                pre.next = temp;
                break;
            }else{ // 如果后面还剩下至少两个节点
                pre.next = temp.next;
            }
            
            pre = temp;
            cur = pre.next;
        }
        return newHead;
    }
}
```

## 方法三

方法三来自代码随想录。就是设置一个头结点，以便统一对所有节点的操作，逻辑更加的清晰。

```java
// 方法三：设置虚拟头结点，统一所有节点的操作
class Solution {
  public ListNode swapPairs(ListNode head) {
        ListNode dumyhead = new ListNode(-1); // 设置一个虚拟头结点
        dumyhead.next = head; // 将虚拟头结点指向head，这样方便后面做删除操作
        ListNode cur = dumyhead;
        ListNode temp; // 临时节点，保存两个节点之后的那个节点
        ListNode firstnode; // 临时节点，保存两个节点之中的第一个节点
        ListNode secondnode; // 临时节点，保存两个节点之中的第二个节点
        while (cur.next != null && cur.next.next != null) {
            temp = cur.next.next.next;
            firstnode = cur.next;
            secondnode = cur.next.next;
            cur.next = secondnode;       // 步骤一
            secondnode.next = firstnode; // 步骤二
            firstnode.next = temp;      // 步骤三
            cur = firstnode; // cur移动，准备下一轮交换
        }
        return dumyhead.next;
    }
}

// 自己写的改进版，感觉好记一点
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummyHead = new ListNode(0, head);
        ListNode currDummyHead = dummyHead; // 当前两节点的虚拟头结点
        while(currDummyHead.next != null && currDummyHead.next.next != null){
            ListNode currHead = currDummyHead.next; // 当前两节点的头结点
            ListNode currTail = currDummyHead.next.next; // 当前两节点的尾结点
            ListNode nextHead = currTail.next; // 下两节点的头结点

            // 开始交换
            currHead.next = nextHead;
            currTail.next = currHead;
            currDummyHead.next = currTail;

            // 准备下次交换
            currDummyHead = currHead;
        }
        return dummyHead.next;
    }
}
```
