# 19.删除链表的倒数第N个节点

如题。本题有两种解法，第一种较为容易想到，就是遍历两次，第一次遍历算出链表的长度，第二次遍历就可以找到倒数第N个节点。第二种方法就是典型的双指针法，设置一个快指针先找到的顺数第N个节点的位置，然后同时移动快慢指针直到快指针到达链表末尾的位置，要点在于快慢指针的间距始终是N，此方法只需要一次遍历就可以找到要删除的节点并删除。

我的代码（第一种方法）：

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode kobeNode = new ListNode(-1, head);
        int count = 0;
        ListNode pre = kobeNode;
        while(pre.next != null){
            count++;
            pre = pre.next;
        }
        pre = kobeNode;
        int temp = count - n;
        while(temp != 0){
            pre = pre.next;
            temp--;
        }
        pre.next = pre.next.next;
        if(kobeNode.next == null){
            return null;
        }else{
            return kobeNode.next;    
        }
    }
}
```

第二种方法（双指针法）：

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode kobeNode = new ListNode(-1, head);
        ListNode fastNode = kobeNode;
        ListNode slowNode = kobeNode;
        for(int i = 0; i <= n; i++){
            fastNode = fastNode.next;
        }
        while(fastNode != null){
            slowNode = slowNode.next;
            fastNode = fastNode.next;
        }
        slowNode.next = slowNode.next.next;
        return kobeNode.next;
    }
}
```
