# 51. N 皇后

[https://leetcode.cn/problems/n-queens/](https://leetcode.cn/problems/n-queens/)

## 方法一

思路是定义一个`List<Integer> pathIntList`用来存储一次解决方案中从上到下的每个皇后存放的列索引值，行索引其实不用存储，因为行索引就隐含在`List`的索引中，也就是说`pathIntList.get(i)`表示第`i`个皇后存放在第i列，也等同于第`i`行的皇后存放在第`i`列。剩下的就是有效性判断和递归，注意不在同列和同一正副对角线就好了。为什么不用判断是否在用一行呢？因为pathIntList的索引就代表行数，索引都是不同，所以默认就不在同一行了，不用进行显式判断是否在同一行。代码如下：

```java
// 方法一
class Solution {
    List<List<String>> result = new ArrayList<>();
    List<Integer> pathIntList = new ArrayList<>();
    public List<List<String>> solveNQueens(int n) {
        getNQueens(n, 0);
        return result;
    }

    public void getNQueens(int n, int QueenIndex_line) {
        if(pathIntList.size() == n){
            List<String> pathStrList = new ArrayList<>();
            String lineStr = "";
            // 将列索引转换成列字符串
            for(int i = 0; i < pathIntList.size(); i++){
                lineStr = "";
                for(int j = 0; j < pathIntList.get(i); j++){
		                // 最好用StringBuilder或者下面的方法二
		                // +=的时间复杂度太高，因为字符串是不可变的，每次拼接都会创建新对象
                    lineStr += ".";
                }
                lineStr += "Q";
                for(int j = pathIntList.get(i) + 1; j < n; j++){
                    lineStr += ".";
                }
                pathStrList.add(lineStr);
            }
            result.add(new ArrayList<>(pathStrList));
        }

        for(int row = 0; row < n; row++){
            if(!isValid(QueenIndex_line, row)){
                continue;
            }
            pathIntList.add(row);
            getNQueens(n, QueenIndex_line + 1);
            pathIntList.remove(pathIntList.size() - 1);
        }
    }

    // 有效性判断
    public boolean isValid(int line, int row){
        for(int i = 0; i < pathIntList.size(); i++){
            // 不能在同一列，同一对角线（包括正副对角线，abs同时对这两者进行了判断）
            if(pathIntList.get(i) == row || Math.abs(pathIntList.get(i) - row) == Math.abs(i - line)){
                return false;
            }
        }

        return true;
    }
}

```

## 方法二

还有更快的对有效性进行判断的方法。可以发现如下规律：

1. 处在同一主斜线（左上到右下）上的元素，他们的行减去列的值相同且唯一
2. 处在同一副斜线（右上到左下）上的元素，他们的行加上列的值相同且唯一

所以我可以在将每个点加入到`pathIntList`的同时，也将其行减去列的值和行加上列的值加入到两个`Set`集合中，这样在后面每加入一个点都看看这个点的行减去列的值和行加上列的值在`Set`集合中是否都已存在，如果存在说明主斜线或者副斜线上已经有皇后了，此时不能加入`pathIntList`，否则就可以加入`pathIntList`。这种方法可以使得优化有效性检查的时间复杂度从 O(n) 降到了 O(1)。代码如下：

```java
class Solution {
    // 最终结果集：存储所有合法的棋盘排列
    List<List<String>> res = new ArrayList<>();
    
    // 路径记录：记录每一行皇后所在的列索引。例如 [1, 3, 0, 2] 表示第0行皇后在第1列...
    List<Integer> queenColIndices = new ArrayList<>();
    
    // 状态记录：利用 Set 快速判断当前列、主对角线、副对角线是否已经存在皇后 (O(1) 复杂度)
    Set<Integer> columnSet = new HashSet<>();
    Set<Integer> mainDiagonalSet = new HashSet<>(); // 主对角线 (左上到右下)：行减列的值 row - column 是固定的
    Set<Integer> antiDiagonalSet = new HashSet<>(); // 副对角线 (右上到左下)：行加列的值 row + column 是固定的

    public List<List<String>> solveNQueens(int n) {
        // 特殊情况处理：1x1 有解，2x2 和 3x3 无解
        if (n == 2 || n == 3) return new ArrayList<>();

        backtrack(n, 0); // 从第 0 行开始回溯
        return res;
    }

    // row表示当前递归到棋盘的第row行了，也可以认为当前正在处理第n个皇后（即将行索引视为皇后的索引）
    public void backtrack(int n, int row) {
        // 终止条件：如果行数等于 n，说明 0 ~ n-1 行都放好了皇后
        if (row == n) {
            res.add(generateBoard(n)); // 将当前的记录转换成题目要求的字符串格式
            return;
        }

        // 遍历当前行的每一列，尝试放置皇后
        for (int column = 0; column < n; column++) {
            // 检查当前位置 (row, column) 是否会被攻击
            if (isSafe(row, column)) {
                
                // 1. 做选择
                queenColIndices.add(column);
                columnSet.add(column);
                mainDiagonalSet.add(row - column);
                antiDiagonalSet.add(row + column);

                // 2. 递归：进入下一行
                backtrack(n, row + 1);

                // 3. 撤销选择
                // 这一步是回溯的核心：把状态恢复原样，尝试当前行的下一列
                queenColIndices.remove(queenColIndices.size() - 1);
                columnSet.remove(column);
                mainDiagonalSet.remove(row - column);
                antiDiagonalSet.remove(row + column);
            }
        }
    }

    // 位置有效性判断
    public boolean isSafe(int row, int column) {
        // 如果列、主对角线、副对角线任何一个已经存在皇后，则不安全
        if (columnSet.contains(column) || 
            mainDiagonalSet.contains(row - column) || 
            antiDiagonalSet.contains(row + column)) {
            return false;
        }
        return true;
    }

    // 辅助函数：根据 queenColIndices 记录的列索引生成最终的棋盘字符串列表
    public List<String> generateBoard(int n) {
        List<String> board = new ArrayList<>();
        for (int colIndex : queenColIndices) {
            char[] rowArray = new char[n];
            Arrays.fill(rowArray, '.'); // 先全部填满点
            rowArray[colIndex] = 'Q';   // 在记录的位置放上皇后
            board.add(new String(rowArray)); // 完成一行棋盘的生成，准备生成下一行
        }
        return board;
    }
}
```
