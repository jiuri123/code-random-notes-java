# 78. 子集（含回溯总结）

![image.png](78%20%E5%AD%90%E9%9B%86%EF%BC%88%E5%90%AB%E5%9B%9E%E6%BA%AF%E6%80%BB%E7%BB%93%EF%BC%89/image.png)

本题也是使用回溯法，由于要找所有可能的子集，所以每增加一个新的箱子前都要对已有的箱子进行一波收集。也就是说之前的题目都是等到某个终止节点才开始收集结果，而本题是需要对每个中间结果进行收集。可以在进入循环后但是还没有开始for循环前就开始收集（for循环前当前递归层的箱子还没有建立，只有开始for循环才说明新箱子已建立）。代码如下：

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        // 暂存当前的子集状态
        List<Integer> path = new ArrayList<>();
        // 从索引 0 开始回溯
        backtrack(nums, 0, path, res);
        return result;
    }

    private void backtrack(int[] nums, int startIndex, List<Integer> path, List<List<Integer>> res) {
        // 1. 收集结果：每一个节点都是一个子集
        res.add(new ArrayList<>(path)); // 易错点，一定要新建 List 再加入 res
        
        if(startIndex == nums.length) return; // 可有可无

        // 2. 终止条件：当 startIndex 达到数组长度时，循环自然结束
        for (int i = startIndex; i < nums.length; i++) {
            // 3. 处理节点
            path.add(nums[i]);
            
            // 4. 递归：从下一个元素开始，避免重复使用当前元素
            backtrack(nums, i + 1, path, result);
            
            // 5. 回溯：撤销选择
            path.remove(path.size() - 1);
        }
    }
}
```

## 回溯章节总结

到目前为止，回溯的题目分为两种，一种是将所有的箱子整体且连续的看待，不需要特殊的中间变量记录每个箱子存什么，因为每个箱子存的元素一般就只有一个（比如一个数字或者一个字母），只需要一个path变量记录每个箱子中的元素连起来的东西是什么就好了。到达终止条件后，只需要将path放入结果列表中就行。题目如：[**77. 组合**](77%20%E7%BB%84%E5%90%88%201c842abd57ae80ecb30fd195a310ddd7.md)，[**216. 组合总和 III**](216%20%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8C%20III%201ca42abd57ae8053b06ff71f49c18889.md)， [**17. 电话号码的字母组合**](17%20%E7%94%B5%E8%AF%9D%E5%8F%B7%E7%A0%81%E7%9A%84%E5%AD%97%E6%AF%8D%E7%BB%84%E5%90%88%201cb42abd57ae80ea863edbfd4b56a2e0.md)，[**39. 组合总和**](39%20%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8C%201cc42abd57ae8078b626f94bbf59d03d.md)， [**40. 组合总和 II**](40%20%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8C%20II%201cc42abd57ae805e9de4d76000a37f66.md)，以及本题。

另一种是将每个箱子相对孤立的看待，每进入到一层递归准备创建新箱子的时候，都需要创建一个中间变量保存这个箱子存的元素，方便对这个元素进行某些条件判断。而且这个元素的长度一般是可以变化的，比如字符串或者一串数字。当到达终止条件后，再根据实际情况将每个箱子里面存放的元素拼接在一起放进结果队列中。题目如：[**131. 分割回文串**](131%20%E5%88%86%E5%89%B2%E5%9B%9E%E6%96%87%E4%B8%B2%201ce42abd57ae80ba8f98ef533017abdd.md)（需要判断每个箱子中的字符串是否是回文串），[**93. 复原 IP 地址**](93%20%E5%A4%8D%E5%8E%9F%20IP%20%E5%9C%B0%E5%9D%80%201cf42abd57ae80099fa1e2e05968230c.md)（每个箱子存放的字符串是可变的，而且需要对字符串进行条件判断）。

因此遇到一道题，还需要看看这道题是**将每个箱子独立看待，还是将所有箱子整体看待**，这两种思路极大的决定了后续代码的发展。一般可以**通过一个箱子放的元素长度是可变的不可变的来进行判断**。
