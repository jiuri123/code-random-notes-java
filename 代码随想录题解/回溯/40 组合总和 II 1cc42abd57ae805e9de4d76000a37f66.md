# 40. 组合总和 II

[https://leetcode.cn/problems/combination-sum-ii/](https://leetcode.cn/problems/combination-sum-ii/)

本题与之前题目不同的地方在于给定的候选人编号的集合 `candidates`中的元素是存在重复元素的（不像之前的题目：[**39. 组合总和**](39%20%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8C%201cc42abd57ae8078b626f94bbf59d03d.md) ，在提示中会提示你`candidates` 的所有元素 **互不相同**），因此在对每个箱子选取数字的时候需要去重，否则可能会出现相同的组合。

而且题目说每个数字在每个组合中只能使用一次，所以一个组合中是可以出现重复数字的。只不过这些重复的数字是来自原集合中不同位置的重复数字，因为并没有说重复的数字在每个组合中只能使用一次。

举个例子，假设集合有两个1，那么第一个箱子选了第一个1之后，不代表其他的箱子不能再选1这个数字，只是说其他的箱子不能再选第一个1，但是可以选第二个1啊。这就是问题的关键了：每个数字只能被选1次，那多个相同的数字就可以被选择多次。所以不要直接对集合去重，这样会直接让多次出现的重复数字的次数直接降为1，也就是只能被一个箱子选了，但是这些数字虽然一样，但是是可以被多个箱子选的（出现多少次就被多少个箱子选）。代码如下：

```
class Solution {
    List<List<Integer>> ansList = new ArrayList<>();
    List<Integer> tempList = new ArrayList<>();

    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        if (candidates.length == 0) {
            return ansList;
        }

				// 去重的前提：排序
        Arrays.sort(candidates);
        getCombinationSum(candidates, target, 0);
        return ansList;
    }
		
		// 单个集合的递归，所以要用index
    public void getCombinationSum(int[] candidates, int target, int index) {
        if (target == 0) {
            ansList.add(new ArrayList<>(tempList));
            return;
        }

        for (int i = index; i < candidates.length; i++) {
            // 正确的剪枝
            if (target - candidates[i] < 0) {
                break;
            }
            // 单箱去重：跳过重复的元素，避免解集出现重复组合
            if (i > index && candidates[i] == candidates[i - 1]) {
                continue;
            }
            tempList.add(candidates[i]);
            // 多箱去重：将i + 1传给下层的index，使得每个数字在每个组合中只能使用一次
            getCombinationSum(candidates, target - candidates[i], i + 1);
            tempList.remove(tempList.size() - 1);
        }
    }
}
```

本题与[**39. 组合总和**](39%20%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8C%201cc42abd57ae8078b626f94bbf59d03d.md) 的不同：本题每个数字只能被使用一次，而[**39. 组合总和**](39%20%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8C%201cc42abd57ae8078b626f94bbf59d03d.md) 中的每个数字可以被选择多次，所以本题将`i + 1`传给下层的`index`，而[**39. 组合总和**](39%20%E7%BB%84%E5%90%88%E6%80%BB%E5%92%8C%201cc42abd57ae8078b626f94bbf59d03d.md) 将`i`传给下层的`index`。
