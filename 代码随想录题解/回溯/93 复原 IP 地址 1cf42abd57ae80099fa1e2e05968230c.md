# 93. 复原 IP 地址

[https://leetcode.cn/problems/restore-ip-addresses/description/](https://leetcode.cn/problems/restore-ip-addresses/description/)

看似很难，其实还是回溯那一套，就是要处理一些特殊情况，其他的直接套回溯的模板就好了，没什么搞头，代码如下：

```java
// LeetCode需要导入StringJoiner才能使用
import java.util.StringJoiner;

class Solution {
    List<String> validIpAddresses = new ArrayList<>();
    List<String> currentSegments = new ArrayList<>();
    public List<String> restoreIpAddresses(String s) {
        // 检查输入字符串长度是否合法
        if (s.length() < 4 || s.length() > 12) {
            return validIpAddresses;
        }
        getIpAddresses(s, 0);
        return validIpAddresses;
    }

    public void getIpAddresses(String s, int startIndex) {
        // 如果已经分割成4段，而且全部数字均已分割完毕，
        // 则将四段数字拼接成一个完整的IP地址，然后结束递归
        if(currentSegments.size() == 4 && startIndex == s.length()){
            StringJoiner sj = new StringJoiner(".");
            for(String str : currentSegments){
                sj.add(str);
            }
            validIpAddresses.add(sj.toString());
            return;
        }

        String boxString = "";
        for(int i = startIndex; i < s.length(); i++){
            boxString += String.valueOf(s.charAt(i));

            int num = Integer.parseInt(boxString);
            
            // 开始判断整数是否合法
            // 不能含有前导 0
            if(boxString.startsWith("0") && boxString.length() != 1){
                break;
            }
            // 每个整数位于 0 到 255 之间
            if(num < 0 || num > 255){
                break;
            }
            currentSegments.add(boxString);

            getIpAddresses(s, endIndex + 1);

            currentSegments.remove(currentSegments.size() - 1);
        }
    }
}
```

易错点：

- 在“不能含有前导 0”的判断处，容易写成如下的语句：

```java
int num = Integer.parseInt(boxString);
if(boxString.startsWith("0") && num != 0){
    break;
}
```

但是如果出现连续的0，本来应该也是要退出循环的，但是num此时是0，也就不会进行if循环，导致连续的0也被作为IP地址的一个段，而这样显然是错误的。

- 在递归的结束条件中容易忘掉startIndex == s.length()这一句，比如写成如下：

```java
if(tempStrList.size() == 4){
    StringJoiner sj = new StringJoiner(".");
    for(String str : tempStrList){
        sj.add(str);
    }
    ansIPStrs.add(sj.toString());
    return;
}
```

这样容易导致还没将s遍历完就结束递归，提前收集答案。比如当`s = "25525511135"`时，容易出现`"2.5.5.2”`这样的答案，很明显是提前结束递归了。所以需要再遍历完s之后在收集答案，而不是有了4段之后就收集。正确代码如下：

```java
if(tempStrList.size() == 4 && startIndex == s.length()){
    StringJoiner sj = new StringJoiner(".");
    for(String str : tempStrList){
        sj.add(str);
    }
    ansIPStrs.add(sj.toString());
    return;
}
```
