# 216. 组合总和 III

[https://leetcode.cn/problems/combination-sum-iii/](https://leetcode.cn/problems/combination-sum-iii/)

思路跟[**77. 组合**](77%20%E7%BB%84%E5%90%88%201c842abd57ae80ecb30fd195a310ddd7.md) 这一题差不多，只不过多了一个对总和的判断，同时剪枝操作也有微小的变化。代码如下：

```java
class Solution {
    List<List<Integer>> ansLists = new ArrayList<>();
    List<Integer> tempList = new ArrayList<>();
    public List<List<Integer>> combinationSum3(int k, int n) {
        getCombination(k, n, 1);
        return ansLists;
    }

    public void getCombination(int k, int n, int index) {
        // 剪枝操作一
        if(n < 0){
            return;
        }

        if(tempList.size() == k){
            if(n == 0){
                ansLists.add(new ArrayList<>(tempList));
            }
            return;
        }

        // 剪枝操作二
        for(int i = index; i <= 9 - (k - tempList.size()) + 1; i++){
            tempList.add(i);
            getCombination(k, n - i, i + 1);
            tempList.remove(tempList.size() - 1);
        }
    }
}
```
