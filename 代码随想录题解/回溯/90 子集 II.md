# 90. 子集 II

![image.png](90%20%E5%AD%90%E9%9B%86%20II/image.png)

与[**78. 子集（含回溯总结）**](78%20%E5%AD%90%E9%9B%86%EF%BC%88%E5%90%AB%E5%9B%9E%E6%BA%AF%E6%80%BB%E7%BB%93%EF%BC%89.md) 题目类似，只不过需要加一个去重操作，一定要记得去重的前提是排序！代码如下：

```java
class Solution {
    List<List<Integer>> ansList = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        // 要去重，先排序！
        Arrays.sort(nums);
        getSubsetsWithDup(nums, 0);
        return ansList;
    }

    public void getSubsetsWithDup(int[] nums, int index) {
        ansList.add(new ArrayList<>(path));
        if(index == nums.length){
            return;
        }

        for(int i = index; i < nums.length; i++){
            // 去重操作
            if(i > index && nums[i] == nums[i - 1]){
                continue;
            }
            path.add(nums[i]);
            getSubsetsWithDup(nums, i + 1);
            path.remove(path.size() - 1);
        }
    }
}
```
