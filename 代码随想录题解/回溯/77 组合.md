# 77. 组合

[https://leetcode.cn/problems/combinations/description/](https://leetcode.cn/problems/combinations/description/)

经典的组合问题，因为每个组合限制长度为k，所以可以想象有k个箱子摆放成一排，每个箱子可以放的数的范围是1~n。但是如果第一个箱子放了数字1，那么第二个箱子放的数的范围只能是2~n，所以递归的时候还要传递一个开始遍历的索引begin。代码如下：

```java
class Solution {
    List<List<Integer>> ansLists = new ArrayList<>();
    List<Integer> statusList = new ArrayList<>();
    public List<List<Integer>> combine(int n, int k) {
        getCombine(n, k, 1);
        return ansLists;
    }

    // 未剪枝优化版本
    public void getCombine(int n, int k, int begin) {
        // 递归结束条件：当前组合长度已为k
        if(statusList.size() == k){
            ansLists.add(new ArrayList(statusList));
            return;
        }

        // for循环针对的是某一个箱子，箱子里的数的填充范围是begin ~ n
        for(int i = begin; i <= n; i++){
            statusList.add(i);
            // 递归针对的是下一个箱子，下一个箱子的填充范围是i + 1 ~ n
            getCombine(n, k, i + 1);
            statusList.remove(statusList.size() - 1);
        }
    }
}
```

总结：for循环是对某一个箱子中要填充的数的遍历，也就是这个箱子可以填什么数，由for循环控制。而for循环中的递归则是对下一个箱子的填充，下一个箱子可以填什么数，由下一个箱子的for循环控制。所以可以看到，由于函数会不断地递归，所以会一直递归到最后一个箱子，对最后一个箱子中可以填的数遍历一遍之后，再遍历倒数第二个箱子……总之由于递归，操作的方向是反的。

本题还可以通过剪枝操作来降低时间复杂度。假如n = 4，k = 3，那么第一个箱子就不可能放数字3，因为如果放了3，那么第二个箱子只能放4，这时第三个箱子就没有数字可填了，也就是说后面长度不够了，因此可以通过对剩余长度的判断来对某个箱子进行剪枝操作。**如果for循环选择的起始位置之后的元素个数已经不足我们需要的元素个数了，那么就没有必要搜索了**。代码如下：

```java
// 剪枝优化版本
    public void getCombine(int n, int k, int begin) {
        if(statusList.size() == k){
            ansLists.add(new ArrayList(statusList));
            return;
        }

        // 剪枝操作，如果剩下长度不够，那么就不用处理当前箱子及其之后的箱子了
        for(int i = begin; i <= n - (k - statusList.size()) + 1; i++){
            statusList.add(i);
            getCombine(n, k, i + 1);
            statusList.remove(statusList.size() - 1);
        }
    }
```

`k`：目标组合长度；

`statusList.size()`：当前组合长度；

`k - statusList.size()`：还需要的元素个数；

`n - (k - statusList.size()) + 1`：在集合n中至多要从该起始位置开始遍历

## 补充：排列和组合的区别

**排列** (Permutation) 和 **组合** (Combination) 最核心的区别在于：**顺序是否重要**。

简单来说：

- **排列 (Permutation)：** **讲究顺序**。先选出来，再排队。（例如：密码、名次）
- **组合 (Combination)：** **不讲究顺序**。只管选出来，不排队。（例如：打牌、组队）

| **维度** | **排列 (Permutation)** | **组合 (Combination)** |
| --- | --- | --- |
| **核心关键词** | **有序 (Ordered)** | **无序 (Unordered)** |
| **关注点** | 选出元素，并且**给它们排座次**。 | 仅仅**选出元素**，不管它们怎么站位。 |
| **判定标准** | 改变元素的顺序，**算**不同的结果。 | 改变元素的顺序，**不算**不同的结果。 |
| **符号表示** | 通常用 $P$ 或 $A$ (Arrangement) | 通常用 $C$ (Combination) |

**黄金法则：** 问自己一个问题 —— **“如果我把选出来的东西交换一下位置，它还是同一回事吗？”**

- 如果是，那是组合。
- 如果不是，那是排列。
