# 17. 电话号码的字母组合

[https://leetcode.cn/problems/letter-combinations-of-a-phone-number/](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

本题还是组合类型题目的变体，继续使用我的箱子思路解法。本题给出的`digits` 的长度即为箱子的个数，对于每个箱子可以填充3~4个字母。代码如下：

```java
public class Solution {
    // 1. 建立数字到字母的映射表（索引与数字对应）
    private static final String[] MAPPING = {
        "",     // 0
        "",     // 1
        "abc",  // 2
        "def",  // 3
        "ghi",  // 4
        "jkl",  // 5
        "mno",  // 6
        "pqrs", // 7
        "tuv",  // 8
        "wxyz"  // 9
    };

    public List<String> letterCombinations(String digits) {
        List<String> res = new ArrayList<>();
        // 边界处理：如果输入为空，直接返回空列表
        if (digits == null || digits.length() == 0) {
            return res;
        }
        
        // 开始回溯
        backtrack(res, new StringBuilder(), digits, 0);
        return res;
    }

    private void backtrack(List<String> res, StringBuilder path, String digits, int digitsIndex) {
        // 递归终止条件：当路径长度等于数字串长度时，说明找到一个完整组合
        if (digitsIndex == digits.length()) {
            res.add(path.toString());
            return;
        }

        // 获取当前数字对应的所有字母
        String letters = MAPPING[digits.charAt(digitsIndex) - '0'];
        
        for (char c : letters.toCharArray()) {
            path.append(c); // 做出选择
            backtrack(res, path, digits, digitsIndex + 1); // 递归进入下一层
            path.deleteCharAt(path.length() - 1); // 回溯：撤销选择
        }
    }
}
```

总结：

- 本题涉及到大量的拼接操作，建议尽量使用`StringBuilder` 。
- `String`：使用 `length()` 方法获取字符串长度。
- 数组：使用 `length` 属性获取数组长度。
- `List`：使用 `size()` 方法获取列表长度。
- `Integer.parseInt()` 方法期望接收一个 `String` 类型的参数，不可以接收`char` 类型，可以使用以下两种方式来将`char` 类型转换成`int`类型：
`int digit = Integer.parseInt(String.valueOf(digits.charAt(boxIndex)));`
`int digit = digits.charAt(boxIndex) - '0';`
