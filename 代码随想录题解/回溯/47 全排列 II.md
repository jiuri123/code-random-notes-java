# 47. 全排列 II

[https://leetcode.cn/problems/permutations-ii/description/](https://leetcode.cn/problems/permutations-ii/description/)

本题在上题的基础上增加了重复的元素（**提示**中没说`nums`中的所有整数 **互不相同**），因此除了多箱去重，还要增加一个单箱去重。一个简单的单箱去重方法是用一个`Set`记录当前箱子曾经使用过的元素，也就是单层去重。代码如下：

```java
// 方法一：使用Set进行单箱去重
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        boolean[] used = new boolean[nums.length];

        backTrack(nums, path, used, result);

        return result;
    }

    private void backTrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> result) {
        // 找到一个排列
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path));
            return;
        }

        // 单箱去重：使用Set记录当前箱子使用过的元素
        Set<Integer> boxSet = new HashSet<>();
        // 排列：i从0开始；组合：i从startIndex开始
        for (int i = 0; i < nums.length; i++) {
            // 跳过已使用的元素，看看之前的箱子是不是已经放了这个数
            // 避免在同一排列中重复选择某个位置的元素
            if (used[i]) {
                continue;
            }

						// 单箱去重，看看当前箱子之前有没有选过这个数
            if(boxSet.contains(nums[i])){
                continue;
            }
            
            // 选择当前元素
            path.add(nums[i]);
            // 多箱去重逻辑
            used[i] = true;
            // 记录当前箱子使用过的元素
            boxSet.add(nums[i]);
            
            // 递归
            backTrack(nums, path, used, result);
            
            // 回溯
            path.remove(path.size() - 1);
            used[i] = false;
            // 单箱去重在回到当前箱子后不需要回退
            // boxSet.remove(nums[i]);
        }
    }
}
```

注意：单箱去重在回到当前箱子后不需要回退，因为此时`for`循环可能还没有结束，也就是对当前箱子的填充还没有结束，如果回退的话相当于单箱去重无效。那什么时候会回退呢？由于 `boxSet`是临时变量，所以当函数递归返回的时候 `boxSet`会自动消失，然后进入下一层递归时才会重新创建一个新的 `boxSet`。

第二种单箱去重方法使用的则是排序法。也就是将序列进行排序后，判断当前遇到的数字与前一个数字是否相同即可。代码如下：

```java
// 方法二：使用used进行单箱去重
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        // 单箱去重的前提：排序
        Arrays.sort(nums);
        
        backTrack(nums, path, used, result);
        return result;
    }

    private void backTrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> result) {
        // 找到一个排列
        if (path.size() == nums.length) {
            result.add(new ArrayList<>(path));
            return;
        }

        for (int i = 0; i < nums.length; i++) {
            // 跳过已使用的元素，与多箱去重无关，仅仅是为了避免在同一排列中重复选择某个元素
            if (used[i]) {
                continue;
            }

            // 单箱去重方法二：used[i - 1] == false表示此时是单箱去重
            if(i > 0 && used[i - 1] == false && nums[i] == nums[i - 1]){
                continue;
            }
            // 改成used[i - 1] == true也可以通过，但是时间消耗比上面的要大
            // if(i > 0 && used[i - 1] == true && nums[i] == nums[i - 1]){
            //     continue;
            // }
            
            // 选择当前元素
            path.add(nums[i]);
            // 多箱去重逻辑
            used[i] = true;
            
            // 递归
            backTrack(nums, path, used, result);
            
            // 回溯
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

需要注意本方法去重的判断还要加上`used[i - 1] == false`这一句，为什么？

考虑这样一个序列：1, 1, 1, 2，当第一个箱子选择第一个1，第二个箱子的去重判断如果没有`used[i - 1] == false`这一句，就会出现错误，因为此时第二个1是与第一个1相同的，会执行continue从而跳过这个1。但实际上第二个1还没用过，是应该放在第二个箱子的，这是去重的判断需加上`used[i - 1] == false`这一句的第一个理由。第二个理由，考虑此时已经回溯到第二个箱子，第二个箱子将之前放的第二个1弹出，并将第二个1的used置为false。然后进入下一个for循环，此时遇到第三个1，在加上`used[i - 1] == false`这一句后，此时if条件成立，执行continue，跳过当前的第三个1，成功完成单箱去重。也就是说当`used[i - 1] == false`成立时，说明这个箱子刚刚有弹出过元素，也就是说我接下来对这个箱子的放入操作已经不是第一次的放入操作了，那么此时执行的就是单箱去重。

但是本题神奇的地方就在于将`used[i - 1] == false`改成`used[i - 1] == true`也能通过，为什么？

考虑这样一个序列：1a, 1b, 1c, 1d, 1e, 2。有5个1和1个2，稍微推导一下可以发现，`used[i - 1] == false`生成的其中一个答案是这样的：1a, 1b, 1c, 1d, 1e, 2；而`used[i - 1] == true`生成的答案是这样的：1e, 1d, 1c, 1b, 1a, 2。可以发现前四个1的顺序反过来了。因为`used[i - 1] == true` 使得每个箱子的数字不可以跟前一个箱子的数字相同，所以在我选取数字的时候可以发现如果是相同的数字排在一起，那么选取的时候就是每次隔着一个数字来选取，只有将最后一个相同的数字（这里是1e）放在第一个箱子，倒数第二个相同的数字放在第二个箱子……这样放下去才能出现正确的答案，因为此时`used[i - 1] == true`始终为false（数字是从后往前取的）。也就是说`used[i - 1] == false`是从前往后取数字，而`used[i - 1] == true`是从后往前取数字，

由此也可以看出`used[i - 1] == true`虽然也可以得到答案，但是这样非常的慢，因为你要递归到非常深的层后在回过头来慢慢找到正确答案，多了很多耗时的递归操作。而`used[i - 1] == false`只需要一次递归就可以得到一个正确的队列，所以推荐还是使用`used[i - 1] == false`，省时而且好理解。

所以本题写成`used[i - 1] == false`和`used[i - 1] == true`都可以通过，那为什么还要写这个条件呢？直接这样写不就完事了：

```
if (i > 0 && nums[i] == nums[i - 1]) {
    continue;
}
```

不行，一定要保证`used[i - 1]`一直是 `true` 或者一直是`false` 才可以，而不是 一会是`true` 一会又是`false`。也就是说你不可以一会是单箱去重，一会是多箱去重，两种去重方式混合在一起肯定是错误的。
