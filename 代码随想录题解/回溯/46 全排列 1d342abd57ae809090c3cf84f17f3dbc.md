# 46. 全排列

[https://leetcode.cn/problems/permutations/](https://leetcode.cn/problems/permutations/)

本题很明显就是单集合且所有箱子整体看待的回溯题目，但是求的是全排列，所以本题不需要index，只需要path记录所有箱子的整体排列就行。而且本题使用过的元素不可以继续使用，因此需要一个used来记录已经使用过的元素。代码如下：

```java
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        // 记录当前的路径（排列）
        List<Integer> path = new ArrayList<>();
        // 记录数组中的元素是否被使用过
        boolean[] used = new boolean[nums.length];

        backtrack(nums, path, used, res);
        
        return res;
    }

    public void backtrack(int[] nums, List<Integer> path, boolean[] used, List<List<Integer>> res) {
        // 终止条件：路径长度等于数组长度，说明找到了一个全排列
        if(path.size() == nums.length){
            res.add(new ArrayList<>(path)); // 注意要新建一个 List 存入结果
            return;
        }

        for(int i = 0; i < nums.length; i++){
            if(used[i] == false){ // 如果当前数字不在路径中
                path.add(nums[i]);
                used[i] = true;
                backtrack(nums, path, used, res); // 递归进入下一层决策树
                used[i] = false;
                path.remove(path.size() - 1);
            }
        }
    }
}
```
