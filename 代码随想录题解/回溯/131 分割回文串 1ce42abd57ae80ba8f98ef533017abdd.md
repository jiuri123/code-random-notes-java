# 131. 分割回文串

[https://leetcode.cn/problems/palindrome-partitioning/description/](https://leetcode.cn/problems/palindrome-partitioning/description/)

其实本题还是回溯问题，只不过每个箱子可以存的元素从固定长度1（数字）变成了不固定的长度（字符串），而且箱子的个数也是不固定的。

思路：对于每个箱子，每次从s中截取一个或者多个字符组成字符串，然后判断这个字符串是不是回文串，如果是的话就加入临时队列保存，然后对下一个箱子进行递归（也就是寻找下一个截取点）。但是如果这个字符串不是回文串的话，那就继续添加一个字符（也就是截取点往下移动一位），重复进行判断。代码如下：

```java
class Solution {
    List<List<String>> ansList = new ArrayList<>();
    List<String> tempList = new ArrayList<>();
    public List<List<String>> partition(String s) {
        getPartition(s, 0, 0);
        return ansList;
    }

    // tempListStrLen表示所有箱子中的字符串长度总和
    public void getPartition(String s, int tempListStrLen, int index) {
        // 如果总长度已满足要求
        if(tempListStrLen == s.length()){
            ansList.add(new ArrayList<>(tempList));
            return;
        }

        // boxString表示每一个箱子中存的字符串是什么
        String boxString = "";
        for(int i = index; i < s.length(); i++){
            boxString += String.valueOf(s.charAt(i));
            tempListStrLen++;
            // 如果不是回文串，就继续增加当前箱子的字符串长度
            // 其实也就是将分割点往后移一位
            if(!isSymmetryStr(boxString)){
                continue;
            }
            // 将新更新的字符串加入到数组中
            tempList.add(boxString);

            // 继续对下一个箱子进行递归
            getPartition(s, tempListStrLen, i + 1);

            // 将当前箱子存放的旧字符串移掉，因为下一循环要开始存新的字符串
            tempList.remove(tempList.size() - 1);
        }
    }

    // 判断是否是回文串
    public boolean isSymmetryStr(String s) {
        int strLen = s.length();
        for(int i = 0; i < strLen / 2; i++){
            if(s.charAt(i) != s.charAt(strLen - i - 1)){
                return false;
            }
        }

        return true;
    }
}
```

AI优化版本：

```java
class Solution {
    private List<List<String>> result = new ArrayList<>();
    private List<String> currentPartition = new ArrayList<>();
    
    public List<List<String>> partition(String s) {
        backtrack(s, 0);
        return result;
    }
    
    private void backtrack(String s, int startIndex) {
        // 如果起始位置已经到达字符串末尾，说明找到了一组分割方案
        if (startIndex >= s.length()) {
            result.add(new ArrayList<>(currentPartition));
            return;
        }
        
        // 尝试分割出不同长度的子串
        for (int endIndex = startIndex; endIndex < s.length(); endIndex++) {
            // 判断从startIndex到endIndex的子串是否为回文
            if (isPalindrome(s, startIndex, endIndex)) {
                // 是回文，添加到当前分割方案中
                String palindrome = s.substring(startIndex, endIndex + 1);
                currentPartition.add(palindrome);
                
                // 递归处理剩余部分
                backtrack(s, endIndex + 1);
                
                // 回溯，移除当前添加的回文子串
                currentPartition.remove(currentPartition.size() - 1);
            }
        }
    }
    
    private boolean isPalindrome(String s, int start, int end) {
        while (start < end) {
            if (s.charAt(start) != s.charAt(end)) {
                return false;
            }
            start++;
            end--;
        }
        return true;
    }
}
```

## 方法二（面试推荐）

```java
class Solution {
    List<List<String>> res = new ArrayList<>();
    List<String> path = new ArrayList<>();
    
    public List<List<String>> partition(String s) {
        int n = s.length();
        boolean[][] dp = new boolean[n][n]; // 用于存储 s[i...j] 是否为回文串
        // 由于dp数组左下角都是j < i，因此无需处理
        // 只需要处理右上角的元素即可
        // 又由于 dp[i][j] 依赖于左下角的 dp[i + 1][j - 1]
        // 所以按列遍历，而不是按行遍历（左下角还没更新）
        for(int j = 0; j < n; j++){ // 从左往右，一列一列遍历
            for(int i = 0; i <= j; i++){ // 从上往下，到达对称轴即可
                // 如果两端字符相等，且 (子串长度<=2 或 内部子串也是回文)
                if(s.charAt(i) == s.charAt(j) && (j - i <= 2 || dp[i + 1][j - 1])){
                    dp[i][j] = true;
                }
            }
        }

        // 开始回溯
        backtrack(s, 0, dp);
        return res;
    }

    public void backtrack(String s, int startIndex, boolean[][] dp) {
        if(startIndex >= s.length()){
            // 如果切割到了字符串末尾，说明找到了一组符合条件的分割方案
            res.add(new ArrayList<>(path)); // 易错点，记得 new
            return;
        }

        // startIndex 表示当前桶对字符串 s 的切割起点
        // endIndex 表示当前桶对字符串 s 的切割终点
        for(int endIndex = startIndex; endIndex < s.length(); endIndex++){
            // 利用预处理好的 DP 表，O(1) 时间判断回文
            if(dp[startIndex][endIndex] == true){
                // 是回文串，则截取并继续深搜（substring 左闭右开）
                path.add(s.substring(startIndex, endIndex + 1));
                backtrace(s, endIndex + 1, dp); // 处理下一个桶
                path.remove(path.size() - 1);
            }
        }
    }
}
```
