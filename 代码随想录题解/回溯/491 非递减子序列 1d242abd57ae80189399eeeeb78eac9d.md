# 491. 非递减子序列

![image.png](491%20%E9%9D%9E%E9%80%92%E5%87%8F%E5%AD%90%E5%BA%8F%E5%88%97/image.png)

本题就是经典的单个队列且所有箱子需要整体看待的问题，所以需要index和path，但是不需要中间变量记录每个箱子的值，因为每个箱子只能存一个元素。代码如下：

```java
class Solution {
    List<List<Integer>> ansList = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    public List<List<Integer>> findSubsequences(int[] nums) {
        if(nums.length <= 1){
            return ansList;
        }
        getSubsequences(nums, 0);
        return ansList;
    }

    public void getSubsequences(int[] nums, int index) {
        // 收集方式一
        if(path.size() > 1){
            ansList.add(new ArrayList<>(path));
        }
        // 下面的if语句可有可无
        if(index == nums.length){
            return;
        }

				// 每个箱子都会配备一个usedSet
				// 用于记录当前箱子使用过的元素
        Set<Integer> usedSet = new HashSet<>(); 
        for(int i = index; i < nums.length; i++){
            if(path.size() > 0 && nums[i] < path.get(path.size() - 1)){
                // 易错点一：
                // 不应该用break，因为队列是无序的
                // 后面还有可能出现比当前path中最后一个元素要大的
                // 应该用continue，直到找到更大的那个数
                // break;
                continue;
            }

            // 易错点二：
            // 对有序序列的去重方式，但是本题不能对原队列进行排序
            // 所以原队列无序，因而不能使用这种去重方式
            // if(i > index && nums[i] == nums[i - 1]){
            //     continue;
            // }

            // 正确的对无序序列的去重方式：使用Set记录用过的元素
            if(usedSet.contains(nums[i])){
                continue;
            }

            path.add(nums[i]);
            usedSet.add(nums[i]);
            // 收集方式二
            // if(path.size() > 1){
            //     ansList.add(new ArrayList<>(path));
            // }
            getSubsequences(nums, i + 1);
            path.remove(path.size() - 1);
        }
    }
}
```
